# WorkBuddy 教程

**WorkBuddy** 是腾讯推出的全场景职场 AI 智能体工作台。你用一句自然语言说清目标，它就能在本地电脑上自主规划步骤、读写文件，交付 PPT、表格分析、文档、调研报告等真实成果——而不是只"回答问题"。

本板块从安装到自动化，带你把 WorkBuddy 真正用起来。

## 适合谁

- **职场新手**：想用 AI 处理 Word/Excel/PPT、文件整理、资讯汇总等日常琐事
- **效率玩家**：想搭一套"人机协作"的自动化工作流
- **团队负责人**：想了解多 Agent 协作与团队落地方式
