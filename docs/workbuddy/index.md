# WorkBuddy 教程

**WorkBuddy** 是腾讯推出的全场景职场 AI 智能体工作台。你用一句自然语言说清目标，它就能在本地电脑上自主规划步骤、读写文件，交付 PPT、表格分析、文档、调研报告等真实成果——而不是只"回答问题"。

本板块按「上手 → 扩展 → 案例 → 进阶 → 速查」五组组织，从安装一路带到搭起自己的 AI 工作系统。

## 学习路线

```mermaid
flowchart LR
    A[安装登录] --> B[界面与第一个任务]

    C --> D[连接器 / IM 助理 / 自动化]
    D --> E[案例实战]
    E --> F[进阶：打造 Skill、多 Agent、可靠性]
```
