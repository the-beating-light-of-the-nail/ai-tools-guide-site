# WorkBuddy 怎么装？下载、安装、登录全流程（附截图）

想试 WorkBuddy，第一步往往最劝退：你不知道从哪下、下完不知道装哪、装完不知道该扫微信还是输手机号。

这篇把下载、安装、登录、更新四步一次走完，每一步都配了截图。你照着点就行。

## 下载：只认官方入口

你打开官方地址 [codebuddy.cn/work](https://www.codebuddy.cn/work/)，选择 WorkBuddy，点「下载 WorkBuddy」。

![官网下载入口](/workbuddy/02-install/assets/001_image_GGeabJkE2o.png)

网站会自动检查你的设备，判断该给你 Mac ARM64、Mac x64 还是 Windows x64。

![自动检测设备版本](/workbuddy/02-install/assets/002_image_HaXcbwaJXo.png)

切记：从官方入口下载，不从网盘或不明镜像获取安装包。

## Windows 安装

1. 下载完成后，你双击安装文件。

![双击安装文件](/workbuddy/02-install/assets/003_image_Ehpebt4Eso.png)

2. 系统弹出安全提示时，先核对发布者和下载来源，确认无误再继续。

![核对发布者后继续](/workbuddy/02-install/assets/004_image_LG3MbcWpvo.png)

3. 你按安装向导一路走完并启动 WorkBuddy。

![安装向导](/workbuddy/02-install/assets/005_image_CMvYbYWFOo.png)

![安装向导](/workbuddy/02-install/assets/006_image_Wujkbd9eTo.png)

![安装向导](/workbuddy/02-install/assets/007_image_V9L2bhWF2o.png)

![安装完成](/workbuddy/02-install/assets/008_image_DjcGbKYJSo.png)

4. 首次启动会进入准备运行环境，你等它跑完。

![准备运行环境](/workbuddy/02-install/assets/009_image_Q0l3bAkUPo.png)

## macOS 安装

1. 你打开安装文件，把 WorkBuddy 拖入「应用程序」。

![拖入应用程序](/workbuddy/02-install/assets/010_image_TmYPbu7Ibo.png)

![拖入应用程序](/workbuddy/02-install/assets/011_image_UlJcbVqX7o.png)

2. 你从「应用程序」里启动。别在 DMG 窗口里直接双击运行——那是个只读的临时盘，更新和设置容易出问题。

![从应用程序启动](/workbuddy/02-install/assets/012_image_LtqPbQ2z6o.png)

## 登录

1. 你点登录按钮。

![点击登录按钮](/workbuddy/02-install/assets/013_image_MMIXbZJafo.png)

2. 会自动跳转到网页登录。

![跳转到网页登录](/workbuddy/02-install/assets/014_image_MdmYbB2Avo.png)

3. 你选微信扫码登录，也可以用手机号登录。选定一种就固定下来，换着用容易找不到自己的历史任务。

![微信扫码或手机号登录](/workbuddy/02-install/assets/015_image_WZrBbbWono.png)

4. 登录完成，就能开始用 WorkBuddy 干活了。

![登录完成](/workbuddy/02-install/assets/016_image_Pmh8b7xc8o.png)

> 若公司电脑禁止安装软件，不要绕过终端安全策略，应联系 IT 管理员确认白名单或企业部署方式。

## 更新

点左下角个人中心，选择「检查更新」。有新版就按提示更新，不用卸载重装。

![检查更新](/workbuddy/02-install/assets/017_image_Qt1gbb7J3o.png)

## 常见问题

**安装包打不开，或者提示损坏？**
你先删掉安装包，从官网重新下一次，核对系统和芯片版本。还是不行，把系统版本、安装包名和报错截图留好，走官方反馈渠道。别去关系统安全功能。

**登录完没反应？**
你看三处：默认浏览器是不是拦截了登录回跳、网络代理有没有影响认证、系统时间准不准。退出应用重开一次，还不行就保留日志和截图反馈。

**读不了、写不了文件？**
你先确认任务选的工作目录对不对、系统有没有给这个目录授权、文件是不是被别的程序锁着。拿一个空白文本文件先试，别直接拿重要文件反复试错。

**更新前要备份吗？**
应用更新一般不会动你的工作文件。但长期项目还是把输入、产物、配置和自定义 Skill 纳入版本管理，或者定期备份一份。
