# 附录 A 常用指令模板

拿来即用的任务指令模板。方括号 `【】` 内替换成你的实际内容。新手建议从 A.1—A.4 开始，写法要点见[快速完成第一个任务](/workbuddy/04-first-task/)的六要素表。

## A.1 文件整理

```text
请整理当前文件夹中的文件。
按文件类型和主题分类，生成新的文件夹结构。
在执行前先给我一个整理方案，不要直接移动文件。
```

## A.2 Excel 分析

```text
请分析这个 Excel 文件。
请输出：核心指标、异常数据、趋势变化、可能原因、建议行动。
请生成一个摘要报告和图表。
```

## A.3 PPT 生成

```text
请根据这份 Word 文档生成一份 PPT 大纲。
要求：10 页左右，每页包含标题、3-4 个要点和建议图表。
风格正式，适合管理层汇报。
```

## A.4 会议纪要

```text
请整理这段会议内容。
输出：会议结论、待办事项、负责人、截止时间、风险点、未决问题。
```

## A.5 行业调研

```text
请调研【行业/公司/产品】。
输出：市场背景、主要玩家、竞品对比、趋势判断、机会点、风险点。
请附上信息来源链接。
```

## A.6 销售方案

```text
请基于客户资料生成一份售前方案。
包括：客户背景、痛点分析、推荐场景、实施路径、预期收益、演示流程。
```

## A.7 二次修改（不重写，说差异）

```text
请在上一版【文档名】基础上进行修改，不要重新生成整篇。
修改要求：【列出具体改动点】
输出修改后的 v2 版，并在 changelog.md 中列出本次修改内容。
```

## A.8 文档对比（制度 / 合同 / 方案）

```text
比较【文件A】与【文件B】。
输出新增、删除、修改和仅格式变化四类差异，附章节和原文定位。
重点标记金额、日期、责任主体、审批条件、例外和否定表达。
生成影响清单和待确认问题，不修改原文件。
```

## A.9 多表合并与对账

```text
合并【目录】中的【N】个表格。
先检查列名、数据类型、日期范围和主键，不一致时停止并列差异。
汇总前输出总行数、空值、异常值和重复数。
生成清洗后文件、异常清单和对账说明。
金额汇总必须与各源表合计对账，差异不为 0 时不生成管理结论。
```

## A.10 投资研究：公司事实底座

```text
请帮我系统梳理【公司名】的基础情况，输出结构化总结，包括：
1）核心业务与主要产品线
2）收入与利润来源构成
3）主要客户与应用场景
4）公司在产业链中的位置
5）近几年最重要的战略变化
要求：只使用可核实的信息；每一部分用 3-5 条要点说明；
不做投资建议，只做事实整理。
```

> 更完整的投资研究提示词链路（行业视角、业务拆解、多空分歧、尽调级全家桶）见[把投资分析变成日常](/workbuddy/case-investment/)。本模板仅用于辅助研究，不构成投资建议。

## A.11 多 Agent 任务 Brief

```text
目标：为【产品/项目】制作一支【时长】的【产物类型】。
风格：【参考风格】。
素材：【素材空间路径或已提供的文件】。
角色：【主理人、角色A、角色B……】
确认节点：【哪些环节完成后需用户确认再继续】。
全自动/半自动：【是否需要中间节点人工介入】。
```

## A.12 自动化任务定义

```text
任务名称：【名称】
触发方式：【每天 09:00 / 每周五 / 每月 1 日】
Prompt：【完整任务指令】
数据源：【@技能或连接器清单】
质量门禁：【有效条目 ≥ N 条；数据源可用数量 ≥ N 个】
输出格式：【结构化清单/文件】
推送目标：【飞书群 / 邮件 / 文档追加】
幂等控制：批次 ID = 【前缀】-{date}，推送成功后标记，不重复推送
重试策略：数据源超时重试 1 次；推送失败退避重试 2 次；其他失败转人工
owner：【负责人】
停用方式：WorkBuddy 自动化任务管理页 → 暂停
```
