# Qoder 是什么

Qoder 把自己定义为 **Agentic Coding Platform（智能代理编程平台）**：面向真实软件开发场景，将增强的上下文工程（Context Engineering）与智能代理（Agent）技术结合，让 AI 不只"给建议"，而是能理解你的整个项目、持续执行多步骤任务并交付可审查的成果。

## 从"补全"到"委派"

传统 AI 编程工具的交互是"你写一行，它猜一行"；Qoder 的思路是把粒度放大到**任务级**：

| | AI 补全类工具 | Qoder 的 Agent/Quest 模式 |
| --- | --- | --- |
| 交互单位 | 光标处的一行/一段 | 一个完整需求（如"给全站加暗色模式"） |
| 上下文 | 当前文件附近 | 整个项目 + 你指定的上下文 |
| 执行方式 | 逐次采纳建议 | 自主拆解、多文件修改、持续执行 |
| 你的角色 | 不断按键采纳 | 像验收者一样看进度、审 diff、提返工意见 |

当然，Qoder 也保留了轻量交互（NEXT 编辑建议、行间会话、Ask 问答），从"改一行"到"委派一个项目"都在同一个工作台里完成——详见[核心功能速览](/qoder/03-core-features)。

## 产品矩阵

Qoder 不只是一个桌面 IDE，官方文档列出的产品形态包括：

- **IDE**（主力桌面端，macOS / Windows）
- **JetBrains 插件**：装进现有 JetBrains 全家桶
- **CLI**：命令行里使用编码代理
- **Agent SDK**：把 Qoder 的代理能力集成进自己的系统
- **Cloud Agents**：云端代理，任务不占本地机器
- **移动端与网页版**：随时随地查看/推进任务
- **企业版**

> 具体各产品线的开放状态与收费策略可能随版本调整，以 [qoder.com](https://qoder.com/) 与官方文档为准。

## 和本站其他两个工具的关系

- **WorkBuddy**：办公场景的 AI 智能体工作台（文档、表格、自动化），面向职场效率
- **Trae**：字节跳动的 AI IDE，Chat/Builder/SOLO 交互体系，面向编程
- **Qoder**：智能代理编程平台，主打 Quest 长程任务委派与上下文工程

三者受众有重叠但侧重不同：办公选 WorkBuddy，编程 daily driver 可以在 Trae 和 Qoder 里按手感选，很多开发者两个都装、按任务类型切换。
