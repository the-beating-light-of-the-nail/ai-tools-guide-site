# 安装与登录

从零到打开第一个项目，5 分钟搞定。

## 1. 下载安装

前往官网下载页 **[qoder.com/download](https://qoder.com/download)**，选择对应平台（macOS / Windows）的安装包，下载后按引导安装、启动。

> 国内网络环境下如遇下载缓慢，可尝试切换网络或使用代理后重试。

## 2. 注册与登录

首次启动后登录账号，两种方式：

1. **网页注册**：点击注册，在网页端创建 Qoder 账号
2. **第三方登录**：直接使用 **Google** 或 **GitHub** 账号登录

在 IDE 内随时可以进入账号管理：点击右上角用户图标，或按 `⌘⇧,`（macOS）/ `Ctrl+Shift+,`（Windows）。

> Qoder 个人版提供免费试用，试用政策可能调整，以官网当时公示为准。

## 3. 打开第一个项目

| 操作 | macOS | Windows |
| --- | --- | --- |
| 打开本地项目 | `⌘ O` | `Ctrl O` |
| 克隆 GitHub 仓库 | 启动页选择 Clone | 同左 |

两类入口：

- **本地项目**：选一个已有文件夹直接打开。建议第一次用一个小的、结构清晰的项目（比如一个十几文件的小工具），代理理解快、你也容易验收
- **克隆仓库**：直接贴 GitHub 仓库地址，适合拿开源项目练手

## 4. 快速自检

打开项目后，按 `⌘ L`（macOS）/ `Ctrl L`（Windows）唤出右侧 Chat 面板，问一句：

```
这个项目的目录结构和技术栈是什么？
```

能给出符合项目实际的回答，说明索引和上下文都正常工作，可以进入下一课了。
