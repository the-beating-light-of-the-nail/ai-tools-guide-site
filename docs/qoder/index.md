# Qoder 教程

**Qoder** 是一款面向真实软件开发的 Agentic Coding Platform（智能代理编程平台）：不只是补全代码，而是把"上下文工程"和智能代理结合起来——你可以把一个长程任务完整委派给它，在独立视窗里看板式地跟踪进度、审查产物。

本板块为本站原创中文教程，事实以[官方文档 docs.qoder.com](https://docs.qoder.com/zh/quick-start) 为准，建议配合官方文档阅读。

## 适合谁

- 想尝试"委派长程任务给 AI"的个人开发者
- 需要在多文件、多步骤任务里保持代码质量的工程师
- 同时也在对比 Trae / Cursor 等工具的选型者
