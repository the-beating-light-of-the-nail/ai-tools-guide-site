# 進階：意識、成本與安全工作環境

三個"越用越順"的機制：讓 AI 記住你（意識）、讓 Credits 花得值（成本）、讓任務跑在隔離區（安全工作環境）。

> 官方檔案：[memory](https://docs.qoder.com/zh/qoderwork/memory) ｜ [settings](https://docs.qoder.com/zh/qoderwork/settings)

## 意識：跨會話記憶與個性化

意識（Awareness，v0.6.0 上線）是 QoderWork 的記憶與個性化系統：持續記錄你的偏好和工作習慣，讓新對話自帶完整上下文。三層機制：記憶、反思、技能自進化。

入口：左側導航「意識」圖示。兩個主開關：

- **意識模式**：總開關；
- **自動記憶**：自動維護使用者畫像與長短期記憶，定期觸發記憶反思。

進化動態面板：記憶趨勢圖（按天/周/月）、今日統計（審查次數、新增記憶、技能更新數、反思次數）、近期動態。

**意識資訊檔案對照表**（想深度定製就看這裡）：

| 條目 | 檔案/位置 |
| --- | --- |
| 儲存位置 | `~/qoderwork/awareness/main` |
| 協作風格 | SOUL.md（可選預設或自定義） |
| 工作手冊 | AGENTS.md（可直接編輯） |
| 使用者畫像 | USER.md（自動維護，不建議手改） |
| 長期記憶 | MEMORY.md（自動維護） |
| 短期記憶 | memory/ 目錄（按天對話摘要） |
| 備份與恢復 | 意識目錄可匯出/匯入（多裝置同步靠手動） |

三個**不可恢復**的危險操作：重置協作風格、重置工作手冊、清空記憶——動手前三思。

實用建議：發現 AI 犯同一個錯 → 立刻寫進規則/工作手冊，不要每次靠嘴糾正；記憶不是越多越好，定期清理過時內容——權威性來自"每條都算數"。

## Credits 成本控制

QoderWork 按 Credits 計費，與 Qoder 全家桶共享餘額（國際版：Pro $20/月=2000 Credits、Pro+ $60、Ultra $200；資源包 $20/1500；國內版有簽到、師生認證等加贈活動）。模型檔位消耗差異大（標準/高階/旗艦逐級升高），省錢打法：

1. **分步用模型**：標準檔跑通 → 旗艦檔出關鍵結論 → 標準檔格式化（切換即時生效不丟上下文）；
2. **先跑通再固化**：完整執行一次工作流了解成本，再配定時任務；
3. **任務單一主題**：無關內容新開任務，避免重放舊上下文；
4. **輸出寫明字數/格式**：減少返工輪次（社群實測：明確"300 字"比開放式輸出省一半）；
5. **技能複用**：成熟的 Skill 一次配置反覆使用，比每次重新描述省 Token。

## 安全工作環境（本地 VM 沙盒）

設定 → 高階 → 安全工作環境：在你的電腦上單獨開闢一塊**獨立空間**跑任務，檔案資料不離開裝置。清理工作環境檔案只釋放磁碟，不刪對話和產物。適合：處理敏感材料、測試來源不明的技能、跑大批次檔案操作。

配合三條底線使用：

1. 只授權必要的[工作目錄](/zh-tw/qoderwork/04-files)；
2. 第三方技能先在隔離目錄測試（它會要什麼許可權，先看清楚）；
3. 資料共享開關預設保持關閉（設定裡可選"資料不用於產品改進"的隱私模式；企業賬號該設定僅管理員可改）。

## 系統設定速查

- **通用**：語言、主題、介面風格、字型字號、開機自啟動、**保持系統喚醒**（防任務中斷，建議常開）、桌面/聲音通知、網路代理；
- **系統許可權七項**：完全磁碟訪問、錄屏錄音、輔助功能、麥克風、自動化、通知、位置服務——用到哪項開哪項；
- **快捷鍵與 QuickPick**：見[電腦操控與語音輸入](/zh-tw/qoderwork/adv-computer-use)；
- **實驗特性**：生成式 UI、彈出獨立視窗、對話列表篩選，嚐鮮可開。
