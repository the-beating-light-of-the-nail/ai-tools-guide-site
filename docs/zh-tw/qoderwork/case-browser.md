# 案例：瀏覽器自動化——20 分鐘整理 230 篇公眾號文章

瀏覽器自動化是 QoderWork 公認的強項。這一章的主案例來自一位網路工程師的完整實測，零程式碼完成過去要寫 Python 爬蟲的活。

> 改編自朱嘉盛（公眾號"網工手藝"）的實測[《阿里 QoderWork 瀏覽器自動化初體驗：20 分鐘搞定 230 餘篇公眾號文章連結》](https://zhuanlan.zhihu.com/p/2057217208250528785)（2026-07）。

## 任務背景

博主想把公眾號 200 多篇歷史文章整理成【釋出日期】【標題】【連結】三要素表格，再匯入騰訊 ima 知識庫，變成可對話的"個人知識助理"。

- 手動方案：800 多次複製貼上；
- 爬蟲方案：被公眾號後臺登入態 + 介面加密勸退；
- QoderWork 方案：接管已登入的瀏覽器頁面，零程式碼。

## 完整流程（11 步）

1. 下載安裝（Windows 選 X64 User 版），登入阿里雲賬號；
2. 單獨建工作目錄：`D:\QoderWork\公众号文章整理`；
3. 底部工具欄「管理聯結器」→ 找到「瀏覽器」→ 啟用；
4. 安裝瀏覽器擴充套件（Chrome 走應用商店；Edge 手動裝：`edge://extensions` 開發人員模式 → 把安裝目錄下的 chrome-extension 資料夾拖入）；
5. **關鍵一步**：人工用瀏覽器登入 mp.weixin.qq.com，進入"內容管理 → 發表記錄"——公眾號後臺要本人掃碼，AI 無法獨立完成身份驗證，所以讓它**接管已登入的頁面**；
6. 點瀏覽器工具欄的 QoderWork 擴充套件圖示，面板顯示"當前標籤頁 已連線"即接管成功；
7. 準備模板 Excel（序號、釋出日期、標題、連結四列）放入工作目錄；
8. 派活（提示詞全文）：

```text
請檢視【模板】網工手藝-微信公眾號發表記錄連結.xlsx 內容。
這些是從 EDGE 瀏覽器中已連線的頁面裡，點選"內容管理"→"發表記錄"獲取的，有分頁。
請參考模板檔案，把 24 個分頁中逐個釋出記錄，
按【釋出日期】【標題】【連結】整理成 excel 檔案。
```

9. 任務監控區自動拆解四步：提取 24 頁發表記錄 → 讀取模板結構 → 按模板生成 Excel → 驗證檔案；
10. 迭代兩三輪：第一輪漏了部分文章、第二輪補全、第三輪調格式——"急事得緩做，AI 做事，人校準"；
11. 匯入 ima 知識庫（每次 10 個連結，200 多篇約 20 輪），個人文章庫變成可 AI 問答的知識庫。

**結果**：238 條記錄（2021-11 至 2026-06 全部文章），標題/日期/連結一個不落，連結自動設為可點選超連結，按時間倒序排列。全程**不到 20 分鐘**（手動需要半天）。

## 技術亮點：AI 自己找到了 API

QoderWork 沒有笨拙地逐頁點"下一頁"，而是**發現發表記錄頁內嵌了結構化資料變數 `publish_page`，直接透過頁面介面一次性拉取全部記錄**——作者類比"老練的指令碼小子先 inspect 元素找 API 再批次拉資料"。這是 Agent 與"錄屏回放式 RPA"的本質區別：它看得到頁面結構，會挑效率最高的路徑。

## 同款打法：電商五店鋪日報（官方使用者案例）

跨境電商運營每天逐個登入 5 個後臺導資料，"早課"1 小時還常漏店：

```text
依次登入美/歐/日三個站點後臺，進入業務報告頁匯出昨日資料，
合併為一個 Excel：各站銷售額/訂單量/退貨率、Top 10 熱銷 SKU、
環比變化下降項標紅，最後附 200 字內運營摘要。
```

跑通後**封裝為 Skill**，以後每天一句"跑一下今天的店鋪日報"。效果：**1 小時 → 10 分鐘**；資料積累後追加 30 天趨勢分析。

## 可遷移場景

批次下載網頁資料、自動填表申報、定時抓取行情、批次截圖存檔、跨網站比價彙總——凡是你會在瀏覽器裡重複做的，都可以試著派給它，全程零程式碼。

## 三條安全提醒

1. 採集過程會讀取瀏覽器登入憑證——**勿在公共裝置操作**；
2. 匯出資料做好賬號資訊脫敏；
3. AI 爬取的資料**務必人工抽檢**（標題、日期、連結各抽幾條）。
