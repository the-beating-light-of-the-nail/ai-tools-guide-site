# 案例：資料分析與調研報告

從"十萬行表格"到"帶來源的調研 PPT"，這一章講 QoderWork 的資料類打法。

> 社群素材：CSDN[《阿里 QoderWork 最新實操指南》](https://blog.csdn.net/weixin_43107715/article/details/157585560)（2026-01/02，2.9 萬閱讀）與官方使用者案例庫。

## 場景一：十萬行 CSV 的四點指令

CSDN 實測：上傳 10634 行（另一場景為十萬行級）營業資料 CSV，一條指令完成多維分析：

```text
分析這份景區客流資料 CSV：
1. 按"景點型別"（博物館/古鎮水鄉）分組；
2. 計算總人數、男女人數、男女比例（保留 1 位小數）；
3. 產出 Excel 彙總 + 按性別分色的柱狀圖；
4. 儲存到"資料包告/202601"目錄。
```

任務監控面板自動拆成四步：讀取 → 分組計算 → 圖表生成 → 儲存。實測十萬行級資料**手動 2 小時 → 約 30 秒**。

官方同類場景（10634 行營業日報）的四維分析模板：

```text
@營業日報.xlsx 按"銷售人員"（客戶數/案件種類/總銷售額/人均）、
"月份"（趨勢/環比）、"客戶"（Top 20 貢獻度/集中度）三個維度分析，
輸出報告（表格+圖表），再分別翻譯成日文和英文版。
```

價值不在"快"，在**隨時切換分析維度**——傳統報表換個口徑要重做，這裡一句話。

## 場景二：帶來源的調研 PPT

```text
調研【戶外服飾】市場，做一份 12 頁 PPT：
- 調研維度：2025 營收與 2026 預測、Top 5 品牌份額（Patagonia、The North Face 等）、
  可持續產品佔比、線上渠道增速
- 結構：封面 → 目錄 → 市場規模 → 品牌分析 → 趨勢洞察 → 總結
- 圖表：趨勢用折線圖、份額用餅圖、對比用條形圖
- 所有資料標註來源（Statista / IBISWorld），找不到的資料標註"待核實"
```

關鍵在最後一條：**所有資料標註來源**。AI 生成的市場數字必須可溯源，否則彙報現場一個提問就翻車。生成後可繼續對話調整配色和版式。

## 場景三：萬行銷售資料的報告流水線

官方典型案例的標準四步：

```text
@sales_data.csv：
1. 說明行列數與欄位型別
2. 按類別統計銷售額與平均單價，列出 Top 10 產品
3. 按月分析趨勢
4. 生成互動式 HTML 報告（自動呼叫 Python 繪圖）
```

## 方法論：資料任務的五個習慣

1. **先讓 AI 描述資料**（欄位含義、髒資料、缺失值），確認理解一致再分析；
2. **指標口徑寫進指令**（"毛利率 = 毛利/銷售額"），別讓 AI 猜；
3. **異常值單獨列出**，不要混在彙總裡被平均掉；
4. **圖表型別你來定**（趨勢折線、佔比餅圖、對比柱狀），AI 預設選擇未必符合彙報語境；
5. **抽查三個數字**與原始檔手工核對——AI 算錯機率低但存在，彙報翻車成本高。

## 成本提示

資料類任務讀大檔案消耗 Token 較多。控制成本的打法：先用[標準檔模型](/zh-tw/qoderwork/03-first-task)跑通流程，確認中間結果正確後，最後一步再切旗艦檔出報告。更多見[意識、成本與安全環境](/zh-tw/qoderwork/adv-memory-cost)。
