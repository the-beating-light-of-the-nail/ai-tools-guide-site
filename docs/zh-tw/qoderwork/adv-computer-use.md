# 進階：電腦操控、語音輸入與應用快照

瀏覽器自動化之外，QoderWork 還能直接操控你的電腦介面、聽你說話、擷取當前應用——這是它"AI 智慧專員"人設的完整形態。

> 官方檔案：[computer-use](https://docs.qoder.com/zh/qoderwork/computer-use) ｜ [voice-input](https://docs.qoder.com/zh/qoderwork/voice-input)

## 電腦操控（Computer Use）

讓 QoderWork 完成那些必須在圖形介面裡操作的任務。四項核心能力：

- **螢幕感知**：操作過程中持續截圖，確認上一步成功再決定下一步；
- **滑鼠鍵盤控制**：點選、雙擊、拖拽、輸入、快捷鍵，精度到畫素級；
- **後臺自主執行**：不搶佔你的前臺焦點，你可以繼續幹別的；
- **跨應用流程**：根據實時反饋動態調整，而非照搬固定指令碼。

**開啟**：擴充套件 → 聯結器 →「計算機控制」卡片開啟 → 確認彈窗 → 首次授權兩項系統許可權：**輔助功能**（讀取 UI 元素樹）和**螢幕錄製**。macOS 14+ 起，Windows 自 v0.5.7 支援。

**執行透明**：每個動作走"截圖 → 操作描述 → 實際操作 → 結果確認（再次截圖核對）"四階段，全程在任務監控裡可見。

**執行策略三選**（重要）：

| 策略 | 行為 | 適合 |
| --- | --- | --- |
| 每次詢問（預設） | 每次操控先確認 | 不可逆操作（發郵件、提交訂單） |
| 自動執行 | 連續執行不詢問 | 熟悉的重複流程 |
| 禁用 | 關閉操控 | 只想用其他能力時 |

實測示例（阿里工程師徐靖峰）：

```text
從杭州去三亞旅遊，幫我去飛豬攜程搜尋機票比價，然後幫我制定一個旅行攻略，
生成一個 PDF，並且把日程加到 Mac 自帶的日曆裡。
```

產出：三亞攻略 PDF + 含詳細時間安排的日曆日程。

**限制與注意**：

- CAPTCHA、簡訊驗證碼、人臉識別無法完成，需要你手動介入；
- 速度慢於純對話（每步都要截圖分析）；介面複雜時精度下降；
- 授予訪問許可權 = 授予操控許可權——AI 可以"以你的身份"驅動其他應用；
- 執行前關閉含密碼的視窗；操控期間不要手動搶被控應用；
- 官方建議：**網頁任務優先用瀏覽器自動化，比電腦操控更快更精準**。

## 語音輸入：按住 Fn 說話

預設**按住 Fn 鍵即錄音**，無需點圖示（備用入口：輸入框右側麥克風圖示）。五步：按住 → 說需求（無嚴格時長限制）→ 自動轉錄顯示在輸入框 → 按需編輯 → 傳送。

- 依賴作業系統內建語音識別引擎，語種取決於已裝語言包；需麥克風許可權；
- 使用策略："**語音起草、鍵盤修正**"；
- v0.6.2 起實時轉寫；v0.6.6 語音快捷鍵自動傳送；v0.7.1 聲紋隔離（嘈雜環境只保留你的聲音）；
- 配合玩法：語音 + 附件（附 PDF 後說"總結要點列出待辦"）；交付後口頭追加（"標題再大一些"）。

## 應用快照（Beta）

從"看到問題"到"開始提問"只要一步：同時按下左右兩個 Option 鍵（可自定義全域性快捷鍵），捕獲**最前方應用的截圖與可讀文字**作為對話上下文——螢幕上有個報錯想問 AI？一個快捷鍵搞定。需 macOS 輔助功能 + 螢幕錄製許可權（授權一次即可）。

## 快捷鍵速查（macOS / Windows）

| 功能 | macOS | Windows |
| --- | --- | --- |
| 開啟設定 | ⌘, | Ctrl+, |
| 建立新任務 | ⌘N | Ctrl+N |
| 搜尋全部任務 | ⌘G | Ctrl+G |
| 當前任務中搜尋 | ⌘F | Ctrl+F |
| 傳送訊息 | ↵ 或 ⌘↵ | Enter |
| 插入換行 | ⇧↵ | Shift+Enter |
| 快速切換任務 | ⌃Tab | Ctrl+Tab |

另有 **QuickPick**：全域性快速任務視窗（如 ⌥Space 或雙擊修飾鍵觸發），不切主視窗隨時提交任務。
