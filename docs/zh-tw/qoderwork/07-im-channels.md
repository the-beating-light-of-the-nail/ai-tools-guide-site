# IM 頻道：聊天窗裡遠端指揮

開啟 IM 頻道，QoderWork 就接入你常用的聊天工具。核心原則官方一句話說清：**"哪裡來的，回哪裡去"**——IM 裡發的訊息，結果回傳到同一個聊天視窗；桌面端建立的任務結果留在桌面端，不會推送 IM。

> 官方檔案：[docs.qoder.com/zh/qoderwork/im-channels](https://docs.qoder.com/zh/qoderwork/im-channels)

## 七個平臺的接入方式

| 平臺 | 接入方式 |
| --- | --- |
| **釘釘** | 掃碼完成應用註冊和繫結（二維碼過期可重新整理） |
| **飛書 / Lark** | 掃碼自動建立應用並配置許可權與事件回撥 |
| **微信** | 掃碼授權，"即開即用" |
| **企業微信** | 快捷繫結（掃碼推薦）或手動配置（管理後臺建機器人，填 Bot ID 和 Secret） |
| **Slack** | 填 Bot Token（xoxb- 開頭）+ App-Level Token（xapp- 開頭）→ 測試連線 |
| **WhatsApp** | 手機掃碼繫結 |

## 准入策略：開放還是配對

- **開放模式**：所有人和群都能直接對話；
- **配對模式**：經你允許後會話才能用（以會話為單位：私聊允許後該使用者可對話；群聊允許後群內所有成員可對話）。

個人使用建議預設配對模式——避免機器人被同事隨意呼叫消耗你的 Credits。

## 桌面端仍是管控中心

所有 IM 會話在桌面端對映為**獨立會話視窗，上下文完全隔離**。在桌面端你可以：檢視進度、接管操作、調整 MCP/Skill/聯結器配置（對所有 IM 會話生效）。

## /bind：把訊息路由到指定任務

IM 裡可直接下指令管理任務繫結：

```text
/bind          檢視可繫結的任務列表
/bind 2        繫結編號為 2 的任務
/unbind        解除繫結
```

繫結後，IM 訊息直接轉發至該任務，回覆實時同步回 IM。前置條件：已開通 IM 頻道 + 桌面端存在該任務。訊息順序有保證：連續傳送多條時按順序依次處理，不丟訊息、不亂序。

## 支援的訊息型別

文字、圖片（OCR、背景替換）、檔案（PDF/Excel/PPT/Word/CSV/TXT 等）、語音（自動識別）、合併轉發訊息、圖片+文字組合——把合同照片、報銷發票直接丟進聊天窗就能處理。

## 五個典型場景

| 場景 | 打法 |
| --- | --- |
| 移動端輕量對話 | 通勤時發"查一下上季度華東區報價單的關鍵數字" |
| 圖片檔案處理 | 拍下合同/票據發過去："提取關鍵條款/金額，彙總成表" |
| 遠端派活 | 手機指揮家裡電腦執行長任務並回傳產物 |
| 定時結果推送 | 定時任務生成日報 → 每早 9 點自動推送到釘釘群（配合[定時任務](/zh-tw/qoderwork/08-automation)） |
| 群聊協作 | @機器人"總結今天群裡討論的要點和待辦" |

## 注意事項

- 釘釘群的「歸屬組織」需與建立機器人的組織一致；
- 從開放模式切回配對模式後，之前未配過的使用者需重新配對；
- 「移除配置」會清除全部資訊；
- 多個頻道可同時開啟、完全獨立，上下文不互通。
