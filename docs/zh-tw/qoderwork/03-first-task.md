# 第一次怎麼派活給 QoderWork？描述完等它交檔案，三步跑通

你盯著輸入框，遊標一閃一閃。材料你其實都有——一份銷售資料表、幾份散落的檔案——可你就是不知道第一句該寫什麼。複製進聊天框自己寫？那又繞回老路了，AI 替的活最後還是你幹。

這一章把 QoderWork 的使用迴圈講透：你描述任務 → 盯著它執行 → 收下產物。跑完第一單，你就明白它和聊天機器人差在哪。

## 建任務的五步

你新建一個任務，照這五步走：

1. 描述任務：提示詞要「面向結果」——直接說「要拿到什麼」，而不是「按什麼步驟做」；
2. 選工作臺：輸入框左下角，預設「通用」（另有設計 / 幻燈片 / 寫作三個垂類工作臺，見[三大工作臺](/zh-tw/qoderwork/adv-workbenches)）；
3. 選模型：右下角模型選擇器（下節細說）；
4. 選工作目錄（可選）：讓 AI 直接讀寫某個本地資料夾，見[工作資料夾](/zh-tw/qoderwork/04-files)；
5. 傳送。

一個適合你第一次跑的任務，把下面這段直接粘進去，改改檔名就能發：

```text
分析我上傳的銷售資料.csv：說明欄位含義，按品類統計銷售額並排名，
生成一份 Excel 彙總表和 3 條結論。
要求：數字與原始檔一致，無法確認的標註待核實。
```

## 給任務加料的三個入口

你描述得再清楚，也不如把材料直接掛上去。三個入口這麼用：

| 入口 | 用法 | 適合 |
| --- | --- | --- |
| + 按鈕 | 從選單新增：專家套件、技能、連接器、檔案 | 上傳附件、掛能力 |
| @ 引用 | 輸入 @ 引用已有物件：套件、歷史任務、定時任務、檔案 | 關聯已有內容 |
| / 呼叫 | 輸入 / 呼叫技能與指令（xlsx、pptx、pdf、find-skills 等） | 精確點名 |

官方最佳實踐原話：“附上正確引用與附件的任務，幾乎總是比一大段文字描述表現更好。”所以你手上有檔案，優先 @ 或 + 掛上去。

## 模型怎麼選

你選模型時看這張表，日常別糾結：

| 檔位 | 適合 | 消耗 |
| --- | --- | --- |
| 旗艦 | 複雜推理、容錯低的關鍵報告、跨多檔案分析 | 最高 |
| 高階 | 強勁均衡的重點專案 | 較高 |
| 標準 | 日常任務，速度與質量平衡——絕大多數場景夠用 | 中 |
| Qwen3.7-Max / Plus | 通義千問系列：Max 進階推理，Plus 日常又快又省 | 各異 |

兩個關鍵機制你得知道：

- 隨時切換、立即生效：同一個任務執行中你也能換模型，不丟上下文。官方示例打法是：標準檔收資料 → 旗艦檔深度分析 → 標準檔格式化輸出；
- 餘額不足時：你買 Credits，或者切到高階 / 標準檔降耗。

## 盯著它幹：任務監控面板

你派完活，進度在工作區右邊，分三個小面板：

- 待辦計劃：AI 拆出來的執行步驟，跟著進度一個個勾；
- 產物：任務輸出的檔案卡片，點一下就能在系統裡開啟；
- Skills & MCP：這輪用到的技能和連接器——全程透明，你能看見。

**中途追加指令**：任務跑著的時候你發的訊息會排隊，等當前這輪結束接著執行（上下文完整保留）；任務結束後再發，就立即執行。不滿意直接說：“按價格從低到高排序”“第三條的結論依據是什麼”。

## 任務的邊界，別踩

你建任務時記住幾條邊界：

- 一個任務 = 一次獨立的 AI 工作會話，有自己的對話、上下文、監控和產物，兩個任務之間互不共享資料；
- 相關迭代（初稿 → 修改 → 定稿）留在同一任務裡；不相干的事新開任務——上下文乾淨，也不浪費 Credits 重放舊對話；
- 所有任務（含沒傳送的草稿）自動儲存；任務列表按「最近」排，能搜尋、分組、置頂、匯出成 Markdown、歸檔（歸檔能恢復，優先歸檔而不是刪除）。

## 提示詞三要素

你寫任務前，過一遍這張骨架：

| 要素 | 回答什麼 | 示例 |
| --- | --- | --- |
| 目標 | 交付物是什麼 | “一份 Excel 彙總表” |
| 格式 | 輸出成什麼 | “輸出為 .xlsx，含圖表” |
| 約束 | 必須包含 / 避免什麼 | “不虛構資料；金額保留兩位小數” |

更多模板見[常用指令模板](/zh-tw/qoderwork/ref-templates)，提示詞方法論的完整版（六項進階技巧 + 五大誤區）見[場景速查](/zh-tw/qoderwork/ref-scenarios)的引用。

## 新手常見問題

**第一句到底該寫什麼？**
別寫「你能做什麼」這種開場。你直接寫結果：要什麼檔案、什麼格式、什麼不能碰。上面那段銷售資料提示詞，改改檔名就能直接發。

**模型選哪個不浪費？**
絕大多數場景標準檔夠用。你等活特別複雜、要跨多檔案推理，再上高階或旗艦。同一任務裡還能中途換檔，不丟上下文。

**它可以同時幫我做兩件不相干的事嗎？**
不建議。兩個任務互不共享資料，你最好一事一任務，上下文乾淨，也省 Credits。

**中途發現它跑偏了怎麼辦？**
直接發訊息追一句指令，會排進佇列等這輪結束接著跑。你說“按價格從低到高排序”，它就照做。

**草稿沒傳送會丟嗎？**
不會。所有任務含未傳送草稿都自動儲存，按最近排列，還能歸檔（歸檔能恢復）。
