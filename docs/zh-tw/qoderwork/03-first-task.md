# 第一個任務：從描述到產物

QoderWork 的使用迴圈只有三步：**描述任務 → 監控執行 → 收取產物**。這一章把每一步的細節和官方最佳實踐講清。

## 建立任務的五步

1. **描述任務**：提示詞要"面向結果"——直接說"要拿到什麼"，而不是"按什麼步驟做"；
2. **選擇工作臺**：輸入框左下角，預設「通用」（另有設計/幻燈片/寫作三個垂類工作臺，見[三大工作臺](/zh-tw/qoderwork/adv-workbenches)）；
3. **選擇模型**：右下角模型選擇器（見下節）；
4. **選擇工作目錄**（可選）：讓 AI 直接讀寫某個本地資料夾，見[工作資料夾](/zh-tw/qoderwork/04-files)；
5. 傳送。

一個適合第一次跑的任務：

```text
分析我上傳的銷售資料.csv：說明欄位含義，按品類統計銷售額並排名，
生成一份 Excel 彙總表和 3 條結論。
要求：數字與原始檔一致，無法確認的標註待核實。
```

## 豐富上下文的三個入口

| 入口 | 用法 | 適合 |
| --- | --- | --- |
| **+ 按鈕** | 從選單新增：專家套件、技能、聯結器、檔案 | 上傳附件、掛能力 |
| **@ 引用** | 輸入 @ 引用已有物件：套件、歷史任務、定時任務、檔案 | 關聯已有內容 |
| **/ 呼叫** | 輸入 / 呼叫技能與指令（xlsx、pptx、pdf、find-skills 等） | 精確點名 |

官方最佳實踐原話："**附上正確引用與附件的任務，幾乎總是比一大段文字描述表現更好。**"

## 模型怎麼選

| 檔位 | 適合 | 消耗 |
| --- | --- | --- |
| 旗艦 | 複雜推理、容錯低的關鍵報告、跨多檔案分析 | 最高 |
| 高階 | 強勁均衡的重點專案 | 較高 |
| 標準 | 日常任務，速度與質量平衡——**絕大多數場景夠用** | 中 |
| Qwen3.7-Max / Plus | 通義千問系列：Max 進階推理，Plus 日常又快又省 | 各異 |

兩個關鍵機制：

- **隨時切換、立即生效**：同一任務執行中可以換模型，不丟上下文。官方示例打法：標準檔收資料 → 旗艦檔深度分析 → 標準檔格式化輸出；
- 餘額不足時：購買 Credits，或切高階/標準檔降耗。

## 觀察執行：任務監控面板

任務監控在工作區右側，包含三個子面板：

- **待辦計劃**：AI 拆解出的執行步驟，隨進度勾選；
- **產物**：任務輸出的檔案卡片，點選可在系統中開啟；
- **Skills & MCP**：本輪用到的技能和聯結器——全程透明。

**中途追加指令**：任務執行中發的訊息會排入佇列，等當前這輪結束後接著執行（保留完整上下文）；任務結束後傳送的立即執行。不滿意直接說："按價格從低到高排序""第三條的結論依據是什麼"。

## 任務的邊界

- 一個任務 = 一次獨立的 AI 工作會話，有自己的對話、上下文、監控和產物，**兩個任務之間互不共享資料**；
- 相關迭代（初稿→修改→定稿）留在同一任務裡；無關的事新開任務——乾淨上下文，也不浪費 Credits 重放舊對話；
- 所有任務（含未傳送的草稿）自動儲存；任務列表按"最近"排列，可搜尋、分組、置頂、匯出為 Markdown、歸檔（歸檔可恢復，優先歸檔而不是刪除）。

## 提示詞三要素

官方總結的提示詞骨架，寫任務前過一遍：

| 要素 | 回答什麼 | 示例 |
| --- | --- | --- |
| 目標 | 交付物是什麼 | "一份 Excel 彙總表" |
| 格式 | 輸出成什麼 | "輸出為 .xlsx，含圖表" |
| 約束 | 必須包含/避免什麼 | "不虛構資料；金額保留兩位小數" |

更多模板見[常用指令模板](/zh-tw/qoderwork/ref-templates)，提示詞方法論的完整版（六項進階技巧 + 五大誤區）見[場景速查](/zh-tw/qoderwork/ref-scenarios)的引用。
