# QoderWork 三大工作臺怎麼選？設計、幻燈片、寫作一次講清

你做海報、做簡報 PPT、寫長文，每次都從空白檔案開始，憋半天。通用工作臺能幹活，但這類高頻產出 QoderWork 單獨建了垂直工作臺：設計畫布、16:9 幻燈片、長文寫作。切換入口在輸入框左下角的工作臺選擇器，你按產出型別挑一個就行。

> 官方檔案：docs.qoder.com/zh/qoderwork 下的 design / slides / writing 三頁。

## 設計工作臺：AI 原生的"設計即程式碼"畫布

你用自然語言描述，在無限畫布上獲得可執行、可編輯、可交付的設計產物；你做出的產物是程式碼資產，可一鍵「交付給 Qoder」（IDE）繼續開發。

你切換工作臺後，八步跑完：描述需求（你截圖和連結可直接貼上）→ 可選設定（風格參考 / 工作目錄 / 保真度 / 元件庫）→ 選執行模式（「直接執行」跳過澄清；「進入設計計劃模式」先對齊）→ 回答澄清問題（每題有備選項，可"AI 自行決定"）→ 你確認設計計劃（稽核"契約"面板：產物/平臺/輸出/元件庫/保真度/風格）→ 觀察生成（左側"深度思考"即時推理）→ 預覽（可點 CTA、看 hover、走查導航流）。

你挑風格、保真度、元件庫，看這張表：

| 設定 | 可選值 |
| --- | --- |
| 風格參考 | 自動選擇（161 個參考裡挑）或指定 Airbnb / Apple / Carbon / Ant Design 等 |
| 保真度 | 線框圖 / 高保真（預設） |
| 元件庫 | 不指定（HTML-first）/ shadcn/ui / Spark Design / Ant Design |

迭代三板斧：你追加指令；Nudge 微調（配色、間距、圓角引數，無需重新描述）；你直接編輯畫布背後的設計檔案原始碼。三大機制（Questions 追問、Design Plan、Nudge）解決的是"AI 猜錯方向"的老問題——資訊不足時先追問，而不是猜。

## 幻燈片工作臺：先大綱後成片

你做簡報、課件、路演，用幻燈片工作臺：右側畫布是 16:9、1280×720 的 HTML 幻燈片工作區。硬性前置：你必須先確認大綱——「大綱」標籤裡每節帶一句簡介和版式標籤（封面頁/文字大綱/左圖右文/雙欄/引文等），"接受大綱"才開始生成，不合適可附反饋駁回。

你切換工作臺，描述需求，挑模版（可"不使用模版"，內建 35 個）→ 回答澄清（受眾、頁數、語言）→ 確認大綱 → 看生成過程（縮圖逐張就緒）→ 後處理選項（可全跳過）→ 檢視成果。

你匯出可選 PPTX、PDF、HTML 三格式；常用模版可"儲存為模版"複用。

官方給你的建議：好的需求往往同時點出受眾和想讓對方記住什麼，而不僅僅是主題。

## 寫作工作臺：長文的版本化管理

你寫長文、報告、推文，用寫作工作臺：面向文章、報告、推文、技術指南、內部檔案。Document 工作區 = Markdown 檔案樹 + 編輯器；產物落到本地 `outputs/` 目錄；每一輪迭代都保留為可回溯的版本（編輯器右上角可切"最新版本/早期版本"，可匯出 PDF）。

你選語氣：不指定（AI 自行判斷）/ 正式 / 輕鬆 / 技術 / 創意。

你常見的五種寫法，官方給了模板：

| 場景 | 輸入 → 輸出 |
| --- | --- |
| 零散筆記 → 技術指南 | 散記資料夾 → 結構化指南 |
| 無責內部故障復盤 | 對話/日誌 → 復盤檔案 |
| PR 列表 → 釋出說明 | git 記錄 → 按 Features/Improvements/Fixes 分組 |
| 技術部落格 | 主題+字數結構 → 成稿 |
| API 規範 → 整合指南 | 介面檔案 → 鑑權、cURL 示例、錯誤碼錶、FAQ |

注意：你手動編輯後，AI 後續輪次會基於你的修改繼續——人改稿不會被 AI 覆蓋。

## 怎麼選

你按產出型別選，看這張表：

| 需求 | 工作臺 |
| --- | --- |
| 檔案、資料、調研、自動化 | 通用 |
| 海報、落地頁、UI 原型 | 設計 |
| 彙報、課件、路演 | 幻燈片 |
| 文章、報告、指南 | 寫作 |

> 對比視角：TraeWork 的做法是用 Design 模式 + HTML 產物覆蓋設計場景（見[做一套能上臺的 PPT](/zh-tw/traework/case-ppt)），QoderWork 的垂類工作臺更"開箱即用"——兩種路線你按手感選。

## 常見問題

**做 PPT 必須先確認大綱嗎？**
必須。你先在「大綱」標籤裡審每節的版式和簡介，接受後才生成；不滿意附反饋駁回，比生成完再大改省事。

**設計產物能繼續改程式碼嗎？**
能。產物是程式碼資產，你一鍵「交付給 Qoder」進 IDE 接著開發，不卡在畫布裡。

**長文寫到一半我手改了，會被覆蓋嗎？**
不會。AI 後續輪次基於你的修改繼續，你改的稿子它不動。

**三個工作臺怎麼挑？**
你按產出型別選：檔案資料用通用，海報原型用設計，彙報路演用幻燈片，文章報告用寫作。

**幻燈片能不用模版嗎？**
你能選「不使用模版」，內建 35 個模版也能「儲存為模版」複用，按你的習慣來。

**寫作的版本能回退嗎？**
你能切「最新版本 / 早期版本」，每輪迭代都留檔，改歪了隨時退回上一版。
