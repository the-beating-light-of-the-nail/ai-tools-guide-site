# 連接器與 MCP 怎麼接？讓 AI 替你操作瀏覽器和釘釘，不用你守著

你想要的從來不是「讓它回答一個問題」，而是「讓它去釘釘發個訊息」「讓它把網頁裡的表格搬下來」。QoderWork 的連接器乾的就是這個——它是你電腦和外部系統之間的橋。開啟後，AI 能像你一樣操作瀏覽器、讀寫系統日曆和郵件、對接 Microsoft 365 和釘釘。MCP 則是接更多外部工具的開放協議。

> 官方檔案：[connectors](https://docs.qoder.com/zh/qoderwork/connectors) ｜ [釘釘 MCP 實戰](https://docs.qoder.com/zh/qoderwork/mcp-walkthrough)

## 連接器總覽

你從這裡進統一入口：左側導航 → 擴充套件 → 連接器，有「市場」和「已安裝」兩個選項卡。預設全部關閉，只有你明確完成授權與配置，QoderWork 才拿到相應權限。

| 類別 | 連接器 |
| --- | --- |
| 內建 | **瀏覽器**（網頁操作、資料提取、表單填寫）、**macOS 應用**（提醒事項、日曆、備忘錄、郵件、通訊錄）、**Microsoft 365**（Outlook / 日曆 / 聯絡人 / To Do / OneNote / OneDrive） |
| 整合市場 | 釘釘、飛書、Notion、Linear、Todoist、Canva、Supabase、Vercel、Neon、Slack、Figma、Google 日曆、Google 地圖、LINE、企查查等 |

## 接入步驟（三個高頻的）

瀏覽器連接器（QoderWork 的招牌能力）：你在連接器頁找「瀏覽器」點 + →「在 Chrome 應用商店中安裝」擴充套件 → 狀態顯示「擴充套件已連線」。它複用你真實的瀏覽器登入態——後臺導資料、填表單都不用你重新登入。

**Microsoft 365**：點「連線微軟賬戶」→ 瀏覽器彈窗登入 → 確認授權。

釘釘：「市場」選項卡 → 釘釘卡片 →「登入釘釘賬號」完成授權。

⚠️ 關鍵限制：你開關連接器後，需要新建一個對話任務才能生效——別在原來的對話裡追問「怎麼沒反應」。

## MCP：AI 世界的 USB 介面

MCP（Model Context Protocol）是標準化 AI 應用接外部工具的開放協議。你從連接器頁右上角「+ 新增」進，兩種方式：

1. **貼上 JSON 配置**匯入（推薦）；
2. 手動填寫。

兩種伺服器型別：Streamable HTTP / SSE（遠端託管，URL 訪問，推薦前者）；**STDIO**（本地命令列啟動，需 Node.js / Python）。JSON 結構示例：

```json
{
  "mcpServers": {
    "钉钉文档": {
      "type": "streamable-http",
      "url": "https://mcp-gw.dingtalk.com/mserver/...key=..."
    }
  }
}
```

## 實戰：接入釘釘 MCP（四步）

釘釘有自己的 MCP 市場，適合你已用釘釘協作的團隊：

1. 開啟 [mcp.dingtalk.com](https://mcp.dingtalk.com) 並登入，按關鍵詞搜尋（帶「平臺精選」標籤的是官方推薦）；
2. 在 MCP 詳情頁右側「使用 MCP」區域，複製 JSON Config；
3. QoderWork 連接器頁「+ 新增」→ 貼上 JSON →「通過 JSON 匯入」（釘釘 MCP 一般無需額外 Headers，留空即可）；
4. 驗證：服務名稱左側顯示綠色圓點即連線成功，然後你在對話裡直接試：

```text
幫我找一下名為《2026 Q3 營銷計劃》的檔案
幫我查一下北京的天氣（高德地圖 MCP）
幫我建立一個明天上午 10 點的日程（釘釘日曆 MCP）
```

常用釘釘 MCP：釘釘檔案、釘釘日曆、釘釘通訊錄、釘釘待辦、釘釘群聊、高德地圖、釘釘 AI 表格。

## 注意事項與故障排查

- 瀏覽器連接器僅支援 Chromium 核心（Safari / Firefox 暫不支援）；任務執行期間你別手動去碰被託管的標籤頁；
- macOS 應用首次開啟會彈系統權限，你誤拒了就去「系統設定 → 隱私與安全性」手動放行；
- 驗證碼、簡訊驗證、掃碼登入需要你人工接管；
- MCP 連不上你按順序查：JSON / URL 完整性 → 網路 → 額外授權要求 → 刪除重加。

**最佳實踐**：你直接在 Prompt 裡給 URL；連接器與本地檔案讀寫結合著用；複雜流程你先手動跑通，再固化為 Skill 或定時任務。

> MCP 的通用原理與安全邊界（它和 API 的關係、「怎麼連」與「連了安不安全」），見 WorkBuddy 板塊的[看懂 AI 工作系統](/zh-tw/workbuddy/11-ai-work-system/)。

## 新手常見問題

連接器預設是開著的嗎？
不是。預設全部關閉，只有你明確授權並配置後，QoderWork 才拿到權限。你沒開的，它碰不到。

我開了連接器，為什麼對話裡沒反應？
你開關連接器後，得新建一個對話任務才生效。在原來的對話裡追問是沒反應的，新開一單就好。

**瀏覽器連接器支援所有瀏覽器嗎？**
只支援 Chromium 核心，也就是 Chrome、Edge 這類。Safari 和 Firefox 暫時接不上。

MCP 連不上先查什麼？
你按順序查：JSON / URL 完不完整、網路通不通、有沒有額外授權要求，最後才刪除重加。

**釘釘 MCP 怎麼判斷連成功了？**
服務名稱左側顯示綠色圓點就是連上了。你直接在對話裡發一句“找一下某檔案”試一下就知道。
