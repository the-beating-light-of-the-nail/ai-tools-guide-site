# 定時任務：到點自己幹

官方定位一句話："定時任務讓 QoderWork 從「你問它才動」變成「到點自己幹」。"

> 官方檔案：[docs.qoder.com/zh/qoderwork/scheduled-tasks](https://docs.qoder.com/zh/qoderwork/scheduled-tasks)

## 執行模型

到了預定時間 → 自動新建一個對話任務 → 按你寫好的 Prompt 執行 → 結果儲存在該對話中。定時任務可以呼叫 MCP 工具、使用聯結器（瀏覽器自動化、macOS 原生應用）、執行技能、讀寫本地檔案——**凡是手動任務能用的能力，定時任務都能用**。

## 兩種建立方式

**方式一：對話中自然語言建立**（推薦）

直接在對話裡說時間 + 任務，AI 自動推斷執行頻率、時間和內容，無需 cron 表示式。這些說法都能識別：

```text
每隔 3 小時……
每個月最後一個工作日……
每週二和週四下午 2 點……
```

**方式二：面板手動建立**

左側導航「定時任務」→ 右上角「+ 新建定時任務」→ 填寫 → 儲存即生效。

## 計劃時間六種

| 頻率 | 適合 |
| --- | --- |
| 不重複（指定日期時間執行一次） | 會議準備、截止檢查、定時傳送 |
| 間隔（每 N 小時/天） | 價格監控、進度輪詢 |
| 每小時 | 監控告警、服務巡檢 |
| 每天 | 每日早報、資料包表 |
| 每週 | 週報草稿、競品追蹤 |
| 每月 | 月度分析、賬單彙總 |

其他配置：任務名稱、任務 Prompt、工作目錄（可選，建議指定以獲得固定上下文）、附件（可選）。

## 管理與除錯

- 卡片左上角開關啟停；
- 「...」選單：**立即執行**（除錯或補執行）/ 刪除 / 編輯；
- 執行記錄狀態：成功 / 執行中 / 失敗。

## 必須知道的限制

1. **由本地桌面客戶端排程**：執行時間以你電腦系統時區為準；**電腦睡眠或關機無法觸發**——重要任務開啟「保持系統喚醒」（定時任務頁右上角有此開關）；
2. **錯過的任務不會自動補執行**，需在執行記錄中「立即執行」手動補；
3. 每次執行建立獨立對話，**與手動對話一樣消耗 Credits**；
4. 瀏覽器自動化任務前置：聯結器已開瀏覽器且 Chrome 保持執行；目標網站登入過期會導致失敗。

## 定時任務 Prompt 寫作清單

無人值守的對話，提示詞越細越穩：

- [ ] 資料來源寫明確（哪個檔案/哪個網頁/哪個系統）
- [ ] 輸出格式與儲存位置寫明確（"輸出 Markdown 存到 reports/ 目錄"）
- [ ] 判斷標準寫明確（"環比跌幅超過 20% 標紅"）
- [ ] 異常處理寫明確（"資料為空時輸出說明，不要硬湊"）
- [ ] **先手動跑通一次，調好 Prompt 再固化**

一個完整模板：

```text
任務名稱：每日運營早報
時間：每個工作日早上 9:00
Prompt：讀取 data/ 目錄下昨日的運營資料檔案，生成早報：
1. 核心指標彙總（銷售額、訂單量、退款率），附環比
2. 環比波動超過 ±20% 的指標標黃並給出可能原因（資料裡找不到原因就標註待核實）
3. 輸出 Markdown 存到 reports/{日期}-早報.md，同時推送到釘釘「運營群」
```

推送 IM 需要[IM 頻道](/zh-tw/qoderwork/07-im-channels)已配置——定時任務 + IM 是 QoderWork 自動化的黃金組合。

進階玩法（把"跑一下"變成一句話觸發）見[電商日報案例](/zh-tw/qoderwork/case-browser)與[對話式建立技能](/zh-tw/qoderwork/adv-skill-create)。
