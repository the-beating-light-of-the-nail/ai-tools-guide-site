# 技能與專家套件

技能（Skill）是"一份提前寫好的工作指南"；專家套件（Expert Kit）是把一個崗位的專業知識、工作流和判斷標準整體打包。兩者是 QoderWork 生態裡"從會用到專業"的兩級臺階。

> 官方檔案：[skills](https://docs.qoder.com/zh/qoderwork/skills) ｜ [expert-kits](https://docs.qoder.com/zh/qoderwork/expert-kits)

## 技能：AI 的"專業能力說明書"

每個 Skill 本質是一個包含 SKILL.md 檔案的資料夾，存於 `~/.qoderwork/skills/`。SKILL.md 用自然語言寫，無需程式碼，寫清"面對某類任務時遵循的步驟、輸出格式和注意細節"。

四大價值：告別重複解釋、保證輸出一致性、個人經驗變成可複用資產、讓 AI 從"通才"變"專才"。

**獲取的四個渠道**：

1. **對話中搜尋安裝**：直接說"幫我找一個做 XX 的技能"，內建 find-skills 檢索推薦，一鍵安裝；
2. **Skill 廣場瀏覽**：擴充套件 → 技能，市場裡挑；
3. **從開源社群獲取**：發一個 GitHub 倉庫連結，自動克隆、放置、載入；
4. **手動上傳**：技能頁點「安裝技能」上傳 SKILL.md 檔案。

**使用的四種方式**：自動觸發（描述需求自動匹配）、`/` 快捷呼叫、`@` 新增上下文（注意：@ 是補充上下文，不是呼叫）、對話中點名（"使用 xxx 技能生成組圖"）。

**內建技能 9 個**：docx / pdf / pptx / xlsx（提到對應檔案型別自動觸發）、find-skills、create-skill、plugin-creator、install-skill-dependency、vm-error-recovery。

**分享**：技能頁點個人技能旁的分享圖示 → 複製連結 → 對方一鍵安裝。注意：**分享連結有效期約 24 小時**，且只能分享自己建立的技能。

## 專家套件：把"懂行"打包給團隊

官方定位："讓 AI 變成一個真正懂行的專業人士。"套件 = Skill + 資料連線 + 工作流 + 輸出標準的整合包——解決的不是"AI 怎麼做某件事"，而是"**如何讓團隊統一使用同一套 AI 工作方案**"，實現一人配置、全員複用。

**內建 12 個套件**：產品管理、產品設計、企業法務、企業財稅、合同管理、諮詢交付、市場營銷、投研分析、投行業務、股權投資、財富管理、科技服務助手。

**用法**：

1. 擴充套件 → 專家套件，點卡片右側 + 安裝（技能自動載入）；
2. 新建任務，輸入 `/` 選套件名（如 `/审查合同`），描述需求。

**安裝第三方套件**：右上角「+ 新增」→「上傳套件」，上傳 .zip 包（須含 `.qoder-plugin/plugin.json`，plugin.json 必含 name 欄位）。

## 一個真實案例：律師的 20 年經驗資產化

官方實戰頁記錄了一位律所合夥人的用法（著作權侵權案應訴）：

- 邊辦案邊建立 Skill：證據整理（分類規則+編號體系）、類案檢索（首輪結果不理想後**收窄案由範圍**）、抗辯體系構建（第三稿調整論證層次）、答辯狀起草；
- 結果：**四天獨立完成全套應訴文書**——答辯狀、質證意見、證據清單、代理詞、356 頁證據冊；
- 結案後把十個 Skill 整合為法務專家套件分發給團隊，新人一鍵生成、合夥人稽核。

打造套件的四步：①用 Skill 跑通一個工作流（起點：選你最近一週重複做過兩次以上的工作）→ ②補 Skill 覆蓋完整流程 → ③整合為專家套件 → ④分享給團隊。

三個常見誤區：套件輸出是高質量**初稿**不是終稿；不能一次封裝永久使用（要迭代）；套件不是越大越好（聚焦"合同審查"而非"所有法務工作"）。

## 自己做技能：/create-skill

對話中輸入 `/create-skill`，描述"觸發語 + 步驟 + 輸出格式"，QoderWork 幫你生成 SKILL.md。詳細打法見進階篇[對話式建立技能](/zh-tw/qoderwork/adv-skill-create)。

> 想把整本書蒸餾成技能集？思路參考 WorkBuddy 板塊的[打造 Skill：知識蒸餾](/zh-tw/workbuddy/adv-build-skill/)——SKILL.md 規範兩邊相通。
