## 提示詞五大誤區（官方檔案）

你寫提示詞常踩的坑，官方列了五個，你逐一對照能少走彎路：

| ❌ 誤區 | ✅ 正解 |
| --- | --- |
| 一句話概括所有需求 | 說具體：目標 + 格式 + 約束 |
| 不檢查結果就繼續 | 錯誤會在後續步驟放大，每步抽查 |
| 同一任務混多主題 | 一事一任務，無關新開 |
| 從不使用附件 | "@檔案 + 一句要求"勝過一大段描述 |
| 不告訴用途 | 說明"給誰看、用來做什麼"，輸出更對路 |

## 硬限制備忘

你開工前，這七條硬限制先記牢，省得任務跑一半翻車：

- 一個任務只能關聯**一個**工作資料夾；
- 開關連接器後需**新建對話**才生效；
- 定時任務由本地客戶端排程：電腦睡眠/關機不觸發，錯過不補（可手動「立即執行」）；
- CAPTCHA、簡訊驗證碼、人臉識別必須人工介入；
- 瀏覽器連接器僅支援 Chromium 核心；
- 歷史任務存本地裝置，不會跨裝置同步，你換電腦就看不到；
- 技能分享連結約 24 小時有效，你發給同事要趁早。

## 三家工具怎麼選

你拿不準時，直接看這張結論表。你拿不準選哪家，這張表直接給結論；三家賬號獨立，互不衝突：

| 需求 | 推薦 | 原因 |
| --- | --- | --- |
| 瀏覽器自動化（帶登入態） | QoderWork | 連接器複用真實瀏覽器 |
| 釘釘生態 | QoderWork | IM 頻道 + 釘釘 MCP 市場 |
| 桌面軟體自動化 | QoderWork | Computer Use 雙平臺支援 |
| 深度飛書/騰訊檔案 | TraeWork | 外部應用授權 13 個飛書模組 |
| 三端同步、移動派活 | TraeWork | 網頁/桌面/移動任務即時同步 |
| 辦公三件套深度處理 | WorkBuddy | 檔案/表格/PPT 技能生態成熟 |
| 都想要 | 三個都裝 | 賬號獨立、互不衝突 |

你拿不準自己歸哪類，就先看「按人群」那張表；已經知道想幹啥，直接查「功能定位」。兩張表都查完還糾結，再去「三家工具怎麼選」比對。

## 常見問題

**我就是純新手，該先點哪個功能？**
你先別研究功能，直接進第一個任務跑通一次，感覺比看錶來得快。

**我想讓它整理資料夾，用哪個？**
你用工作資料夾那套；想看別人怎麼整理，去檔案整理案例照著做。

**提示詞老寫不好，表裡說的誤區我全中怎麼辦？**
最常見的是「一句話概括所有需求」。你改成「目標 + 格式 + 約束」三件套，效果立竿見影。

**QoderWork、TraeWork、WorkBuddy 我都要裝嗎？**
不是必須。你按主要需求選一家先跑順，真遇到短板再補，三家賬號獨立互不衝突。

**我該先裝還是先讀？**
你先讀上手篇裡的第一個任務，裝好就能照著做，不用先讀完所有章節。

**硬限制裡哪條最容易踩？**
你最容易忘的是「一個任務只關聯一個工作資料夾」，綁錯目錄會讀錯檔案，開工前先確認。

**提示詞誤區改一條就夠嗎？**
你先從「一句話概括所有需求」改起，改成「目標 + 格式 + 約束」，其餘四條順手對照。

**零基礎的我先看哪張表？**
你先看「按人群」那張，對號入座比硬記功能快。
