# 案例：批次檔案處理與多媒體

簡歷篩選、外貿單證、票據歸檔、音影片處理——這些"規則明確、量大、易錯"的檔案活，是 AI 辦公的主場。

> 素材來源：CSDN 實操指南、官方使用者案例庫、社群實測（文內註明）。

## 場景一：115 份簡歷批次篩選（CSDN 實測）

```text
遍歷【簡歷資料夾】中全部 115 份 Word 簡歷，按以下 JD 要求篩選：
- 英語六級或雅思 6.0 以上
- 有小紅書或 Instagram 運營經驗
- 熟悉海外社媒演算法
合格者歸檔至"合格簡歷-海外運營"資料夾；
輸出 Excel：姓名、聯絡方式、英語水平、運營經驗、匹配度（1-10 分）、推薦理由。
```

實測約 **1.5 分鐘**完成，示例輸出："匹配度 8 分，雅思 6.5，有 3 個月 Instagram 賬號運營經驗"。注意：匹配度評分是參考，終面前的複核不能省。

## 場景二：外貿 Tech Pack 結構化（官方使用者案例）

外貿服裝跟單員，每份訂單 20 多頁英文 PDF、30+ 測量點（POM）、允差表、7 個尺碼的分數數值（1/2"、3/4"）。手工 2-3 小時/份，曾因誤讀半英寸致整批返工損失二十多萬元。做法：按訂單建資料夾「訂單-2024SS-客戶ABC」，設為工作目錄：

```text
逐份提取 Tech Pack 中的測量點並翻譯中文：
列出結構：測量部位 | 英文名 | 中文名 | 允差(+/-)；
每行為各尺碼數值；分數數值保持原始精度（1/2"、3/4"）。
請特別注意分數單位的準確性，這直接關係到生產品質。
```

效果：**2-3 小時/份 → 10 分鐘處理 3 份，準確率 100%**。複用只要一句："新到了兩個 Style 的 Tech Pack，請按之前的格式處理。"——這正是[工作資料夾](/zh-tw/qoderwork/04-files)持續複用的威力。

## 場景三：報銷收據照片歸檔（官方使用者案例）

痛點：收據照片檔名全是隨機字串。四步指令：

```text
識別【收據資料夾】中每張照片的消費日期、金額、商戶、型別（餐飲/交通/住宿/其他）：
1. 按"日期-型別-金額-商戶名.jpg"重新命名（如 20260301-餐飲-128元-某餐廳.jpg）
2. 按型別建子資料夾歸檔
3. 生成 Excel 報銷彙總表（日期/型別/金額/商戶/備註）
先輸出識別結果預覽，我確認後再重新命名。
```

OCR 識別 + 分類 + 重新命名一步到位。

## 場景四：多媒體處理三連

**音訊轉雙語字幕**（CSDN）：上傳 MP3 →

```text
生成時間軸精度 1 秒的 SRT 字幕，同時輸出"時間 + 中文 + 英文"三欄 Word，
存到"會議記錄"資料夾。
```

SRT 可直接匯入剪映。

**影片批次轉 GIF**（沉默王二實測）：

```text
把資料夾裡所有影片轉成 GIF，控制在 10M 以內，速度調成 2 倍速，
生成後備注清楚影片時長、生成時間和適配場景。
```

全部符合 10M 限制且帶備註——替代"錄屏→剪輯→匯出→反覆調幀率"的半小時手工流程。

**PPT 轉影片**（徐靖峰實測）：

```text
@【簡報.pptx】開啟並瀏覽每一頁，製作成一個短影片，時長儘量短一點。
```

自動完成翻頁錄製、字幕與配音合成。

## 打法總結

| 場景共性 | 設計要點 |
| --- | --- |
| 規則明確（欄位/格式固定） | 把欄位清單和格式寫進指令 |
| 量大 | 資料夾批次 + 模板檔案 |
| 易錯（單位/精度/命名） | 關鍵約束單獨強調（"分數單位直接關係品質"） |
| 需複用 | 跑通後固化為 Skill，一句話觸發 |

最後一條通用驗收：**交付物拿給別人之前，自己完整過一遍**——抽三份核對欄位、開啟 GIF 看能否播放、檢查 Excel 公式。
