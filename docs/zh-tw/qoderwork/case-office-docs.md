# QoderWork 怎麼批次處理檔案和多媒體？簡歷、單證、票據、字幕一次跑完

你每天被這些活淹沒：115 份簡歷要篩、幾十頁英文單證要翻、一相機 Roll 的收據要歸檔、會議錄音要出字幕。它們有個共同點——規則明確、量大、容易錯。這類活恰恰是 QoderWork 的主場：你把規則寫清，它一把跑完。

> 素材來源：CSDN 實操指南、官方使用者案例庫、社群實測（文內註明），你照著抄就能落地。

## 場景一：115 份簡歷批次篩選

你扔給它一個裝了 115 份 Word 簡歷的資料夾，附上 JD 要求，它自己篩：

```text
遍歷【簡歷資料夾】中全部 115 份 Word 簡歷，按以下 JD 要求篩選：
- 英語六級或雅思 6.0 以上
- 有小紅書或 Instagram 運營經驗
- 熟悉海外社媒演算法
合格者歸檔至"合格簡歷-海外運營"資料夾；
輸出 Excel：姓名、聯絡方式、英語水平、運營經驗、匹配度（1-10 分）、推薦理由。
```

實測約 1.5 分鐘完成，示例輸出：「匹配度 8 分，雅思 6.5，有 3 個月 Instagram 賬號運營經驗」。你注意一點：匹配度評分只是參考，終面前的複核省不掉。

## 場景二：外貿 Tech Pack 結構化

外貿跟單員每份訂單 20 多頁英文 PDF、30+ 測量點（POM）、允差表、7 個尺碼的分數數值（1/2"、3/4"）。手工 2-3 小時 / 份，曾因誤讀半英寸致整批返工、損失二十多萬。你按訂單建資料夾「訂單-2024SS-客戶 ABC」，設為工作目錄，再下指令：

```text
逐份提取 Tech Pack 中的測量點並翻譯中文：
列出結構：測量部位 | 英文名 | 中文名 | 允差(+/-)；
每行為各尺碼數值；分數數值保持原始精度（1/2"、3/4"）。
請特別注意分數單位的準確性，這直接關係到生產品質。
```

效果：2-3 小時 / 份 → 10 分鐘處理 3 份，準確率 100%。你之後複用只要一句：「新到了兩個 Style 的 Tech Pack，請按之前的格式處理。」——這正是[工作資料夾](/zh-tw/qoderwork/04-files)持續複用的威力。

## 場景三：報銷收據照片歸檔

你拍了一堆收據，檔名全是隨機字串。四步指令就理清：

```text
識別【收據資料夾】中每張照片的消費日期、金額、商戶、型別（餐飲/交通/住宿/其他）：
1. 按"日期-型別-金額-商戶名.jpg"重新命名（如 20260301-餐飲-128元-某餐廳.jpg）
2. 按型別建子資料夾歸檔
3. 生成 Excel 報銷彙總表（日期/型別/金額/商戶/備註）
先輸出識別結果預覽，我確認後再重新命名。
```

OCR 識別 + 分類 + 重新命名一步到位，重新命名前還會拿給你確認。

## 場景四：多媒體處理三連

你遇到音訊、影片這類多媒體活，也能一把過。

音訊轉雙語字幕（CSDN）：你傳一段 MP3——

```text
生成時間軸精度 1 秒的 SRT 字幕，同時輸出"時間 + 中文 + 英文"三欄 Word，
存到"會議記錄"資料夾。
```

SRT 能直接拖進剪映。

影片批次轉 GIF（沉默王二實測）：

你要把長影片壓成 GIF，這句就夠。

```text
把資料夾裡所有影片轉成 GIF，控制在 10M 以內，速度調成 2 倍速，
生成後備注清楚影片時長、生成時間和適配場景。
```

全部壓在 10M 內且帶備註，替掉你「錄屏 → 剪輯 → 匯出 → 反覆調幀率」的半小時手工。

PPT 轉影片（徐靖峰實測）：

```text
@【簡報.pptx】開啟並瀏覽每一頁，製作成一個短影片，時長儘量短一點。
```

它自動完成翻頁錄製、字幕與配音合成。

## 打法總結

你把這些場景歸納一下，打法就清楚了。

| 場景共性 | 設計要點 |
| --- | --- |
| 規則明確（欄位 / 格式固定） | 把欄位清單和格式寫進指令 |
| 量大 | 資料夾批次 + 模板檔案 |
| 易錯（單位 / 精度 / 命名） | 關鍵約束單獨強調（「分數單位直接關係品質」） |
| 需複用 | 跑通後固化為 Skill，一句話觸發 |

你交付之前，自己完整過一遍——抽三份核對欄位、開啟 GIF 看能否播放、檢查 Excel 公式。這一條通用驗收誰都替不了。

## 常見問題

**匹配度評分能直接當錄用依據嗎？**
不能。它只是初篩參考，幫你從 115 份裡圈出值得看的人，終面判斷得你自己做。

**外貿單證裡的分數單位會不會被算錯？**
你把「分數精度直接關係生產品質」寫進指令，它會原樣保留 1/2"、3/4"，不會擅自換算。

**收據重新命名前我能先看一眼嗎？**
能。指令里加一句「先輸出預覽，我確認後再重新命名」，它就不會貿然動檔案。

**這類流程跑熟了怎麼省事？**
固化成一個 Skill，下次一句話觸發，不用每次重寫那段長指令。
