# QoderWork 是什麼

**QoderWork** 是阿里系（Qoder 團隊 / 國內為阿里雲端計算）推出的桌面端智慧工作助手，官方口號「**你說需求，它交付結果**」，也自稱"AI 智慧專員"。它把 Qoder 的 Agent 能力從程式碼領域擴充套件到日常工作場景：檔案整理、資料處理、檔案生成、瀏覽器自動化、定時任務、IM 遠端指揮——傳統 AI 是"你問它答，動手還得靠自己"，QoderWork 是直接把活幹完，產物落到你電腦上。

> 官方檔案：[docs.qoder.com/zh/qoderwork](https://docs.qoder.com/zh/qoderwork/introduction) ｜ 國內版：[qoder.com.cn/qoderwork](https://qoder.com.cn/qoderwork)（QoderWork CN，阿里雲渠道）

## 八大能力

| 能力 | 一句話說明 |
| --- | --- |
| 檔案處理 | 對話式讀取、編寫、整理檔案、表格、演示稿和 PDF |
| 瀏覽器自動化 | 自動導航網頁、填表單、提取資料，無需寫指令碼 |
| 桌面控制 | 直接操控桌面應用的點選、輸入、滾動 |
| 定時任務 | 週期性或一次性自動執行（日報、提醒、監控） |
| IM 頻道 | 連線釘釘、飛書、微信等，聊天窗裡遠端指揮 |
| 技能與擴充套件 | 技能市場、專家套件、MCP 伺服器、第三方聯結器 |
| 語音輸入 | 按住 Fn 說話，AI 轉錄並執行 |
| 意識（記憶） | 跨會話記憶與協作風格個性化，越用越懂你 |

## 三個核心概念

官方快速開始檔案強調的三個概念，第一次用就會遇到：

- **澄清**：任務開始前的簡短確認，用來對齊模糊的需求（需求清晰則自動跳過）——別嫌煩，澄清暴露的問題不處理，最後都會變成返工；
- **任務監控**：工作區右側的執行面板，實時展示計劃、工具呼叫、用到的技能和被操作的檔案——官方強調"一切都是透明的"；
- **產物**：任務輸出的真實本地檔案（表格、報告、幻燈片……），直接儲存在你電腦上，可隨時開啟、編輯、轉移。

## 和 Qoder（程式設計平臺）的關係

Qoder 家族包括 Qoder IDE、JetBrains 外掛、CLI、Cloud Agents、**QoderWork** 等多條產品線。QoderWork 是家族中面向非程式設計師的"辦公版"分支，是**獨立的桌面應用**——不存在"在其他產品裡切換到 QoderWork 標籤"的概念。

賬號與權益互通：QoderWork 使用 Qoder 統一賬號登入，**Credits 餘額和會員權益在所有 Qoder 產品間共享**。注意：歷史任務儲存在本地裝置，**不跨裝置同步**。

## 和本站其他工具的關係

- **WorkBuddy**（騰訊）：辦公 AI 智慧體工作臺，辦公三件套技能生態成熟
- **TraeWork**（位元組）：AI 原生工作臺，三端協同 + 飛書生態深
- **QoderWork**（阿里）：桌面智慧工作助手，瀏覽器自動化與 IM 頻道是強項

三家定位相近、各有側重。QoderWork 的差異化：本地優先（檔案操作在本地完成）、瀏覽器自動化"像你一樣操作網頁"、7 個 IM 平臺遠端指揮。
