# 案例：檔案整理與照片管理

檔案整理是 QoderWork 的"入門第一課"，也是感知"AI 真的把活幹完"最直接的場景。這一章合併官方典型場景、使用者案例和社群實測。

> 社群素材：沉默王二實測（[javabetter.cn](https://javabetter.cn/sidebar/itwanger/ai/qoderwork-review.html)）、官方使用者案例庫。提示詞均經本站整理。

## 場景一：Downloads 大掃除

**重複檔案清理**（官方示例提示詞）：

```text
掃描我的 Downloads 資料夾，找出所有重複的檔案，保留最新版本。
```

實測資料（沉默王二，內測期）：2444 份簡歷檔案搬運耗時**不到 6 秒**；上萬檔案的超大 Downloads 清理約 300 秒，輸出一份標明"重複 / 刪除 / 保留"的清單報告。AI 用 MD5 值識別重複、按時間分組，比手動整理快兩個數量級。

安全設計：工具**不擅自刪除檔案**，列出方案等你授權確認後才執行；刪除只進系統回收站（見[工作資料夾](/zh-tw/qoderwork/04-files)安全三條）。

**分類歸檔**（官方典型場景）：

```text
整理【目錄】：圖片移入 assets/images/、檔案(.md/.txt/.pdf)移入 docs/、
配置檔案(.json/.yaml/.toml)移入 config/、程式碼按語言歸入 src/ 子目錄。
執行前先給出方案，確認後再移動；最後生成整理報告（數量統計 + 目錄樹）。
```

進階版帶重新命名規則：

```text
整理下載資料夾，按檔案型別（檔案/圖片/影片/壓縮包）分類，
重新命名為"型別_日期_原名稱"格式，生成分類日誌。
```

## 場景二：照片牆變成照片檔案

官方典型場景（照片管理）：

```text
整理 ~/Pictures/2024 目錄：
1. 讀取每張照片的 EXIF 拍攝時間
2. 按年月建立層級資料夾（2024-01/、2024-02/…）
3. 按拍攝時間移動並重新命名為"日期_序號.jpg"
4. 生成一份 CSV 清單（原檔名、新路徑、拍攝時間）
先給方案，我確認後再動檔案。
```

## 場景三：行政總監的年度總結（官方使用者案例）

300 人科技公司的行政總監李姐，每年要整合 8 個部門的年終彙報——桌面 50+ 份 Word/PDF，"每年至少花兩天"。做法：

1. 建資料夾「2024年度總結資料」，12 份檔案統一命名（部門名-年份-檔案型別）；
2. 選定為[工作目錄](/zh-tw/qoderwork/04-files)；
3. 一次結構化指令：

```text
以 2023 年度總結.docx 為格式模板，整合各部門彙報材料：
提取各部門成果與業績資料，結合財務與經營指標，
按"經營概況 / 業務板塊 / 團隊建設 / 規劃展望"四大板塊組織，
參考歷年總結的行文風格，保持模板排版，輸出 Word 到 output/ 目錄。
```

結果：**兩天 → 6 分鐘**，關鍵業績資料 100% 保留。後續新檔案放進同一資料夾，一句"加入了新資料，請更新報告"即可增量更新。

## 通用打法小結

| 場景 | 核心提示詞結構 | 關鍵約束 |
| --- | --- | --- |
| 查重清理 | 掃描 → 保留最新 → 生成清單 | 先方案後執行 |
| 分類歸檔 | 分類規則 + 命名規則 + 報告 | 先方案後移動 |
| 照片管理 | EXIF → 分層目錄 → 重新命名 → 清單 | 先方案後動檔案 |
| 週期彙總 | 模板檔案 + 板塊結構 + 風格參照 | 資料必須溯源 |

四條安全底線：

1. 永遠"先方案、後執行"——確認清單再放行；
2. 大批次操作前備份（或確認回收站機制可用）；
3. 授權範圍最小化，只給需要的目錄；
4. 執行完抽查：檔案數量守恆（原數量 = 移動 + 保留 + 待確認）。
