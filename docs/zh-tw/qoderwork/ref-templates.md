# QoderWork 指令模板怎麼套用？16 個拿來即用的例子，改兩處就能發

你對著輸入框發過呆嗎？知道要它幹活，卻不知道這句話該怎麼寫——寫短了它理解偏，寫長了還不如自己動手。這一頁給你 16 個能直接複製的指令模板，你只要把 `【】` 和 `{}` 裡的佔位符換成自己的內容，就能發出去。

## 模板怎麼用

別整段照抄。你拿到模板先做三件事：

1. 換佔位符：`【】` 和 `{}` 裡的內容換成你的真實目錄、檔名、欄位。留著不換，它只能猜。
2. 補約束：模板給的是骨架，你要是關心輸出格式、要不要先確認、資料不能瞎編，就在末尾加一句。
3. 先跑小樣：涉及移動、重新命名、刪除、提交的指令，你先讓它出方案，確認後再執行。

提示詞的三要素（目標 / 格式 / 約束）寫在[第一個任務](/zh-tw/qoderwork/03-first-task)，你覺得模板不夠用時去那兒看原理。

## 怎麼挑

你不確定用哪個模板時，先判斷這一步是「讀檔案」「算資料」「改檔案」「定時跑」還是「操作瀏覽器」——對著下面的分類找就行。你是新手，建議從檔案整理類開始：這一類不會動到外部系統，你就算指令寫得糙，損失也只是多花幾分鐘重跑一遍。

## 檔案整理類

### Downloads 大掃除

```text
掃描【目錄】，找出所有重複的檔案，保留最新版本，生成清單等我確認後再執行。
```

### 分類歸檔

```text
整理【目錄】：圖片移入 assets/images/、檔案(.md/.txt/.pdf)移入 docs/、
配置(.json/.yaml/.toml)移入 config/、程式碼按語言歸入 src/。
執行前先給出方案；最後生成整理報告（數量統計 + 目錄樹）。
```

### 照片歸檔

```text
整理【照片目錄】：讀取 EXIF 拍攝時間，按年月建資料夾（2026-01/），
移動並重新命名為"日期_序號.jpg"，生成 CSV 清單。先給方案，確認後再動檔案。
```

### 收據/票據歸檔

```text
識別【資料夾】中每張收據照片的日期、金額、商戶、型別（餐飲/交通/住宿/其他）：
按"日期-型別-金額-商戶.jpg"重新命名，按型別歸檔，
生成 Excel 報銷彙總表。先輸出識別預覽，我確認後再重新命名。
```

## 資料分析類

### Excel 多維分析

```text
@【資料.xlsx】分析：
1. 說明欄位含義，檢查缺失值和異常值
2. 按【維度】統計【指標】並排名
3. 按月/周出趨勢
4. 生成 Excel 彙總 + 圖表
要求：數字與原始檔一致，無法確認的標註待核實。
```

### 十萬行級 CSV

```text
分析【客流/銷售資料.csv】：
按【分組欄位】分組；計算總量、佔比（保留 1 位小數）；
產出 Excel + 分色柱狀圖；儲存到【輸出目錄】。
```

### 調研 PPT（帶來源）

```text
調研【主題】，做一份【N】頁 PPT：覆蓋【維度清單】；
結構：【封面→…→總結】；趨勢用折線圖、份額用餅圖；
所有資料標註來源，找不到的標註"待核實"。
```

## 檔案處理類

### 簡歷批次篩選

```text
遍歷【資料夾】全部簡歷，按 JD 篩選：【要求 1/2/3】；
合格者歸檔至"合格簡歷-【崗位】"資料夾；
輸出 Excel：姓名、聯絡方式、【關鍵項】、匹配度（1-10 分）、推薦理由。
```

### 批次格式統一

```text
將【資料夾】中的 10 份 Word 檔案統一調整為：標題宋體加粗 18 號、
正文宋體 12 號、1.5 倍行距、首行縮排 2 字元。先預覽一份給我確認。
```

### 檔案對比

```text
比較【檔案A】與【檔案B】：輸出新增、刪除、修改三類差異，
重點標記金額、日期、責任主體、審批條件，生成待確認問題清單。
```

## 自動化類

### 定時日報（含推送）

```text
（定時：每個工作日 09:00）讀取 data/ 昨日資料，生成早報：
核心指標彙總（附環比）；波動 ±20% 以上標黃並說明原因
（資料裡找不到就標註待核實）；輸出 Markdown 到 reports/，
並推送到釘釘【群名】。
```

### 自然語言定時

```text
每隔 3 小時檢查【網頁/檔案】，有更新就摘要通知我。
```

## 電腦/瀏覽器類

### 網頁批次採集

```text
從已連線的瀏覽器頁面【入口路徑】採集【N】個分頁的記錄，
按模板【template.xlsx】整理成 Excel：日期、標題、連結。
```

### 操作類任務（安全版）

```text
幫我在【網站】填寫【表單】，資訊來自【附件】。
填完後停留在提交頁等我確認，不要點選提交。
```

## 流程類

### 讓 AI 先出方案

```text
【任務描述】。請先給出你的計劃（分幾步、動哪些檔案、怎麼命名），
我確認後再執行。
```

### 封裝技能

```text
/create-skill 把剛才的【流程名】封裝為技能：
觸發語：【一句話】；步驟：【編號步驟】；
輸出：【格式與位置】；邊界：【不做什麼】。
```

## 常見問題

**為什麼我照抄模板，出來的結果還是不對？**

多半是佔位符沒換乾淨，或者你沒說清輸出格式。你把 `【】` 裡的內容換成具體路徑和檔名，再補一句「輸出成 Excel」「先給方案別動檔案」，準確率會高很多。

**模板裡的中文括號要一起刪掉嗎？**

要。`【】` 和 `{}` 只是這一頁的佔位標記，你換成真實內容時得連括號一起去掉，別留著。

**涉及刪除和提交的指令，怎麼避免誤操作？**

你在末尾加一句「先輸出方案，我確認後再執行」。上面「讓 AI 先出方案」和「操作類任務（安全版）」兩個模板就是幹這個的，你直接拿去用。

**常用模板能存下來下次直接調嗎？**

能，而且更省事。你用「封裝技能」那個模板，把跑通的流程固化成技能，以後一句話就能觸發，不用每次都翻這一頁。
