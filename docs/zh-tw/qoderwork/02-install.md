# 怎麼把 QoderWork 裝到電腦上？十分鐘裝好，登入後不踩隱私坑

你點開官網的下載按鈕，結果頁面彈出兩個東西：一個 .dmg，一個 .exe。你盯著它們犯嘀咕——到底該下哪個？裝完會不會亂動我電腦裡的檔案？這一篇就把你從「下載」一路帶到「登入後第一眼該看什麼」，一步步走完。

QoderWork 是個跑在你自己電腦上的桌面軟體，不是網頁。它對系統的要求是這樣的：

- macOS 14 及以上（Apple Silicon 和 Intel 兩種晶片都支援）；
- **Windows 10 及以上 64 位**；
- 磁碟至少留 500MB；
- 網路要穩，因為模型、技能和連接器都得從雲端拉下來。

> 官方安裝檔案：[macOS](https://docs.qoder.com/zh/qoderwork/installation-macos) ｜ [Windows](https://docs.qoder.com/zh/qoderwork/installation-windows)

## 去哪下載

你有兩個入口，看你是國際版還是國內版：

- 國際版：[qoderwork.com](https://qoderwork.com)（官方快速開始檔案指定的地址）；
- 國內版：[qoder.com.cn/qoderwork](https://qoder.com.cn/qoderwork)（走阿里雲渠道，用 Qoder CN 賬號登入）。

## macOS 怎麼裝

你下載 .dmg 之後，把它拖進「應用程式」資料夾就算裝上了。第一次啟動如果被系統攔下，別慌：開啟「系統設定 → 隱私與安全性」，在最底下點一下「仍然開啟」——這個提示只會出現一次。

接著用已有的 Qoder 賬號直接登入；沒有就郵箱註冊，或者用第三方賬號登入。進到工作介面，你就裝好了。

更新很省心：它預設在後臺檢查，但要你點確認才會下載並重啟，絕不會不問你就替你換掉當前版本。你想手動查，點選單欄的 QoderWork → 檢查更新就行。

解除安裝也簡單，拖進廢紙簍即可。你要是想連配置一起清乾淨，退出登入後在終端執行 `rm -rf ~/.qoderwork`——注意，這會清掉沒同步到雲端的本地任務歷史。

## Windows 怎麼裝：先選對安裝包

你在 Windows 上會看到兩個安裝包，**功能完全一樣**，差別只在安裝位置和權限：

| | 系統版 X64(System) | 使用者版 X64(User) |
| --- | --- | --- |
| 安裝位置 | Program Files | %LOCALAPPDATA% |
| 誰能用 | 所有賬戶 | 僅當前賬戶 |
| 管理員權限 | 需要 | **不需要** |

官方原話是這麼說的：“拿不準就選使用者版：不需要管理員權限，安裝最省事。”所以你拿不準，閉眼選使用者版。

要是被 SmartScreen 攔了，點「更多資訊」→「仍要執行」就能繼續。解除安裝走「設定 → 應用 → 已安裝的應用 → 搜 Qoder → 解除安裝」；想清配置就刪 `%USERPROFILE%\.qoderwork`。

## 登入後先做三件事

你剛登入進去，別急著派活，先做三件小事：

1. **切中文**：左下角有語言設定（預設可能是英文，你看不懂就先把它改成中文）；
2. **看積分**：右上角點 Credits 按鈕看餘額。新使用者註冊會送積分禮包；國內版還有每天簽到來領積分的活動（留意活動有效期，別讓它過期）；
3. 理解計費：QoderWork 按 Credits 扣費，和 Qoder 全家桶共用一個餘額。模型分標準 / 高階 / 旗艦三檔，消耗不一樣——日常任務用標準檔就夠。想細看怎麼省錢，翻[意識、成本與安全環境](/zh-tw/qoderwork/adv-memory-cost)。

## 裝不上？對照這張表

你遇到報錯時，先翻這張表：

| 問題 | 解決 |
| --- | --- |
| macOS 提示“無法驗證開發者” | 系統設定 → 隱私與安全性 → 仍要開啟 |
| Windows 權限不足 | 換使用者版安裝包，或以管理員身份執行 |
| 低於 macOS 14 | 無法啟動，需先升級系統 |
| 任務執行提示權限不足 | 檢查是否授權了對應工作目錄 |

## 隱私三條，你得心裡有數

你最擔心的「它會亂翻我檔案嗎」，官方給了三條口徑：

1. 檔案操作在你電腦本地完成，不會上傳到雲端；但相關文本內容會發給大模型的服務商去處理；
2. 它只能進你明確授權的工作目錄，沒授權的目錄真要訪問，會先問你同不同意；
3. 檔案內容不會在雲端永久存著。

## 新手常見問題

**它會不會偷偷上傳我電腦裡的檔案？**
不會。檔案操作在你的電腦本地完成，只有文本內容會發給大模型服務商處理，檔案本身不會傳到雲端永久儲存。你沒授權的目錄它進不去，真要進會先問你。

**我該下哪個 Windows 安裝包？**
拿不準就選使用者版（User）。它不需要管理員權限，裝在你的個人目錄裡，最省事。系統版需要管理員權限、所有賬戶都能用，普通人不常用得上。

裝完要立刻付費嗎？
不用。新使用者註冊送積分禮包，國內版還有每日簽到領積分。你先看積分餘額，日常任務用標準檔模型，消耗很慢。

**登入後介面是英文的，正常嗎？**
正常，預設可能是英文。你點左下角語言設定切到中文就好，這是登入後第一件該做的事。

**我想徹底解除安裝並清空記錄怎麼辦？**
拖進廢紙簍解除安裝軟體；要清配置，退出登入後在終端執行 `rm -rf ~/.qoderwork`（Windows 刪 `%USERPROFILE%\.qoderwork`）。注意這會清掉沒同步的本地任務歷史。
