# 怎麼讓 AI 直接讀你電腦裡的檔案？授權一個資料夾，它自己翻

你之前用聊天 AI，每次都得手動把檔案拖進對話方塊，幹完再手動下載。可你電腦裡那個堆滿報表的資料夾，它根本夠不著。QoderWork 和「聊天式 AI」最大的分水嶺就在這：你授權一個本地目錄，它直接讀寫你電腦上的檔案，上傳下載那套麻煩事全沒了。官方原話：“合理組織資料夾並選定為工作目錄，是讓 QoderWork 發揮最大價值的關鍵操作。”

## 設定方法

你按這四步把資料夾交出去：

1. 點 + 新建任務；
2. 輸入框下方點「在資料夾中工作」（部分版本文案是「選擇工作目錄」）；
3. 在系統檔案選擇器裡選中目標資料夾；
4. 直接輸入需求，AI 自動讀取資料夾內容。

**硬限制：一個任務只能關聯一個工作資料夾**；你要處理不同資料夾，分別建任務。

## 什麼時候用資料夾

你拿不準該不該用工作資料夾時，看這張表：

| 場景 | 建議 |
| --- | --- |
| 處理單個檔案 | 直接拖拽上傳到對話 |
| 多個相關檔案 | 工作資料夾 |
| 檔案會持續增加 | 工作資料夾（AI 能立刻感知新檔案） |
| 產物需要存到指定位置 | 工作資料夾 |

## 檔案安全三條規則

你最在意的「它會不會把我檔案刪了」，看這三條：

1. 只訪問你明確授權的目錄——其他位置真要訪問時，會先徵求你的同意；
2. **不會永久刪除檔案**——刪除操作只移進系統回收站；
3. 檔案內容不會永久儲存——處理時發給 AI 模型，但不在雲端永久儲存。

建議：你只授權常用工作資料夾，別把整個使用者目錄設成工作目錄。

## 支援的格式

你手上的檔案基本都能吃進去、吐出來：

| | 格式 |
| --- | --- |
| 讀取 | PDF、Word(.docx)、Markdown、純文本、RTF、Excel(.xlsx/.xls)、CSV、TSV、PNG/JPG/SVG/GIF（支援 OCR）、全部程式碼原始檔、PowerPoint(.pptx)、JSON/YAML/XML/SQL |
| 輸出 | Word、PDF、Markdown、HTML、Excel、CSV、PPTX、PNG、SVG、互動式 HTML 報告、任意語言程式碼、JSON/XML |

幾乎覆蓋辦公全場景；唯一常見缺口是老式 .doc / .ppt 二進位制格式，你遇到先轉成 docx / pptx。

## 持續使用：一次設定，長期複用

工作資料夾真正的威力在「持續積累」。官方打個比方：**“資料夾是「原料倉」，提示詞是「施工圖」。”**

你跑熟了，迴圈是這樣的：

```text
第一週：把 12 份部門年度彙報放進「2024年度總結」資料夾，選定工作目錄，
        讓 AI 生成年度總結 → 6 分鐘拿到成品
第二週：新增 3 份資料，開啟 QoderWork（工作目錄沒變，無需重選），
        一句"加入了新的資料，請更新報告" → 5 分鐘內更新完成
```

組織資料夾的四個技巧，你照著做：

1. 命名帶日期或序號：`2024-03-月考成绩.xlsx`，AI 排序不亂；
2. **一事一資料夾**：生活和三個專案別混在一個目錄；
3. 格式統一：相同模板、相同列名的檔案能自動對齊合併；
4. **善用子資料夾**：支援遞迴讀取，按 `原始材料/输出/参考` 分層。

## 新手常見問題

授權資料夾後，它會把我別的檔案也翻一遍嗎？
不會。它只進你明確授權的那個目錄，沒授權的真要訪問會先問你。你也別圖省事把整個使用者目錄設成工作目錄。

**一個任務能掛兩個資料夾嗎？**
不能。一個任務只能關聯一個工作資料夾，這是硬限制。你要處理不同資料夾，分別建任務。

它刪檔案是不是就找不回來了？
不會永久刪。刪除只移進系統回收站，你還能從回收站撈回來。所以你大批次操作前也別忘備份。

**老 .doc 和 .ppt 打不開怎麼辦？**
工作資料夾對老式二進位制格式支援不佳，你先轉成 docx / pptx，再丟進去。

**加了新檔案，要重新選目錄嗎？**
不用。工作目錄沒變的話，你直接說“加入了新資料，請更新”，它立刻能感知新檔案。
