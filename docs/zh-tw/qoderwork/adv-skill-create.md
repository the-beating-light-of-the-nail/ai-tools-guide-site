# QoderWork 怎麼把重複活做成技能？/create-skill 對話式建立一次講清

你有沒有過這種時候：同一段任務說明，這週寫了第三遍。週報格式、案件分析流程、店鋪日報——每次都從頭描述，累且容易漏。你這次寫的第三遍，就是該做成技能的訊號。QoderWork 把這件事的門檻降到了「說人話」：內建 `/create-skill` 指令，你跟它聊幾句，它就生成一份 SKILL.md，以後一句話觸發。

> 官方檔案：[skills](https://docs.qoder.com/zh/qoderwork/skills) ｜ 實戰素材見官方使用者案例庫。

## 一個真實樣本：銷售週報技能

社群實測的完整建立過程（CSDN 指南），你照著做是這樣的：

1. 你直接在對話裡輸入 `/create-skill`；
2. 你描述觸發語與流程：

```text
建立一個"銷售週報"技能：
觸發語：生成本週銷售週報
步驟：讀取 sales/ 目錄下的銷售資料.xlsx → 計算周環比增長率
（(本週-上週)/上週×100%）→ 生成 Top 5 產品柱狀圖 →
按固定模板生成 Word 週報，儲存到 reports/ 目錄。
依賴：Excel 處理、Python-Matplotlib 繪圖。
```

3. QoderWork 生成 SKILL.md 並存入 `~/.qoderwork/skills/`，你以後隨時能調；
4. 以後任何新任務裡你輸入 `/`，選「銷售週報」，或直接說「生成本週銷售週報」就能觸發。

更徹底的資產化樣本（官方使用者案例，一位律師），你也能這樣封裝：

```text
請把剛才的案件分析流程封裝為一個 Skill，命名為"商事糾紛案件分析"：
輸入：案件材料資料夾（起訴狀、合同、補充協議、微信截圖、轉賬憑證、律師函）；
輸出：案件時間線 + 爭議焦點 + 證據鏈分析（標註強/中/弱）+ 訴訟策略報告；
分析框架固定，內容根據每個案件的材料動態生成。
```

20 年的執業經驗就此變成團隊可複用的標準化工具：新人一鍵生成、合夥人稽核。

## SKILL.md 的質量要點

`/create-skill` 生成的是初稿，你按這張清單過一遍再儲存：

- [ ] 觸發條件寫具體：「當使用者要求生成周報 / 資料彙總時」，而不是「處理資料」；
- [ ] 觸發語避免與其他技能衝突（衝突會導致無法觸發）；
- [ ] 步驟可判定：「第一步核對檔案數量是否為 7，不足先提問」；
- [ ] 輸出給樣例：貼一段期望產物的樣子；
- [ ] 宣告邊界：明確不做什麼（「不修改原始 CSV」「不給法律結論」）；
- [ ] 依賴寫清楚（需要 Excel / Python / 網路時註明）。

## 從技能到團隊標準

官方推薦的進階路線是：**先用 Skill 跑通最佳實踐 → 打包為[專家套件](/zh-tw/qoderwork/05-skills) → 團隊統一使用**。你判斷某類工作值不值得做技能，就看一句話——「選擇你最近一週內重複做過兩次以上的工作」。

> 跨工具視角：Skill 的 SKILL.md 規範在 WorkBuddy / TraeWork / QoderWork 三家之間高度相通，你學會一次，三處通用。深度方法論（把書和影片蒸餾成技能集）見 WorkBuddy 板塊的[打造 Skill：知識蒸餾](/zh-tw/workbuddy/adv-build-skill/)。

## 常見問題

**我不會寫程式碼，能做技能嗎？**
能。你只要用 `/create-skill` 說清觸發語和步驟，它生成 SKILL.md，不用你寫一行程式碼。

**做出來的技能會和自己衝突嗎？**
會，如果觸發語太像。你寫具體觸發條件，避開別的技能的說法，就不會搶觸發。

**團隊怎麼共用我做的技能？**
你打包進專家套件，或技能頁生成分享連結發給同事，對方一鍵安裝。

**分享連結一直有效嗎？**
不是，約 24 小時有效。你臨時發給同事沒問題，長期共用還是走套件或市場。
