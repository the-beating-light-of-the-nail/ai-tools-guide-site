# 外掛與外部應用授權

外掛把外部工具、服務與資料來源接進 TraeWork；外部應用授權讓 AI 直接操作你在飛書、GitHub 裡的資料。兩者疊加，TraeWork 才真正"長"在你的工作流上。

> 官方文件：[work_plugins](https://docs.trae.cn/work_plugins) ｜ [七大熱門外掛](https://docs.trae.cn/work_seven-popular-plugins-in-traework)

## 裝外掛：三步

1. 左側導航欄頂部點「外掛市場」（預設「外掛」頁籤）；
2. 找到目標外掛，點卡片右側「安裝外掛」圖示（或進詳情頁點右上角「新增外掛」）；
3. 需要連外部服務的外掛，按提示完成授權。

使用時：**開始對話前**，在對話輸入框左下方選擇可用外掛（可選多個）。注意外掛必須在對話開始前選好，禁用狀態下無法在對話中使用。

## 七大熱門外掛速覽

| 外掛 | 能幹什麼 | 亮點 |
| --- | --- | --- |
| **飛書** | 訊息、雲文件、雲盤、多維表格、日曆、任務、審批、會議、妙記、OKR | 辦公場景首選，示例指令如"日程安排在下週一上午 10 點" |
| **騰訊文件** | 建立/讀取/編輯 Word、Excel、幻燈片、智慧文件、智慧表格、思維導圖、流程圖 | 線上協作文件一把抓 |
| **企業微信** | 通訊錄與訊息查詢，管理會議、日程、待辦、文件及線上表格 | 示例："新增一個明天 18:00 截止的待辦" |
| **Remotion** | 以編寫 React 程式碼的方式製作影片（佈局、動畫、字幕、音訊） | 程式碼化影片，適合程式化短片 |
| **HyperFrames** | 用 HTML + CSS + GSAP 製作影片 | 水墨質感、品牌色示例：#11C566 |
| **同花順 iFinD** | 金融資料查詢與投研分析（需 API Key，資料分免費版/訂閱套餐） | 注意：債券實時行情不含銀行間 |
| **通達信** | A 股/基金/指數/港股行情查詢、條件選股（漲停、低 PE、MACD 金叉等） | 不支援期貨、期權、債券 |

> 官方宣告：金融類外掛內容僅用於展示能力，不構成投資建議。

## 外部應用授權：飛書

授權後無需手動配置 MCP Server，即可讀寫飛書雲文件、多維表格、日曆、訊息、郵箱、會議等：

1. 左欄頂部「外掛市場」→ 右上角「管理」→「應用授權」頁籤；
2. 飛書應用右側點「連結」，跳轉飛書授權頁；
3. 勾選許可權 →「確認授權」→ 二次確認頁核對帳號與許可權 → 點「授權」。

可授權模組共 13 個（按能力顆粒度）：多維表格（約 38 項操作，最多）、雲文件（25 項）、即時通訊（18 項）、知識庫（14 項）、日曆/任務/會議/郵箱（各 10 項）、雲空間（8 項）、幻燈片、審批、通訊錄、電子表格、獲取使用者身份標識。授權完成後，TraeWork 會自動安裝本地 CLI 及相關技能。

官方給出的三條場景鏈路：

```text
① 需求文件驅動：傳送雲文件 → 讀取內容 → 基於文件幹活 → 進展回寫文件
② 多維表格驅動：檢索記錄 → 讀取任務詳情 → 執行 → 新增/更新記錄狀態
③ 協作同步：建立日曆日程 → 讀取會議紀要 → 編輯相關雲文件
```

## 外部應用授權：GitHub

入口：左下角頭像 → 設定 → 「外部應用授權」→ GitHub 點「連線」→ 登入並授權 TRAE-AI CN 訪問。授權後可以：

- **AI 建立 PR**：AI 檢視兩分支差異並生成摘要 → 一鍵建立 PR → 開啟 GitHub 視窗確認合併；
- **手動建立 PR** / **AI 檢查 PR**：讓 AI 先看相關檔案變更再執行 git diff 審查。

⚠️ GitHub 應用**僅 Code 模式支援**；桌面版需開啟從 GitHub 拉取的專案並切到「雲端」。

## 許可權邊界

- 智慧體只在**獲得授權的範圍內**呼叫對應服務；
- 整合類功能入口分散在兩處：設定 > 外部應用授權（帳號級），外掛市場 > 管理 > 應用授權（外掛級），拿不準時兩處都看一眼。
