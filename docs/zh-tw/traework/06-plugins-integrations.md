# 外掛和外部授權怎麼接？讓 AI 碰得動你的飛書、GitHub

你裝好 TraeWork，它預設是個能幹活的空殼。真正讓它在你工作流上「長」出來的，是外掛和外部應用授權：外掛把外部工具、服務、資料來源接進來；授權讓 AI 直接碰你在飛書、GitHub 裡的資料。你接上這兩樣，它才真的長在你的日常裡。官方說明在 [work_plugins](https://docs.trae.cn/work_plugins) 和[七大熱門外掛](https://docs.trae.cn/work_seven-popular-plugins-in-traework)。

## 裝外掛：三步

你點左側導航欄頂部的「外掛市場」（預設就在「外掛」頁籤）。你找到目標外掛，點卡片右側「安裝外掛」圖示，或者進詳情頁點右上角「新增外掛」。

需要連外部服務的外掛，你按提示走完授權這一步。

注意一個時間點：用之前，你在對話輸入框左下方選好可用外掛（能多選）。外掛必須在對話開始前選，停用狀態下你對話裡用不了。

## 七大熱門外掛速覽

你先掃一眼這張表，挑跟你日常最貼的。你挑錯外掛白裝，所以先對清楚：

| 外掛 | 能幹什麼 | 亮點 |
| --- | --- | --- |
| 飛書 | 訊息、雲檔案、雲盤、多維表格、日曆、任務、審批、會議、妙記、OKR | 辦公場景首選，示例指令如“日程安排在下週一上午 10 點” |
| 騰訊檔案 | 建立/讀取/編輯 Word、Excel、幻燈片、智慧檔案、智慧表格、思維導圖、流程圖 | 線上協作檔案一把抓 |
| 企業微信 | 通訊錄與訊息查詢，管理會議、日程、待辦、檔案及線上表格 | 示例：“新增一個明天 18:00 截止的待辦” |
| Remotion | 以編寫 React 程式碼的方式製作影片（佈局、動畫、字幕、音訊） | 程式碼化影片，適合程式化短片 |
| HyperFrames | 用 HTML + CSS + GSAP 製作影片 | 水墨質感、品牌色示例：#11C566 |
| 同花順 iFinD | 金融資料查詢與投研分析（需 API Key，資料分免費版/訂閱套餐） | 注意：債券即時行情不含銀行間 |
| 通達信 | A 股/基金/指數/港股行情查詢、條件選股（漲停、低 PE、MACD 金叉等） | 不支援期貨、期權、債券 |

官方宣告：金融類外掛內容僅用於展示能力，不構成投資建議。

## 外部應用授權：飛書

授權之後，你不用手動配 MCP Server，就能讀寫飛書雲檔案、多維表格、日曆、訊息、郵箱、會議這些。

你第一次授權飛書，點左欄頂部「外掛市場」→ 右上角「管理」→「應用授權」頁籤。飛書應用右側點「連結」，跳到飛書授權頁。你勾選權限 →「確認授權」→ 二次確認頁核對賬號與權限 → 點「授權」。

你可授權的模組共 13 個（按能力顆粒度）：多維表格（約 38 項操作，最多）、雲檔案（25 項）、即時通訊（18 項）、知識庫（14 項）、日曆/任務/會議/郵箱（各 10 項）、雲空間（8 項）、幻燈片、審批、通訊錄、電子表格、獲取使用者身份標識。授權完，TraeWork 會自動裝好本地 CLI 和相關技能，你後續在對話裡就能直接喊它讀飛書檔案。

官方給了三條場景鏈路：

```text
① 需求檔案驅動：傳送雲檔案 → 讀取內容 → 基於檔案幹活 → 進展回寫檔案
② 多維表格驅動：檢索記錄 → 讀取任務詳情 → 執行 → 新增/更新記錄狀態
③ 協作同步：建立日曆日程 → 讀取會議紀要 → 編輯相關雲檔案
```

## 外部應用授權：GitHub

入口在左下角頭像 → 設定 →「外部應用授權」。你點 GitHub 的「連線」，登入並授權 TRAE-AI CN 訪問。授權後你可以：

- AI 建立 PR：AI 看兩分支差異並生成摘要 → 一鍵建立 PR → 開啟 GitHub 視窗確認合併；
- 手動建立 PR / AI 檢查 PR：讓 AI 先看相關檔案變更再執行 git diff 審查。

⚠️ GitHub 應用僅 Code 模式支援；桌面版需開啟從 GitHub 拉取的專案並切到「雲端」。你常做程式碼評審，這條最實用。

## 權限邊界

智慧體只在你授權的範圍內呼叫對應服務。

整合類功能的入口分散在兩處：設定 > 外部應用授權（賬號級），外掛市場 > 管理 > 應用授權（外掛級）。你拿不準時兩處都翻一下，省得漏配。

## 新手常見問題

外掛必須在對話前選好嗎？
對。你在對話輸入框左下方選，而且得在對話開始之前選好；你進了對話再想加，停用狀態下加不進去。

飛書授權要勾哪些模組？
一共 13 個模組按顆粒度給，多維表格最多（約 38 項操作），往下是雲檔案 25 項、即時通訊 18 項、知識庫 14 項，日曆/任務/會議/郵箱各 10 項，還有云空間、幻燈片等。你用到哪個勾哪個，別一股腦全給。

金融類外掛能當投資建議用嗎？
不能。官方明確說這類外掛只展示能力，不構成投資建議。你真要查資料，同花順 iFinD 要 API Key，而且債券即時行情還不包含銀行間。你別拿它當買賣依據。

GitHub 授權為什麼在網頁版用不了？
GitHub 應用僅 Code 模式支援，桌面版還得開啟從 GitHub 拉取的專案、切到「雲端」才行，你網頁版這條路走不通。

授權和外掛的入口怎麼分？
賬號級授權你去「設定 > 外部應用授權」；外掛級去「外掛市場 > 管理 > 應用授權」。你拿不準時兩處都看一眼，比只翻一處穩。
