# TraeWork 教程

**TraeWork** 是位元組跳動推出的 AI 原生工作臺（2026 年 6 月推出，「讓 TRAE 為你工作」）：一句自然語言說清目標，AI 自主拆解步驟、呼叫技能與工具執行，交付文件、報告、演示稿、網頁等真實成果。網頁版、桌面版、行動端三端共享帳號與任務資料。

> 注意：TraeWork 是**辦公工作臺**，給白領用；程式設計師用的 TraeCode IDE 不在本站覆蓋範圍。官網 [trae.cn/work](https://www.trae.cn/work) ｜ 文件 [docs.trae.cn](https://docs.trae.cn/)

本板塊為本站原創，事實依據官方文件（截至 2026-08-31）核對撰寫，案例篇改編自社群實戰並註明出處。結構對標《WorkBuddy 實戰藍皮書》五組框架。

## 適合誰

- 想用 AI 處理文件、資料、彙報但不會寫程式碼的職場人
- 飛書/騰訊文件重度使用者（外部應用授權是 TraeWork 強項）
- 想搭"定時跑 + IM 推送"自動化流水線的效率玩家
- 同時在對比 WorkBuddy / QoderWork 的選型者
