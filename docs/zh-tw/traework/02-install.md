# TraeWork 怎麼裝？三端連好，手機和電腦任務不脫節

你剛聽同事說 TraeWork 能替你跑活，興沖沖想裝上試試。可它一口氣甩出三個端——網頁版、桌面版、移動端——你一下懵了：三個都得裝嗎？賬號會不會亂套？手機派了活，電腦怎麼接著幹？

別慌。這三個端共用同一套賬號和任務資料。你在手機上派的任務，到工位開電腦能接著看、接著收。這一篇就把三個端一次裝齊、連起來，照著做就行。

## 網頁版：免安裝，先體驗

網頁版最省事，不用裝。你直接開啟 [work.trae.cn](https://work.trae.cn/)，用 TRAE 賬號登入就能幹活。它的任務全在雲端跑，不吃你電腦的本地資源——先走一遍核心流程，順手了再決定要不要裝桌面版。

> 網頁版只支援雲端任務；要操作本地檔案，需要桌面版。

## 桌面版：主力工作臺

你要幹正活，桌面版才是主戰場。裝起來就三步：

1. 你開啟 [trae.cn](https://www.trae.cn/) 下載中心（或產品頁上的「下載 TraeWork」按鈕）；
2. 你挑 macOS 或 Windows 安裝包，下載並裝上；
3. 你用手機號登入（和網頁版是同一個賬號）。

桌面版比網頁版多出幾樣關鍵能力，差別一張表看明白：

| 能力 | 網頁版 | 桌面版 |
| --- | --- | --- |
| 執行環境 | 僅雲端 | 本地 + 雲端 |
| 操作本地檔案 | ✗ | ✓ |
| 辦公助理（IM 繫結） | ✗ | ✓（首次繫結必須在桌面版發起） |
| 新增自定義模型 | ✗ | ✓ |
| 電腦控制 / 外部瀏覽器 | ✗ | ✓ |

## 移動端：口袋裡的任務中心

通勤、排隊、躺床上，用手機就能派活。裝上它：

1. 你在手機應用商店搜「TRAE」下載（iOS 要用非美區 Apple ID，它還沒在美區上架）；
2. 你用和桌面版相同的手機號登入；
3. 進首頁左下角點「任務執行環境」→「連線我的電腦」，照提示完成配對。

連線手機和電腦，從頭到尾是這麼走的：

1. 你手機上登入 TRAE 移動端，首頁左下角點「任務執行環境」；
2. 你點「連線我的電腦」；
3. 你電腦開啟 TraeWork 桌面版，用同一手機號登入；
4. 桌面版進 設定 > TRAE 移動端，開啟「允許 TRAE 移動端控制當前裝置」；
5. 在「僅必要內容會儲存在雲端」彈窗點「確認」；
6. 你授權移動端訪問電腦 `/documents` 目錄。

配對好，記幾件事：

- 連線有效期 180 天，到期要重新配對；
- 可選「保持電腦處於喚醒狀態」，免得任務跑到一半電腦睡過去；
- 裝置離線時，系統自動切到雲端跑任務，活不中斷；
- 電腦休眠可能中斷訊息收發（辦公助理也一樣）。

## 三端協同的典型一天

連好了，三個端怎麼配合？給你看一天的真實節奏：

```text
08:30  通勤路上，移動端給雲端派一個「整理本週行業資訊」任務
09:00  到工位開啟桌面版，任務已跑完，直接驗收產物
10:00  在桌面版發起需要本地檔案的複雜任務
12:30  午飯時移動端檢視進度，追加一句需求
18:00  下班前在桌面版啟動長任務，回家用移動端收結果
```

## 新使用者積分禮包

新使用者註冊能一次性拿到 2000 通用積分 + 2000 Work 專屬積分（31 天有效）；另外每天簽到能領 Work 專屬積分，每月登入還送 500 通用積分。積分怎麼用、消耗按什麼順序，看 [模型與積分避坑](/zh-tw/traework/adv-models-credits) 這篇。

## 新手常見問題

**三個端我都要裝嗎？**
不用全裝。你先用網頁版登入體驗，覺得順手再裝桌面版幹正活。移動端看要不要隨時隨地派活，裝不裝隨你。三個端賬號互通，同一個手機號就行。

**桌面版和網頁版差在哪？**
網頁版只在雲端跑，碰不了本機檔案，也綁不了辦公助理、加不了自定義模型、控不了電腦。這些活都得桌面版來。上面對照表一眼能看清。

**手機和電腦怎麼連上？**
你手機登入後，進「任務執行環境」點「連線我的電腦」，電腦端開桌面版、同一手機號登入，再到 設定 > TRAE 移動端 開啟允許控制，彈窗確認、授權目錄就成了。配對好能用 180 天，到期重連一次。

**iOS 搜不到 TRAE 怎麼辦？**
它在美區還沒上架。你換一個非美區 Apple ID 去應用商店搜「TRAE」就能下。安卓和其它區一般直接搜得到。

**積分會過期嗎？**
會。新手套餐的 2000 通用 + 2000 Work 專屬積分 31 天有效，領了趁早用。每天簽到、每月登入還能續上 Work 專屬和通用積分，規則看積分避坑那篇。
