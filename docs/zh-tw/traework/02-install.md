# 安裝、登入與三端協同

TraeWork 的三個端（網頁版 / 桌面版 / 行動端）共享帳號和任務資料。這一章把它們一次裝齊、連起來。

## 網頁版：免安裝，先體驗

直接開啟 [work.trae.cn](https://work.trae.cn/)，登入 TRAE 帳號即可用。網頁版的任務全部在雲端執行，不佔本地資源——適合先體驗核心流程，再決定裝不裝桌面版。

> 網頁版只支援雲端任務；要操作本地檔案，需要桌面版。

## 桌面版：主力工作臺

1. 開啟 [trae.cn](https://www.trae.cn/) 下載中心（或產品頁「下載 TraeWork」按鈕）；
2. 選擇 macOS 或 Windows 安裝包下載安裝；
3. 啟動後用手機號登入（與網頁版同一帳號）。

桌面版相比網頁版的關鍵差異：

| 能力 | 網頁版 | 桌面版 |
| --- | --- | --- |
| 執行環境 | 僅雲端 | 本地 + 雲端 |
| 操作本地檔案 | ✗ | ✓ |
| 辦公助理（IM 綁定） | ✗ | ✓（首次綁定必須在桌面版發起） |
| 新增自定義模型 | ✗ | ✓ |
| 電腦控制 / 外部瀏覽器 | ✗ | ✓ |

## 行動端：口袋裡的任務中心

1. 手機應用商店搜「TRAE」下載（iOS 需非美區 Apple ID，尚未在美區上架）；
2. 用與桌面版相同的手機號登入；
3. 首頁左下角點「任務執行環境」→「連線我的電腦」，按提示完成配對。

連線手機與電腦的完整步驟：

1. 手機 TRAE 行動端登入後，首頁左下角點「任務執行環境」；
2. 點「連線我的電腦」；
3. 電腦開啟 TraeWork 桌面版，同一手機號登入；
4. 桌面版進入 **設定 > TRAE 行動端**，開啟「允許 TRAE 行動端控制當前裝置」；
5. 在「僅必要內容會儲存在雲端」彈窗點「確認」；
6. 授權行動端訪問電腦 `/documents` 目錄。

注意事項：

- 連線有效期 **180 天**，到期需重新配對；
- 可選「保持電腦處於喚醒狀態」，避免任務執行中電腦睡眠；
- 裝置離線時，系統會自動切換至雲端執行任務，任務不中斷；
- 電腦休眠可能中斷訊息收發（辦公助理同理）。

## 三端協同的典型一天

```text
08:30  通勤路上，行動端給雲端派一個「整理本週行業資訊」任務
09:00  到工位開啟桌面版，任務已跑完，直接驗收產物
10:00  在桌面版發起需要本地檔案的複雜任務
12:30  午飯時行動端檢視進度，追加一句需求
18:00  下班前在桌面版啟動長任務，回家用行動端收結果
```

## 新使用者積分禮包

新使用者註冊可一次性獲得 **2000 通用積分 + 2000 Work 專屬積分**（31 天有效）；另有每日簽到領 Work 專屬積分、每月登入贈 500 通用積分等活動。積分規則與消耗順序詳見[模型與積分避坑](/zh-tw/traework/adv-models-credits)。
