# 模型和積分怎麼管？避坑別燒錢

你用 TraeWork 按「積分」計費，你模型選得不好，積分燒得飛快。這篇把官方計費檔案裡最容易踩的坑，整理成一張避坑地圖。官方說明在 [work_models](https://docs.trae.cn/work_models) 和[ide_plans-and-billing](https://docs.trae.cn/ide_plans-and-billing)。價格與套餐截至 2026-08-31，以 [trae.cn/pricing](https://www.trae.cn/pricing) 即時資訊為準。

## 兩種積分，你先分清

| | 通用積分 | Work 專屬積分 |
| --- | --- | --- |
| 適用範圍 | TraeCode + TraeWork 均可用 | 僅 TraeWork |
| 來源 | Pro / Pro+ / Ultra 會員、增購、註冊禮包、簽到等活動 | Lite 會員、註冊禮包、每日簽到、邀請 |

消耗規則你記三條：僅呼叫 TRAE 內建模型才消耗積分，你接自定義模型不消耗；消耗順序優先有效期最短的 → 同期 Work 專屬優先於通用 → 獎勵積分優先於會員積分；Seed-2.1-Turbo 和 Seed-Code 計費享 2.5 折（各檔會員均含）。

## 套餐速覽（國內版）

你選套餐看這張表：

| | Lite | Pro | Pro+ | Ultra |
| --- | --- | --- | --- | --- |
| 單月 | ¥49 | ¥99 | ¥239 | ¥699 |
| 連續包月 | ¥45（首月 ¥9.9） | ¥89（首月 ¥59） | ¥219 | ¥629 |
| 積分/月 | 2000 Work 專屬 | 4000 通用 | 12000 通用 | 40000 通用 |
| 雲端並行 | 2 | 10 | 10 | 20 |

你免費使用者也能玩：每月登入贈 500 通用積分 + 每日簽到 200 Work 專屬 + 新使用者註冊 2000+2000 禮包。

避坑點你盯緊：

1. Lite 只有 Work 專屬積分——你同時用 TraeCode 程式設計，買 Lite 會發現程式設計那邊用不了，直接上 Pro；
2. 增購積分（¥50/1000）全是通用積分，且只有付費會員可購；你會員到期後，有效期內增購的還能用；
3. 不支援降檔，週期結束後才能改訂更低檔；升級差價按未使用比例折算；
4. 因敏感詞攔截、底層模型報錯或死迴圈導致的失敗可退積分，你本地報錯（如磁碟滿）不退。

## 模型怎麼選

你挑模型前先看清單。Work 模式內建模型（節選）：Seed-2.1-Pro / Seed-2.1-Turbo、GLM-5.3 / GLM-5.2、DeepSeek-V4-Pro / V4-Flash、Kimi-K3 / K2.7-Code、MiniMax-M3、Qwen3.8-Max 等。標註 `*` 的旗艦模型僅 Pro+ / Ultra / Express 會員可用。

實用策略你照著來：

- 日常任務：你預設 Auto Mode（綜合速度、效能與資源佔用自動選模型）或標準檔；
- 省錢跑量：你用 Seed-2.1-Turbo（2.5 折）+ 明確簡短的任務說明（Token 少，消耗低）；
- 重要交付：關鍵報告、複雜分析你切旗艦檔，一次做對比反覆返工省。

## 接入自己的模型（不耗積分）

你設定 > 模型 >「新增模型」（僅桌面版，且你自定義模型僅本地環境可用）：

1. 你選預設服務商（按量計費 / Coding Plan / Agent Plan）或「自定義模型」；
2. API 格式你二選一：OpenAI Chat Completions 格式（相容 OpenAI、DeepSeek、Kimi、GLM、OpenRouter 等）或 Anthropic Messages 格式（Claude 系）；
3. 你填 API 地址、模型 ID、金鑰，系統會驗證；
4. 高階配置可選：上下文視窗、工具呼叫輪數、是否支援圖片、思考模式、Temperature 等。

常用組合速查：Claude-4 = Anthropic 格式 + Claude-4 系列；GPT-5 = OpenAI 格式 + GPT-5 系列；GLM/DeepSeek/Kimi = OpenAI 格式 + 對應系列。

你金鑰只填在客戶端設定裡，別寫進任務說明或分享的檔案。

## 省積分習慣清單

- [ ] 一個任務一個主題，無關內容你新開任務（避免重放舊上下文）
- [ ] 你先用便宜模型跑通流程，最後一步再切旗艦潤色
- [ ] 任務說明你寫清輸出格式，減少返工輪次
- [ ] 長檔案你先讓 AI 出大綱，確認後再全文展開
- [ ] 定時任務你跑前先手動跑通一次，避免無人值守時反覆失敗燒積分

## 新手常見問題

通用積分和 Work 專屬積分能混用嗎？
不能隨便混。你消耗順序優先有效期最短的，同期 Work 專屬優先於通用，獎勵積分優先於會員積分——你不用手動排，系統按這順序扣。

Lite 檔為什麼不夠用？
Lite 只有 Work 專屬積分，你如果同時用 TraeCode 程式設計，那邊的額度就用不了。你兩個都要，直接上 Pro。

接自己的模型真的不耗積分嗎？
對。你自定義模型在本地環境跑，不扣 TRAE 積分。但注意它僅桌面版、僅本地環境可用，雲端任務還是走內建模型計費。

增購積分有什麼坑？
增購（¥50/1000）全是通用積分，且只有付費會員能買。你會員過期後，還在有效期的增購積分照常用，但沒法再買。

怎麼最省？
你日常用 Auto 或 Seed-2.1-Turbo（2.5 折）跑量，關鍵交付再切旗艦；任務說明寫清格式、長檔案先出大綱，都能少返工、少燒錢。
