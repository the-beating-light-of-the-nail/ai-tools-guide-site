# 進階：模型管理與積分避坑

TraeWork 按"積分"計費，模型選擇直接影響消耗速度。這一章把官方計費文件裡最容易踩的坑整理成一張避坑地圖。

> 官方文件：[work_models](https://docs.trae.cn/work_models) ｜ [ide_plans-and-billing](https://docs.trae.cn/ide_plans-and-billing)。**價格與套餐截至 2026-08-31，以 [trae.cn/pricing](https://www.trae.cn/pricing) 實時資訊為準。**

## 兩種積分，先分清

| | 通用積分 | Work 專屬積分 |
| --- | --- | --- |
| 適用範圍 | TraeCode + TraeWork 均可用 | **僅 TraeWork** |
| 來源 | Pro / Pro+ / Ultra 會員、增購、註冊禮包、簽到等活動 | Lite 會員、註冊禮包、每日簽到、邀請 |

消耗規則要點：

- 僅呼叫 **TRAE 內建模型**消耗積分，呼叫自定義模型不消耗；
- TraeWork 的消耗順序：**優先有效期最短的 → 同期 Work 專屬優先於通用 → 獎勵積分優先於會員積分**；
- Seed-2.1-Turbo 和 Seed-Code 計費享 2.5 折（各檔會員均含）。

## 套餐速覽（國內版）

| | Lite | Pro | Pro+ | Ultra |
| --- | --- | --- | --- | --- |
| 單月 | ¥49 | ¥99 | ¥239 | ¥699 |
| 連續包月 | ¥45（首月 ¥9.9） | ¥89（首月 ¥59） | ¥219 | ¥629 |
| 積分/月 | 2000 Work 專屬 | 4000 通用 | 12000 通用 | 40000 通用 |
| 雲端並行 | 2 | 10 | 10 | 20 |

免費使用者：每月登入贈 500 通用積分 + 每日簽到 200 Work 專屬 + 新使用者註冊 2000+2000 禮包。

**避坑點**：

1. **Lite 只有 Work 專屬積分**——如果你同時用 TraeCode 程式設計，買 Lite 會發現程式設計那邊用不了，直接上 Pro；
2. 增購積分（¥50/1000）全是通用積分，且**僅付費會員可購**；會員到期後仍在有效期內的增購積分可繼續用；
3. **不支援降檔**，週期結束後才能改訂更低檔；升級差價按未使用比例折算；
4. 因敏感詞攔截、底層模型報錯或死迴圈導致的失敗可退積分，本地報錯（如磁碟滿）不退。

## 模型怎麼選

Work 模式內建模型（節選）：Seed-2.1-Pro / Seed-2.1-Turbo、GLM-5.3 / GLM-5.2、DeepSeek-V4-Pro / V4-Flash、Kimi-K3 / K2.7-Code、MiniMax-M3、Qwen3.8-Max 等。標註 `*` 的旗艦模型僅 Pro+ / Ultra / Express 會員可用。

實用策略：

- **日常任務**：預設 Auto Mode（綜合速度、效能與資源佔用自動選模型）或標準檔模型；
- **省錢跑量**：Seed-2.1-Turbo（2.5 折）+ 明確、簡短的任務說明（Token 少，消耗低）；
- **重要交付**：關鍵報告、複雜分析切旗艦檔，一次做對比反覆返工省。

## 接入自己的模型（不耗積分）

設定 > 模型 > 「新增模型」（**僅桌面版**，且自定義模型僅本地環境可用）：

1. 選預設服務商（按量計費 / Coding Plan / Agent Plan）或「自定義模型」；
2. API 格式二選一：**OpenAI Chat Completions 格式**（相容 OpenAI、DeepSeek、Kimi、GLM、OpenRouter 等）或 **Anthropic Messages 格式**（Claude 系）；
3. 填 API 地址、模型 ID、金鑰，系統會驗證；
4. 高階配置可選：上下文視窗、工具呼叫輪數、是否支援圖片、思考模式、Temperature 等。

常用組合速查：Claude-4 = Anthropic 格式 + Claude-4 系列；GPT-5 = OpenAI 格式 + GPT-5 系列；GLM/DeepSeek/Kimi = OpenAI 格式 + 對應系列。

> 金鑰只填在客戶端設定裡，不要寫進任務說明或分享的檔案。

## 省積分習慣清單

- [ ] 一個任務一個主題，無關內容新開任務（避免重放舊上下文）
- [ ] 先用便宜模型跑通流程，最後一步再切旗艦潤色
- [ ] 任務說明寫清輸出格式，減少返工輪次
- [ ] 長文件先讓 AI 出大綱，確認後再全文展開
- [ ] 定時任務跑前先手動跑通一次，避免無人值守時反覆失敗燒積分
