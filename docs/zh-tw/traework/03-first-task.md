# 第一個任務怎麼跑通？從一句話拿到能交的活

你剛裝好 TraeWork，介面乾乾淨淨，輸入框在中間閃著遊標。你手頭其實有材料——一份要統計的銷售表、幾個散落的檔案——可你就是不知道第一句該敲什麼。要是複製進聊天框自己寫，那又繞回老路：AI 替的活最後還是你幹。

這單別想複雜。你走一遍完整流程：發起、觀察、驗收、分享。跑完這一圈，就明白它和聊天 AI 到底差在哪。

## 發起任務：選好專案，再發指令

你先在主介面對話方塊裡選一個專案。網頁版圖省事你也可以不選，直接發指令，系統會自動建一個專案，還按你指令裡的關鍵詞起名字。

然後把任務指令寫進去——文字或語音都行——點傳送。

輸入框還能補上下文，你往裡塞這些：附件（.pptx、.xlsx 這些）、圖片、斜槓命令（那個「/」）、技能。你材料給得越齊，它跑偏的機率越低。

第一次別搞複雜。你拿下面這段直接發，把檔名換成你自己的就行：

```text
讀取我上傳的銷售資料.xlsx，按產品線統計本月銷售額和毛利率並排名，
輸出一份 Excel 彙總表和一段 200 字的結論摘要。
要求：數字必須與原始檔一致，不要推測原因，無法確認的標註待核實。
```

## 觀察它怎麼幹：工具面板

你點介面右上角的「展開工具面板」，就能看見 AI 幹活的全過程。它會按模式給你不同頁籤：

| 頁籤 | 可用模式 | 用途 |
| --- | --- | --- |
| 任務摘要 | Work / Design：待辦、任務產物、參考資訊；Code：待辦、上下文 | 看拆解出的步驟與產物 |
| 瀏覽器 | 全模式 | 預覽 AI 產物、驗證視覺與互動 |
| 終端 | Code | 執行終端命令 |
| 畫布 | Design | 預覽/整理產物、匯出設計檔案 |

你不用盯死每一行，但得確認它「先讀材料、再動手」——這是你驗收的前置判斷。

## 驗收與修改：三種改法

Web 應用類的活幹完，會自動開啟預覽頁籤。你看不對，有三種方式讓它改：

1. 直接修改：你點右上角「選擇元素」，選中要改的，在「設計」或「CSS」面板裡改屬性。注意手動編輯只支援文字類元素，字號、加粗、對齊這些能調。
2. 評論到對話：你填一句修改意見，連著選中的元素一起發給 AI 處理。
3. 截圖修改：你截下某個元素或區域，用矩形或箭頭標一下，填意見發過去。也能加到評論列表裡批次發。

HTML 產物（需求檔案、產品原型、分析報告這類）還有個省心功能：原型與檔案聯動。你改了原型某一塊，PRD 檔案裡對應的內容會跟著同步更新。

## 管任務、管產物

你做好的東西得找得到、管得住。你點左側工作列裡懸浮的「更多操作」，或者對話面板頂部任務名旁邊，能置頂、看任務檔案（列表或樹狀）、新建、重新命名、刪除。介面左上角的搜尋圖示是全域性搜尋，跨模式找任務或 Query 都行。

產物集中放在左側導航「我的檔案」——本地產物、雲端產物、飛書雲檔案都在一塊管。卡片上的「···」選單能置頂、「在任務中開啟」（繼承原對話上下文接著改）、分享、下載（只雲端產物有）、刪除。你注意：刪除會連帶刪掉對應的原始任務，而且不可恢復。

## 分享給同事

你做出好結果想給人看，點對話流裡懸浮的 Query 或答覆的「分享」，或者左側任務列表右擊任務選「分享」，勾選要分享的內容，兩種形式挑：

- 生成圖片：複製或下載，適合貼群、貼檔案；
- 分享連結：生成連結和二維碼。

## 任務說明怎麼寫：六要素

和所有任務型 AI 一樣，TraeWork 交的活好不好，全看任務說明寫沒寫清。記六個要素就行：

| 要素 | 要回答的問題 |
| --- | --- |
| 目標 | 最終要解決什麼問題 |
| 輸入 | 使用哪些檔案、目錄或連結 |
| 動作 | 分析、整理、轉換還是生成 |
| 約束 | 哪些不能改，採用什麼規範 |
| 輸出 | 交付什麼檔案，放到哪裡 |
| 驗收 | 用什麼標準判斷合格 |

第一次不熟沒關係。左側導航頂部有模板庫，裡面按場景備好了任務說明、執行步驟和交付要求，你點「做同款」補點背景素材就能直接發。

## 新手常見問題

發起任務必須選專案嗎？
不強制。網頁版你可以不選，直接發指令，系統會自動建專案並按關鍵詞命名。桌面版建議選一下，方便後面歸類找。

工具面板的頁簽為什麼有時沒有？
頁籤是按模式給的。「終端」只在 Code 模式有，「畫布」只在 Design 模式有。全模式都有的是「任務摘要」和「瀏覽器」。

刪除產物會把任務也刪了嗎？
會。卡片「···」選單裡的刪除，會連帶刪掉對應的原始任務，而且不可恢復。你刪之前先下載或分享留底。

手動改只能改文字嗎？
對。直接修改（選擇元素 + 設計/CSS 面板）目前只支援文字類元素，字號、加粗、對齊能調。你複雜佈局還是交給 AI 改更穩。

模板庫適合什麼時候用？
第一次不熟、懶得從頭寫任務說明時，你點「做同款」補素材直接發，最省事。
