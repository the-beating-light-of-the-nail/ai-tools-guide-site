# 第一個任務：從一句話到交付物

裝好之後，用一次完整的任務流走一遍：發起 → 觀察 → 驗收 → 分享。以 Work 模式為主線。

## 發起任務

1. 在主介面對話方塊中**選擇一個專案**（網頁版也可以不選直接發指令，系統會自動建立專案並按指令關鍵詞命名）；
2. 輸入任務指令——文字或語音都行；
3. 傳送。

輸入框還能補充上下文：附件（.pptx、.xlsx 等）、圖片、斜槓命令（`/`）、技能。

一個適合第一次跑的任務示例：

```text
讀取我上傳的銷售資料.xlsx，按產品線統計本月銷售額和毛利率並排名，
輸出一份 Excel 彙總表和一段 200 字的結論摘要。
要求：數字必須與原始檔一致，不要推測原因，無法確認的標註待核實。
```

## 觀察執行：工具面板

介面右上角「展開工具面板」是觀察 AI 幹活的地方，按模式提供不同頁籤：

| 頁籤 | 可用模式 | 用途 |
| --- | --- | --- |
| 任務摘要 | Work / Design：待辦、任務產物、參考資訊；Code：待辦、上下文 | 看拆解出的步驟與產物 |
| 瀏覽器 | 全模式 | 預覽 AI 產物、驗證視覺與互動 |
| 終端 | Code | 執行終端命令 |
| 畫布 | Design | 預覽/整理產物、匯出設計檔案 |

## 驗收與修改產物

Web 應用類產物開發完成後會自動開啟預覽頁籤。修改產物有三種方式：

1. **直接修改**：點右上角「選擇元素」→ 選中元素 → 在「設計」或「CSS」面板改屬性（手動編輯僅支援文字類元素，可調字號、加粗、對齊）；
2. **評論到對話**：填修改意見，連同所選元素髮給 AI 處理；
3. **截圖修改**：擷取元素或區域 → 可用矩形/箭頭標記 → 填修改意見 → 發給 AI（也可新增到評論列表批次發）。

HTML 產物（需求文件、產品原型、分析報告）支援**原型與文件聯動**：修改原型某部分後，PRD 文件中對應內容會同步更新。

## 管理任務與產物

- **任務管理**：左側工作列懸浮「更多操作」（或對話面板頂部任務名旁）→ 置頂、檢視任務檔案（列表/樹狀）、新建/重新命名/刪除；
- **全域性搜尋**：介面左上角搜尋圖示，跨模式查詢任務或 Query；
- **產物空間**：左側導航「我的檔案」，集中管理本地產物、雲端產物和飛書雲文件。卡片「···」選單可置頂、「在任務中開啟」（繼承原對話上下文繼續編輯）、分享（生成公開連結，產物更新後同一連結仍可看最新版）、下載（僅雲端產物）、刪除（**會連帶刪除對應原始任務，不可恢復**）。

## 分享對話

做出好結果想給同事看：對話流中懸浮 Query/答覆點「分享」圖示（或左側任務列表右擊任務選「分享」）→ 勾選要分享的內容 → 兩種形式：

- **生成圖片**：複製或下載，適合貼群、貼文件；
- **分享連結**：生成連結和QR Code。

## 任務說明怎麼寫

和所有任務型 AI 一樣，TraeWork 的產出品質由任務說明決定。六要素：

| 要素 | 要回答的問題 |
| --- | --- |
| 目標 | 最終要解決什麼問題 |
| 輸入 | 使用哪些檔案、目錄或連結 |
| 動作 | 分析、整理、轉換還是生成 |
| 約束 | 哪些不能改，採用什麼規範 |
| 輸出 | 交付什麼檔案，放到哪裡 |
| 驗收 | 用什麼標準判斷合格 |

第一次不熟練？左側導航頂部有**模板庫**，按場景提供預設好任務說明、執行步驟和交付要求的模板，點「做同款」補齊背景素材即可直接發起。
