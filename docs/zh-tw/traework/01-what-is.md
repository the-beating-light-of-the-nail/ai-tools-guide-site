# TraeWork 是什麼？第一次用之前看這篇

如果你聽過 Trae，八成是從寫程式碼的朋友那兒聽來的——那是 TraeCode，給程式設計師用的程式設計工具。

TraeWork 是字節跳動 2026 年 6 月釋出的另一條產品線：給不寫程式碼的人用的 AI 原生工作臺，官方口號「讓 TRAE 為你工作」。你說一句「把這份銷售資料做成帶圖表的週報」，它自己拆步驟、調工具，交回檔案、資料包告、演示稿或網頁——而不是甩給你一段文字，讓你自己去弄。

> 官方產品頁：[trae.cn/work](https://www.trae.cn/work) ｜ 官方檔案：[docs.trae.cn](https://docs.trae.cn/work_what-is-trae-work)

## 和 TraeCode（Trae IDE）什麼關係

| | TraeCode | TraeWork |
| --- | --- | --- |
| 給誰用 | 開發工程師 | 產品、運營、資料分析這些非開發崗 |
| 幹什麼 | 寫程式碼、除錯、管程式碼庫 | 檔案、資料、演示稿、調研、自動化 |
| 一句話 | 程式設計師的 AI 程式設計工具 | 辦公人的 AI 工作臺 |

你先弄清兩個容易誤會的地方：

- TraeWork 由 TraeCode 的 SOLO 模式能力發展而來，但你不用裝 TraeCode 也能直接用；
- 兩者同屬 TRAE 賬號體系，積分怎麼互通，見[模型與積分避坑](/zh-tw/traework/adv-models-credits)。

本站只講 TraeWork；程式設計師用的 TraeCode 不在覆蓋範圍，不用操心。

## 三種模式，你只用管一個

你開啟介面，左上角就能在 Work / Code / Design 三種模式間切換。第一次用不用糾結——辦公場景就在 Work 模式待著，這也是本教程的主線。Code 是寫程式碼的，Design 是做設計的，用不上就當沒看見。

## 手機、網頁、桌面，先裝哪個

- 網頁版（[work.trae.cn](https://work.trae.cn/)）：你用瀏覽器開啟就能用，免安裝、不佔本地資源。臨時有需求、外出、想先試試手的，從這兒開始；
- 桌面版：你到 [trae.cn](https://www.trae.cn/) 下載中心拿安裝包（macOS / Windows），本地和雲端兩種執行環境都支援，長期使用裝這個；
- 手機 App：你到應用商店搜「TRAE」。它不是縮小版工作臺，定位是「跨裝置的任務下發中心」——通勤路上派任務、看進度、收結果。注意：手機端只有 Work 和 Code 模式，沒有 Design。

三端共用同一套賬號和任務資料，即時同步。典型玩法是：你地鐵上用手機派個活，雲端沙箱或家裡電腦執行，結果推回手機。

## 它能幹的活

- 任務自動執行：你提目標，它拆步驟、調技能和工具，你驗收；
- 辦公助理：你繫結飛書 / 微信，在聊天窗裡直接派活（見[辦公助理](/zh-tw/traework/05-bot-assistant)）；
- 外部應用授權：你授權後它直接操作飛書雲檔案、多維表格、日曆、GitHub；
- 外掛市場：飛書、騰訊檔案、同花順 iFinD、通達信、Remotion 影片等熱門外掛；
- 自動化任務：定時的資訊彙總、週報、競品監控，到點自動跑；
- 技能（Skills）：你給 AI 裝「崗位說明書」，按需載入（見[Skills](/zh-tw/traework/04-skills)）；
- 電腦 / 瀏覽器控制：授權後讓它替你操作介面、填表單、抓資料；
- 語音討論：聊著把需求定下來，會後它自動轉成清洗過的結構化紀要。

## 和本站其他工具什麼關係

WorkBuddy（騰訊）、QoderWork（阿里）和 TraeWork 定位接近，都是「任務委派 + 技能 + 定時 + IM」這套打法，細節各有取捨。你辦公場景可以都裝上，按手感留一兩個，很多功能章節能對照著看。

## 新手常見問題

**免費嗎？**
註冊就送：你新使用者一次性拿 2000 通用積分 + 2000 Work 專屬積分（31 天有效），另有每日簽到、每月登入送積分的活動。積分怎麼扣、扣完怎麼辦，見[模型與積分避坑](/zh-tw/traework/adv-models-credits)。

**不裝 TraeCode 能用嗎？**
能。TraeWork 是獨立應用，你用網頁版的話連裝都不用裝。

**手機上能幹活嗎？**
能派活、看進度、收結果，重活由雲端或電腦執行。把手機端當遙控器，別當主機。
