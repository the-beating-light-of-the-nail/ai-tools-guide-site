# TraeWork 常用指令模板怎麼抄？拿來即用

你盯著空白的任務框，最怕的不是不會寫，而是不知道從哪句開頭。這篇把高頻場景的提示詞打包好，你拿去改改檔名、填填空就能發。寫法要點回顧：六要素（目標/輸入/動作/約束/輸出/驗收）見[第一個任務](/zh-tw/traework/03-first-task)。【】裡的替成實際內容。

## 檔案類

### 檔案速讀

```text
幫我看看【檔名/附件】主要寫了什麼內容，按主題歸納，標註我需要重點關注的 3 個問題。
```

### 週報生成

```text
幫我最佳化【工作總結檔案】，按照本週結論、關鍵進展、下週計劃寫週報：
結論用一句話說清本週最值得彙報的成果；關鍵進展列 3-5 條（做了什麼、帶來什麼結果）；
下週計劃 2-3 條（要推進的事、需要的支援）。
```

### 寫入飛書並推送

```text
把剛才的【週報/紀要/報告】寫入飛書檔案，併傳送到【群名】。
```

### 兩版檔案對比

```text
比較【檔案A】與【檔案B】，輸出新增、刪除、修改三類差異，
重點標記金額、日期、責任主體和審批條件，生成待確認問題清單，不修改原檔案。
```

## 資料類

你拿到表格要分析，別讓它瞎編數字，先框死口徑。

### Excel 分析

```text
讀取【資料檔案.xlsx】，先不要修改原檔案。
業務問題：【要回答的問題，如各產品線本月表現】。
輸出：欄位說明與髒資料檢查、按【維度】統計的核心指標、圖表、
3 條可直接用於復盤的結論。
要求：數字與原始檔一致，無法確認的標註待核實。
```

### 資料看板

```text
做一個【週期】資料看板：最上面是【核心指標】總覽，
下面是【維度】趨勢圖、漏斗圖和對比圖，圖表可互動。
```

## 彙報類

### 述職報告

```text
根據我的工作記錄整理一份述職報告。要求：
1. 工作內容歸類、合併、去重，不寫流水賬
2. 提煉 3-5 項核心業績，按"背景—行動—結果—價值—個人貢獻"展開
3. 優先用資料和前後對比，區分團隊成果與個人貢獻
4. 不得虛構資訊
5. 輸出：述職總結、核心業績、能力沉澱、問題復盤、下一階段計劃
崗位：【崗位】 述職週期：【週期】 工作記錄：【@檔案】
```

### 做 PPT（方法論版，見案例篇）

```text
請先不要生成 PPT。先分析【材料】，提取核心主張和論證骨架，
整理一份 memo 和 10 頁左右的 slide plan，每頁只保留一個 claim。
輸出後停住，等我確認。
```

## 自動化類

你想讓 AI 定時跑，提示詞要比平時寫得細——沒人半夜替你補話。

### 定時資訊彙總

```text
【工作日早上 9 點】，收集過去 24 小時內與【主題】相關的公開報道，
按【分類維度】分類，標註來源連結；有效資訊少於 3 條時輸出說明；
輸出 Markdown 存到【目錄】。
```

### 輿情週報

```text
每週一上午 9 點，彙總上週與【公司/產品】相關的報道和社媒討論，
輸出"媒體報道 / 使用者反饋 / 競品動態"三欄週報，標註情感傾向和來源。
```

## 電腦控制類

你讓 AI 動介面，安全弦要繃緊：填完停在提交頁等人確認。

### 填表單（安全版）

```text
幫我填寫【表單名/網址】表單，資訊來自【附件】。
填完後停留在提交頁等待我確認，不要點選提交。
```

### 按模板批次處理

```text
複製【模板】檔案，將【欄位】替換為每條記錄的對應資料，
逐條處理後儲存到 output/ 目錄，最後輸出處理清單。
不要傳送或釋出任何產物。
```

## 流程類

你跑長任務，先用工作流把步子框住再放手。

### Plan 模式（先看計劃）

```text
/plan 整理【目錄】下的【N】份檔案：先給出你的計劃（分幾步、動哪些檔案、
怎麼命名），我確認後再執行。
```

### Goal 模式（目標續跑）

```text
/goal 把【目錄】下所有【檔案型別】轉換為【目標格式】，
每完成 10 個抽查 1 個，全部完成且抽查通過後停止。
```

## 新手常見問題

模板裡的【】怎麼處理？
你把它們替成實際內容就行，比如【檔名】換成你那份檔案。別連【】一起發，AI 會當佔位符理解。

六要素一定要寫全嗎？
你第一次寫建議寫全，跑順了可以精簡。目標、輸入、約束、驗收這四樣最不能省，漏了它容易瞎編。

自動化模板為什麼格外長？
你定時任務是無人值守的對話，沒人半夜補話。資料來源、路徑、異常處理都得寫死，否則一跑就卡。

電腦控制的模板為什麼要「等待我確認」？
你讓 AI 填表單，停在提交頁等人確認最穩，別讓它自己點提交，出錯了難撤回。

資料類別範本怎麼防 AI 編數？
寫明「數字與原始檔一致，無法確認的標註待核實」，它就不敢補寫。髒資料和口徑先框清。
