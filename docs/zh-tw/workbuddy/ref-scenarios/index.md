# 不知道該用哪個功能？按人群和場景一張表查到你該去哪

你開啟 WorkBuddy，看著一堆功能不知道從哪下手——這很正常。這張表就是給你這種「知道要幹啥、但不知道點哪個」的人用的。你按「你是誰」或「你想做什麼」兩路查，找到場景，對照推薦入口和人工檢查點，直接跳過去。你不用通讀全站，查到就能用。你越急著找功能，越該先看清自己屬於哪類人。

| 安排、修改或取消騰訊會議 | 騰訊會議 Skill | 主題、時間、時區、參會人和取消範圍 |

## 知識管理速查

你做知識沉澱、剪藏、復盤時，入口和該留意的邊界列在這裡。你挑對應動作，看建議入口和檢查點。你別讓 AI 自動擴寫你的原話，保留原意比看起來工整更重要。

| 我想做什麼 | 建議入口 | 人工檢查點 |
| --- | --- | --- |
| 隨口記錄一個想法 | 靈感捕手、ima | 保留原話，不自動擴寫成事實 |
| 微信檔案進入知識庫 | ima-skills | 目標庫、權限、重複與隱私 |
| 微信收藏批次整理 | 微信收藏知識庫 | 抓取失敗、來源、版權與重複 |
| 整理 WPS 檔案和碎片筆記 | WPS 知識庫、kdocs skill | Key、測試目錄、分享權限 |
| 建本地 Obsidian Wiki | LLM-Wiki 中文版 | Vault 備份、命名與批次寫入 |
| 網頁轉 Obsidian 筆記 | url-to-obsidian | 來源、日期、版權和原始連結 |
| 會議沉澱為專案記憶 | 紀要 + 知識庫 Skill | 事實、決策、推測和待辦分開 |
| 把知識變成自媒體內容 | 證據包 + 內容 Skill | 事實版本、引用和版權 |
| 定期清理知識庫 | Wiki 體檢、斷鏈和重複檢查 | 不自動刪除或合併人工筆記 |

你整理知識時，最該守的規矩是「原話不丟、來源留痕」。你讓 AI 當搬運和索引，不當替你改寫大腦的角色。

## 常見問題

**我該從哪張表開始查？**
你先按「人群速查」對號入座，找到自己這個崗位通常從哪起步；具體要幹某件事，再翻對應的場景速查表。兩路你都能用。你今天只想查一個動作，直接看場景速查就行。

**表裡的「人工檢查點」是什麼意思？**
意思是這事 AI 能幫你做，但上線前得你自己盯一眼。比如合併 Excel 你要核對主鍵和金額守恆，發公眾號你要確認賬號和移動預覽。你把檢查點當成驗收清單，別跳過。

**生活服務類 Skill 有什麼要注意的？**
健康類不診斷不開藥，急症轉線下；卜卦類標明瞭是娛樂，你別拿去做現實高風險決定。你用之前看清檢查點，涉及身體的事以線下為準。

**為什麼有些場景跳的是本站章節，有些是官方 SkillHub？**
本站聚焦辦公場景，所以辦公、知識、自媒體、影片這些有專章；研發、日常生活這類不在本站範圍，你直接去官方 SkillHub 檢索更全。你找 Skill 時認準官方入口，別裝來路不明的包。
