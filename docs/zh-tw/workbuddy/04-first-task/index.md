# WorkBuddy 第一單怎麼跑？八步走完拿到能交的彙報

你盯著空蕩蕩的 WorkBuddy 介面，材料其實都齊了——一份電商銷售表格、幾份零散檔案——可你就是不知道第一句該敲什麼。複製進聊天框自己寫？那又繞回老路了，AI 替的活最後還是你幹。這單別想複雜，就做一份「分析銷售資料、生成簡報 PPT」。你跟著下面八步走，跑完這一圈，你就明白它和聊天 AI 到底差在哪。

## 八步把第一單跑通

1. 你點「新建任務」。

![點選「新建任務」入口](/workbuddy/04-first-task/assets/001_image_C4q3bdNKso.png)

2. 你選擇或建立一個獨立的工作目錄。

*PS：WorkBuddy 採用資料夾級授權與高危攔截，首次操作請先在演練目錄進行、留意授權範圍，處理真實業務資料前謹慎確認*

![選擇或建立獨立工作目錄](/workbuddy/04-first-task/assets/002_image_GeeybIFZLo.png)

3. 你判斷該用哪種模式，預設是 Craft，也可以設成 Ask 或 Plan。

![選擇工作模式：Craft、Ask 或 Plan](/workbuddy/04-first-task/assets/003_image_DZ55bxbCvo.png)

4. 你選擇模型，可以指定想用的模型，不同模型積分消耗不同。

![選擇任務使用的模型](/workbuddy/04-first-task/assets/004_image_JiigbkdTKo.png)

5. 你在輸入框寫下任務說明，比如：「幫我分析一下《電商銷售資料.xlsx》資料，生成一份簡報 PPT。」

![在輸入框寫下任務說明](/workbuddy/04-first-task/assets/005_image_ReDxbwNkYo.png)

6. 如有必要，你再指定 Skill、專家、連接器或資料庫，這一單先忽略它們。

![可選：指定 Skill、專家、連接器](/workbuddy/04-first-task/assets/006_image_INLGb7TDQo.png)

7. 你點傳送，然後觀察它的計劃、工具呼叫和檔案變更。

![傳送後觀察執行計劃與工具呼叫](/workbuddy/04-first-task/assets/007_image_BD1FbDdcEo.png)

8. 你在結果區預覽產物並驗收。

檔案可以本地開啟、上傳雲端、或分享，注意分享前先確認產物不含敏感或涉密資訊，按公司規範選擇共享範圍。

![結果區預覽生成的簡報 PPT 並驗收](/workbuddy/04-first-task/assets/008_image_TzOAb2lxIo.png)

## 任務說明怎麼寫才不像白話

你發任務前，先把要說的話拆成六要素。六要素齊了，它才知道往哪使勁，也不會自作主張。

| 要素 | 要回答的問題 |
|-|-|
| 目標 | 最終要解決什麼問題 |
| 輸入 | 使用哪些檔案、目錄或連結 |
| 動作 | 需要分析、整理、轉換還是生成 |
| 約束 | 哪些不能改，採用什麼規範 |
| 輸出 | 交付什麼檔案，放到哪裡 |
| 驗收 | 用什麼標準判斷合格 |

下面三段提示詞你直接抄去發就行，把檔名換成你自己的。

### 入門任務 A：整理檔案

```text
目標：整理 input 目錄中的練習檔案，便於按型別查詢。
輸入：僅處理當前工作區的 input 目錄。
動作：識別檔案型別，提出分類和重新命名方案。
約束：不刪除、不覆蓋原檔案；重名時保留兩份並標記序號。
輸出：先生成 inventory.xlsx 和 proposed-actions.md。
驗收：清單檔案數與 input 實際檔案數一致，所有動作可追溯。
在我確認 proposed-actions.md 前，不移動檔案。
```

### 入門任務 B：生成會議紀要

```text
請把 input/meeting.txt 整理為結構化會議紀要。
必須包含：會議結論、待辦事項、負責人、截止日期、待確認問題。
不能從原文確認的負責人或日期寫“待確認”，不要自行補全。
輸出 output/會議紀要.md 和 output/待辦清單.xlsx。
驗收：每一項結論可以在原文找到依據；待辦不遺漏負責人和時間狀態。
```

### 入門任務 C：Word 轉 PPT

```text
把 input/專案彙報.docx 轉成 10 頁以內的內部簡報 PPT。
受眾：部門負責人；彙報時長：8 分鐘。
保持原文事實和數字，不新增未經證實的資料。
結構：背景、現狀、問題、方案、計劃、需要決策。
使用 reference/brand-guide.pdf 中的顏色與字型規範。
輸出 output/專案彙報_v1.pptx，同時提供逐頁內容清單。
驗收：每頁只有一個核心觀點，數字與原文一致，正文在投影狀態可讀。
```

## 新手常見問題

**第一單一定要用獨立工作目錄嗎？**
強烈建議。WorkBuddy 是資料夾級授權，獨立目錄能把權限框住，避免它誤讀誤改別的資料。你在演練目錄先跑一遍更穩妥。

**模式預設 Craft，新手會不會太危險？**
Craft 會直接動本地檔案。你第一單如果沒把握，建任務時把它改成 Ask（只看不動）或 Plan（先看方案），等熟悉了再用 Craft。

**任務說明寫多長才夠？**
不用長，但要全。把上面六要素（目標、輸入、動作、約束、輸出、驗收）說清，比寫一大段流水賬管用。上面三段模板你改改檔名就能發。

**它生成的東西能直接發出去嗎？**
先驗收再分享。檔案可以本地開啟、上傳雲端或分享，但分享前你務必確認產物不含敏感或涉密資訊，並按公司規範選共享範圍。
