# 第 18 章 把投資分析變成你的日常

投資是一件高度資訊密集、強結構化、又極度依賴判斷的事：讀不完的財報、理不清的行業、吵不停的多空。整理碎片資訊、拆解複雜材料、把思考過程擺到檯面上，恰好是 AI 擅長的。本章講在一次完整的股票研究裡，AI 能替你做掉哪些低質量的重複勞動，把精力還給判斷本身。

> **風險提示：本章所有提示詞、Skill 與案例均以"輔助研究"為目的，不構成任何投資建議。股市有風險，投資需謹慎。**

## 先想清楚：AI 在投資裡該幹什麼

多數人對"AI 炒股"的想象是讓它預測漲跌。但從真實的高頻用法看，有價值的用法集中在四類：

- 讀不完的財報，幫我總結；
- 行業太複雜，幫我把邏輯理一遍；
- 市場吵得太兇，幫我把多空觀點放進一張表；
- 我怕自己自嗨，幫我找反證。

這四類都不是"預測漲跌"，而是**減少低質量思考的時間**。AI 在投資裡最合理的位置，是一個不知疲倦、不帶情緒、隨叫隨到的研究助理——它負責把事實底座打牢，把判斷留給你。

動手前，和[辦公三件套](/zh-tw/workbuddy/case-office/)一樣先用五個問題定標：

| 問題 | 要說清什麼 | 示例 |
| --- | --- | --- |
| 目標 | 這次研究要支撐什麼決定 | 判斷是否納入觀察池，還是決定當下加減倉 |
| 標的 | 具體哪家公司、哪個行業 | 天孚通訊（300394），光通訊 / CPO 板塊 |
| 材料 | 哪些是事實來源，哪些只是參考 | 年報、三季報、券商研報是事實來源；股吧觀點只作情緒參考 |
| 深度 | 只要事實梳理，還是到估值和多空推演 | 先做事實底座，再上盡調級 DeepResearch |
| 驗收 | 怎麼判斷結果可用 | 每個判斷都能追到資料來源，事實與觀點分開標註 |

## 金融場景的 Skill 組合

| Skill | 適合處理 | 本章怎麼用 |
| --- | --- | --- |
| `stock-advisor` | 單隻股票的端到端分析 | 上傳截圖或給出程式碼，自動跑完技術面、基本面、交叉驗證、私董會、排版 |
| `a-share-analyst` | A 股日常行情與選股 | 實時行情、技術指標、量化選股、每日報告 |
| `financial-expert` | 金融資料查詢與篩選 | 選股、財務指標、宏觀/行業時序、研報檢索（依賴資料來源 MCP） |
| `peers-advisory-group` | 多視角決策討論 | 四位"幕僚"圍繞一個議題交叉辯論 |

搭配思路：**日常盯盤和批次選股用 `a-share-analyst` 與 `financial-expert`；要對一隻票下深功夫、出完整報告，用 `stock-advisor`；需要跳出單一視角、逼自己看反面時，叫上 `peers-advisory-group`。**

## 一套可複用的研究提示詞鏈路

按"最簡單 → 相對複雜"排列，覆蓋從"查資料"到"下判斷"的完整鏈路。先用前三條建立事實底座，需要深挖時再往後走。用法：把 `【】` 裡的佔位換成你的標的，貼上執行。

### Prompt 1｜給公司建一個"事實底座"

很多錯誤判斷從第一步認錯業務就開始——你以為它靠 A 賺錢，結果利潤主要來自 B。這一步壓縮你"搞清楚事實"的時間成本。

```markdown
請幫我係統梳理【XXX 公司】的基礎情況，輸出結構化總結，包括：
1）核心業務與主要產品線
2）收入與利潤來源構成
3）主要客戶與應用場景
4）公司在產業鏈中的位置
5）近幾年最重要的戰略變化

## 要求：
- 只使用可核實的資訊
- 每一部分用 3–5 條要點說明
- 不做投資建議，只做事實整理
```

### Prompt 2｜行業視角：這是不是一個"好行業"

你選的往往不是公司，而是行業。AI 適合做行業的"第一性梳理"，但行業拐點、價格見底這類問題別指望它給答案。

```markdown
請從行業研究的角度，分析【XXX 公司】所在的【XXX 行業】：
1）行業所處的週期階段（復甦/擴張/衰退/蕭條）
2）供需關係與主要驅動因素（產能、開工率、庫存、訂單/交付週期）
3）價格變化機制與歷史波動（價格指數/價差/成本傳導、Capex 趨勢與新增產能）
4）行業集中度與競爭格局
5）影響行業的關鍵外部變數（政策、技術、宏觀）
請明確指出：哪些是長期結構性因素，哪些是短期波動因素。
輸出週期階段判斷 + 關鍵證據圖表清單 + 領先指標(3個)與滯後指標(3個)。
```

### Prompt 3｜業務拆解：錢到底是怎麼賺來的

從"看公司"到"看生意"的關鍵一步。混雜型公司（主業 A、利潤卻來自 B）尤其適合讓 AI 幫你看清楚。

```markdown
請你以【價值投資 / 基本面研究】視角，對【XXX 公司】進行業務拆解，
核心問題：這家公司真正、長期靠什麼賺錢？

## 要求
- 僅基於可驗證資訊（年報、招股書、定期公告、權威行業報告）
- 明確區分【事實】與【判斷】，所有判斷必須給出證據或邏輯鏈

## 必答結構
一、公司"賺錢方式"的一句話結論（不超過 50 字）
二、業務結構全拆解（必須量化）：各業務線的收入佔比、毛利率、增長趨勢；
    哪些業務貢獻大部分利潤；是否存在"主業≠利潤核心"的情況
三、賺錢機制：錢怎麼收（一次性/訂閱/復購）；成本花在哪；毛利率由什麼決定；
    是否具備規模效應
四、客戶、渠道與定價權：核心客戶集中度；是否具備定價權；客戶更換成本
五、非主營利潤：哪些來自投資收益/補貼/資產處置，對長期估值的影響
六、穩定性與脆弱點：哪些假設被破壞，賺錢邏輯就失效；
    用 3–5 條"關鍵監控指標"總結如何持續驗證這門生意是否成立
```

### Prompt 4-7｜財務質量、股權治理、市場分歧、估值護城河

中間四步各解決一個具體問題，提示詞骨架類似（明確要求 + 交叉驗證 + 不給結論）：

```markdown
請分析【XXX 公司】近幾年的財務質量：
1）收入、利潤與經營現金流的匹配情況
2）應收賬款、存貨、合同資產變化
3）非經常性損益對利潤的影響
4）可能需要重點關注的財務風險點
## 研究原則：不預測股價，只判斷財務"質量"；
強制進行"利潤 vs 現金流"的交叉驗證；對所有異常給出解釋假設與驗證路徑。
```

```markdown
請整理市場對【XXX 公司】的主要分歧點：
1）多方核心邏輯  2）空方核心邏輯  3）各自最重要的論據
4）哪些分歧可以被未來資料驗證  5）關鍵驗證節點是什麼
## 分析要求：不得站隊；不給投資建議；所有判斷必須可被未來資料或事件驗證。
```

```markdown
以價值投資視角分析【XXX 公司】的護城河，必須引用公司披露/權威來源：
定價權、轉換成本、網路效應/規模效應、無形資產、競爭反應五個維度逐一給證據。
輸出：護城河強度評分(0-5) + 證據表 + 最可能被侵蝕的點與監控指標。
```

### Prompt 8｜全家桶：一份盡調級 DeepResearch

把前七步的邏輯壓進同一個框架的"投資者盡職調查報告"，強制區分事實與判斷、強制交叉驗證、強制推演空方邏輯與黑天鵝——用來對抗人最容易犯的**確認偏誤**。在各家 AI 的 DeepResearch 模式裡都很好用。骨架：

```markdown
我需要一份投資者盡職調查報告，標的【XXX】，風格【價值投資】，週期【中長線 1-3 年】。

## 研究原則
1. 財務資料涵蓋過去 3-5 年趨勢（CAGR），估值分位回溯過去 5-10 年
2. 區分【事實】與【判斷】，判斷必須基於可驗證資料（年報、招股書、問詢函）
3. 雙重驗證："利潤 vs 現金流"交叉驗證 + "公司 vs 同行"對比驗證
4. 反直覺思考：必須包含空方邏輯與黑天鵝風險推演

## 推演階段
Phase 1 商業模式與護城河拆解（主業賺吆喝、副業賺利潤？）
Phase 2 行業週期與供需格局（庫存、開工率、Capex 為證）
Phase 3 財務健康度掃雷（ROE 杜邦拆解、現金含金量、扣非利潤）
Phase 4 治理結構與資本配置（質押、減持、資本配置能力）
Phase 5 估值邏輯與風險反脆弱（歷史分位、反向 DCF、空方視角）

## 輸出
訊號燈評級（買入/觀望/賣出）+ 關鍵財務資料表 + 五階段正文 +
估值儀表盤 + 未來監控清單（事件 A 強化邏輯 / 資料 B 惡化即證偽退出）
```

## 從提示詞到 Skill：`stock-advisor` 是怎麼長出來的

八條提示詞單獨看都好用，但真要完整研究一隻票：要手動串、換標的重來、資料靠眼睛、決策容易自嗨、交付靠手工。`stock-advisor` 把這條鏈路**從"一堆提示詞"變成"按一次就跑完的流水線"**：

![](/workbuddy/case-investment/assets/001_stock-advisor-overview_Lxy0b4axOo.png)

| 模組 | 做什麼 | 關鍵設計 |
| --- | --- | --- |
| ① 技術面分析 | 從 K 線圖識別形態、均線、MACD，用行情資料交叉驗證 | 影象識別 + 資料雙軌，衝突時以資料為準並標註差異 |
| ② 基本面分析 | 識別財報關鍵指標，補充估值與行業對比 | 技術/基本/資金三面各自打分，再合成評級 |
| ③ 多維交叉驗證 | 聯網檢索研報、行業動態、新聞、政策 | 出現矛盾訊號必須明確標註分歧 |
| ④ 私董會討論 | 呼叫 `peers-advisory-group`，四位幕僚交叉辯論 | 複用現成 Skill，把"找反證"制度化 |
| ⑤ 排版輸出 | 結構化報告，轉雜誌風 HTML / PDF，可上傳飛書 | 複用排版與文件 Skill |

這裡藏著 Skill 創作最值得學的一點：**複用而非重寫**。技術指標指令碼複用 `a-share-analyst`，決策討論複用 `peers-advisory-group`，排版複用 `magazine-layout`——它自己新寫的只有少數幾塊。做一個複雜 Skill，先把已有能力當積木，缺哪塊補哪塊，再用一條主線編排起來。

它還有兩個"產品化"小設計：首次使用建檔（問你風險偏好、投資週期、關注行業、倉位上限，存進記憶）；兩種入口同一條流水線（上傳截圖走影象識別 + 資料驗證，直接給程式碼走純資料驅動）。

一句話：**把"一次嚴肅的股票研究"從半天的手工活，壓縮成一次對話。** 人從"搬運和拼接"變成"拍板和質疑"。

## 實戰：用 `stock-advisor` 跑一遍天孚通訊（300394）

標的是天孚通訊（300394），光通訊 / CPO 板塊。整個過程三步遞進：先看圖、再看財報、最後開一場私董會。

### 第一步：上傳 K 線圖，要一份技術面速讀

```text
我上傳了一隻 A 股的 K 線日線圖和技術指標圖（MACD）。請你作為一位專業的技術分析師：
1. 識別股票資訊：這是哪隻股票？當前股價大約是多少？
2. K 線形態分析：近期呈現什麼形態？近 5 日 K 線的具體表現？
3. 均線系統分析：MA5/MA10/MA20 的排列狀態，最近是否出現金叉或死叉？
4. MACD 分析：DIF 和 DEA 的位置關係，柱狀圖趨勢，是否出現背離？
請以表格 + 文字結合的方式輸出技術面速讀報告。
```

![](/workbuddy/case-investment/assets/003_image_CrgibiDW3o.png)

WorkBuddy 先從圖裡識別出這是天孚通訊，當前股價約 368.70 元，然後給出結構化速讀：MA5 > MA10 > MA20 標準多頭排列仍在主升浪；但當日一根長上影線（最高衝 376.10 回落到 368.70）、MACD 紅柱開始縮短、乖離率偏大；支撐看 MA5（347）/ MA10（319），壓力看當日高點 376。這一步它沒有猜漲跌，而是把"圖裡能讀到的事實"結構化了。

![](/workbuddy/case-investment/assets/004_image_WX6WbFC9Oo.png)

### 第二步：補上財報截圖，做一次全面分析

```text
我又上傳了這隻股票的 2025 年三季度報資料和全年預增資料。請你：
1. 先識別截圖中的所有財務指標資料
2. 結合第一輪的技術面分析，做一次全面的 A 股分析：
   技術面總評、基本面總評（營收增速、盈利能力、估值水平）、資金面觀察、
   綜合評級（強烈推薦/推薦/中性/謹慎/迴避）
3. 給出短期（1-2 周）、中期（1-3 月）的操作建議
4. 明確標註關鍵支撐位和壓力位，按專業研報的格式輸出。
```

![](/workbuddy/case-investment/assets/007_image_CScebfl1io.png)

它先逐條識別截圖裡的財務指標（營收 39.18 億、同比 +63.63%，ROE 31.30%，PE 146.70……），然後合成綜合評級表：

| 維度 | 評分 | 權重 | 加權得分 |
| --- | --- | --- | --- |
| 技術面 | 4.0 / 5.0 | 25% | 1.00 |
| 基本面 | 4.5 / 5.0 | 30% | 1.35 |
| 估值水平 | 2.0 / 5.0 | 25% | 0.50 |
| 資金面 | 4.0 / 5.0 | 20% | 0.80 |
| **綜合評分** | — | — | **3.65 / 5.0** |

最終評級"推薦"，核心結論很剋制：**中期趨勢向好（CPO 高景氣 + 高成長），但短期估值透支、漲幅過大，不宜追高，等回撥再擇機。** 估值太貴就在總分裡扣回來——不會因為成長性好就無腦看多。

![](/workbuddy/case-investment/assets/008_image_I6uBbecypo.png)

### 第三步：拿不定主意，開一場私董會

```text
但我對這隻股票還是拿不定主意。請啟動一場私董會，請四位幕僚討論它是否值得投資：
- 巴菲特：價值投資角度（內在價值、護城河、安全邊際）
- 馬斯克：科技趨勢和顛覆性創新角度
- 比爾·蓋茨：商業模式和行業格局角度
- 喬布斯：產品力和使用者體驗角度
討論要求：每位先各自發表獨立觀點；然後交叉質詢；最後每人一句話給出
買入/持有/賣出的最終建議；你作為主持人綜合意見給出執行方案。
請基於前兩輪的分析資料展開，讓幕僚們"帶著資料聊"。
```

![](/workbuddy/case-investment/assets/011_image_LuArbEta0o.png)

私董會環節系統先聯網更新了資料（2025 全年營收、2026 Q1 環比下滑、和中際旭創/新易盛的橫向對比）——交叉驗證模組把討論從截圖資料推進到了全網最新事實。四位幕僚觀點分裂成 2:2：巴菲特迴避（"PE 142，安全邊際為零"）、蓋茨等待（"等 PE 回到 60 倍以下，或換價效比更高的標的"）、馬斯克 All in（"CPO 是光通訊的 iPhone 時刻"）、喬布斯有條件持有（"前提是 CPO FAU 在 2026 H2 如期兌現"）。

主持人最後綜合出**分投資者型別的執行方案**，並把決策掛到未來驗證節點上：

| 投資者型別 | 建議 | 執行要點 |
| --- | --- | --- |
| 價值投資者 | 堅決迴避 | 等 PE < 40 |
| 成長投資者 | 可持有，需止損 | 跌破 MA5(347) 減倉，跌破 MA10(319) 清倉 |
| 趨勢投資者 | 謹慎參與 | 等回撥至 MA10 / MA20 再介入 |
| 激進投資者 | 小倉位試倉 | 最多 3 成，跌破 300 元清倉 |

## 常見錯誤與使用邊界

| 常見錯誤 | 為什麼錯 | 正確做法 |
| --- | --- | --- |
| 讓 AI 給"買點 / 賣點" | 它不掌握實時全量資訊，也不為你的錢負責 | 只用它做事實梳理和多空推演，買賣自己拍板 |
| 完全相信截圖識別的數字 | 影象識別會看錯，財報口徑也會變 | 關鍵數字交叉驗證 |
| 指望它判斷行業拐點、價格見底 | 依賴前瞻資訊和經驗，AI 給不了 | 讓它梳理"該盯哪些領先指標"，拐點自己盯 |
| 只看多方邏輯，越看越上頭 | 確認偏誤，AI 會順著你的語氣強化觀點 | 用多空分歧提示詞和私董會，強制給反證 |
| 把 AI 報告直接當投資依據 | 報告是研究輔助，不是投資建議 | 結論僅供參考，決策與風險自負 |
