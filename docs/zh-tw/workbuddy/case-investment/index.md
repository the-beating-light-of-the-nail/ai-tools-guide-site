# 怎麼把股票研究變成日常？八條提示詞加 stock-advisor 流水線

你開啟炒股軟體，滿屏紅綠，財報讀不完、行業理不清、多空吵不停。投資這件事又密又依賴判斷。但整理碎片資訊、拆解複雜材料、把思考過程攤開——恰好是 AI 擅長的。這一篇講在一次完整的股票研究裡，AI 能替你幹掉哪些低質量的重複勞動，把精力還給判斷本身。你不用樣樣自己來，先把 AI 擺到研究助理的位置上。

> **風險提示：本章所有提示詞、Skill 與案例均以“輔助研究”為目的，不構成任何投資建議。股市有風險，投資需謹慎。**

## 先想清楚：AI 在投資裡該幹什麼

多數人對「AI 炒股」的想像是讓它預測漲跌。但從真實的高頻用法看，你值得用的價值集中在四類：

- 讀不完的財報，幫我總結；
- 行業太複雜，幫我把邏輯理一遍；
- 市場吵得太兇，幫我把多空觀點放進一張表；
- 我怕自己自嗨，幫我找反證。

這四類都不是「預測漲跌」，而是**減少低質量思考的時間**。AI 在投資裡最合理的位置，是一個不知疲倦、不帶情緒、隨叫隨到的研究助理——它負責把事實底座打牢，把判斷留給你。你動手前，和[辦公三件套](/zh-tw/workbuddy/case-office/)一樣先用五個問題定標：

| 問題 | 要說清什麼 | 示例 |
| --- | --- | --- |
| 目標 | 這次研究要支撐什麼決定 | 判斷是否納入觀察池，還是決定當下加減倉 |
| 標的 | 具體哪家公司、哪個行業 | 天孚通訊（300394），光通訊 / CPO 板塊 |
| 材料 | 哪些是事實來源，哪些只是參考 | 年報、三季報、券商研報是事實來源；股吧觀點只作情緒參考 |
| 深度 | 只要事實梳理，還是到估值和多空推演 | 先做事實底座，再上盡調級 DeepResearch |
| 驗收 | 怎麼判斷結果可用 | 每個判斷都能追到資料來源，事實與觀點分開標註 |

## 金融場景的 Skill 組合

| Skill | 適合處理 | 本章怎麼用 |
| --- | --- | --- |
| `stock-advisor` | 單隻股票的端到端分析 | 上傳截圖或給出程式碼，自動跑完技術面、基本面、交叉驗證、私董會、排版 |
| `a-share-analyst` | A 股日常行情與選股 | 即時行情、技術指標、量化選股、每日報告 |
| `financial-expert` | 金融資料查詢與篩選 | 選股、財務指標、宏觀/行業時序、研報檢索（依賴資料來源 MCP） |
| `peers-advisory-group` | 多視角決策討論 | 四位“幕僚”圍繞一個議題交叉辯論 |

你搭配思路：**日常盯盤和批次選股用 `a-share-analyst` 與 `financial-expert`；要對一隻票下深功夫、出完整報告，用 `stock-advisor`；需要跳出單一視角、逼自己看反面時，叫上 `peers-advisory-group`。** 你挑 Skill 時記一條：別指望一個 Skill 包攬全流程，按需組合才穩。

## 一套可複用的研究提示詞鏈路

你按「最簡單 → 相對複雜」排列，覆蓋從「查資料」到「下判斷」的完整鏈路。你先用前三條建立事實底座，需要深挖時再往後走。你用法很簡單：把 `【】` 裡的佔位換成你的標的，貼上執行。

### Prompt 1｜給公司建一個“事實底座”

很多錯誤判斷從認錯業務就開始——你以為它靠 A 賺錢，結果利潤主要來自 B。你這一步壓縮「搞清楚事實」的時間成本。

```markdown
请帮我系统梳理【XXX 公司】的基础情况，输出结构化总结，包括：
1）核心业务与主要产品线
2）收入与利润来源构成
3）主要客户与应用场景
4）公司在产业链中的位置
5）近几年最重要的战略变化

## 要求：
- 只使用可核实的信息
- 每一部分用 3–5 条要点说明
- 不做投资建议，只做事实整理
```

### Prompt 2｜行業視角：這是不是一個“好行業”

你選的往往不是公司，而是行業。你讓 AI 做行業的「第一性梳理」，但行業拐點、價格見底這類問題別指望它給答案。

```markdown
请从行业研究的角度，分析【XXX 公司】所在的【XXX 行业】：
1）行业所处的周期阶段（复苏/扩张/衰退/萧条）
2）供需关系与主要驱动因素（产能、开工率、库存、订单/交付周期）
3）价格变化机制与历史波动（价格指数/价差/成本传导、Capex 趋势与新增产能）
4）行业集中度与竞争格局
5）影响行业的关键外部变量（政策、技术、宏观）
请明确指出：哪些是长期结构性因素，哪些是短期波动因素。
输出周期阶段判断 + 关键证据图表清单 + 领先指标(3个)与滞后指标(3个)。
```

### Prompt 3｜業務拆解：錢到底是怎麼賺來的

從「看公司」到「看生意」的關鍵一步。你讓 AI 幫你看清楚混雜型公司（主業 A、利潤卻來自 B）的錢到底怎麼賺。

```markdown
请你以【价值投资 / 基本面研究】视角，对【XXX 公司】进行业务拆解，
核心问题：这家公司真正、长期靠什么赚钱？

## 要求
- 仅基于可验证信息（年报、招股书、定期公告、权威行业报告）
- 明确区分【事实】与【判断】，所有判断必须给出证据或逻辑链

## 必答结构
一、公司"赚钱方式"的一句话结论（不超过 50 字）
二、业务结构全拆解（必须量化）：各业务线的收入占比、毛利率、增长趋势；
    哪些业务贡献大部分利润；是否存在"主业≠利润核心"的情况
三、赚钱机制：钱怎么收（一次性/订阅/复购）；成本花在哪；毛利率由什么决定；
    是否具备规模效应
四、客户、渠道与定价权：核心客户集中度；是否具备定价权；客户更换成本
五、非主营利润：哪些来自投资收益/补贴/资产处置，对长期估值的影响
六、稳定性与脆弱点：哪些假设被破坏，赚钱逻辑就失效；
    用 3–5 条"关键监控指标"总结如何持续验证这门生意是否成立
```

### Prompt 4-7｜財務質量、股權治理、市場分歧、估值護城河

中間四步各解決一個具體問題，你照骨架填就行：明確要求 + 交叉驗證 + 不給結論：

```markdown
请分析【XXX 公司】近几年的财务质量：
1）收入、利润与经营现金流的匹配情况
2）应收账款、存货、合同资产变化
3）非经常性损益对利润的影响
4）可能需要重点关注的财务风险点
## 研究原则：不预测股价，只判断财务"质量"；
强制进行"利润 vs 现金流"的交叉验证；对所有异常给出解释假设与验证路径。
```

```markdown
请整理市场对【XXX 公司】的主要分歧点：
1）多方核心逻辑  2）空方核心逻辑  3）各自最重要的论据
4）哪些分歧可以被未来数据验证  5）关键验证节点是什么
## 分析要求：不得站队；不给投资建议；所有判断必须可被未来数据或事件验证。
```

```markdown
以价值投资视角分析【XXX 公司】的护城河，必须引用公司披露/权威来源：
定价权、转换成本、网络效应/规模效应、无形资产、竞争反应五个维度逐一给证据。
输出：护城河强度评分(0-5) + 证据表 + 最可能被侵蚀的点与监控指标。
```

### Prompt 8｜全家桶：一份盡調級 DeepResearch

你把前七步的邏輯壓進同一個框架的「投資者盡職調查報告」，強制區分事實與判斷、強制交叉驗證、強制推演空方邏輯與黑天鵝——用來對抗人最容易犯的**確認偏誤**。你各家 AI 的 DeepResearch 模式裡都很好用。骨架：

```markdown
我需要一份投资者尽职调查报告，标的【XXX】，风格【价值投资】，周期【中长线 1-3 年】。

## 研究原则
1. 财务数据涵盖过去 3-5 年趋势（CAGR），估值分位回溯过去 5-10 年
2. 区分【事实】与【判断】，判断必须基于可验证数据（年报、招股书、问询函）
3. 双重验证："利润 vs 现金流"交叉验证 + "公司 vs 同行"对比验证
4. 反直觉思考：必须包含空方逻辑与黑天鹅风险推演

## 推演阶段
Phase 1 商业模式与护城河拆解（主业赚吆喝、副业赚利润？）
Phase 2 行业周期与供需格局（库存、开工率、Capex 为证）
Phase 3 财务健康度扫雷（ROE 杜邦拆解、现金含金量、扣非利润）
Phase 4 治理结构与资本配置（质押、减持、资本配置能力）
Phase 5 估值逻辑与风险反脆弱（历史分位、反向 DCF、空方视角）

## 输出
信号灯评级（买入/观望/卖出）+ 关键财务数据表 + 五阶段正文 +
估值仪表盘 + 未来监控清单（事件 A 强化逻辑 / 数据 B 恶化即证伪退出）
```

## 從提示詞到 Skill：`stock-advisor` 是怎麼長出來的

八條提示詞單獨看都好用，但你真要完整研究一隻票：要手動串、換標的重來、資料靠眼睛、決策容易自嗨、交付靠手工。`stock-advisor` 把這條鏈路**從「一堆提示詞」變成「按一次就跑完的流水線」**：

![stock-advisor Skill：一鍵跑完股票研究流水線](/workbuddy/case-investment/assets/001_stock-advisor-overview_Lxy0b4axOo.png)

| 模組 | 做什麼 | 關鍵設計 |
| --- | --- | --- |
| ① 技術面分析 | 從 K 線圖識別形態、均線、MACD，用行情資料交叉驗證 | 影像識別 + 資料雙軌，衝突時以資料為準並標註差異 |
| ② 基本面分析 | 識別財報關鍵指標，補充估值與行業對比 | 技術/基本/資金三面各自打分，再合成評級 |
| ③ 多維交叉驗證 | 聯網檢索研報、行業動態、新聞、政策 | 出現矛盾訊號必須明確標註分歧 |
| ④ 私董會討論 | 呼叫 `peers-advisory-group`，四位幕僚交叉辯論 | 複用現成 Skill，把“找反證”制度化 |
| ⑤ 排版輸出 | 結構化報告，轉雜誌風 HTML / PDF，可上傳飛書 | 複用排版與檔案 Skill |

這裡藏著 Skill 創作最值得你學的一點：**複用而非重寫**。技術指標指令碼複用 `a-share-analyst`，決策討論複用 `peers-advisory-group`，排版複用 `magazine-layout`——它自己新寫的只有少數幾塊。你做一個複雜 Skill，先把已有能力當積木，缺哪塊補哪塊，再用一條主線編排起來，這才是它最該被你記住的地方。

它還有兩個「產品化」小設計：首次使用建檔（問你風險偏好、投資週期、關注行業、倉位上限，存進記憶）；兩種入口同一條流水線（上傳截圖走影像識別 + 資料驗證，直接給程式碼走純資料驅動）。

一句話：**把「一次嚴肅的股票研究」從半天的手工活，壓縮成一次對話。** 你從「搬運和拼接」變成「拍板和質疑」。

## 實戰：用 `stock-advisor` 跑一遍天孚通訊（300394）

標的是天孚通訊（300394），光通訊 / CPO 板塊。你實戰跑一遍，整個過程三步遞進：先看圖、再看財報，再開一場私董會。

### 先上傳 K 線圖，要一份技術面速讀

你上傳 K 線圖，要一份技術面速讀：

```text
我上傳了一隻 A 股的 K 線日線圖和技術指標圖（MACD）。請你作為一位專業的技術分析師：
1. 識別股票資訊：這是哪隻股票？當前股價大約是多少？
2. K 線形態分析：近期呈現什麼形態？近 5 日 K 線的具體表現？
3. 均線系統分析：MA5/MA10/MA20 的排列狀態，最近是否出現金叉或死叉？
4. MACD 分析：DIF 和 DEA 的位置關係，柱狀圖趨勢，是否出現背離？
請以表格 + 文字結合的方式輸出技術面速讀報告。
```

![上傳天孚通訊 K 線圖要技術面速讀](/workbuddy/case-investment/assets/003_image_CrgibiDW3o.png)

WorkBuddy 先從圖裡識別出這是天孚通訊，當前股價約 368.70 元，然後給你結構化速讀：MA5 > MA10 > MA20 標準多頭排列仍在主升浪；但當日一根長上影線（最高衝 376.10 回落到 368.70）、MACD 紅柱開始縮短、乖離率偏大；支撐看 MA5（347）/ MA10（319），壓力看當日高點 376。這一步它沒有猜漲跌，而是把「圖裡能讀到的事實」結構化了。

![技術面速讀結果：均線排列、支撐壓力結構化](/workbuddy/case-investment/assets/004_image_WX6WbFC9Oo.png)

### 再補上財報截圖，做一次全面分析

你補上財報截圖，做一次全面分析：

```text
我又上傳了這隻股票的 2025 年三季度報資料和全年預增資料。請你：
1. 先識別截圖中的所有財務指標資料
2. 結合第一輪的技術面分析，做一次全面的 A 股分析：
   技術面總評、基本面總評（營收增速、盈利能力、估值水平）、資金面觀察、
   綜合評級（強烈推薦/推薦/中性/謹慎/迴避）
3. 給出短期（1-2 周）、中期（1-3 月）的操作建議
4. 明確標註關鍵支撐位和壓力位，按專業研報的格式輸出。
```

![補上傳財報截圖，做全面分析](/workbuddy/case-investment/assets/007_image_CScebfl1io.png)

它先逐條識別截圖裡的財務指標（營收 39.18 億、同比 +63.63%，ROE 31.30%，PE 146.70……），然後合成綜合評級表：

| 維度 | 評分 | 權重 | 加權得分 |
| --- | --- | --- | --- |
| 技術面 | 4.0 / 5.0 | 25% | 1.00 |
| 基本面 | 4.5 / 5.0 | 30% | 1.35 |
| 估值水平 | 2.0 / 5.0 | 25% | 0.50 |
| 資金面 | 4.0 / 5.0 | 20% | 0.80 |
| **綜合評分** | — | — | **3.65 / 5.0** |

最終評級「推薦」，核心結論很剋制：**中期趨勢向好（CPO 高景氣 + 高成長），但短期估值透支、漲幅過大，不宜追高，等回撥再擇機。** 估值太貴就在總分里扣回來——不會因為成長性好就無腦看多。

![綜合評級表：技術面、基本面、估值、資金面加權評分](/workbuddy/case-investment/assets/008_image_I6uBbecypo.png)

### 還拿不定主意，開一場私董會

你拿不定主意時，開一場私董會：

```text
但我對這隻股票還是拿不定主意。請啟動一場私董會，請四位幕僚討論它是否值得投資：
- 巴菲特：價值投資角度（內在價值、護城河、安全邊際）
- 馬斯克：科技趨勢和顛覆性創新角度
- 比爾·蓋茨：商業模式和行業格局角度
- 喬布斯：產品力和使用者體驗角度
討論要求：每位先各自發表獨立觀點；然後交叉質詢；再由每人一句話給出
買入/持有/賣出的最終建議；你作為主持人綜合意見給出執行方案。
請基於前兩輪的分析資料展開，讓幕僚們"帶著資料聊"。
```

![私董會：四位幕僚帶著資料交叉辯論](/workbuddy/case-investment/assets/011_image_LuArbEta0o.png)

私董會環節系統先聯網更新了資料（2025 全年營收、2026 Q1 環比下滑、和中際旭創/新易盛的橫向對比）——交叉驗證模組把討論從截圖資料推進到了全網最新事實。四位幕僚觀點分裂成 2:2：巴菲特迴避（「PE 142，安全邊際為零」）、蓋茨等待（「等 PE 回到 60 倍以下，或換價效比更高的標的」）、馬斯克 All in（「CPO 是光通訊的 iPhone 時刻」）、喬布斯有條件持有（「前提是 CPO FAU 在 2026 H2 如期兌現」）。

主持人綜合出**分投資者型別的執行方案**，並把決策掛到未來驗證節點上：

| 投資者型別 | 建議 | 執行要點 |
| --- | --- | --- |

## 常見錯誤與使用邊界

你用 AI 做投資，最容易踩的坑都在下表裡：

| 常見錯誤 | 為什麼錯 | 正確做法 |
| --- | --- | --- |
| 讓 AI 給“買點 / 賣點” | 它不掌握即時全量資訊，也不為你的錢負責 | 只用它做事實梳理和多空推演，買賣自己拍板 |
| 完全相信截圖識別的數字 | 影像識別會看錯，財報口徑也會變 | 關鍵數字交叉驗證 |
| 指望它判斷行業拐點、價格見底 | 依賴前瞻資訊和經驗，AI 給不了 | 讓它梳理“該盯哪些領先指標”，拐點自己盯 |
| 只看多方邏輯，越看越上頭 | 確認偏誤，AI 會順著你的語氣強化觀點 | 用多空分歧提示詞和私董會，強制給反證 |
| 把 AI 報告直接當投資依據 | 報告是研究輔助，不是投資建議 | 結論僅供參考，決策與風險自負 |

## 常見問題

**AI 能替我決定買還是賣嗎？**
不能，也不該。它不掌握即時全量資訊，更不為你的錢負責。你只用它做事實梳理和多空推演，買賣自己拍板——這一步它全程沒替你做。

**截圖識別的數字能直接信嗎？**
別全信。影像識別會看錯，財報口徑也會變。你關鍵數字一律交叉驗證，別把截圖當唯一真相。

**行業拐點、價格見底這種問題它能答嗎？**
答不了。這類依賴前瞻資訊和經驗，AI 給不出。你讓它梳理「該盯哪些領先指標」，拐點自己盯。

**stock-advisor 和普通提示詞差在哪？**
你把八條散裝提示詞變成按一次就跑完的流水線：看圖、看財報、開私董會、出報告三輪對話搞定。它複用已有 Skill 當積木，你不用手動串。

**私董會是不是走過場？**
不是。四位幕僚帶著資料交叉辯論，系統還會聯網更新到全網最新事實，再按投資者型別給你分檔執行方案，並把決策掛到未來驗證節點上——逼你看反面，對抗確認偏誤。
