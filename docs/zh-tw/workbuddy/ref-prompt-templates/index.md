# WorkBuddy 指令模板怎麼用？附錄 A 的 12 個例子，改兩處就能發

第一次開啟 WorkBuddy，卡住人的往往不是功能，而是這句話該怎麼說。你要它整理資料夾，只說「幫我整理一下」，它可能給你一套誰都看不懂的目錄結構；把要求寫清楚，同樣的活兒質量能差出一倍。這一頁給你 12 個能直接複製的指令模板，你把方括號 `【】` 裡的內容換成自己的實際內容就能發。

## 模板怎麼用

別整段照抄。你拿到模板先做三件事：

1. 換佔位符：`【】` 裡的內容換成你的真實檔名、行業、欄位。留著不換，它只能猜。
2. 補輸出格式：模板給的是骨架。你要 Excel 還是 Markdown、要不要圖表、多少頁，都在末尾加一句說清楚。
3. 先跑小樣：涉及移動、刪除、覆蓋原檔案的指令，你先讓它出方案，確認後再執行。

新手建議從 A.1—A.4 開始，這四類最常用也最不容易出錯。寫法要點見[快速完成第一個任務](/zh-tw/workbuddy/04-first-task/)的六要素表。

## 怎麼挑

你不確定用哪一個時，先判斷這一步是「整理檔案」「算資料」「生成檔案」還是「定時跑」。A.1—A.4 覆蓋日常八成的活兒，新手就先吃透這四個。A.7 到 A.9 是進階用法——二次修改、檔案對比、多表對賬，這三類最容易出靜默錯誤，跑完記得自己核一遍數字。A.10 到 A.12 偏專業場景，等你熟悉了再上。

## A.1 檔案整理

```text
請整理當前資料夾中的檔案。
按檔案型別和主題分類，生成新的資料夾結構。
在執行前先給我一個整理方案，不要直接移動檔案。
```

## A.2 Excel 分析

```text
請分析這個 Excel 檔案。
請輸出：核心指標、異常資料、趨勢變化、可能原因、建議行動。
請生成一個摘要報告和圖表。
```

## A.3 PPT 生成

```text
請根據這份 Word 檔案生成一份 PPT 大綱。
要求：10 頁左右，每頁包含標題、3-4 個要點和建議圖表。
風格正式，適合管理層彙報。
```

## A.4 會議紀要

```text
請整理這段會議內容。
輸出：會議結論、待辦事項、負責人、截止時間、風險點、未決問題。
```

## A.5 行業調研

```text
請調研【行業/公司/產品】。
輸出：市場背景、主要玩家、競品對比、趨勢判斷、機會點、風險點。
請附上資訊來源連結。
```

## A.6 銷售方案

```text
請基於客戶資料生成一份售前方案。
包括：客戶背景、痛點分析、推薦場景、實施路徑、預期收益、演示流程。
```

## A.7 二次修改（不重寫，說差異）

```text
請在上一版【檔名】基礎上進行修改，不要重新生成整篇。
修改要求：【列出具體改動點】
輸出修改後的 v2 版，並在 changelog.md 中列出本次修改內容。
```

## A.8 檔案對比（制度 / 合同 / 方案）

```text
比較【檔案A】與【檔案B】。
輸出新增、刪除、修改和僅格式變化四類差異，附章節和原文定位。
重點標記金額、日期、責任主體、審批條件、例外和否定表達。
生成影響清單和待確認問題，不修改原檔案。
```

## A.9 多表合併與對賬

```text
合併【目錄】中的【N】個表格。
先檢查列名、資料型別、日期範圍和主鍵，不一致時停止並列差異。
彙總前輸出總行數、空值、異常值和重複數。
生成清洗後檔案、異常清單和對賬說明。
金額彙總必須與各源表合計對賬，差異不為 0 時不生成管理結論。
```

## A.10 投資研究：公司事實底座

```text
請幫我係統梳理【公司名】的基礎情況，輸出結構化總結，包括：
1）核心業務與主要產品線
2）收入與利潤來源構成
3）主要客戶與應用場景
4）公司在產業鏈中的位置
5）近幾年最重要的戰略變化
要求：只使用可核實的資訊；每一部分用 3-5 條要點說明；
不做投資建議，只做事實整理。
```

> 更完整的投資研究提示詞鏈路（行業視角、業務拆解、多空分歧、盡調級全家桶）見[把投資分析變成日常](/zh-tw/workbuddy/case-investment/)。本模板僅用於輔助研究，不構成投資建議。

## A.11 多 Agent 任務 Brief

```text
目標：為【產品/專案】製作一支【時長】的【產物型別】。
風格：【參考風格】。
素材：【素材空間路徑或已提供的檔案】。
角色：【主理人、角色A、角色B……】
確認節點：【哪些環節完成後需使用者確認再繼續】。
全自動/半自動：【是否需要中間節點人工介入】。
```

## A.12 自動化任務定義

```text
任務名稱：【名稱】
觸發方式：【每天 09:00 / 每週五 / 每月 1 日】
Prompt：【完整任務指令】
資料來源：【@技能或連接器清單】
質量門禁：【有效條目 ≥ N 條；資料來源可用數量 ≥ N 個】
輸出格式：【結構化清單/檔案】
推送目標：【飛書群 / 郵件 / 檔案追加】
冪等控制：批次 ID = 【字首】-{date}，推送成功後標記，不重複推送
重試策略：資料來源超時重試 1 次；推送失敗退避重試 2 次；其他失敗轉人工
owner：【負責人】
停用方式：WorkBuddy 自動化任務管理頁 → 暫停
```

## 常見問題

**為什麼我照抄模板，出來的結果還是不對？**

多半是佔位符沒換乾淨，或者你沒說清輸出格式。你把 `【】` 裡的內容換成具體的檔名和欄位，再補一句「輸出成 Excel」「控制在 10 頁內」，準確率會高很多。

**方括號要一起刪掉嗎？**

要。`【】` 只是這一頁的佔位標記，你換成真實內容時得連括號一起去掉，別留著。

**A.7 和重新生成整篇有什麼區別？**

A.7 明確要求「在上一版基礎上修改，不要重新生成整篇」。你不說這句，它多半會重寫一遍，你之前手動調過的措辭就全沒了。

**對賬類任務怎麼避免算錯？**

A.9 裡有一句「金額彙總必須與各源表合計對賬，差異不為 0 時不生成管理結論」，你別刪這句。它是在逼系統停下來報差異，而不是硬湊一個總數給你。
