# WorkBuddy 教學

**WorkBuddy** 是騰訊推出的全場景職場 AI 智能體工作台。你用一句自然語言說清目標，它就能在本機電腦上自主規劃步驟、讀寫檔案，交付 PPT、表格分析、文件、調研報告等真實成果——而不是只「回答問題」。

本板塊按「上手 → 擴展 → 案例 → 進階 → 速查」五組組織，從安裝一路帶到搭起自己的 AI 工作系統。

## 學習路線

```mermaid
flowchart LR
    A[安裝登入] --> B[介面與第一個任務]
    B --> C[Skill 與專家]
    C --> D[連接器 / IM 助理 / 自動化]
    D --> E[案例實戰]
    E --> F[進階：打造 Skill、多 Agent、可靠性]
```
