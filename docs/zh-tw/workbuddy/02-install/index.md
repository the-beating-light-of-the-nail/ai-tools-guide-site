# WorkBuddy 怎麼裝？下載、安裝、登入全流程（附截圖）

想試 WorkBuddy，第一步往往最勸退：你不知道從哪下、下完不知道裝哪、裝完不知道該掃微信還是輸手機號。

這篇把下載、安裝、登入、更新四步一次走完，每一步都配了截圖。你照著點就行。

## 下載：只認官方入口

你開啟官方地址 [codebuddy.cn/work](https://www.codebuddy.cn/work/)，選擇 WorkBuddy，點「下載 WorkBuddy」。

![官網下載入口](/workbuddy/02-install/assets/001_image_GGeabJkE2o.png)

網站會自動檢查你的裝置，判斷該給你 Mac ARM64、Mac x64 還是 Windows x64。

![自動檢測裝置版本](/workbuddy/02-install/assets/002_image_HaXcbwaJXo.png)

切記：從官方入口下載，不從網盤或不明映象獲取安裝包。

## Windows 安裝

1. 下載完成後，你雙擊安裝檔案。

![雙擊安裝檔案](/workbuddy/02-install/assets/003_image_Ehpebt4Eso.png)

2. 系統彈出安全提示時，先核對釋出者和下載來源，確認無誤再繼續。

![核對釋出者後繼續](/workbuddy/02-install/assets/004_image_LG3MbcWpvo.png)

3. 你按安裝嚮導一路走完並啟動 WorkBuddy。

![安裝嚮導](/workbuddy/02-install/assets/005_image_CMvYbYWFOo.png)

![安裝嚮導](/workbuddy/02-install/assets/006_image_Wujkbd9eTo.png)

![安裝嚮導](/workbuddy/02-install/assets/007_image_V9L2bhWF2o.png)

![安裝完成](/workbuddy/02-install/assets/008_image_DjcGbKYJSo.png)

4. 首次啟動會進入準備執行環境，你等它跑完。

![準備執行環境](/workbuddy/02-install/assets/009_image_Q0l3bAkUPo.png)

## macOS 安裝

1. 你開啟安裝檔案，把 WorkBuddy 拖入「應用程式」。

![拖入應用程式](/workbuddy/02-install/assets/010_image_TmYPbu7Ibo.png)

![拖入應用程式](/workbuddy/02-install/assets/011_image_UlJcbVqX7o.png)

2. 你從「應用程式」裡啟動。別在 DMG 視窗裡直接雙擊執行——那是個只讀的臨時盤，更新和設定容易出問題。

![從應用程式啟動](/workbuddy/02-install/assets/012_image_LtqPbQ2z6o.png)

## 登入

1. 你點登入按鈕。

![點選登入按鈕](/workbuddy/02-install/assets/013_image_MMIXbZJafo.png)

2. 會自動跳轉到網頁登入。

![跳轉到網頁登入](/workbuddy/02-install/assets/014_image_MdmYbB2Avo.png)

3. 你選微信掃碼登入，也可以用手機號登入。選定一種就固定下來，換著用容易找不到自己的歷史任務。

![微信掃碼或手機號登入](/workbuddy/02-install/assets/015_image_WZrBbbWono.png)

4. 登入完成，就能開始用 WorkBuddy 幹活了。

![登入完成](/workbuddy/02-install/assets/016_image_Pmh8b7xc8o.png)

> 若公司電腦禁止安裝軟體，不要繞過終端安全策略，應聯絡 IT 管理員確認白名單或企業部署方式。

## 更新

點左下角個人中心，選擇「檢查更新」。有新版就按提示更新，不用解除安裝重灌。

![檢查更新](/workbuddy/02-install/assets/017_image_Qt1gbb7J3o.png)

## 常見問題

**安裝包打不開，或者提示損壞？**
你先刪掉安裝包，從官網重新下一次，核對系統和晶片版本。還是不行，把系統版本、安裝包名和報錯截圖留好，走官方反饋渠道。別去關係統安全功能。

**登入完沒反應？**
你看三處：預設瀏覽器是不是攔截了登入回跳、網路代理有沒有影響認證、系統時間準不準。退出應用重開一次，還不行就保留日誌和截圖反饋。

**讀不了、寫不了檔案？**
你先確認任務選的工作目錄對不對、系統有沒有給這個目錄授權、檔案是不是被別的程式鎖著。拿一個空白文本檔案先試，別直接拿重要檔案反覆試錯。

**更新前要備份嗎？**
應用更新一般不會動你的工作檔案。但長期專案還是把輸入、產物、配置和自定義 Skill 納入版本管理，或者定期備份一份。
