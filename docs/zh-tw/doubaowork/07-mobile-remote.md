# 手機遙控電腦：出門也不斷線

有些任務要跑十幾分鐘，你總不能端著電腦等它。豆包工作的「手機遙控電腦」適合**人臨時離開電腦、但任務還想繼續跑**的場景：人在外面看進度、補一句要求，真正幹活的還是那台電腦——臨時出去一趟，在計程車上也能遠端指揮電腦端幹活。

## 開啟步驟

1. 手機和電腦登入**同一個豆包帳號**；
2. 電腦端進入「手機遙控電腦」，開啟「可被相同帳號的裝置控制」；
3. 需要長時間執行時，再打開「**讓這台裝置保持喚醒狀態**」——開著任務去忙別的事就不會因鎖屏中斷；用完記得關；
4. 手機豆包進入工作任務，選擇線上電腦。

第一次連線，先發一條**唯讀測試**，確認手機連的是正確的電腦：

```text
請告訴我下載資料夾中，最新的檔案名稱。
```

## 適合的場景

- 查看一個已經在電腦端執行的長任務進度；
- 讓豆包在指定目錄中查找候選檔案並回傳摘要；
- 繼續整理本機素材、表格或專案檔案；
- 任務等待確認時，透過手機給出下一步指令；
- 接收任務進度提醒，需要時再回到電腦檢查最終產出。

## 一個真實片段

臨時要改一份總結，人又不在電腦前：手機打開豆包工作連上自己的電腦，讓豆包先在本機找到那份總結，再動手改，改完直接透過飛書發回同事——全程沒碰電腦，手機上看著它幹完。
