# 人不在電腦前，正在跑的活就沒人管了嗎？手機遙控電腦，讓你出門也能盯著進度、補一句話

你剛給電腦端下了個活，老闆喊你去開會，或者地鐵上還惦記著那份總結跑到哪一步。電腦擱在桌上，你人已經在外面，總不能端著電腦跑。有些任務一跑就是十幾分鍾，你乾等著也彆扭。

這時候用豆包工作的「手機遙控電腦」就順了。它適合人臨時離開電腦、但任務還想繼續跑的場景：你在外面看進度、補一句要求，真正幹活的還是那臺電腦。臨時出去一趟，在出租車上也能遠端指揮電腦端接著幹活，不用守在螢幕前。

## 怎麼把它開啟

你要先確認手機和電腦登入的是**同一個豆包賬號**。這步別跳，賬號不對，手機根本找不到你的電腦。

接著你在電腦端進「手機遙控電腦」，把「可被相同賬號的裝置控制」這個開關開啟，手機才被允許連上來。

碰到要跑很久的任務，你再額外開啟「**讓這臺裝置保持喚醒狀態**」。開著它，你中途去幹別的事，電腦也不會因為鎖屏把任務掐斷。不過這是把雙刃劍——用完記得關掉，別一直掛著。

隨後你在手機豆包裡進工作任務，挑那臺線上的電腦連上就行。

第一次連，你先發一條只讀測試，別一上來就讓它動真格。目的是確認手機連的確實是你的那臺電腦，不是別人共享賬號裡的機器：

```text
請告訴我下載資料夾中，最新的檔名。
```

它報回來的檔名你認得，就說明連對了。

## 什麼情況下用它最值

- 想看一個已經在電腦端跑起來的長任務，走到哪一步了；
- 讓豆包去某個目錄裡翻候選檔案，再把摘要甩回來；
- 接著整理本地的材料、表格或者專案檔案，不用回電腦前；
- 任務卡在等你確認，在手機上給個下一步指令就能放行；
- 收著進度提醒，等有空了再回到電腦檢查最後成品。

## 一個真實片段

臨時要改一份總結，人又不在電腦前：手機開啟豆包工作連上自己的電腦，讓豆包先在本機找到那份總結，再動手改，改完直接通過飛書發回同事——全程沒碰電腦，就在手機上看著它幹完。

## 新手常見問題

**手機連不上電腦，最可能卡在哪？**
先查賬號：手機和電腦是不是登入的同一個豆包賬號。再查電腦端「可被相同賬號的裝置控制」開關有沒有開啟。這兩處有一處沒對上，手機就看不見你的電腦。

**「保持喚醒狀態」一直開著行不行？**
最好別。它只在任務要跑很久、你又得離開時才打開，防止鎖屏把活掐斷。活幹完了就關掉，別讓它一直掛著耗著。

第一次連線為什麼要先發只讀測試？
為了確認手機連的真是你的電腦，不是同名賬號裡的別的機器。只讀測試不會改動任何檔案，只問一個檔名，安全又好認。連對了你再派正經活。

**我在手機上能下什麼指令？**
和電腦端一樣派活就行：查進度、補要求、給確認、讓它在指定目錄找檔案。真正執行還發生在那臺電腦上，手機只負責你人不在時遠端盯著和指揮。

**飛書發檔案這種操作手機上能做嗎？**
可以。就像上面那個片段，人在外面，讓豆包改完總結直接通過飛書發回同事，全程不用碰電腦。前提是電腦端本來就連著飛書這類通道。
