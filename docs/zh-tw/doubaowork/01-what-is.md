# 豆包工作是什麼？新手第一課

你大概已經在豆包裡聊過天：問它週報怎麼寫，它給你一段範文。然後呢？複製、貼上、自己改成能交的東西。

豆包工作是字節跳動推出的、面向真實工作任務的 AI 助手（入口：[doubao.com/work](https://www.doubao.com/work)）。它把「然後呢」這一步包了：你說「分析這個資料夾裡的銷售資料，生成一份簡報 PPT」，它自己讀檔案、算數、做表、排版，交回一份可以繼續編輯的 PPT。

一句話記住區別：聊天 AI 給答案，豆包工作交作業。

## 它具體能幫你幹什麼

你不是沒活幹，是活太碎：一份 Excel 要清洗、透視、排名；一段會議錄音要變成紀要；一篇文章要改成三個平臺的版本。這些活的共同點是——有材料、有明確交付物、過程煩人。

豆包工作就是幹這個的。HR、教育、金融、財務、營銷、法律、科研、研發……崗位不限，判斷標準就一條：你的活裡有沒有「讀一堆材料、產出一份東西」的環節。

不知道從哪開始的話，[場景速查表](/zh-tw/doubaowork/ref-scenarios)按「你是誰 / 你遇到了什麼」列了三十多條路線，每條都有現成的提示詞。

## 第一次用，別問「你能做什麼」

新手最容易踩的坑就是這個。一上來問「你能做什麼」，它會回你一大篇功能介紹，看完還是不會用。

正確的開局是派一單小活，四步走完：

1. **給素材**：把檔案、資料夾或連結交給它；
2. 說結果：要週報、要 PPT、要表格，說清楚；
3. **定邊界**：哪些不能改、拿不準的先問你；
4. 看過程：讓它自主推進，關鍵步驟你把關。

會不會出錯？會。所以它交的活你要驗收：數字對不對、事實有沒有編。它負責幹活，你負責驗收，這個分工從第一單就要建立。

介面不用提前研究，裝好後只看三塊：左邊找入口，中間看過程和結果，底部寫任務、加素材、控權限（詳見[主介面、任務和專案](/zh-tw/doubaowork/03-interface)）。

## 新手常見問題

**它會亂動我電腦裡的檔案嗎？**
不會為所欲為。每單任務都有權限檔位：始終詢問 / 按需確認 / 全部允許。第一單建議選「按需確認」——它每次要動重要東西，都會先問你。

要會寫提示詞嗎？
會說人話就行。把任務當成給同事派活：材料在哪、要什麼結果、什麼不能碰。這三樣說清楚，比背提示詞模板管用。

**和聊天豆包是什麼關係？**
一家出品，兩種分工。聊天豆包管「回答問題」；豆包工作管「完成任務」——能讀你授權的資料、呼叫技能和連接器（連接器就是授權它碰飛書檔案這類外部服務的通道）、輸出能繼續編輯的檔案。

**適合我這種崗位嗎？**
你的工作裡只要出現「讀一堆材料、產出一份東西」，就值得試。拿不準就翻[場景速查表](/zh-tw/doubaowork/ref-scenarios)，按人群對號入座。
