# 豆包工作是什麼

**豆包工作**是字節跳動推出的、面向真實工作任務的 AI 助手（入口：[doubao.com/work](https://www.doubao.com/work)）。它面向 HR、教育、金融、財務、行銷、法律、科研、研發等不同職場角色，能夠理解目標、規劃步驟、呼叫工具，並交付可以繼續編輯的工作成果——而不是只「回答問題」。

## 它和普通聊天 AI 有什麼差別

聊天工具擅長給答案；豆包工作還會讀取你授權的資料、拆解步驟、呼叫技能和連接器，並產生能繼續編輯的檔案。能不能交差，最後仍要你來驗收。

一個典型的用法：直接告訴它「分析指定資料夾裡的銷售資料，產生一份簡報 PPT」，它自己完成讀取、分析、製表、做稿的全過程。

## 第一次用，別問「你能做什麼」

第一次用這類工作 Agent，最容易犯的錯就是一上來問「你能做什麼」。回答通常很長，關掉以後還是不會用。

豆包工作更適合從一個小交付開始：

1. **給素材**：把檔案、資料夾或連結交給它；
2. **說結果**：明確要什麼交付物；
3. **定邊界**：說清哪些不能改、不確定的怎麼辦；
4. **看過程**：讓它自主推進，或在關鍵步驟按需確認，隨時檢查。

主介面只要先看懂三塊：左邊找入口，中間看過程和結果，底部寫任務、加素材、控權限（詳見[主介面、任務和專案](/zh-tw/doubaowork/03-interface)）。
