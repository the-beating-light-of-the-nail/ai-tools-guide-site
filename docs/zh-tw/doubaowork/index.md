# 豆包工作教學

**豆包工作**（doubao.com/work）是字節跳動推出的、面向真實工作任務的 AI 助手。你用一句自然語言說清目標，它就能讀取你授權的資料、拆解步驟、呼叫技能與連接器，交付 Word、Excel、PPT、調研報告等可以繼續編輯的工作成果——而不是只「回答問題」。它與飛書深度打通：文件、表格、會議紀錄、群聊、多維表格都能直接讀、也能寫回。

本板塊按「上手 → 擴充 → 案例 → 進階 → 速查」五組組織，案例篇涵蓋日常辦公、個人提效、自媒體、知識管理、電商、金融六大場景共 35 篇實戰。

## 適合誰

- **職場新人**：想用 AI 處理 Office 三件套、檔案整理、會議紀錄、日報週報等日常瑣事
- **飛書重度使用者**：想讓 AI 直接讀寫飛書文件、表格、知識庫和群聊，不再搬運資料
- **內容創作者 / 自媒體**：想要一條從選題到成稿、發布、覆盤的 AI 內容生產線
- **投研與資料崗**：想要可回源、可覆核、口徑統一的篩選、財報與估值工作流
