# Skill 怎麼選，怎麼用

豆包工作本身負責理解任務和組織執行；**Skill（技能）是一組可重複使用的說明、腳本、參考資料和資源**，告訴 Agent 某類任務應該怎麼做、呼叫什麼工具、交付什麼格式。（Anthropic 於 2025 年 10 月推出 Agent Skills，12 月將其發布為開放標準。）

## 一個標準的 Skill 長什麼樣

```text
my-skill/
├── SKILL.md          # 唯一必需的檔案
├── scripts/
│   └── check.py
├── references/
│   └── guide.md
└── assets/
    └── template.pptx
```

其中只有 `SKILL.md` 是必須的，核心就是一段「這類任務怎麼做」的說明：

```markdown
---
name: tech-article-writing
description: 用於撰寫 AI 產品、模型評測和科技行業相關文章
---

收到寫作任務後：

1. 先確認文章核心角度
2. 查找一手資料
3. 對核心事實交叉驗證
4. 根據使用者寫作風格完成初稿
5. 檢查禁用句式和 AI 味表達
```

## Skill 是怎麼工作的：漸進式揭露

Skill 最關鍵的設計不是 SKILL.md 本身，而是 **Progressive Disclosure（漸進式揭露）**。假設 Agent 裝了 100 個 Skill，它不會把 100 份完整內容全塞進上下文——那既浪費 Token，又讓模型被無關指令干擾。標準做法分三層：

1. **啟動時**只載入所有 Skill 的名稱和 description（每個只佔幾十至上百 Token）；
2. **任務命中時**才載入完整的 `SKILL.md`——比如你說「幫我寫一篇豆包工作的公眾號文章」，Agent 根據 description 判斷 `tech-article-writing` 相關，這時才讀全文；
3. **執行中**需要更細的資料才繼續讀取 `references/style.md`、執行 `scripts/check-ai-phrases.py`。

OpenAI Codex 也採用類似機制。所以 Skill 解決了一個長期困擾 Agent 的問題：**怎麼給 Agent 很多知識和工作方法，又不把所有東西永遠塞在 Prompt 裡。**

## Skill 的四個作用

**1 · 補充程序性知識。** 大模型往往知道大量通用知識，但未必知道你公司的事：`canonical user_id` 在哪張表、`subscriptions` 表是 append-only、查退款要排除某個狀態、Grafana 對應的 dashboard ID。Anthropic 內部數百個 Skill 主要集中在 API 與內部庫使用、產品驗證、資料分析、業務流程自動化、程式碼腳手架、程式碼審查、CI/CD、故障 Runbook 和維運九類場景。

**2 · 固定複雜工作流。** 普通 Prompt 是「詳細調研一下豆包工作」，模型每次都要重新想：去哪找資料、先查什麼、怎麼驗證、跟誰比、輸出什麼結構。Skill 把流程固定成：官方網站 → 官方公眾號和發表會 → 產品文件 → 實際產品測試 → 同類產品對比 → 核心觀點提煉 → 事實核驗。這類叫 **Encoded Preference Skill**（按你的工作方式組織既有能力）；另一類 **Capability Uplift Skill** 則補充模型原本做不好或不穩定的能力，如複雜文件、PDF 和 PPT 處理。

**3 · 減少重複 Prompt。** 你反覆叮嚀的「不要寫得太 AI、長短句結合、不要過度條列、技術內容要克制、不要編造例子」，天然適合做成一個 `writing-style` Skill。以後 Prompt 只需要一句「寫一篇豆包工作文章」，寫作習慣、資料標準、禁用表達都由 Skill 提供。

**4 · 把經驗資產化。** 傳統 Prompt 散落在聊天紀錄、文件和個人腦子裡；Skill 是檔案，可以 Git 管理、版本回滾、團隊共享、A/B 測試、自動評測、持續更新。

## 在豆包工作裡找 Skill

打開左側「技能·連接器·夥伴」：可按**金融、法律、新媒體創作、辦公協作、程式設計、學術**等分類瀏覽，或在頂部搜尋框按名稱或需求搜尋。找到後點右側「+」添加；部分技能支援「在對話中試用」。已添加的技能統一在「我的技能」中管理。

也可以**新建或上傳自己的技能**：點頁面右上角「新建」，選「與豆包對話新建技能」或「上傳技能」。上傳前檢查技能包的來源、腳本和權限範圍。

## 用 Skill 解決一個任務

例：文章需要降低 AI 痕跡——在技能市集搜尋「去 AI 味」技能，添加後回到工作任務，在輸入框輸入 `/` 或點「更多技能」選中它，附上文章和具體要求。豆包工作會按技能說明決定處理步驟，並展示執行過程和結果。

完成後重點核對技能要求是否真正落實：是否刪除了指定句式、事實和語氣是否保留、專有名詞有沒有被誤改。
