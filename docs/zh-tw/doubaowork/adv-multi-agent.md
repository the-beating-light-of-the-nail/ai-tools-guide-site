# 多 Agent（工作小隊）實操

一個任務需要**調研、分析、寫稿和複核**多道工序時，多 Agent（在豆包工作裡叫「工作小隊」）確實能省時間——前提是每個角色都知道自己要幹什麼、交付什麼、交給誰。

## 小隊裡都有誰

以「爆款內容創作小隊」為例：開啟它，點「對話」，可以看到四位成員——**創意總監（隊長）、爆款行銷策劃師、爆款內容創作專家、AI 畫師**。隊長的職責主要是創意設計、團隊分工，以及最後的總結交付。

## 直接說人話，它會自己分工

在對話方塊裡把需求說清楚就行，比如：

> 我在小區開了家貓舍，養了十幾只貓咪，想拍抖音但完全不知道拍啥，幫我想想第一個月怎麼拍。

豆包工作會據此主動安排合適的多個專家 Agent 跟進任務，最終幾個專家協作完成——你不需要替它寫分工方案（但複雜任務仍建議像[上一章](/zh-tw/doubaowork/adv-buddy-or-squad)那樣，先確認分工再開工）。

## 一個容易找不到的入口

任務發出去以後，如果你點到了其他介面，想找回剛剛的任務：要去**「夥伴對話 → 任務」**裡找，而不是在最近的普通工作任務列表裡。

## 什麼時候值得拆成小隊

| 訊號 | 說明 |
| --- | --- |
| 工序 ≥ 3 道且角色不同 | 策劃、寫作、設計、複核各有專業口徑 |
| 存在前後依賴 | 畫師要等文案主線，稽核要等全部產物 |
| 你一個人同時頂幾個角色 | 最該外包給小隊的時刻 |

反過來，單一專業範圍內的一次性任務（分析一份表、改一份稿），開新任務或找單個工作夥伴更省 token、更快。
