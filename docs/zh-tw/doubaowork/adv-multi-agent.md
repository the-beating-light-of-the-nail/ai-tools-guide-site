# 多 Agent 工作小隊怎麼用？說人話就能讓它自己分工

你手上有個任務，要調研、要分析、要寫稿、還要複核，好幾道工序串在一起，一個人幹到頭大。這時候多 Agent（在豆包工作裡叫「工作小隊」）確實能省時間——但前提是你得讓每個角色都清楚自己要幹什麼、交什麼、交給誰。這一篇就講你怎麼把小隊用順，以及那個特別容易找不到的入口。

## 小隊裡都有誰

你開啟「爆款內容創作小隊」，點「對話」，能看到四位成員——創意總監（隊長）、爆款營銷策劃師、爆款內容創作專家、AI 畫師。隊長的職責主要是創意設計、團隊分工，以及最後的總結交付。

## 直接說人話，它會自己分工

你在對話方塊裡把需求說清楚就行，比如你開了家貓舍想拍抖音，就直接說：

> 我在小區開了家貓舍，養了十幾只貓咪，想拍抖音但完全不知道拍啥，幫我想想第一個月怎麼拍。

豆包工作會據此主動安排合適的多個專家 Agent 跟進任務，最終幾個專家協作完成——你不需要替它寫分工方案（但複雜任務仍建議像[上一章](/zh-tw/doubaowork/adv-buddy-or-squad)那樣，先確認分工再開工）。

## 一個容易找不到的入口

你任務發出去以後，如果手滑點到了別的介面，想找回剛剛那單：要去「夥伴對話 → 任務」裡找，而不是在最近的普通工作任務列表裡翻。這一點你記住，省得回頭找不到活幹到哪了。

## 什麼時候值得拆成小隊

你拿不準該不該叫小隊，對著這張表看訊號：

| 訊號 | 說明 |
| --- | --- |
| 工序 ≥ 3 道且角色不同 | 策劃、寫作、設計、複核各有專業口徑 |
| 存在前後依賴 | 畫師要等文案主線，稽核要等全部產物 |
| 你一個人同時頂幾個角色 | 最該外包給小隊的時刻 |

反過來，單一專業範圍內的一次性任務（分析一份表、改一份稿），你開新任務或找單個工作夥伴更省 token、更快，沒必要拉一支小隊來撐場面。

## 新手常見問題

**我什麼都不用管，小隊就能自己幹完嗎？**
你只要在對話方塊把需求說清，它會自己分工協作。但複雜任務你最好還是先讓它列分工、你確認後再開工，免得方向跑偏返工。

**我發出去的任務去哪找？**
你去「夥伴對話 → 任務」裡找，別在普通工作任務列表裡翻。這是小隊獨有的入口，你第一次用很容易找錯地方。

**什麼樣的活才值得叫小隊？**
工序 Three 道以上、角色不同，或者彼此有前後依賴，比如策劃、寫作、設計、複核串著來。你一個人頂好幾個角色時，最該交給小隊。

**簡單的活也用小隊會不會更慢？**
會。單一專業範圍內的一次性任務，開新任務或找單個工作夥伴更省 token、更快。小隊適合複雜活，不是萬能鑰匙。

**小隊成員能我自己挑嗎？**
你召喚的是現成小隊（比如爆款內容創作小隊），成員由它定。你想自定義分工，就回到上一章用提示詞先寫清「誰負責什麼、交什麼」。
