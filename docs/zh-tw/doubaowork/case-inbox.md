# 收件箱很滿，先找出今天必須處理的事

> 場景：未讀郵件堆積如山。先讓 AI 排優先順序、劃處理視窗，把注意力留給真正需要行動的事。

每天一開啟郵箱，未讀郵件往往已經堆了不少：工作通知、專案進展、協作請求和各種抄送混在一起，一封封檢視很費時間，還容易漏掉真正緊急的事項。哪些必須今天回覆，哪些可以稍後處理，哪些只需知會？

## 第一步：通過連接器授權郵箱

連線郵箱以後，豆包工作才能讀取真實郵件並執行搜尋或整理。

1. 點選「技能·連接器·夥伴」，找到**網易郵箱**，點「+」；
2. 進行郵箱授權（授權碼的獲取方式見[網易郵箱客戶端授權碼說明](https://help.mail.163.com/faqDetail.do?code=d7a5dc8471cd0c0e8b4b8f4f8e49998b374173cfe9171305fa1ce630d7f67ac2a5feb28b66796d3b)）；
3. 授權完成後展開能力列表，確認**讀取、搜尋和傳送**等操作是否可用；
4. 正式整理前，先讀取少量郵件，確認帳號、資料夾和時間範圍都正確——測試沒問題，再做分類和日報。

## 第二步：把收件箱變成一份日報

日報的價值在於把一整頁郵件變成**幾項能行動的判斷**：

```text
讀取最近 7 天內收到的郵件。
按今天必須處理、本週處理、等待他人、僅供知會、疑似風險五類整理。
```

提交後，系統會讀取最近七天的郵件，按行動時間和處理狀態分成五類。這個階段**只做整理，不傳送、不修改原郵件**。即使帳號近期郵件很少，空結果也能驗證連接器是否正常讀取、時間範圍和分類規則有沒有生效。

## 傳送要剋制

連接器也支援傳送郵件，但工作郵件涉及措辭、收件人、附件和承諾時間——**建議先生成草稿，確認無誤後再發送**。
