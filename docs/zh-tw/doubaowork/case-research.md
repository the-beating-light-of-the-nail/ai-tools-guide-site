# 臨時被甩一個調研題目，時間緊、材料亂，怎麼讓豆包工作幫你交一份能上會的報告？

你正忙著別的事，領導突然丟來一句「某某方向你調研一下，週五彙報用」。你一搜網頁，幾十個標籤頁全開著，數字來自不同年份，等到真要上會，手裡一堆材料卻講不清結論。這篇帶你用一份能複用的提示詞，把亂糟糟的臨時調研，變成一份帶著出處、能直接投屏的正式報告。

> 場景：臨時接到調研任務，時間緊、題目大。網頁越開越多，數字來自不同年份，等到做簡報，手裡一堆材料卻講不清結論。

## 動手前，先定三件事

你別一上來就讓豆包工作去搜。你先想清楚：這次調研要幫誰做決定、哪些來源能用、最後交一份檔案還是一套 PPT。這三件事定下來，再讓它去檢索、精讀和整理，後面的頁面才不會反覆推倒重來。

一份能用於彙報的調研，要同時處理好四件事：研究問題服務一個具體決策、資料可追溯、結論有證據、頁面讓讀者快速看懂。穩妥的順序是：先確定範圍和驗收條件，再收集與核驗材料，接著形成結論和證據對應表，最後才製作 PPT。視覺最佳化放在內容確認之後，能少返很多工。

## 一份通用模板

這份模板適合你臨時接到陌生題目時用。你填方括號之前，先確認調研要支援什麼決定、誰會閱讀、時間和地區範圍到哪裡為止——問題越具體，檢索範圍越容易收住。時間緊，你可以減少問題數量和頁數，但關鍵資料的出處必須保留：

```text
請圍繞"【調研主題】"開展深度調研，並生成一份面向【目標讀者】的 PPT 報告。
本次調研用於支援【具體決策】，研究範圍包括【地區範圍】，重點關注【核心問題】，
資訊時間範圍為【開始時間】至【截止時間】。

請先閱讀全部附件，再搜尋公開資料進行補充。
優先使用政府部門、企業官網、財報、監管檔案、學術論文和權威研究機構資料。
對市場規模、增長率、公司經營資料、產品價格、政策規定和時間節點等重要事實，
必須標明來源和釋出日期。每個關鍵結論儘量使用兩個獨立來源進行交叉驗證。

請明確區分：
- 來源中直接說明的事實；
- 根據多個事實形成的分析判斷；
- 缺少充分證據的假設。

不要編造市場資料、公司資料、客戶案例或來源。
不同來源資料存在衝突時，請展示差異並解釋可能原因。

PPT 控制在【15～20】頁，建議包含：執行摘要、研究範圍、市場概覽、關鍵資料、
競爭格局、使用者需求、趨勢判斷、風險、戰略建議、行動計劃和來源附錄。
每頁只表達一個主要觀點，標題使用結論式表達。
儘量使用圖表、對比矩陣、時間線和流程圖表達資訊，避免整頁大段文字。
所有圖表都需要註明資料來源、統計口徑和時間。
最後附完整來源清單，包括資料名稱、機構、釋出日期和網頁連結。

請同時輸出：
- 完整 PPT；
- 一頁管理層摘要；
- 關鍵結論與證據對應表；
- 調研中仍未確認的問題清單。
```

## 例項：Work Agent 行業研究

你看這個例子。它把市場進入、客戶選擇、產品定位和路線圖放進同一項任務，研究問題因此能圍繞管理層決策展開；中國市場是重點，海外材料用於比較，時間範圍寫得清清楚楚：

```text
請圍繞"Work Agent 行業研究"開展深度調研，並生成一份專業的 PPT 報告。

一、研究資訊
目標讀者：公司管理層、戰略負責人和產品負責人
需要支援的決策：
1. 判斷 Work Agent 市場是否值得進入
2. 選擇優先服務的客戶和應用場景
3. 確定產品定位和差異化方向
4. 制定未來 12 至 24 個月的產品路線圖
研究區域：以中國市場為重點，同時參考海外市場。
研究時間：研究 2023 年至 2026 年的發展情況，並分析未來 3 年的發展趨勢。

二、重點研究問題
1. Work Agent 是什麼？與 AI 助手、Copilot 和 RPA 有什麼區別？
2. 當前市場處於什麼發展階段？
3. 中國及全球市場的發展空間如何？
4. 國內外有哪些代表性公司和產品？
5. 不同產品的定位、功能和目標客戶有什麼差異？
6. Work Agent 適合應用在哪些工作場景？
7. 企業客戶最關注哪些產品能力？
8. 當前行業面臨哪些技術、安全和商業風險？
9. Work Agent 未來 3 年可能出現哪些趨勢？
10. 新進入者應該選擇什麼產品和市場策略？

三、外部調研要求
優先參考：企業官網及官方產品資料、政府/行業協會和研究機構、
上市公司財報及公開材料、學術論文和權威市場報告、可信的科技及行業媒體。
關鍵資料需要標註來源、釋出時間和網頁連結。
請區分事實、分析判斷和行業預測。無法核實的資訊標註"待核驗"，不要編造資料或案例。

四、PPT 要求
生成一份 15 至 18 頁的中文 PPT：
1. 每頁突出一個核心觀點；
2. 標題儘量直接表達結論；
3. 避免堆積大段文字；
4. 優先使用圖表、對比表、矩陣和時間軸；
5. 圖表需要標註資料來源和時間。
```

執行時，系統先讀取你的附件和任務範圍，再補充公開資料、核對關鍵數字與時間，把事實、分析判斷和待核驗資訊分別整理，再據此生成報告頁面。結果生成之後，你先看關鍵結論與證據能否逐項對應，再檢查市場資料、公司資訊和產品能力的釋出日期。

## 最後再交給美化技能

內容稽核過之後，你再讓 PPT 美化類技能（如 guizang-ppt）去處理已經穩定的版本，讓工具集中調整版式、配色、圖表和頁面節奏：

```text
使用 Guizang Ppt Skill 美化 PPT 樣式
```

你也可以直介面述風格，比如「修改成新粗野主義風格的 PPT」。你按不同彙報人群和形式，換不同的 PPT Skill 即可。

## 新手常見問題

**臨時調研第一步到底該做什麼？**
你先定三件事：幫誰做決定、哪些來源能用、交檔案還是 PPT。定清楚了再讓豆包工作搜，不然頁面會反覆重做。

**豆包工作會不會自己編資料？**
你要在提示詞裡寫死「不編造」。模板裡已經要求它對無法核實的資訊標「待核驗」，並優先用政府、財報、學術這類權威來源。你收到報告，重點看關鍵數字有沒有掛出處。

**為什麼關鍵資料出處不能省？**
上會時有人追問「這個增長哪來的」，你答不上來就尷尬了。出處保留著，別人質疑你才接得住，也方便你自己回原文核對。

**PPT 能不能一開始就讓它做漂亮？**
別急。視覺最佳化放在內容確認之後。內容沒定就先美化，後面每改一處結論，版式都得跟著返工，更累。

**時間特別緊怎麼砍？**
你可以減少問題數量和頁數，但關鍵資料的出處必須留著。寧可頁數少一點，也不能讓結論沒了依據。
