# 從臨時調研到交付正式報告

> 場景：臨時接到調研任務，時間緊、題目大。網頁越開越多，數字來自不同年份，等到做彙報，手裡一堆材料卻講不清結論。

先定三件事：**這次調研要幫誰做決定、哪些來源能用、最後交一份文件還是一套 PPT**——定下來再讓豆包工作去檢索、精讀和整理，後面的頁面才不會反覆推倒重來。

一份能用於彙報的調研要同時處理四件事：研究問題服務一個具體決策、資料可追溯、結論有證據、頁面讓讀者快速看懂。穩妥的順序是：**先確定範圍和驗收條件 → 收集與核驗材料 → 形成結論和證據對應表 → 製作 PPT**。視覺優化放在內容確認之後，能減少返工。

## 通用模板

適合臨時接到陌生題目時用。填寫方括號前，先確認調研要支持什麼決定、誰會閱讀、時間和地區範圍到哪裡為止——問題越具體，檢索範圍越容易收住。時間緊可以減少問題數量和頁數，但**關鍵資料的出處必須保留**。

```text
請圍繞「【調研主題】」開展深度調研，並生成一份面向【目標讀者】的 PPT 報告。
本次調研用於支持【具體決策】，研究範圍包括【地區範圍】，重點關注【核心問題】，
資訊時間範圍為【開始時間】至【截止時間】。

請先閱讀全部附件，再搜尋公開資料進行補充。
優先使用政府部門、企業官網、財報、監管文件、學術論文和權威研究機構資料。
對市場規模、成長率、公司經營資料、產品價格、政策規定和時間節點等重要事實，
必須標明來源和發布日期。每個關鍵結論盡量使用兩個獨立來源進行交叉驗證。

請明確區分：
- 來源中直接說明的事實；
- 根據多個事實形成的分析判斷；
- 缺少充分證據的假設。

不要編造市場資料、公司資料、客戶案例或來源。
不同來源資料存在衝突時，請展示差異並解釋可能原因。

PPT 控制在【15～20】頁，建議包含：執行摘要、研究範圍、市場概覽、關鍵資料、
競爭格局、用戶需求、趨勢判斷、風險、戰略建議、行動計畫和來源附錄。
每頁只表達一個主要觀點，標題使用結論式表達。
盡量使用圖表、對比矩陣、時間線和流程圖表達資訊，避免整頁大段文字。
所有圖表都需要註明資料來源、統計口徑和時間。
最後附完整來源清單，包括資料名稱、機構、發布日期和網頁連結。

請同時輸出：
- 完整 PPT；
- 一頁管理層摘要；
- 關鍵結論與證據對應表；
- 調研中仍未確認的問題清單。
```

## 實例：Work Agent 行業研究

這個例子把**市場進入、客戶選擇、產品定位和路線圖**放進同一項任務，研究問題因此能圍繞管理層決策展開；中國市場是重點，海外材料用於比較，時間範圍寫得清清楚楚：

```text
請圍繞「Work Agent 行業研究」開展深度調研，並生成一份專業的 PPT 報告。

一、研究資訊
目標讀者：公司管理層、戰略負責人和產品負責人
需要支持的決策：
1. 判斷 Work Agent 市場是否值得進入
2. 選擇優先服務的客戶和應用場景
3. 確定產品定位和差異化方向
4. 制定未來 12 至 24 個月的產品路線圖
研究區域：以中國市場為重點，同時參考海外市場。
研究時間：研究 2023 年至 2026 年的發展情況，並分析未來 3 年的發展趨勢。

二、重點研究問題
1. Work Agent 是什麼？與 AI 助手、Copilot 和 RPA 有什麼區別？
2. 當前市場處於什麼發展階段？
3. 中國及全球市場的發展空間如何？
4. 國內外有哪些代表性公司和產品？
5. 不同產品的定位、功能和目標客戶有什麼差異？
6. Work Agent 適合應用在哪些工作場景？
7. 企業客戶最關注哪些產品能力？
8. 當前行業面臨哪些技術、安全和商業風險？
9. Work Agent 未來 3 年可能出現哪些趨勢？
10. 新進入者應該選擇什麼產品和市場策略？

三、外部調研要求
優先參考：企業官網及官方產品資料、政府/行業協會和研究機構、
上市公司財報及公開材料、學術論文和權威市場報告、可信的科技及行業媒體。
關鍵資料需要標註來源、發布時間和網頁連結。
請區分事實、分析判斷和行業預測。無法核實的資訊標註「待核驗」，不要編造資料或案例。

四、PPT 要求
生成一份 15 至 18 頁的中文 PPT：
1. 每頁突出一個核心觀點；
2. 標題盡量表達結論；
3. 避免堆積大段文字；
4. 優先使用圖表、對比表、矩陣和時間軸；
5. 圖表需要標註資料來源和時間。
```

執行過程：系統先讀取附件和任務範圍，再補充公開資料、核對關鍵數字與時間，把事實、分析判斷和待核驗資訊分別整理，再據此生成報告頁面。結果生成後，先看**關鍵結論與證據能否逐項對應**，再檢查市場資料、公司資訊和產品能力的發布日期。

## PPT 優化交給 Skill

內容審核過之後，再用 PPT 美化類技能（如 guizang-ppt）處理**已經穩定的版本**，讓工具集中調整版式、配色、圖表和頁面節奏：

```text
使用 Guizang Ppt Skill 美化 PPT 樣式
```

也可以直接口述風格，比如「修改成新粗野主義風格的 PPT」。按不同彙報人群和形式換不同的 PPT Skill 即可。
