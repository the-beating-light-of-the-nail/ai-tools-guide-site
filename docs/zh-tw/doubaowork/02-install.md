# 下載、安裝與登入

## 從官方入口下載

打開豆包工作官網 [doubao.com/work](https://www.doubao.com/work)，點擊「下載豆包工作」，根據系統和晶片選擇安裝包。

- **Mac 使用者**：不確定晶片時，點左上角蘋果選單裡的「關於本機」查看；
- **Windows 使用者**：在「設定 → 系統 → 系統資訊」裡查看。

> **切記：只從官方入口下載，不要從網路硬碟或不明鏡像取得安裝包。**

## 安裝

**macOS**：打開下載得到的 DMG 安裝映像檔，把「豆包工作」拖入「Applications（應用程式）」資料夾，然後從「應用程式」啟動。

**Windows**：下載適合裝置的版本後雙擊安裝檔；如系統彈出安全提示，點擊「執行」，按安裝精靈完成安裝，再從開始選單或桌面啟動。

## 登入

首次啟動後按頁面引導登入，支援**手機號碼登入**和**飛書帳號登入**。

> 注意：不同登入方式之間是隔離的——手機號碼登入和飛書登入各自獨立、互不影響。建議固定用一種方式，避免找不到自己的歷史任務。

## 更新

點擊左下角個人頭像，在選單中選擇「檢查更新」。偵測到新版本時按頁面提示完成更新即可。
