# 豆包工作怎麼裝？Mac / Windows 下載、安裝、登入一次講清

想試豆包工作，你常卡在第一步：搜「豆包下載」出來一堆結果，分不清哪個是工作版；下完雙擊沒反應；好不容易登進去，發現上次的任務不見了。

這篇把下載、安裝、登入三步一次講完。你照著做，裝完就能用。

## 急著用？看這四行

1. 你開啟 [doubao.com/work](https://www.doubao.com/work)，點「下載豆包工作」；
2. 裝好以後，你從「應用程式」（Mac）或開始選單（Windows）啟動，別在安裝包裡直接開；
3. 手機號或飛書賬號登入，二選一，你選定就別換；
4. 你點左下角頭像 →「檢查更新」，確認是最新版。

## 下載：只認一個入口

你開啟官網 [doubao.com/work](https://www.doubao.com/work)，點「下載豆包工作」，按你的系統和晶片選安裝包。

不確定自己的電腦是什麼晶片，這樣查：

- Mac：點左上角蘋果選單 →「關於本機」；
- Windows：「設定 → 系統 → 系統資訊」。

只從官方入口下。網盤連結、論壇附件、所謂高速映象，都別碰。你不知道那些包裡被加了什麼。

## Mac 怎麼裝

下載得到的是 DMG 安裝映象。雙擊開啟，把「豆包工作」圖示拖進「Applications（應用程式）」資料夾，然後從「應用程式」裡啟動。

你新手最常犯的兩個錯，先記牢：

- 在 DMG 視窗裡直接雙擊執行。能開，但那是個只讀的臨時盤，更新和設定容易出問題。你要做的只有一步：拖進應用程式再啟動。
- 裝完找不到圖示。去啟動臺搜「豆包工作」，或者開啟訪達裡的應用程式資料夾。

裝完，你 DMG 和安裝包可以刪，不影響已經裝好的程式。

## Windows 怎麼裝

下載適合你裝置的版本，雙擊安裝檔案。系統彈出安全提示時，你先看一眼釋出者是不是官方，確認沒問題再點「執行」，然後按安裝嚮導走完，從開始選單或桌面啟動。

> 公司電腦禁止裝軟體的話，別想辦法繞過終端安全策略，找 IT 管理員確認白名單或企業部署方式。

## 登入：手機號還是飛書

首次啟動後按頁面引導登入，支援手機號登入和飛書賬號登入。

選之前先看這條：兩種登入方式是隔離的。手機號登進去和飛書登進去，是兩個互不相通的賬號，歷史任務不打通。

所以你現在公司用什麼，就固定用什麼。今天手機號、明天飛書，最後你會發現兩邊各剩一半任務——不是任務丟了，是你在兩個地方各幹了一半。

## 裝完先做三件事

1. 你點左下角頭像 →「檢查更新」，確認是最新版；
2. 想清楚登入方式，別中途換；
3. 直接派一單小活試手，介面先別研究（[五分鐘跑完第一個工作任務 →](/zh-tw/doubaowork/04-first-task)）。

## 新手常見問題

**下載下來打不開，或者提示損壞？**
你先刪掉安裝包，從官網重新下一次，核對系統和晶片有沒有選對。還是不行，就把系統版本、安裝包名和報錯截圖留好，走官方反饋渠道。別去關係統安全功能。

**登入以後沒反應？**
檢查三處：預設瀏覽器是不是攔截了登入回跳、網路代理有沒有影響認證、系統時間準不準。退出應用重開一次，還不行就保留日誌和截圖反饋。

**手機上的豆包能用它嗎？**
不是一個東西。手機上的聊天豆包負責回答問題，豆包工作負責交付成品，得裝電腦版。手機上可以檢視進度、遠端操控電腦，見[手機遙控電腦](/zh-tw/doubaowork/07-mobile-remote)。

**更新要解除安裝重灌嗎？**
不用。點左下角個人頭像 →「檢查更新」，檢測到新版本按提示完成即可。
