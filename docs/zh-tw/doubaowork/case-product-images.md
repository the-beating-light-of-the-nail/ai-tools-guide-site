# 從一張產品原圖到整套主圖

> 場景：電商主圖設計。手上只有一張隨手拍的產品原圖，想要一整套能上架的主圖——這不是簡單的生圖指令，而是一套「電商視覺生產工作流」。

## 這個技能幫你做什麼

[moyuxl-ecom-image-prompt](https://github.com/AlephAITech/moyuxl-ecom-image-prompt) 技能負責：**拆參考、鎖事實、定視覺、寫生產級提示詞、校對成品**。兩種工作模式：

| 模式 | 適用情況 | 它做的事 |
| --- | --- | --- |
| 參考圖反推（重點） | 有產品圖 + 幾張喜歡的參考圖 | 拆開參考圖的構圖/資訊結構/風格，遷移到你的產品上生成新圖 |
| 從零策劃 | 沒有參考圖，只有產品 | 從產品身份與買家決策路徑推導視覺方向，給 2—4 個可選方向 |

按手上的材料不同，產出也不同：只有產品原圖沒有方向 → 調研賣點、從零策劃主圖或詳情頁；產品原圖 + 參考圖 → 拆解參考、遷移手法、生成成套新圖；已有完整文案賣點 → 直接編譯成可複製的生產級生圖提示詞。

在支援 Agent Skills 的環境裡一條命令安裝（也可下載技能資料夾直接匯入豆包工作）：

```text
npx skills add https://github.com/AlephAITech/moyuxl-ecom-image-prompt --skill moyuxl-ecom-image-prompt
```

## 實戰：1 張手持產品圖 → 7 張主圖

起點是一張**沒有任何版式設計**的隨手拍：手持產品、背景是綠植。

### 參考圖分別「借什麼」

不是照抄某一張，而是**各取一類機制**，再用自己的產品和視覺系統重組：

| 參考圖 | 借它的機制 | 明確不搬 |
| --- | --- | --- |
| 棚拍對稱式 | 產品置中、左右對稱的穩定首圖構圖 | 它的產品、配色與文案 |
| 原料浸沒式 | 產品「泡進」原料中的融合手法 | 它的瓶型與專屬畫面 |
| 資訊圖式 | 分欄、卡片、流程線的資訊骨架 | 它的原始資料與措辭 |
| 航拍產地式 | 產地氛圍與空間敘事 | 它的具體面積/產量數字 |

### 先發散，再收斂

不急著定稿——圍繞同一產品，按**構圖/場景/資訊/色調**各試一組方向再挑：

- **第一批·棚拍手法 4 方向**：忠實遷移、構圖升級、場景敘事、資訊設計（忠實遷移版的產品保真與構圖穩定度最高）；
- **第二批·原料浸沒式 3 變體**：產品被紅富士蘋果環繞——斜插版最貼近參考範式、近景正立版產品佔比最大、側躺版動態感最強；
- **第三批·資訊圖式 3 變體**：真實果園背景加四象限資訊與手繪箭頭——四象限版資訊版面最清晰、畫框版產品最突出、行間透視版縱深感最強；
- **第四批·航拍產地式 3 變體**：競品的種植面積、冷庫噸位等資料不可繼承，統一替換為本品已確認的「源自煙台、當季紅富士、100% 鮮蘋果汁」等真實資訊，**不編造規模數字**；
- **第五批·原創風格 5 方向**：脫離參考圖後的探索，覆蓋從極簡到動態、從清涼到溫暖、從日常到高端的完整風格光譜，用於反推最終套系的調性取捨。

## 方法要點

1. **參考圖是機制庫，不是抄襲對象**——每張只借一類構圖/資訊/氛圍機制，產品和資料永遠用你自己的；
2. **事實先鎖死**——產地、成分、賣點等可寫上畫面的資訊，先確認為真實資訊，競品數字不可繼承；
3. **批量變體做 A/B**——同一機制出 3—4 個變體對比（產品佔比、動態感、資訊密度），再挑進入最終套系；
4. **調性光譜反推**——用原創方向的風格光譜，反過來決定整套主圖統一的視覺調性。
