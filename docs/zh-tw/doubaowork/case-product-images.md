# 手上只有一張隨手拍的產品圖，怎麼讓豆包工作生成一整套能上架的主圖？

你手裡只有一張隨手拍的產品原圖，背景還是綠植，想上架電商卻連一張像樣的首圖都沒有。你以為這是一句生圖口令就能解決的事，其實它是一套電商視覺生產工作流。這篇帶你用一套技能，把一張原圖變成成套主圖，還不編造任何產品數字。

你可能會覺得，這不就是一句話讓 AI 生張圖嗎？你真試過就知道，隨口一句口令生成的圖，往往產品變形、數字亂編。你要想上架賣貨，得走一套完整工作流。你跟著下面的技能，把一張隨手拍變成成套主圖。你不用懂設計，它把最難的部分包了；你也不用擔心版權，競品數字它一概不繼承；你只要把真實產品和賣點交給它就行。

## 這個技能幫你做什麼

[moyuxl-ecom-image-prompt](https://github.com/AlephAITech/moyuxl-ecom-image-prompt) 技能負責：拆參考、鎖事實、定視覺、寫生產級提示詞、校對成品。兩種工作模式：

| 模式 | 適用情況 | 它做的事 |
| --- | --- | --- |
| 參考圖反推（重點） | 有產品圖 + 幾張喜歡的參考圖 | 拆開參考圖的構圖/資訊結構/風格，遷移到你的產品上生成新圖 |
| 從零策劃 | 沒有參考圖，只有產品 | 從產品身份與買家決策路徑推導視覺方向，給 2—4 個可選方向 |

你手上的材料不同，產出也不同：只有產品原圖沒有方向，它調研賣點、從零策劃主圖或詳情頁；產品原圖 + 參考圖，它拆解參考、遷移手法、生成成套新圖；已有完整文案賣點，它直接編譯成可複製的生產級生圖提示詞。

## 實戰：1 張手持產品圖 → 7 張主圖

起點是一張沒有任何版式設計的隨手拍：手持產品、背景是綠植。

### 參考圖分別「借什麼」

你不是照抄某一張，而是各取一類機制，再用自己的產品和視覺系統重組：

| 參考圖 | 借它的機制 | 明確不搬 |
| --- | --- | --- |
| 棚拍對稱式 | 產品居中、左右對稱的穩定首圖構圖 | 它的產品、配色與文案 |
| 原料浸沒式 | 產品“泡進”原料中的融合手法 | 它的瓶型與專屬畫面 |
| 資訊圖式 | 分欄、卡片、流程線的資訊骨架 | 它的原始資料與措辭 |
| 航拍產地式 | 產地氛圍與空間敘事 | 它的具體面積/產量數字 |

### 先發散，再收斂

你別急著定稿——圍繞同一產品，按構圖、場景、資訊、色調各試一組方向再挑：

- 第一批·棚拍手法 4 方向：忠實遷移、構圖升級、場景敘事、資訊設計（忠實遷移版的產品保真與構圖穩定度最高）；
- 第二批·原料浸沒式 3 變體：產品被紅富士蘋果環繞——斜插版最貼近參考範式、近景正立版產品佔比最大、側躺版動態感最強；
- 第三批·資訊圖式 3 變體：真實果園背景加四象限資訊與手繪箭頭——四象限版資訊佈局最清晰、畫框版產品最突出、行間透視版縱深感最強；
- 第四批·航拍產地式 3 變體：競品的種植面積、冷庫噸位等資料不可繼承，統一替換為本品已確認的「源自煙臺、當季紅富士、100% 鮮蘋果汁」等真實資訊，不編造規模數字；
- 第五批·原創風格 5 方向：脫離參考圖後的探索，覆蓋從極簡到動態、從清涼到溫暖、從日常到高階的完整風格光譜，用於反推最終套系的調性取捨。

## 方法要點

1. 參考圖是機制庫，不是抄襲物件——每張只借一類構圖/資訊/氛圍機制，產品和資料永遠用你自己的；
2. 事實先鎖死——產地、成分、賣點等可寫上畫面的資訊，先確認為真實資訊，競品數字不可繼承；
3. 批次變體做 A/B——同一機製出 3—4 個變體對比（產品佔比、動態感、資訊密度），再挑進入最終套系；
4. 調性光譜反推——用原創方向的風格光譜，反過來決定整套主圖統一的視覺調性。

## 新手常見問題

**我沒有設計基礎能用這套技能嗎？**
你能。你只要給一張產品原圖，它負責拆參考、定視覺、寫生產級提示詞。你真正要盯的，是產品資訊和數字別被它編出來。

**參考圖能直接照抄嗎？**
不能，也不該。你只借每一張的「機制」——構圖、資訊骨架、氛圍，產品和真實資料永遠用你自己的。抄別人的產品和數字，上架就侵權了。

**為什麼競品的面積、產量數字不能繼承？**
那不是你的真實資訊。技能要求事實先鎖死，競品數字不可繼承，統一替換成本品已確認的內容，避免你上架圖裡出現編造的規模。

**我該一次生成幾張？**
你按「先發散、再收斂」來：同一機製出 3—4 個變體對比，挑進最終套系。一次性懟太多反而難選，分批試更清楚。

**生成的圖能直接上架嗎？**
技能做的是視覺生產，成品質檢還要你過一遍：產品佔比、資訊密度、調性是否統一。確認沒問題，再拿去上架。
