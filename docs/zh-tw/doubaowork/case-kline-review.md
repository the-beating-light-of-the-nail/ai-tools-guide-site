# 一張 K 線截圖，怎麼讓豆包工作變成一場每句話都有資料撐著的投研評審？

你刷到一隻股票的 K 線圖，腦子裡冒出「趨勢向上、放量突破、回撤企穩」——這些詞寫起來快，可你仔細一想，它可能已經越過了圖片本身能證明的範圍。這篇帶你把一張截圖，變成一場每句話都有資料支撐的投研評審會，而不是憑感覺下結論。

> 場景：一張 K 線圖很容易讓人產生判斷——“趨勢向上、放量突破、回撤企穩”這些詞寫起來很快，卻可能已經越過了圖片本身能證明的範圍。把一張截圖變成一場**每句話都有資料支撐**的投研評審會，才是 Agent 該乾的活。

> ⚠️ 本章全部內容僅供學習交流參考，不構成任何投資推薦。

這個案例展示的是一條完整的 Agent 工作流：VLM 視覺識別，接專業工具自動呼叫，再多人深度研討，最後結構化報告輸出，四個環節全程無需你手動切換工具。

你可能會擔心自己不懂金融。其實你不用懂量化模型，也不用會寫程式碼——你只要會截圖、會複製提示詞，剩下的交給它排程。

## 第一步：看圖識勢 · VLM 讀 K 線

你截一隻近期有明顯技術形態的 A 股 K 線日線圖和 MACD 指標圖上傳：

```text
我上傳了一隻 A 股的 K 線日線圖和技術指標圖（MACD）。
請你作為一位專業的技術分析師，完成以下任務：
1. 識別股票資訊：這是哪隻股票？當前股價大約是多少？
2. K 線形態分析：近期呈現什麼形態？近 5 日 K 線的具體表現？
3. 均線系統分析：MA5/MA10/MA20 的排列狀態，最近是否出現金叉或死叉
4. MACD 分析：DIF 和 DEA 的位置關係，柱狀圖趨勢，是否出現背離
請以表格 + 文字結合的方式輸出技術面速讀報告。
```

實測識別非常準確：均線多頭排列識別正確、MACD 訊號判斷準確，連長上影線都有描述——你一張手機截圖就能提取出完整的技術面速讀。

## 第二步：調兵遣將 · 接入財報

你再上傳這隻股票的財報資料截圖：

```text
我又上傳了這隻股票的最新財報資料截圖。現在請你：
1. 先識別截圖中的所有財務指標資料
2. 然後結合第一輪的技術面分析，做一次全面的 A 股分析：
   - 技術面總評（綜合 K 線、均線、MACD、KDJ 給出方向判斷）
   - 基本面總評（營收增速、盈利能力、估值水平）
   - 資金面觀察（成交量變化趨勢）
   - 綜合評級：強烈推薦 / 推薦 / 中性 / 謹慎 / 迴避
3. 給出短期（1-2 周）、中期（1-3 月）的操作建議
4. 明確標註關鍵支撐位和壓力位
請按照專業研報的格式輸出。
```

它還會自動調取 A 股分析類 Skill 展開分析，綜合評級、支撐位壓力位、短中期建議一應俱全，表格、要點、結論層次分明。

## 第三步：群英會 · 四位幕僚的投資私董會

整個流程最關鍵的一步，你只需要一句追問：

```text
分析非常專業！但我對這隻股票還是拿不定主意。
現在請幫我啟動一場私董會，我要請四位幕僚來討論這隻股票是否值得投資：
- 巴菲特：從價值投資的角度（內在價值、護城河、安全邊際）
- 馬斯克：從科技趨勢和顛覆性創新的角度
- 比爾·蓋茨：從商業模式和行業格局的角度
- 喬布斯：從產品力和使用者體驗的角度
討論要求：
1. 每位幕僚先各自發表獨立觀點
2. 然後進入交叉質詢環節，幕僚之間互相挑戰對方觀點
3. 最後每人用一句話給出「買入/持有/賣出」的最終建議
4. 你作為私董會主持人，綜合四位意見給出最終執行方案
請基於前兩輪的分析資料來展開討論，讓幕僚們帶著資料聊。
```

注意：沒有人手動指定「呼叫私董會 Skill」——模型根據需求自己判斷下一步需要什麼工具、什麼資料，然後自己排程完成。這就是 Agent 能力的核心價值：不只是被動回答問題。

四位虛擬幕僚輪番登場，關鍵在於他們不是空聊：每位都在引用前兩輪分析中的真實資料。巴菲特說「這是一家好公司，但不是一個好價格」，馬斯克反駁「你不能用後視鏡開車」；蓋茨補充行業格局資料，喬布斯從產品競爭力給出不同判斷——四個人吵來吵去，但每句話都有資料支撐。這種「帶著資料聊」的編排，需要模型同時具備多 Skill 串聯呼叫、跨 Skill 上下文傳遞、角色一致性維護幾項能力，哪一環掉鏈子都不行。

最後模型自動整合四位幕僚的觀點輸出報告，你還可以讓它呼叫雜誌排版類 Skill 生成「一頁紙摘要（快速過目）+ 詳細分析（存檔復盤）」，風險提示、操作計劃、倉位建議全部到位。

> 本案例使用的 Skills（A 股分析、私董會等）已在 GitHub 開源：[isjiamu/jiamu-skills](https://github.com/isjiamu/jiamu-skills)。同樣的思路可以拓展到任何個股分析平臺，豆包工作同樣支援。

## 新手常見問題

**我沒有金融背景也能跑這套流程嗎？**
你能。你只要會截圖、會貼上提示詞，剩下的讀圖、調財報、組私董會都由它排程。你負責看最終報告裡每條結論有沒有資料撐著。

**為什麼強調「每句話都有資料支撐」？**
因為 K 線圖很容易讓人腦補判斷。你讓它把技術面、基本面、資金面分別列證據，結論才站得住，而不是一句「感覺要漲」。

**私董會那一步要我手動裝 Skill 嗎？**
不用。你只管追問「幫我啟動一場私董會」，模型自己判斷該調哪個工具。這正是 Agent 和聊天機器人的區別。

**截圖識別會不會出錯？**
會。所以你拿到技術面速讀後，自己核對一下股票名、股價、均線排列。識別再準，關鍵數字你也得親眼過一遍。

**這些結論能當投資依據嗎？**
不能。文章開頭的警示一直有效：本章僅供學習交流，不構成任何投資推薦。你拿它練手可以，真金白銀的決策另說。
