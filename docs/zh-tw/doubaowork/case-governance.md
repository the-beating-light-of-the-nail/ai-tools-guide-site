# 看公司，也要看股東、管理層和治理結構

> 場景：研究公司時業務和財務最先被看到，而股東減持、回購、股權激勵、關聯交易和管理層變動很容易散落在幾十份公告裡。這些事不能靠人物標籤判斷——一個股東是不是"長期主義"、一次回購是不是"看好公司"，都要回到具體時間、數量、價格、程式和後續兌現。

這一章用格力電器搭一條治理事件線，把**人物印象改寫成可以查公告、對日期、看執行結果的事件問題**。最後留下的不是管理層畫像，而是一張治理時間線和一組仍需驗證的關係。工具用「公告解讀」技能，並明確要求**工商資料只能補充關係，不能替代交易所和公司公告**。

## 把治理問題改寫成事件問題

```text
請研究格力電器 000651 截至固定資料日的股權、管理層和公司治理情況。

從交易所公告和公司法定披露中梳理控制關係、前十大股東、董事與高管變動、股權激勵、
員工持股、回購、增減持、關聯交易和重要資本配置事件。
工商資料只用於補充關係，不替代法定披露。

把最近三年的事件按日期排成時間線。每個事件寫清公告日期、涉及主體、數量或金額、
實際進度、可能影響和原始連結。影響屬於你的分析時單獨標註，不從公告事實推測人物動機。

最後輸出治理關係圖的文字版、利益一致的證據、潛在衝突的證據
和未來十二個月需要跟蹤的公告清單。
```

Prompt 給每個事件規定了六個欄位：**日期**（什麼時候發生）、**主體**（誰參與）、**數量或金額**（影響範圍）、**實際進度**（區分計劃與完成）、**可能影響**（必須標明是分析）、**原始連結**（回到法定披露）。這樣整理出來的治理材料可以繼續追加，而不是讀完一次就失去用途。

## 一條時間線，比人物標籤更可靠

生成的近三年事件線裡，回購是否完成、員工持股怎樣安排、股東減持發生在什麼時間、關聯交易由哪個主體提出，都進入同一套結構。這比只寫"管理層重視股東回報"更可靠：回購金額、登出或持有安排、實施進度和公告日期都可以核對；員工持股和激勵計劃要看解鎖條件、資金來源與覆蓋物件。**事件本身是事實，事件對治理的影響仍然是分析。**

一個實操細節：同一事件可能被多份公告重複披露（首次方案、進展公告、完成公告），應當關聯到**同一個事件編號**，不能在統計時算成三件事——豆包工作可以協助去重，人工要確認關鍵欄位是否真的指向同一事項。

## 三輪收斂成完整檔案

**第一輪·法定披露終審**：逐項複核每類事件，補上公告日期、主體、數量、進度、原始連結和截止日狀態；工商或媒體材料只能作線索；人物動機、利益一致與潛在衝突必須標成分析欄，不得寫成公告事實。

**第二輪·生成完整結構**：固定資料截止日（精確到時分），基於實際開啟的巨潮公告生成十一部分完整檔案——控制關係文字圖、前十大股東變化、董監高變動、激勵/持股/回購/增減持、關聯交易與資本配置、三年時間線、利益一致證據、潛在衝突證據、未來十二個月跟蹤表、來源複核表、逐項核對清單。**沒有發生、沒有法定披露或未取得的專案也要逐項寫成明確待驗證項，不能省略**；刪除所有未經公告證明的因果判斷（如把關聯交易金額變化直接歸因為某董事離任）。

**第三輪·回讀驗收**：不再擴寫，重新開啟檔案逐項確認——檔名正確、截止日正確、十一部分齊全、待驗證項有說明、分析與事實分欄、統計數量自洽、舊檔案未被覆蓋；任何一項不滿足就重新生成再回讀。

## 把未確認的關係留在待驗證區

公司治理最容易被寫成人物故事。開啟時間線後只看事件、時間、決策程式和原始公告，**不給人物動機補台詞**：先核對股東、董事會和管理層的正式身份，不用媒體簡稱代替法定披露；再按日期排事件——同一個人出現在多份公告裡，不等於事件之間已經建立因果；最後看利益衝突、關聯關係和表決程式，缺公告的關係只寫"待驗證"，不用常識替它補證。

治理研究看的是**承諾怎樣落到事件上**：回購方案、實際執行、減持計劃、激勵條件和關聯交易放回同一條時間線。人物可以表達立場，公告負責留下事實。真正值得跟蹤的，是承諾有沒有兌現、激勵條件有沒有變化、利益關係有沒有被完整披露。治理研究最怕的不是留白，而是用性格判斷替代法定披露。
