# 多空到底在爭什麼？先把共同事實擺上桌，再把研報假設審一遍

你開啟一份研報或一場多空爭論，常覺得兩邊都有道理——多頭一套邏輯、空頭另一套，都引用資料。真正的分歧往往不在數字，而在藏在結論裡的假設。你研報也一樣：事實、預測和目標價排在同一頁，很容易把模型假設當成已經發生的事情。這篇先用寒武紀找多空共同事實，再用工業富聯拆一份研報：先確定雙方都承認什麼，再檢查誰把什麼假設放進了結論。

> 你讀一份研報時，場景往往是：同一家公司，多頭能講出一套完整邏輯，空頭也能講出另一套，兩邊都引用資料——真正的分歧往往藏在假設裡。研報也一樣：事實、預測和目標價排在同一頁，讀者很容易把模型假設當成已經發生的事情。

## 第一部分：多空雙方，先把共同事實擺出來

你先別急著站隊，第一步是把雙方都承認的事實擺上桌。

你觀點越激烈，越要先找共同事實——收入、客戶、產品進度和資本開支能不能回源，決定後面的爭論有沒有地基。你用「市場熱點分析」能力，匿名訊息、二手研報和官方披露分開處理：

```text
請整理截至固定資料日市場圍繞寒武紀 688256 的主要分歧。

先列出多方和空方都能核對的共同事實，包括收入、利潤、現金流、研發投入、
產品進展、客戶和競爭格局。每條事實必須有日期、來源和資料級別。

再分別列出多方與空方對增長、國產替代、競爭、毛利率、研發投入和估值的核心假設。
每個觀點寫明原始出處、最強反駁、可被證偽的條件和下一次驗證節點。
無法找到原始研報時，只能寫成二手觀點線索，不能保留機構目標價作為事實。

匿名傳聞和媒體獨家單獨放在未確認資訊中。
最後輸出共同事實表、分歧矩陣、決定性變數和後續驗證清單，不替我選擇立場。
```

你這個順序會改變回答方式：收入、利潤、現金流和研發投入先按日期與來源記錄，隨後才討論它們是否支援增長邏輯；你一個觀點必須寫出最強反駁與證偽條件——多方要說明出現什麼資料會削弱判斷，空方也要說明什麼變化會迫使自己修正。

### 把口號改寫成可以驗證的假設

你把口號式判斷改寫成可驗證變數，才有下一步可查。你「訂單能否轉成持續收入」比「國產替代空間很大」更容易驗證：前者可以回到收入確認、合同、回款和毛利率，後者沒有時間範圍和可觀察指標就很難判斷是否兌現。你分歧矩陣的作用，就是把宏大判斷改寫成下一次可以檢查的變數。

你三個實操要點：

1. 「共同事實」不代表雙方結論相同——同一筆高研發投入，多方理解為未來產品投入，空方擔心商業化速度。事實表只確認金額、期間和來源，解釋放下一層；兩層混在一起，觀點就披上了事實的外觀；
2. 決定性變數不宜太多——收入確認、毛利率、現金消耗、產品進展和客戶集中度已覆蓋大部分爭論，每個變數配一個可觀察指標和一個時間點，下一輪按原表核對；
3. 每次更新保留舊版本——新財報支援某項假設時記錄新增證據，資料不及預期時寫清觸發了哪條證偽條件，觀點被撤回也保留原因。你幾個季度之後，這張矩陣才能反映判斷怎樣隨證據變化。

你來源是這一輪的主要問題：實測報告主動承認 12 條關鍵事實沒有全部回到第一方材料，部分機構觀點來自二手平臺——只有機構名稱和一個數字，無法證明分析師用了什麼盈利預測、估值方法與時間基準。所以你要做來源等級終審：

```text
請繼續完善寒武紀多空分歧報告，完成一次來源等級終審。

重新檢查相關材料。公司事實優先回到定期報告、公告和投資者關係原文；
機構觀點必須寫明機構、作者、釋出日期、原始可訪問範圍。找不到原始研報時，
只保留為二手觀點線索，刪除目標價和具體盈利預測。匿名傳聞繼續留在未確認區，
不得因為後續股價變化而補證。

請輸出新的《寒武紀多空分歧矩陣.md》，包含共同事實表、多空核心假設、最強反駁、
證偽條件、驗證節點、來源等級表、未確認資訊和逐項核對清單。
另存為新檔案，保留前一版本。最後說明哪些觀點因來源不足被降級或刪除。不替我選擇立場。
```

## 第二部分：拿到研報，先拆事實、假設和目標價

你拿到一份研報，先別看目標價，按下面三步拆。

你研報不是公告——它可以提供框架和預測，但每一層材料的證據等級不同，目標價更要回到模型假設。用「個股研究」能力檢索公開研究材料，同時用公司定期報告核對已發生的事實：

```text
請在網上檢索截至固定資料日公開可訪問的工業富聯 601138 研究資料，
並同時查詢公司最近一期定期報告和相關公告。

優先選擇兩份釋出日期與機構清晰、正文或核心假設可以合法訪問的券商研報。
若只能取得公開摘要，明確標註資料級別，不假裝已經讀過完整研報。
分別提取釋出日期、作者機構、盈利預測、目標價方法、核心假設、催化劑和風險提示。
研報中的事實、分析師假設和投資觀點必須分開。

再用公司原始披露逐項核對收入、利潤、毛利率、資本開支、AI 伺服器相關業務
和客戶或訂單說法。無法從公司披露確認的內容明確標註。

最後比較兩份研報在哪些事實上一致，在哪些假設上分歧，目標價差異由哪些變數造成。
輸出研報對照表、事實核驗表、假設敏感項和下一步應該向分析師追問的問題。
不復述整份研報，也不給交易建議。
```

### OCR 材料不等於合格來源

你要注意，OCR 和截圖都不等於合格來源。你第一版的邊界很明顯：高盛全文來自第三方研報歸檔（慧博 OCR 存檔，作者名還有 OCR 歧義），不能按機構官網原文處理；UOB PDF 可以直接訪問（官方 PDF，印刷日期、目標價方法和盈利預測都有原文支援）。來源審計：

```text
請逐項回查剛才使用的兩份研報。列出原始連結、釋出日期、機構、作者、可訪問範圍
和你實際讀到的內容。無法合法開啟全文時，把所有來自二手摘要的結論降級，
並刪除沒有原文支援的目標價方法和盈利預測。隨後重新生成一張只保留可核驗證據的對照表。
```

你研報原文不合格時，不要為了湊齊兩份材料而降低門檻。實測的替換策略：保留已確認可訪問的 UOB 官方全文，再找一份機構、作者、釋出日期和正文都可從合法渠道直接訪問的研報；若確實找不到第二份合格全文，就把任務範圍改為「一份合格研報與公司原始披露的核驗」，明確關閉為「截至截止日沒有找到第二份合格全文」，而不是繼續保留雙研報目標價比較。

> 你研報分析的第一步不是抽取目標價，而是確認手上這份檔案到底是什麼：網頁摘要、截圖和 OCR 文字都不能直接當成原始研報。研報寫了一個數，不等於這個數已經被證明；原文拿不到就把結論降級，不用搜索摘要替它填滿。

## 先知道雙方在哪個假設上分開

你把這個視角用起來，多空和研報就能一起看。

你多空爭論和研報審計放在一起，最大的好處是能看清觀點的來源：你同一組事實，可以因為增長持續時間、資本開支強度、競爭格局或估值中樞不同，得到完全不同的結論。你研究者需要記錄的不只是「誰看多、誰看空」，而是哪一項假設變化以後，原來的判斷會失效。你目標價可以晚一點看——先把事實和假設分開，市場爭論才會從情緒變成一組能夠繼續驗證的問題。

## 常見問題

**多空雙方都引用資料，怎麼判斷誰對？**
你先別站隊。把收入、利潤、現金流這些共同事實按日期與來源記下來，再分別列雙方假設、最強反駁和證偽條件。爭論的地基穩了，觀點才比得出來。

**研報裡的目標價能直接信嗎？**
你不能。目標價建立在模型假設上，要先確認手上的檔案是不是真研報——網頁摘要、截圖、OCR 文字都不算原文。原文拿不到，就把結論降級。

**機構觀點只有名字和一個數字怎麼辦？**
你這種只能當二手線索。來源等級終審要求寫明機構、作者、釋出日期和可訪問範圍；缺這些，目標價和盈利預測直接刪掉，不替它補全。

**找不到第二份合格研報怎麼湊雙研報比較？**
你別為了湊兩份而降低門檻。明確改成「一份合格研報與公司原始披露的核驗」，關掉雙研報比較，比硬留兩個目標價誠實。

**分歧矩陣有什麼用？**
你把「國產替代空間很大」這種口號，改寫成「訂單能否轉成持續收入」這種可驗證變數——配一個可觀察指標和一個時間點，下一輪按原表核對，判斷才隨證據變化。
