# 常用指令模板怎麼抄？粘進去改檔名，活就派出去了

你新建任務準備派活，卻對著輸入框發呆：這句話到底該怎麼寫，它才聽得懂？別自己硬憋。下面這些模板你直接複製，新建「工作任務」粘進去，再補上你的檔案、連結、時間範圍和輸出位置就行。你改的只是檔名和範圍，骨架不用動。

三條通用紀律你先記牢：涉及多個檔案時建議先建立專案；涉及外部系統時先確認所需連接器已授權；涉及移動、覆蓋、傳送或釋出時，保留人工確認。

## 檔案整理

```text
請先讀取我提供的資料夾，統計檔案型別、數量和重複項。
按照檔案型別和主題給出新的資料夾結構與重新命名規則。
先輸出整理方案和預計改動清單，等我確認後再移動或重新命名檔案。
不要刪除任何檔案；遇到同名檔案時停止並詢問。
```

## Excel 分析

```text
請分析我提供的 Excel 檔案。
先檢查工作表、欄位、缺失值和異常值，再輸出核心指標、趨勢變化、可能原因和建議行動。
請生成摘要報告和必要圖表，並說明每個結論對應的資料範圍。
不要修改原檔案，把結果儲存為新檔案。
```

## PPT 生成

```text
請根據這份 Word 檔案生成一份 10 頁左右的 PPT。
每頁包含標題、3-4 個要點和建議圖表；所有資料與結論都應來自原文。
風格正式，適合管理層彙報。
先給出頁面大綱，確認後再生成完整檔案。
```

## 會議紀要

```text
請整理這段會議內容。
輸出會議結論、待辦事項、負責人、截止時間、風險點和未決問題。
沒有明確負責人或截止時間時標記"待確認"，不要自行補寫。
重要結論儘量保留對應原話或時間位置，方便複核。
```

## 行業調研

```text
請調研【行業 / 公司 / 產品】，時間範圍為【】。
輸出市場背景、主要參與者、競品對比、趨勢、機會和風險。
每條關鍵事實保留來源連結和釋出日期；來源之間存在衝突時並列說明。
無法確認的資訊標記"待核驗"，不要編造。
```

## 定時簡報

```text
請建立一份"每日行業簡報"的任務說明。
每天【時間】彙總過去 24 小時的【主題】資訊，最多 10 條。
每條包含標題、摘要、來源、釋出時間和連結；重複事件合併。
來源不足時說明缺失情況，不要為了湊數編造。
先在普通工作任務中執行一次，確認結果後我再到"定時任務"中儲存。
```

## 使用工作夥伴或小隊

```text
目標：【要完成的交付物】
資料：【專案、檔案或連結】
希望由【工作夥伴 / 工作小隊】完成。
請先說明分工、交接產物和需要我確認的節點，再開始執行。
未經確認不得對外傳送、釋出或覆蓋正式檔案。
```

檔案整理這段，適合桌面或下載目錄亂了的時候，讓它先出方案再動手，不刪不改你的原檔案。Excel 分析覆蓋檢查、指標、圖表，結果存新檔案，原表不動。PPT 生成先給大綱再出全文，避免方向跑偏。會議紀要提取結論、待辦、負責人和時間，沒負責人的標待確認。行業調研每條事實帶來源和日期，衝突並列說明。定時簡報先在普通任務跑通，再存成定時任務。

你第一次用，建議從檔案整理和 Excel 分析抄起，最貼近日常；做簡報翻 PPT 和紀要；做調研或看簡報再看後面。發出去前記得核數字和事實。這些模板都是起點，你按自己情況加減都行，不必照抄每一個字。

你不必每次從頭寫提示詞，骨架都備好了，只改檔名和範圍即可。遇到拿不準的活，先來這翻一段，比自己硬憋快。

## 新手常見問題

**這些模板我能直接抄嗎？**
能。你新建工作任務、粘進去、換掉檔名和範圍就能發，骨架不用自己寫。只是交回來後記得核數字和事實。

**涉及發郵件、發訊息的活，模板安全嗎？**
模板裡寫了「未經確認不得傳送、釋出」。你涉及移動、覆蓋、傳送時一定保留人工確認，別讓它擅自外發。

**多檔案任務，我該注意什麼？**
你涉及多個檔案時先建個專案，把材料歸到一起；涉及飛書、郵箱這類外部系統，先確認連接器已授權，再派活。

**定時簡報為什麼先跑一次再儲存？**
你先在普通任務裡跑一遍，看結果對不對、來源夠不夠，確認沒問題再到「定時任務」裡儲存，免得每天自動推一堆錯的。

**我改了模板，它還是按我的來嗎？**
會。你改的檔名、範圍、交付要求它都認。模板只是起點，你按自己情況加減都行。
