# 常用指令模板

在豆包工作中新建「工作任務」，貼上下面的模板，再補充檔案、連結、時間範圍和輸出位置。三條通用紀律：**涉及多個檔案時建議先建立專案；涉及外部系統時先確認所需連接器已授權；涉及移動、覆蓋、傳送或發布時，保留人工確認。**

## 檔案整理

```text
請先讀取我提供的資料夾，統計檔案類型、數量和重複項。
按照檔案類型和主題給出新的資料夾結構與重新命名規則。
先輸出整理方案和預計改動清單，等我確認後再移動或重新命名檔案。
不要刪除任何檔案；遇到同名檔案時停止並詢問。
```

## Excel 分析

```text
請分析我提供的 Excel 檔案。
先檢查工作表、欄位、缺失值和異常值，再輸出核心指標、趨勢變化、可能原因和建議行動。
請生成摘要報告和必要圖表，並說明每個結論對應的資料範圍。
不要修改原檔案，把結果儲存為新檔案。
```

## PPT 生成

```text
請根據這份 Word 文件生成一份 10 頁左右的 PPT。
每頁包含標題、3-4 個要點和建議圖表；所有資料與結論都應來自原文。
風格正式，適合管理層彙報。
先給出頁面大綱，確認後再生成完整檔案。
```

## 會議紀要

```text
請整理這段會議內容。
輸出會議結論、待辦事項、負責人、截止時間、風險點和未決問題。
沒有明確負責人或截止時間時標記"待確認"，不要自行補寫。
重要結論儘量保留對應原話或時間位置，方便複核。
```

## 行業調研

```text
請調研【行業 / 公司 / 產品】，時間範圍為【】。
輸出市場背景、主要參與者、競品對比、趨勢、機會和風險。
每條關鍵事實保留來源連結和發布日期；來源之間存在衝突時並列說明。
無法確認的資訊標記"待核驗"，不要編造。
```

## 定時簡報

```text
請建立一份"每日行業簡報"的任務說明。
每天【時間】彙總過去 24 小時的【主題】資訊，最多 10 條。
每條包含標題、摘要、來源、發布時間和連結；重複事件合併。
來源不足時說明缺失情況，不要為了湊數編造。
先在普通工作任務中執行一次，確認結果後我再到"定時任務"中儲存。
```

## 使用工作夥伴或小隊

```text
目標：【要完成的交付物】
資料：【專案、檔案或連結】
希望由【工作夥伴 / 工作小隊】完成。
請先說明分工、交接產物和需要我確認的節點，再開始執行。
未經確認不得對外發送、發布或覆蓋正式檔案。
```
