# 隨意操作 Excel，秒變資料分析大師

> 場景：工作表一多就頭大——列寬對不上、日期格式各寫各的、幾份明細要合併、公式還要一格格檢查。美化、清洗、合併、分析全交給豆包工作。

## Excel 一鍵美化

美化只解決**閱讀效率**，不負責修正資料：表頭、列寬、凍結、篩選和交替行底色讓明細更容易瀏覽，減少檢視長表時的誤操作。原始值、公式和工作表名稱應當保持不變。

```text
請美化我上傳的《2026年1月銷售明細.xlsx》檔案，

具體要求：
1. 不修改任何原始資料、公式和工作表名稱。
2. 表頭使用深藍色背景、白色加粗文字。
3. 設定適合的列寬和行高，避免文字被截斷。
4. 凍結首行並啟用篩選。
5. 為資料區域新增交替行底色。
6. 完成後另存為《2026年1月銷售明細_美化版.xlsx》。

只調整格式，不要改變資料內容。
```

驗收：文字有沒有被截斷，篩選和凍結是否可用，原始資料有無改動。

## 資料清洗與標準化

清洗要先定義**什麼算正確**：空格、地區寫法、數值格式和重複記錄都有明確規則，模型才有依據處理。無法確定的內容放進"問題資料"，比自動猜一個值更便於追溯。

```text
請清洗我上傳的《2026年1月銷售明細.xlsx》。

請保留原始工作表不變，新建"清洗後資料"和"問題資料"兩個工作表。

清洗規則：
1. 刪除文本欄位前後的空格。
2. 將"華 東"" 華東"等寫法統一為"華東"。
3. 將銷售數量、銷售單價轉換為數值。
4. 將折扣率統一轉換為小數，例如 10% 應儲存為 0.1。
5. 完全重複的記錄只保留一條。

不要擅自補全無法確定的資料。
```

系統會保留原始工作表，把符合規則的記錄寫入"清洗後資料"，無法確定的內容放進"問題資料"；除本地檔案外還會生成線上表格，適合繼續檢視和協作。

## 多個 Excel 合併

**縱向合併**（1—4 月明細合成總表）：

```text
請合併檔案中 2026 年 1 月至 4 月銷售明細檔案。

處理要求：
1. 按欄位名稱匹配列，不要只根據列的位置合併。
2. 將所有明細追加到一個名為"銷售總表"的工作表。
3. 新增"來原始檔"和"來源工作表"兩列。
4. 檢查各檔案是否缺少欄位或存在多餘欄位。
5. 根據訂單編號檢查重複記錄。
6. 不要直接刪除存在衝突的重複訂單，將其放入"合併異常"工作表。
7. 新建"合併摘要"，列出每個檔案的原始行數、有效行數和異常行數。
8. 最終輸出《2026年1-4月銷售合併表.xlsx》。
```

**橫向關聯**（交易明細 + 產品資訊 + 客戶資訊三張表）：

```text
請關聯以下三個檔案：
1. 2026年1-4月銷售合併表.xlsx
2. 產品資訊表.xlsx
3. 客戶資訊表.xlsx

關聯規則：
1. 使用"產品編號"將產品名稱、產品分類、標準售價和單位成本新增到銷售總表。
2. 使用"客戶編號"將客戶名稱、客戶行業、客戶等級和所在省份新增到銷售總表。
3. 以銷售總表為主表，即使沒有匹配到產品或客戶，也要保留銷售記錄。
4. 未匹配到的資料標記為"未匹配"。
5. 將未匹配記錄整理到"匹配異常"工作表。
6. 輸出產品匹配率和客戶匹配率。
7. 不要通過產品名稱或客戶名稱進行模糊猜測。
```

## 資料分析三步走

**公式新增計算列**（保留公式而非寫死數值）：

```text
請在 2026年1-4月銷售合併表_關聯產品客戶.xlsx 中新增以下計算列：

1. 銷售額 = 銷售數量 × 銷售單價 ×（1 - 折扣率）
2. 成本金額 = 銷售數量 × 單位成本
3. 毛利額 = 銷售額 - 成本金額
4. 毛利率 = 毛利額 ÷ 銷售額
5. 價格偏差率 =（銷售單價 - 標準售價）÷ 標準售價

要求：
1. 使用 Excel 公式，不要把計算結果寫成固定數值。
2. 銷售額、成本金額、毛利額保留兩位小數。
3. 毛利率和價格偏差率顯示為百分比。
4. 銷售額為 0 時，毛利率顯示為空白，不要產生除零錯誤。
5. 使用統一的公式結構填充全部資料行。
6. 對毛利率小於 10% 的訂單使用紅色條件格式。
```

**透視與經營彙總**（注意去重與口徑）：

```text
請根據 2026年1-4月銷售合併表_關聯產品客戶.xlsx 建立"經營分析"工作表。

需要統計：
1. 各月份的銷售額、毛利額、訂單數和毛利率。
2. 各區域的銷售額、毛利額和客戶數量。
3. 各產品分類的銷量、銷售額和毛利額。
4. 各銷售渠道的銷售額佔比。
5. 各銷售人員的銷售額排名。

要求：
- 訂單數按不同訂單編號統計。
- 客戶數量按不同客戶編號統計。
- 毛利率使用"毛利額合計 ÷ 銷售額合計"，不要直接平均明細毛利率。
- 新增總計。
- 金額使用千位分隔符。
```

**管理層儀表盤**（回答管理層每天追問的幾件事：規模有沒有變化、利潤是否健康、哪裡低於目標、誰需要跟進）：

```text
請基於"經營分析"建立一個管理層銷售儀表盤。

儀表盤包含：
1. 銷售額、毛利額、毛利率、訂單數四個核心指標。
2. 月度銷售額趨勢圖。
3. 各區域銷售額對比圖。
4. 產品分類銷售額排名圖。
5. 銷售渠道佔比圖。
6. 銷售人員前 10 名排行榜。
7. 實際銷售額與銷售目標的完成率。

設計要求：
- 整體使用簡潔的商務藍色風格。
- 核心指標放在頂部。
- 圖表標題和單位清晰。
- 不使用 3D 圖表。
- 控制顏色數量，避免過度裝飾。
- 對低於 80% 的目標完成率使用紅色提示。
```

圖表數量不必太多，能把異常和趨勢講清楚就夠了。實測從合併、關聯到公式、透視、儀表盤全流程資料未丟失。
