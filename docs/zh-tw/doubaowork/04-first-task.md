# 豆包工作第一單怎麼跑？五分鐘拿到一份能交的週報

你盯著空蕩蕩的豆包工作介面，遊標在輸入框裡一閃一閃。材料你其實都有——上週的銷售記錄、幾份散落的會議檔案——可你就是不知道第一句該敲什麼。複製進聊天框自己寫？那又繞回老路了，AI 替的活最後還是你幹。

這單別想複雜，就做一份週報。你跟著四步走：建任務、加素材、控權限、驗收。跑完這一圈，就能明白它和聊天豆包到底差在哪。

## 建任務：先開一單，別想名字

你點左側「新工作任務」，任務名隨便起，叫「第一單練習」也沒人笑你。先把這單當成練手，別想著一步到位做出多驚豔的東西。

進了編輯頁，你先加素材。點輸入框左邊的「+」，或者用「@ 新增資料」，把這次要用的檔案、資料夾丟進去。你手上的資料要是在飛書雲盤裡，它讀起來特別順；也能直接 @ 飛書聯絡人，把某個同事拉進這單活。

材料加完，你往下看底部，確認選的是「工作任務」，再挑一個權限檔位。這裡就三檔：始終詢問、按需確認、全部允許。第一單你選「按需確認」——它每次要動重要東西，都會先彈窗問你，最穩。

模型那欄保持 Auto 就行。活特別磨人再換 Turbo 或 Pro，順手把推理強度調一調。第一單用 Auto 夠了，別在模型上糾結。

## 一條能直接用的提示詞

材料齊了，把下面這段直接粘進輸入框，改改檔名就能發：

```text
請讀取我新增的三份工作記錄，整理成一頁週報。
結構為：本週完成、關鍵資料、問題與風險、下週計劃。
只使用材料裡明確出現的資訊；無法確認的內容放進"待確認"，不要補寫。
輸出 Markdown，同時保留每條關鍵結論對應的材料名。
```

點傳送以後，先別急著收結果。盯著它有沒有先讀材料、再生成。如果它一上來就給你寫週報，說明它壓根沒先翻你的檔案——你這時候補一句「先列出材料清單和時間範圍」丟回去，它就會老實先看再動筆。這個判斷技巧記住，往後每單都這麼驗。

## 驗收只看四件事

它交回一份 Markdown 週報。照著下面四件事核一遍：

1. 事實有沒有寫錯；
2. 數字能不能對上；
3. 「待確認」項有沒有留著，沒被它偷偷補寫；
4. 格式能不能繼續編輯，拿到別處還能改。

四件都過了，這單就算跑通。數字對不上就讓它重算，事實寫錯就指出來讓它改。先別急著加技能、接連接器，把第一單的驗收手感養出來再說。

## 三個入門任務

週報跑通，手不生了。下面三單拿去練，材料都在 input 目錄裡，程式碼塊裡的提示詞直接抄去發就行。

### A · 整理檔案

```text
目標：整理 input 目錄中的練習檔案，便於按型別查詢。
```

### B · 會議紀要

```text
請把 input/meeting.txt 整理為結構化會議紀要。
```

### C · Word 轉 PPT

```text
把 input/專案彙報.docx 轉成 10 頁以內的內部簡報 PPT。
```

## 分享前，先過這一關

產物能繼續改、下載、按需分享。但點「分享」之前，先確認內容裡沒有敏感或涉密資訊，再按公司規範選共享範圍。客戶名單、內部報價、未公開資料，別順手就發出去了。

介面還看不太懂沒關係，裝好後左邊找入口、中間看過程和結果，[主介面、任務和專案](/zh-tw/doubaowork/03-interface) 這篇講得更細。拿不準從哪類活下手，翻[場景速查表](/zh-tw/doubaowork/ref-scenarios)，按你的崗位對號入座。

## 新手常見問題

**它會不會亂改我電腦裡的檔案？**
不會為所欲為。每單都有權限檔位管著，你第一單選了「按需確認」，它動重要東西前都會先問你。真要它放手幹，再切到「全部允許」也不遲。

**提示詞要寫很長嗎？**
不用。會說人話就行——材料在哪、要什麼結果、什麼不能碰，這三樣說清，比背模板管用。上面那段週報提示詞，改改檔名就能直接用。

**為什麼它一上來就寫週報，不讀我的檔案？**
說明提示詞沒逼它先看材料。補一句「先列出材料清單和時間範圍」丟回去，它就會先翻再寫。往後每單都先用這招驗它有沒有走心。

**模型 Auto、Turbo、Pro 怎麼選？**
第一單 Auto 足夠，它自己挑合適的。活特別複雜、要長鏈條推理，再換 Turbo 或 Pro，把推理強度加上去。普通週報和整理檔案，用 Auto 就夠了。

**分享要注意什麼？**
點「分享」前，先確認內容沒有敏感或涉密資訊，再按公司規範選共享範圍。別把客戶資料、內部報價順手發出去。
