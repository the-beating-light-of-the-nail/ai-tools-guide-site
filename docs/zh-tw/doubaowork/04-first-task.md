# 五分鐘跑完第一個工作任務

裝好以後，用一單小任務把流程走通：建任務 → 加素材 → 控權限 → 驗收。

## 建立任務

1. 點擊左側「新工作任務」；
2. 點擊輸入框左側「+」或使用「@ 添加資料」，加入本次任務需要的檔案、資料夾或其他資料——豆包工作特別支援**飛書雲端硬碟資料**，還可以 @ 飛書聯絡人；
3. 確認底部選擇的是「工作任務」，可指定所屬專案，並選擇權限模式：**始終詢問 / 按需確認 / 全部允許**（第一單建議選「按需確認」）；
4. 模型保持 Auto 即可，也可按任務複雜度選 Turbo / Pro 和推理強度。

## 一條能直接用的提示詞

```text
請讀取我添加的三份工作紀錄，整理成一頁週報。
結構為：本週完成、關鍵數據、問題與風險、下週計畫。
只使用素材裡明確出現的資訊；無法確認的內容放進「待確認」，不要補寫。
輸出 Markdown，同時保留每條關鍵結論對應的素材名。
```

送出以後，看它**有沒有先讀素材、再產生結果**。如果一上來就寫週報，說明提示詞還可以再加一句「先列出素材清單和時間範圍」。

## 驗收只看四件事

1. 事實有沒有寫錯；
2. 數字能不能對上；
3. 「待確認」項有沒有留著；
4. 格式能不能繼續編輯。

第一單跑通以後，再慢慢加技能和連接器。產出可以繼續修改、下載或按需分享；分享前先確認內容不含敏感或機密資訊，並按公司規範選擇共享範圍。

## 三個入門任務

**A · 整理檔案**

```text
目標：整理 input 目錄中的練習檔案，便於按類型查找。
```

**B · 會議紀錄**

```text
請把 input/meeting.txt 整理為結構化會議紀錄。
```

**C · Word 轉 PPT**

```text
把 input/專案簡報.docx 轉成 10 頁以內的內部簡報 PPT。
```
