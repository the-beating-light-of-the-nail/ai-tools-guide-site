# 整理桌面：先看方案，再動檔案

> 場景：桌面 / 下載目錄一片狼藉。讓豆包工作先"唯讀掃描 + 出方案"，確認後再動手。

桌面檔案一多，先別讓豆包工作直接移動檔案。讓它**唯讀掃描、列出分類方案；確認無誤，再執行整理**。這樣既省時間，也避免重要檔案被放錯位置。

## 第一步：把要整理的資料夾加進專案

豆包工作只能修改**已新增到專案中的本地資料夾**。點選輸入框下方的「專案」，選擇「新增本地資料夾」，把桌面或目標目錄加進來——新增完成後，它才有許可權讀取並修改裡面的檔案。

## 第二步：先看分類方案，再確認執行

直接說明想怎麼整理。第一次建議讓它**先給出分類方案**：準備新建哪些資料夾、每類檔案會放到哪裡。看過方案後再確認執行，整個過程會穩妥很多。確認後，它會按方案建立目錄並移動檔案，散落的檔案歸到對應資料夾裡，基礎整理的效果已經夠用。

## 第三步：系統清理交給專門技能

整理完檔案，再試試系統清理：技能庫裡已有 `Doubao PC Optimizer`，它會按電腦維護流程檢查可清理項，再根據確認結果執行。涉及快取和臨時檔案這類系統內容時，用專門技能處理更穩妥。

## 三個安全習慣

1. 第一次先選一個**範圍較小、可以恢復**的資料夾試執行；
2. 先看**分類方案和移動清單**，確認後再執行；
3. 涉及**刪除、快取和系統清理**時，逐項檢查要處理的內容。

流程跑順以後，再把整理範圍擴大到整個桌面或下載目錄。
