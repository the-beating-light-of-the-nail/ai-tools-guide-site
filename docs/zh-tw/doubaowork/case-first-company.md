# 第一次研究一家公司：從商業模式到八種關鍵追問

> 場景：第一次看一家公司，最容易從股價、概念或新聞開始——資料收集了一大堆，還是說不清它到底賣什麼、客戶為什麼付錢、利潤從哪裡來。

更好的起點是先搭一張**公司事實地圖**：產品、客戶、渠道、成本、競爭壁壘和風險放在同一頁，後面的每個問題才有落腳點。這套方法既適合第一次覆蓋一家公司，也適合接手別人留下的研究資料。

## 第一步：把這門生意拆清楚

概念可以最後再寫。第一輪先回答六個樸素問題：**賣什麼、賣給誰、為什麼買、怎麼交付、成本在哪裡、誰有議價權**。工具用「個股研究」Skill，資料截止日固定：

```text
請基於貴州茅台 600519 年報、定期報告、公告和投資者關係材料，拆解這家公司怎樣賺錢。

1、說明公司賣什麼、賣給誰、通過什麼渠道收錢，收入怎樣確認，成本主要花在哪裡。
按產品和渠道比較收入、毛利率、增長與現金回收。繼續分析經銷體系、直銷渠道、產能、
基酒庫存、品牌定價和分紅在商業模式中的作用。

2、所有數字寫明期間、單位、財報頁碼或官方連結。把公司披露、管理層說法和你的推斷分開。
社會庫存、批價和渠道利潤若來自第三方調查，單獨說明樣本與日期。

3、最後交付業務地圖、賺錢邏輯、五個關鍵監控指標和三項容易被忽略的依賴。不直接給投資結論。
```

這段 Prompt 有一個明確的中心：每一項材料都要回答"這家公司怎樣把產品變成收入和現金"，與主線無關的品牌故事、歷史沿革和泛化行業背景不展開——既控制報告長度，也方便檢查材料是否真的改變了對業務的理解。

生成的業務地圖最實用的地方，是提醒研究者**不要把一個漂亮的指標單獨拿出來**：直銷佔比變化可能影響渠道關係與回款，產品結構會影響毛利率，基酒產量和庫存決定未來可銷售規模，終端批價與公司出廠口徑不能混用。新財報發布後沿同一張地圖更新，不用從公司介紹重新開始。第一次研究公司的讀者，可以把業務地圖當閱讀順序：先看收入來自哪裡 → 毛利率和回款 → 產能與庫存 → 最後才討論品牌與估值。

## 第二步：把八種 Prompt 接到事實底座上

事實底座搭好以後，Prompt 才不會變成八次重複搜尋——每種問法開啟一個研究入口：

| 研究入口 | 測試標的 | Skill | 主要交付 |
| --- | --- | --- | --- |
| 公司事實底座 | 貴州茅台 | 個股研究 | 業務、產品、渠道和戰略變化 |
| 行業週期 | 紫金礦業 | 行業分析報告 | 供需、庫存、價格和領先指標 |
| 業務拆解 | 美的集團 | 個股研究 | 業務結構、利潤來源和現金回收 |
| 財務品質 | 寧德時代 | 業績分析 | 利潤、現金流、單位與公式複核 |
| 股權與治理 | 格力電器 | 公告解讀 | 治理關係、事件線和跟蹤清單 |
| 多空分歧 | 寒武紀 | 市場熱點分析 | 共同事實、分歧假設和驗證節點 |
| 護城河與估值 | 中國神華 | 個股研究 | 護城河證據和估值隱含假設 |
| 盡調級研究 | 比亞迪 | 個股研究 | 業務、行業、財務、治理和反方證據 |

八條提示詞（資料截止日均為固定日期）：

**1 · 公司事實底座**：整理核心業務、主要產品、收入與利潤來源、主要客戶與渠道、產業鏈位置和最近三年重要戰略變化。只用可核驗的公告、定期報告和權威來源，每部分三到五條，數字寫明期間、單位和原始來源。

**2 · 行業週期**：研究供需、庫存、價格、資本開支、新增產能、行業集中度和主要政策變數，區分長期結構因素和短期波動因素；輸出當前週期判斷、三個領先指標、三個滯後指標，以及未來十二個月要觀察的資料。沒有可靠資料的地方直接列為缺口，不把價格預測寫成確定事實。

**3 · 業務拆解**：量化各業務板塊收入、利潤、毛利率和近三年趨勢，檢查是否存在"收入很大但利潤貢獻有限"的業務，也檢查子公司、聯營公司和非經常性損益；輸出一句話賺錢邏輯、業務結構表和五個持續監控指標。

**4 · 財務品質**：交叉驗證利潤與經營現金流，檢查應收、存貨、合同負債、資本開支、折舊攤銷、非經常性損益和會計口徑變化；所有異常給出**兩種解釋**和驗證路徑。

**5 · 股權與治理**：核對控制關係、主要股東、董事會和高管、股權激勵、回購、減持、關聯交易與資本配置；建立未來十二個月的解禁、回購、激勵跟蹤表。人物身份、任職時間和事件日期必須回到法定披露。

**6 · 多空分歧**：先列**共同事實**，再分別寫多方與空方的核心邏輯、最強反駁、可以被未來資料驗證的條件和關鍵驗證節點；未經官方確認的傳聞單獨列出，不站隊。

**7 · 護城河與估值**：用公司披露檢查資源稟賦、成本優勢、長協定價、一體化運營和分紅，再**反推當前估值隱含的煤價、產量、利潤率和分紅假設**。不要把週期高點外推成長期常態。

**8 · 盡調級研究**：

```text
請對比亞迪 002594 做一份投資者盡職調查報告。研究商業模式與護城河、汽車與電池行業供需、
最近三到五年的財務品質、治理與資本配置、估值隱含假設、空方邏輯和黑天鵝風險。
所有結論區分事實、解釋、推斷和判斷。財務資料必須交叉驗證利潤與現金流，
公司資料必須與主要同行使用同一報告期比較。每個關鍵數字註明期間、單位和原始來源。
輸出事實摘要、關鍵財務表、業務與行業分析、估值假設、最強反方證據、未來監控清單和
仍待核驗的問題。不要輸出買入、賣出、倉位或止損建議。
```

## 長任務要把資料缺口公開

實測中：紫金礦業主動列出 21 處資料缺口；格力形成治理跟蹤表；寒武紀把共同事實、多空論據、傳聞和資料等級分開。比亞迪報告越過了截止日（用到了 8 月 29 日才披露的半年報），用審計 Prompt 撤回：

```text
請審計剛才的盡調報告。所有資料繼續固定在截止日及以前，撤回之後才披露的半年報
及由它推匯出的結論。請確認報告是否已覆蓋財務品質、治理與資本配置、估值隱含假設、
最強反方證據和黑天鵝風險。缺失的部分只能使用截止日內已正式披露的材料補齊，
無法補齊時保留為待核驗問題。最後列出撤回內容、補齊內容和仍未完成的範圍。
```

第二輪把最近一期報告退回一季報，撤回全部半年報數字及估值判斷；PE TTM 和 PS 得以保留，PB、EV/EBITDA 因缺同口徑資料標為待核驗——**同行最新報告期和部分第三方資料沒有被強行補齊**。另一類常見問題：長任務停在半路（如空目錄沒生成檔案），就用"請從已經提交的原始要求繼續執行，直接生成檔案並給出檔案路徑"接續，同時重申截止日、來源和交付格式。

## 好 Prompt 會讓問題越來越具體

八種問法不代表每家公司都要跑八遍。第一次覆蓋先用商業模式把骨架搭起來；發現收入結構看不懂，轉向財報；發現市場爭議很大，進入多空審計；發現同行很多，做口徑統一後的橫向比較。Prompt 真正的價值是**讓研究逐步收窄**——問題越問越具體，證據缺口越來越少，這套提問系統才算開始工作。
