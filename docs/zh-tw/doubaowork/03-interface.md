# 主介面、任務和專案

豆包工作主介面分三個區域，先把這三塊看懂，後面的操作都有據可依。

| 區域 | 主要用途 | 使用時重點檢查 |
| --- | --- | --- |
| 左側功能導覽 | 新建任務；進入定時任務、技能、連接器、夥伴、雲端硬碟和「手機遙控電腦」 | 是否進入了正確的任務或功能入口 |
| 中間任務區 | 查看任務拆解、執行過程、工具呼叫和交付結果 | 任務是否按目標推進，結果是否需要補充或重工 |
| 底部輸入與控制區 | 輸入需求、添加資料、選擇工作任務或專案、設定確認方式、呼叫技能和連接器 | 資料、目標、約束和確認方式是否正確 |

一句話記法：**左邊找入口，中間看過程和結果，底部寫任務、加素材、控權限。**

## 任務和專案怎麼選

- **任務**：一件事說完、交付即結束，開新任務即可；
- **專案**：同一主題會反覆補素材、持續重工，或檔案多、時間長、要保持前後文一致——放進專案更合適。

## 模型與回應強度

輸入區右下角預設顯示 **Auto**，旁邊能看到目前回應強度。一般先用 Auto 就夠；如果帳號或版本提供其他選項，再按任務複雜度、速度和額度要求選擇 Turbo / Pro 與推理強度（低 / 中 / 高）。
