# 開啟豆包工作先看這三塊：介面、任務和專案

裝好了，開啟一看：左邊一排圖示，中間一大片，底部一個輸入框。然後呢？

介面你不用研究，記住三塊就夠：左邊找入口，中間看過程和結果，底部寫任務、加素材、控權限。 其餘功能用到再看。

## 左邊：入口都在這兒

新建任務在這裡，定時任務、技能、連接器、夥伴、雲盤、「手機遙控電腦」也都從這裡進。

你用的時候只留一個心眼：進對入口。想讓它定期幹活，別在普通任務裡翻，直接進定時任務；想讓它讀飛書檔案，先去連接器。

## 中間：它幹活的過程和結果

任務拆解、執行過程、工具呼叫，最後是交付結果，都在這兒。

跑偏了在這兒就能看出來。比如你讓它分析三份檔案，它只打開了一份——這時候打斷它，比等它寫完再推翻重來省事得多。

所以這一片別當裝飾。等它寫完只看結果，等於把驗收的機會讓出去了。

## 底部：寫任務、加素材、控權限

輸入框在這兒。新增資料、選擇工作任務或專案、設定確認方式、呼叫技能和連接器，都在這一帶。

你傳送前掃一眼：材料齊不齊、目標說清沒、確認方式對不對。

## 開任務，還是開專案？

判斷標準就一條：

- **一件事說完，交付即結束** → 開任務；
- 同一個主題要反覆補材料、持續返工，或者檔案多、時間長、要保持上下文一致 → 放進專案。

你拿不準就先開任務。跑完發現還要改第二版、第三版，再挪進專案也不遲。

## 右下角那個 Auto，要不要動？

輸入區右下角預設顯示 **Auto**，旁邊是當前響應強度。

你先用 Auto。整理檔案、寫週報、做表格這類活，它夠用。等你的賬號或版本給出 Turbo / Pro 和推理強度（低 / 中 / 高）的選項，再按任務複雜度、想要的速度和額度去挑。

新手最容易誤會的一點：「選最強的就一定最好」。不是。簡單活兒開高強度，等得久、額度花得快，出來的東西未必更準。

## 五分鐘動線

1. 你在左邊點「新工作任務」；
2. 底部輸入框加素材，檔案或連結都行；
3. 確認權限檔位，第一單選「按需確認」；
4. 寫下你要什麼結果，傳送；
5. 你看中間的過程，跑偏了就打斷。

詳細版見[五分鐘跑完第一個工作任務 →](/zh-tw/doubaowork/04-first-task)。

## 新手常見問題

**剛才那個任務找不到了？**
先看你是開在任務裡還是專案裡，再確認是不是換了登入方式——手機號登入和飛書登入是隔離的，互不相通（見[下載、安裝與登入](/zh-tw/doubaowork/02-install)）。

它老彈窗問我，能不能關掉？
那是你選了「按需確認」——它要動重要東西會先問你。第一單建議保持這檔，等你摸清它的脾氣再放寬。

**一定要建專案嗎？**
不用。一次性交付的活開任務就夠，專案是留給要反覆返工、持續補材料的主題的。

**技能、連接器現在就得配嗎？**
不用。前幾單先把「給素材 → 說結果 → 驗收」跑順，之後再按需要接（[連接器：先跑一個能驗收的小任務 →](/zh-tw/doubaowork/05-connectors)）。
