# 知識庫裡的攻略是幾年前的，怎麼讓豆包工作幫你核對過期資訊、還找得到負責人確認？

你興沖沖照著知識庫裡一份旅遊攻略訂行程，結果到了地方發現門票早漲了、地鐵線也變多了。知識庫能存東西，卻保證不了資料始終有效——一份幾年前的攻略，門票價格、開放時間、交通線路都可能變了。你跳過核驗直接用，資料越詳細，越容易讓你信了過時的結論。這篇帶你把「自動核驗 + 找 Owner 確認」寫進提示詞。

> 場景：知識庫能解決資訊存放的問題，卻無法保證資料始終有效。一份幾年前的攻略，門票價格、開放時間、交通線路和預約規則都可能變了——**跳過核驗直接使用，資料越詳細，越容易讓人相信過時的結論**。

你大概也遇到過這種事：照著舊攻略走，到了地方才發現門票漲了、線路變了。你越相信資料越詳細，越容易踩過時的坑。你不用自己逐條核——你把這事交給豆包工作，讓它邊查邊標出處。

以旅遊規劃為例：知識庫裡有一份 2013—2014 年的《上海旅遊攻略 PDF》寫著「東方明珠門票 100 元、地鐵只有 11 條線」，實際 2026 年二球聯票 199 元、地鐵已超 20 條線；聯絡人嚮明分享的《上海旅遊避坑指南（2026 版）》又說老攻略推薦的城隍廟小吃廣場「貴且難吃」。你真要手動逐條核驗，至少兩三個小時。

## 提示詞：把核驗要求寫進去

你先用簡短版，交代出行時間、目的地和輸出格式：

```text
我準備下週五去上海旅遊，請給我規劃一個 3 天 2 晚的行程。
結合我飛書中的相關資訊（知識庫、聊天記錄），為我量身定製旅遊行程，
最後以 HTML 格式輸出。請標註引用來源，並充分核實資訊是否已經過期。
```

完整版你把資料範圍、核驗要求、衝突處理和交付標準補齊：

```text
我準備下週五去上海旅遊，請幫我規劃 3 天 2 晚的行程。
結合我飛書知識庫中的旅遊攻略（Wiki 連結：【連結】），
以及聯絡人嚮明分享的《上海旅遊避坑指南（2026 版）.xlsx》。

要求：
1. 先讀取知識庫和聯絡人檔案，識別哪些資訊已經過期（如門票價格、開放時間、
   地鐵線路），哪些仍然有效。
2. 對於過期或相互衝突的資訊，單獨標註並找資料提供者或負責人確認，
   不要靜默替換。
3. 結合 2026 年的即時資訊（天氣、高鐵時刻、景點預約要求、近期展覽）
   進行核驗和更新。
4. 輸出 HTML 行程方案，包含每日詳細行程、交通、住宿、美食、預算和雨天備選。
5. 每條關鍵資訊標註來源（知識庫 / 嚮明 / 即時網路）和核即時間。
6. 出發前 48 小時提醒我再次確認天氣和景點臨時公告。
```

## 它怎樣推進

你發出去之後，它會這麼走：

1. 先確認資料來源：讀取飛書知識庫的歷史攻略、聯絡人分享的避坑指南和相關聊天記錄——先確定「手上有哪些資料」，避免規劃只依賴某一份攻略；
2. 提取易變資訊重點核驗：門票價格、開放時間、地鐵線路、高鐵車次、預約規則和近期展覽；舊攻略與新指南說法不一致時，保留不同說法及各自來源，不靜默替換；天氣、車次和景點公告等即時資訊聯網核驗；
3. 合併後才組合行程：舊攻略中仍有價值的路線經驗 + 2026 版避坑指南的實際建議 + 當次查詢的天氣交通訊息，放進同一份方案。

## 結果長什麼樣

核心資訊速覽先給你判斷框架：9 月 4—6 日 3 天 2 晚；去程 G256（431 元）返程 G3092（390 元）；住人民廣場或南京東路（1/2/8 號線，步行可到外灘）；人均約 2500—3200 元。三天主線：D1 抵達 → 南京路 → 外灘夜景；D2 上海博物館 → 豫園 → 2 元輪渡過江 → 陸家嘴；D3 武康路 → 安福路 → 本幫菜 → 新天地 → 返程。

結果還說明瞭各類資料的用法，方便你追溯每項建議的依據：2013 年 PDF 的價格和門票已過期，但路線邏輯和美食文化仍有參考價值；嚮明指南的 48 條建議中適合本次的已融入每天安排（選 2 元輪渡、去北外灘觀景、避開人流集中的網紅餐廳）。當次查詢顯示三天都有小雨，方案裡同時安排了浦東美術館、上博東館等雨天備選，並提醒你出發前 48 小時再次確認天氣和臨時公告。

完整的 HTML 行程把每天的時間段、交通路徑、景點預約、餐飲建議、預算和雨天備選放進同一個頁面——避坑建議掛在對應的景點、交通和餐飲環節，並保留資料來源：你清楚某條建議的依據，情況變化時也能回到原始資料重新確認。

## 啟發

這個例子展示的是過期知識的治理方法：保留舊資料中仍有價值的經驗，對易變資訊重新核驗，對來源衝突的內容保留依據和確認入口（找資料提供者或 Owner 確認，而不是靜默替換）。這樣整理後，知識庫才能持續為當下的任務提供可用資訊。你實際用於出行時，還可以補充酒店預算、飲食忌口、步行強度、必去景點，讓它進一步縮小選擇範圍。

## 新手常見問題

**豆包工作怎麼知道資料過期了？**
你讓它先做「識別哪些已過期」這一步，它再拿 2026 年的即時資訊（天氣、高鐵、預約要求）去比對。舊攻略和新指南說法打架時，它保留兩邊說法和來源，不偷偷替你換掉。

**為什麼不能讓它「靜默替換」？**
因為靜默替換會讓你以為資料一直是對的。你寧可看到「這條過期了、這條衝突了」，再決定信哪邊。找得到負責人的，它還會提示你去問本人。

**我手頭沒有飛書知識庫能用嗎？**
能。你把攻略檔案直接傳上去也行，提示詞裡把資料範圍改成本地檔案即可。飛書只是讓它能順帶讀聊天記錄和共享檔案。

**結果裡的價格、車次我能直接信嗎？**
你盯住每條資訊的「來源」和「核即時間」。即時類（天氣、車次）它聯網核驗過，但出行前 48 小時你最好再確認一次臨時公告。

**HTML 行程我能改成自己的嗎？**
能。它輸出的是可繼續編輯的頁面，你補上酒店預算、忌口、必去景點，選擇範圍還能再縮。整理完的行程，下次也能接著用。
