# 把生活瑣事，交給豆包工作先做一版

> 場景：旅行規劃、晚飯吃什麼、幾款商品怎麼選。AI 先整理資料、列候選、出清單；預訂、付款、診斷等重要決定，最後仍由人確認。

旅行怎麼排、晚飯吃什麼、幾款商品怎麼選，這些生活小事看上去都能一句話交代，真做起來卻牽涉預算、偏好、即時資訊和個人隱私。豆包工作適合**先整理資料、列出候選、生成清單**。

## 先判斷是哪類任務

| 類型 | 豆包工作可以輔助 | 人需要負責 |
| --- | --- | --- |
| 資訊整理 | 收集偏好、比較候選、生成清單 | 核對事實並做最終選擇 |
| 即時資訊 | 查詢並整理天氣、路線、價格和規則 | 回到官方頁面核實最新狀態 |
| 健康與隱私 | 整理記錄、準備要問專業人員的問題 | 診斷、治療、用藥和緊急處置 |
| 娛樂體驗 | 生成文化或娛樂性內容 | 不把結果用於高風險決定 |

需要特定能力時，在「技能·連接器·夥伴」中搜索旅行、天氣、地圖、生活、健康等關鍵詞。市場內容會變化，使用前檢視技能來源、許可權和資料去向；沒有合適技能時，先用普通工作任務完成資訊整理。

## 健康諮詢：解讀體檢報告

藉助醫學報告解讀類技能，可以把體檢報告先讀一遍（實測解讀比較準確，還會生成詳細的飛書文件，附飲食建議）：

```text
請解讀我上傳的體檢報告，先確認報告日期、檢查機構、專案名稱、數值、單位和參考區間。

把結果分成正常、超出參考範圍、資訊缺失和需要結合其他檢查判斷四類。
所有數值必須保留原文，不得改寫、補全或自行推算。

請用普通人容易理解的語言解釋每項指標通常反映什麼，以及哪些常見因素可能影響結果。
不要把相關性寫成病因，也不要根據單項指標給出確定診斷或患病機率。

最後整理一份複診時可以詢問醫生的問題，並列出仍需補充的資料。
不要提供處方、劑量、停藥或換藥建議。
```

## 消費比較：三款吹風機怎麼選

```text
我要比較追覓、戴森、徠芬 3 款吹風機。
主要是長頭髮使用，不傷頭髮，預算是 1000 以內。

只使用廠商官網、產品說明書、權威檢測資料和我提供的報價。
每項資訊註明來源和查詢日期。廣告宣傳、媒體體驗和可驗證引數分開呈現，
無法核實的內容標記為"待確認"。

先統一比較口徑，再用表格列出核心引數、實際使用限制、耗材價格、維護成本、
保修政策、隱私風險、總價和長期成本。
最後分別說明每款產品適合誰、在哪些情況下不適合。
不要因為銷量、評分或品牌知名度直接推薦。
```

## 旅遊規劃：先問清楚，再排行程

```text
我要規劃一次去雲南的 7 天旅行。

先不要直接排行程。請用不超過 8 個問題確認出發地、日期、同行人、總預算、
交通偏好、住宿要求、飲食禁忌、體力限制、必去地點和明確不去的地點。
已經提供的資訊不要重複詢問。

收到回答後，先給出兩套路線方向，分別說明行程節奏、主要區別、優缺點和預計花費。
等我選定方向後，再生成逐日計劃。

逐日計劃按上午、下午和晚上排列，寫清地點順序、交通方式、預計用時、餐飲建議、
預約要求和雨天備選。天氣、票價、營業時間、預約規則和交通班次註明查詢日期及來源。
無法確認的資訊標記為"待確認"，不要編造。
```

實測它會先給出兩套方案（含節奏、優缺點、預計花費），選定方向後再生成按上午/下午/晚上排列的逐日計劃。
