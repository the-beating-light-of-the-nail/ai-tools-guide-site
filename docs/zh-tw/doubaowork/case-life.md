# 生活瑣事拿不準？先讓它整理資料列清單，關鍵決定你拍板

旅行怎麼排、晚飯吃什麼、幾款商品怎麼選，這些生活小事你看上去都能一句話交代，真做起來卻牽扯預算、偏好、即時資訊和個人隱私。你一個人查很碎，又怕查不全。豆包工作適合先幫你整理資料、列候選、出清單，預訂、付款、診斷這些重要決定，最後仍由你確認。

> 場景：旅行規劃、晚飯吃什麼、幾款商品怎麼選。AI 先整理資料、列候選、出清單；預訂、付款、診斷等重要決定，最後仍由人確認。

## 先判斷是哪類任務

拿不準該放權到哪，對著這張表看：

| 型別 | 豆包工作可以輔助 | 人需要負責 |
| --- | --- | --- |
| 資訊整理 | 收集偏好、比較候選、生成清單 | 核對事實並做最終選擇 |
| 即時資訊 | 查詢並整理天氣、路線、價格和規則 | 回到官方頁面核實最新狀態 |
| 健康與隱私 | 整理記錄、準備要問專業人員的問題 | 診斷、治療、用藥和緊急處置 |
| 娛樂體驗 | 生成文化或娛樂性內容 | 不把結果用於高風險決定 |

需要特定能力時，在「技能·連接器·夥伴」裡搜旅行、天氣、地圖、生活、健康等關鍵詞。市場內容會變，用前看清技能來源、權限和資料去向；沒有合適的技能，你先用普通工作任務完成資訊整理。

## 健康諮詢：解讀體檢報告

借醫學報告解讀類技能，可以把體檢報告先讀一遍（實測解讀比較準，還會生成詳細的飛書檔案，附飲食建議）：

```text
請解讀我上傳的體檢報告，先確認報告日期、檢查機構、專案名稱、數值、單位和參考區間。

把結果分成正常、超出參考範圍、資訊缺失和需要結合其他檢查判斷四類。
所有數值必須保留原文，不得改寫、補全或自行推算。

請用普通人容易理解的語言解釋每項指標通常反映什麼，以及哪些常見因素可能影響結果。
不要把相關性寫成病因，也不要根據單項指標給出確定診斷或患病機率。

最後整理一份複診時可以詢問醫生的問題，並列出仍需補充的資料。
不要提供處方、劑量、停藥或換藥建議。
```

## 消費比較：三款吹風機怎麼選

```text
我要比較追覓、戴森、徠芬 3 款吹風機。
主要是長頭髮使用，不傷頭髮，預算是 1000 以內。

只使用廠商官網、產品說明書、權威檢測資料和我提供的報價。
每項資訊註明來源和查詢日期。廣告宣傳、媒體體驗和可驗證引數分開呈現，
無法核實的內容標記為"待確認"。

先統一比較口徑，再用表格列出核心引數、實際使用限制、耗材價格、維護成本、
保修政策、隱私風險、總價和長期成本。
最後分別說明每款產品適合誰、在哪些情況下不適合。
不要因為銷量、評分或品牌知名度直接推薦。
```

## 旅遊規劃：先問清楚，再排行程

```text
我要規劃一次去雲南的 7 天旅行。

先不要直接排行程。請用不超過 8 個問題確認出發地、日期、同行人、總預算、
交通偏好、住宿要求、飲食禁忌、體力限制、必去地點和明確不去的地點。
已經提供的資訊不要重複詢問。

收到回答後，先給出兩套路線方向，分別說明行程節奏、主要區別、優缺點和預計花費。
等我選定方向後，再生成逐日計劃。

逐日計劃按上午、下午和晚上排列，寫清地點順序、交通方式、預計用時、餐飲建議、
預約要求和雨天備選。天氣、票價、營業時間、預約規則和交通班次註明查詢日期及來源。
無法確認的資訊標記為"待確認"，不要編造。
```

實測它會先給你兩套方案（含節奏、優缺點、預計花費），你選定方向後再生成按上午/下午/晚上排列的逐日計劃。

## 新手常見問題

**生活的事全交給它，安全嗎？**
只把整理、列清單、出候選交給它；預訂、付款、診斷這些關鍵決定你自己拍板。它給的方案核一遍再行動，別閉眼照做。

**即時資訊（天氣、票價）它給的準嗎？**
讓它註明查詢日期和來源，最終回到官方頁面核實最新狀態。即時資訊變得快，別拿它的初稿當最終答案。

**體檢報告它能當醫生用嗎？**
不能。用解讀類技能只是先讀一遍、整理要問醫生的問題；它明確不diagnosis、不開方。真有問題你帶清單去問醫生。

**商品比較它會不會直接推薦貴的？**
提示詞寫了「不因銷量、評分或品牌直接推薦」，它按引數和限制客觀列。最終適合誰、不適合誰，由你結合自己情況定。

**旅遊規劃它一次給完行程嗎？**
不會。先答它不超過 8 個問題，它給兩套方向，你選了再出逐日計劃。這樣排出來的行程才合你意。
