# 下班前日報寫不出？讓群訊息和待辦自己湊成日報和提醒

你下班前最怕那幾行日報：會開了幾場、群裡回了無數訊息、檔案改了幾版，真到回想時你卻說不清今天到底推進了什麼。明天要跟進的事也散在各處——有的藏在聊天記錄，有的只在會上順口提過，有的已經過了截止時間。你讓豆包工作先把這批記錄收攏起來，日報和提醒就有了可靠的起點。

> 場景：下班前那幾行日報最難寫——會開了幾場、群裡回了無數訊息、檔案改了幾版，真到回想時卻說不清今天推進了什麼。

日報和週報你可以共用同一套過程：先讓它在群訊息、任務和日曆裡收當天發生的事 → 再區分成果、決定、待辦和風險 → 最後把要推進的事項轉成提醒。你寫報告靠的是當天留下的記錄，不用到最後憑記憶硬補。

## 彙總群訊息

群訊息裡混著討論、通知、表情回覆和閒聊。你彙總時更有用的做法是提取已經確認的結論、明確交付、待回答問題和阻塞事項，並保留必要的上下文：

```text
請幫我彙總今天"xxx群"的內容，生成日報。
```

系統會讀你指定工作群當天時間範圍內的訊息，過濾重複通知和閒聊，再提取已確認的結論、行動項、待回答問題和風險。

## 待辦任務提醒

提醒要幫你第二天決定先做什麼，不能只把待辦再念一遍——你結合截止時間、依賴關係、對他人的影響和預計工作量排個序：

```text
將今日待辦內容生成提醒，明天早上 9 點提醒我要先做哪些事情。
```

提醒可以留在豆包工作裡；你需要在固定時間開始、或要留一整段的工作，也可以寫入飛書日曆。日報負責說今天發生了什麼，提醒負責接住明天的動作——兩邊用同一份待辦狀態，任務才不會在不同工具裡反覆冒出來。

## 一套穩定的日常節奏

你早上看優先順序，白天在群裡和任務裡留記錄，晚上彙總成果與風險，再把沒完成的事項帶到下一天。報告因此成了工作的結果，提醒也接得住後續動作。

## 新手常見問題

**它彙總群訊息，會把我閒聊也寫進日報嗎？**
不會。你提示詞讓它提取「已確認結論、明確交付、待回答問題、阻塞事項」，它會過濾重複通知和閒聊，只留有用的。

**提醒能直接寫進我日曆嗎？**
能。提醒留在豆包工作裡也行；你要固定時間開工或留整段時間的，就寫入飛書日曆。日報和提醒共用一份待辦狀態，不重複。

**我白天沒留記錄，晚上還能出日報嗎？**
難。日報靠的是當天留下的群訊息、任務、日曆記錄。你白天隨手在群裡和任務裡留痕，晚上它才好彙總，別全靠記憶補。

**提醒只是把待辦念一遍嗎？**
不是。你讓它結合截止時間、依賴、對他人的影響、工作量排序，幫你決定明天先做什麼，而不是復讀清單。

**日報和週報能共用一套嗎？**
能。你先收當天發生的事，再分成果、決定、待辦、風險，最後轉提醒。日報和週報走的是同一套過程，只是時間範圍不同。
