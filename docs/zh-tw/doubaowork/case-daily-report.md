# 自動總結工作日報，提醒每日工作事項

> 場景：下班前那幾行日報最難寫——會開了幾場、群裡回了無數訊息、文件改了幾版，真到回想時卻說不清今天推進了什麼。

明天要跟進的事也散在各處：有的藏在聊天記錄裡，有的只在會上順口提過，還有的已經過了截止時間。讓豆包工作先把這些記錄收攏起來，日報和提醒就有了可靠的起點。

日報和週報可以共用同一套處理過程：**先從群訊息、任務和日曆裡收集當天發生的事 → 再區分成果、決定、待辦和風險 → 最後把需要繼續推進的事項轉成提醒**。寫報告依靠的是當天留下的記錄，不用等到最後憑記憶補齊。

## 彙總群訊息

群訊息裡同時存在討論、通知、表情回覆和臨時閒聊。彙總時更有用的做法是提取**已經確認的結論、明確交付、待回答問題和阻塞事項**，並保留必要的上下文：

```text
請幫我彙總今天"xxx群"的內容，生成日報。
```

系統會讀取指定工作群當天時間範圍內的訊息，過濾重複通知和閒聊，再提取已確認的結論、行動項、待回答問題和風險。

## 待辦任務提醒

提醒要幫助第二天**決定先做什麼**，不能只把待辦再念一遍——可以結合截止時間、依賴關係、對他人的影響和預計工作量排序：

```text
將今日待辦內容生成提醒，明天早上 9 點提醒我要先做哪些事情。
```

提醒可以留在豆包工作裡；需要在固定時間開始、或需要預留一整段時間的工作，也可以寫入**飛書日曆**。日報負責說明今天發生了什麼，提醒負責接住明天的動作——兩邊使用同一份待辦狀態，任務才不會在不同工具裡反覆出現。

## 一套穩定的日常節奏

早上看優先順序，白天在群裡和任務裡留下記錄，晚上彙總成果與風險，再把未完成事項帶到下一天。報告因此成為**工作的結果**，提醒也能接住後續動作。
