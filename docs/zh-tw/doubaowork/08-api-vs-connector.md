# API 服務和連接器，怎麼選

這兩個功能名字都帶「接」，容易混淆。一句話分清：**方向相反**。

| | API 服務 | 連接器 |
| --- | --- | --- |
| 方向 | 你在自己的網站或應用裡，**呼叫豆包大模型** | 豆包工作去**讀取飛書、網頁或其他業務系統** |
| 適合誰 | 開發者 | 普通職場使用者 |
| 典型用途 | 給自己的產品接上豆包模型的對話、生成能力 | 讓豆包工作直接讀飛書文件、騰訊會議紀錄、Notion 資料庫 |

## API 服務：給開發者

從頭像選單進入「API 服務」，會跳轉到火山引擎的開發者頁面。模型名稱、價格和接入方式可能更新，以當時的官方控制台和文件為準。

## 連接器：給所有人

如果你不是要開發應用，只是想讓豆包工作「搆得著」你的外部資料與工具——加連接器就夠了，詳見[連接器：先跑一個能驗收的小任務](/zh-tw/doubaowork/05-connectors)。
