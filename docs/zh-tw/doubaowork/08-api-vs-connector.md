# API 服務和連接器，我到底該選哪個？記住一個區別，你當場就能選對

你剛在頭像選單裡點開設定，一眼看見兩個入口：一個叫「API 服務」，一個叫「連接器」。名字都帶個「接」字，你心裡犯嘀咕——這倆是不是一回事？點錯了，會不會白忙活一天？

先吃顆定心丸：你不用背功能清單，只記一個詞就夠，叫**方向相反**。把這四個字吃透，後面怎麼選都清楚。

## 先把方向看明白

這兩個功能，說到底就是「誰主動找誰」不一樣。我們用一張表擺清楚：

| | API 服務 | 連接器 |
| --- | --- | --- |
| 方向 | 你在自己的網站或應用裡，**呼叫豆包大模型** | 豆包工作去**讀取飛書、網頁或其他業務系統** |
| 適合誰 | 開發者 | 普通職場使用者 |
| 典型用途 | 給自己的產品接上豆包模型的對話、生成能力 | 讓豆包工作直接讀飛書檔案、騰訊會議記錄、Notion 資料庫 |

你看左邊那列：API 服務，是你自己的網站或應用去「叫」豆包的大模型來幹活。右邊那列：連接器，是反過來，讓豆包工作主動去翻外面的資料。一邊拉它進來，一個是它走出去——這就是方向相反的意思。

## API 服務：給開發者

你如果是要給自己做的產品、網站或者小程式裡接上豆包的能力，走的就是這條路。

從頭像選單進入「API 服務」，它會跳轉到火山引擎的開發者頁面。在那邊你能拿到呼叫模型的方式。有一點記一下：模型名稱、價格和接入方式可能更新，以當時的官方控制台和檔案為準，別拿這篇當死規矩。

## 連接器：給所有人

你如果不是要開發應用，只是想讓豆包工作「夠得著」外面的資料與工具——加個連接器就夠了。

比如你平時資料散在飛書檔案、騰訊會議記錄、Notion 資料庫裡，裝了連接器，豆包工作就能直接讀進去，不用你一份份下載再上傳。具體怎麼跑通第一個，看這篇：[連接器：先跑一個能驗收的小任務](/zh-tw/doubaowork/05-connectors)。

## 怎麼選，一句話

你拿不準的時候，問自己一句：我要不要寫程式碼做產品？要，就上 API 服務；不要，只想讓豆包工作碰我的外部資料，就加連接器。絕大多數辦公場景，連接器就夠你用了。

## 新手常見問題

我是普通員工，用得著 API 服務嗎？
大機率用不著。API 服務是給開發者往自己產品裡接模型用的，你平時讓豆包工作讀飛書、讀會議記錄，靠的是連接器。不是開發者，別碰那塊就對了。

連接器要寫程式碼嗎？
不用你寫一行。它本來就是給普通職場使用者準備的，裝好授權就能讓豆包工作讀你的外部資料。你只要選好要連哪個系統、給它權限就行。

兩個功能能一起用嗎？
能，但面向的人不一樣。你做產品才需要 API 服務；你日常辦公，連接器就夠了。多數情況下只用到其中一個，別被名字裡的「接」字嚇到。

API 服務的價格會變嗎？
會變。模型名稱、價格和接入方式可能更新，一切以當時火山引擎官方控制台和檔案為準。你看到的頁面資訊跟著官方走，這篇只幫你分清概念。

連接器能讀哪些外部系統？
看你接了什麼。常見的飛書檔案、騰訊會議記錄、Notion 資料庫都支援。你具體想連哪個，去連接器那篇看怎麼跑通第一個。
