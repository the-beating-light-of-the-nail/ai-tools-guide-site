# 千問辦公藍皮書

**千問辦公**（qwenwork.cn，阿里推出的面向真實工作任務的 AI 辦公助手）不是又一個「會聊天」的 AI。你用一句自然語言說清目標，它讀取你授權的材料、規劃步驟、呼叫技能與連接器，交付可編輯、可核驗、可繼續流轉的工作成果——Word、Excel、PPT、調研報告，而不是一段只能複製的回答。

本板塊改編自《千問辦公藍皮書 V2.0》，全書只回答一個核心問題：怎麼讓 AI 從「能生成」走到「能交付」——生成內容不等於完成工作，結果只有可編輯、可驗證、可流轉，才算一次可驗收的交付。圍繞這條主線，藍皮書給出了任務交付協議、工作環境架構、自動化邊界、安全治理、價值度量等一套可落地的團隊規範。
