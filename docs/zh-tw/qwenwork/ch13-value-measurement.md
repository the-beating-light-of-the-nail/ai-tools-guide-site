# 價值度量：從使用資料到可復算決策

## 白話導讀

這一章幫你回答最現實的問題：這條 AI 工作流，到底值不值得繼續投。你最容易拿「很多人用、省了不少小時」去交差，但使用量不等於價值，節省工時也不自動等於現金收益。本章給你一套分層賬：使用、效率產能、質量、風險、現金五層分開記，現金 ROI 和可釋放產能不許混著報。你讀完就知道，只有實際減少的支出、有預算依據的避免、可歸因的毛利才能進現金賬；關鍵錯誤和未授權動作不能拿平均效率去抵消。你以後向老闆彙報，能拿出一筆可復算、經得起追溯的價值賬。你別被使用量帶節奏，你賬要回憑證，你分層記才經得起追，你硬門失敗先停。

## 什麼時候需要看

如果你只是想知道一份草稿是否好用，可以先按任務驗收，不必馬上計算價值。只有當你要決定是否繼續投入一份自動生成的週報、經營彙報或其他團隊工作流，比較人工時間、質量、風險、現金投入和可釋放產能時，再回到本章。先記住一句普通話：使用量不等於價值，價值要能回到任務、驗收、風險記錄和成本憑證。

## 30 秒結論

<span id="claim-usage-not-value-01" data-claim-id="claim-usage-not-value-01"></span>DAU、對話數、Token 和產物數只能說明使用，不能單獨證明企業 AI 已產生業務價值。

<span id="claim-capacity-separate-01" data-claim-id="claim-capacity-separate-01"></span>現金 ROI 與可釋放產能必須分開報告；質量和風險也單獨報告，只有形成可核驗的實際損失或收益時才進入現金口徑。

- 先鎖定任務、分母、基線和人工成本，再看試點結果。
- 節省工時不自動等於現金收益，新增產物也不自動等於增量收入。
- 擴大、最佳化、保持試點或停止，都要回到試點前登記的閾值和硬門。

白話解釋：你交價值賬前先鎖任務、分母、基線和人工成本，再看試點結果。你別把省下的工時直接乘工資當現金收益，也別把新產物當增量收入；現金 ROI 和可釋放產能、質量、風險各算各的，關鍵錯誤和未授權動作拿平均效率抵不掉。

## 為什麼重要

使用量很容易取得，也最容易被誤讀。一次任務可能產生多輪對話和多個檔案，卻沒有通過驗收；生成時間下降，也可能把輸入準備、複核和返工轉移給其他人。若團隊只展示活躍人數或「節省小時」，就無法判斷成本是否真實下降、質量是否保持、風險是否增加。

價值度量的用途不是為 AI 找一個更大的數字，而是幫助業務負責人配置資源。可復算的價值賬要讓未參與試點的人沿著任務樣本、時間記錄、驗收結果、風險事件和成本憑證複核結論，並看見不能現金化的部分。

白話解釋：你只看使用量，會被帶偏——一次任務多輪對話多檔案卻沒通過驗收，時間降了但複核返工甩給別人。你只秀活躍人數或省小時，就看不見成本真降沒、質量保沒、風險漲沒。價值賬是幫業務負責人配資源的，不是給 AI 找個更大數字。

## 方法或模型

### 先鎖定場景、樣本和基線

度量單位是一個邊界明確、結果可驗收的場景，不是「全公司使用 AI」。試點開始前登記：

- 任務起點、終點、符合資格的任務和排除規則；
- 基線期、試點期、季節性和任務難度的比較方法；
- 有效任務分母，以及失敗、中止和排除任務的留痕規則；
- 人工輸入準備、執行、等待、複核、返工、溝通和異常處理時間；
- 一次通過、退回、關鍵錯誤、風險事件和業務結果的定義；
- 訂閱、積分、實施、培訓、維護、治理和失敗損失的憑證或估算依據。

所有已啟動任務都保留結果。被排除的任務要保留理由，關鍵錯誤和未授權事件不得因排除而從風險記錄消失。基線和試點使用同一驗收標準；口徑變化時應重新建立基線，不把不可比較資料拼成平均值。

白話解釋：你度量單位是一個可驗收場景，不是「全公司用 AI」。你試點前先登記任務邊界、分母、排除規則、各段人工時間和成本憑證；被排除的任務也要留理由，關鍵錯誤和未授權事件不能因排除就從風險記錄裡消失。你口徑一變就重建基線，不把不可比的資料湊平均。

### 分層記錄，而不是先算一個總分

| 層次 | 最低記錄 | 能回答的問題 | 不能單獨證明 |
|---|---|---|---|
| 使用 | 符合條件任務數、執行數、使用者、重複使用、DAU、對話數、Token、產物數 | 是否有人使用、負載如何 | 質量、現金收益或業務結果 |
| 效率與產能 | 基線與試點總時長中位數、等待、人工步驟、同口徑有效任務量 | 時間在哪裡變化、可釋放多少產能 | 支出已經減少 |
| 質量 | 一次通過、人工修改、返工、關鍵錯誤、專業複核結果 | 交付是否達到同一標準 | 風險已經可接受 |
| 風險 | 未授權事件、隱私與權限問題、錯誤物件、失敗損失和接管結果 | 是否觸發硬門或停止條件 | 業務價值可以抵消風險 |
| 現金 | 已實現收益、增量成本、憑證、歸因和敏感性 | 已實現現金結果能否復算 | 未現金化產能的未來價值 |

白話解釋：你別上來算一個總分。使用、效率、質量、風險、現金五層各記各的——使用層只說明有人用、負載多大，證明不了質量或收益；現金層只回答已實現結果能否復算，證明不了未來產能值多少。你分層記，結論才經得起追。

### 使用唯一現金與產能口徑

<span id="claim-cash-roi-formula-01" data-claim-id="claim-cash-roi-formula-01"></span>本書建議：現金 ROI 只納入已經實現或有可核驗依據的現金收益，並計入從輸入準備、人工複核到治理和失敗損失的全部增量成本。

```text
已實現現金收益 = 已實際減少的支出
               + 有預算依據且可證明的支出避免
               + 可歸因的增量毛利

增量總成本 = 訂閱與積分 + 實施 + 培訓 + 輸入準備 + 人工複核
           + 返工 + 維護 + 治理 + 已實現的失敗損失

現金淨收益 = 已實現現金收益 − 增量總成本
現金 ROI = 現金淨收益 ÷ 增量總成本

可釋放產能 =（基線單任務總時長中位數 − 試點單任務總時長中位數）
             × 同口徑有效任務量
```

現金收益與成本必須使用同一統計期間、幣種和價格口徑。一次性成本和持續成本分列；若用於跨週期決策，應披露一次性成本的處理規則、覆蓋週期、各期持續成本和未計入專案，並服從組織財務制度。禁止混用年收益與月成本，也不能把預測期間收益與已實現期間成本放在同一現金 ROI 中。

增量總成本小於或等於 0 時，不計算或展示現金 ROI。此時報告已實現現金收益、現金淨收益、增量總成本及其為非正數的原因、證據和統計邊界；不能用「無限 ROI」或其他除法結果替代絕對金額。

時長與任務量採用非負、同單位、同口徑輸入：基線與試點時長使用相同時間單位、任務起止點和樣本規則，有效任務量使用同一任務定義和計數單位。基線單任務總時長中位數減去試點單任務總時長中位數為負時，不稱為負的「可釋放產能」，而應按相同時間單位報告為新增產能佔用或產能損失，說明原因，且不得與現金收益抵消。

可釋放產能是時間容量，不是現金收入。只有組織確實減少支出、依據已有預算避免支出，或形成可歸因增量毛利時，相應金額才進入已實現現金收益。避免招聘但沒有已批准預算、員工時間重新分配、新增檔案或新增對話都應在非現金結果中披露。

白話解釋：你算現金 ROI 只進「已實現或能核驗」的收益，並把訂閱、實施、培訓、複核、返工、治理、失敗損失全算進增量成本。你時長不能為負就叫「負產能」，得報成產能佔用或損失；增量成本≤0 時不算 ROI，別拿「無限 ROI」糊弄，老老實實報絕對金額和原因。

### 控制歸因、年化和重複計算

每次價值報告必須同時寫明統計週期、樣本規則、歸因假設和低/中/高敏感性區間。敏感性分析只改變已經披露的關鍵假設，例如有效任務量、人工成本或可歸因比例，不能改變硬門和事實記錄。

短期試點不得無條件年化。若必須形成預算情景，應單列業務週期、季節性、任務量上限、維護成本和失敗率假設，並明確這是預測而非已實現收益。交付加速、質量損失避免額和人工成本不能重複計算；同一結果只能進入一個現金專案，並保留計算路徑。

質量和風險預設單獨報告。只有已經發生、金額可核驗且歸因清楚的返工支出、賠付、損失或收益，才按相同憑證規則進入現金賬。平均效率或現金淨收益不能抵消關鍵錯誤、未授權動作和其他硬門失敗。

白話解釋：你每次報告都得寫清週期、樣本、歸因假設和敏感性區間；敏感性只能動已披露的關鍵假設，不能動硬門和事實。你短期試點別無條件年化，要年化就單列週期和假設並標明是預測。同一筆結果只能進一個現金項，不能重複算；質量風險單獨報，硬門失敗拿平均效率抵不掉。

### 用登記閾值作決定

價值報告不在結果出現後另設門檻。決策引用 [第 10 章閾值登記表](/zh-tw/qwenwork/ch10-pilot-roadmap)：

- **擴大**：全部適用硬門通過，目標指標達到登記閾值，證據支援擴大後的任務和權限範圍。
- **最佳化**：硬門未失敗，但輸入、入口、質量門或人工步驟存在可驗證改進點，修改後重新測試。
- **保持試點**：價值方向尚不明確、樣本或業務週期不足，繼續限定範圍取證。
- **停止**：觸發硬門、無法形成可驗收結果、增量成本不可接受，或繼續取證的價值不足。

白話解釋：你做擴大/最佳化/保持/停止決定，不另設新門檻，直接引用試點前登記的閾值表。你硬門全過且達標才擴大，硬門沒敗但有改進點就最佳化，樣本不足就保持試點，觸發硬門或成本不可接受就停。

### 辦公動作例子：要不要繼續投入自動生成的週報或經營彙報

決定是否繼續，不是看有多少人開啟過工作流，而是把同一批任務的五件事分開看。先記錄輸入版本、人工修改、異常、驗收和最終結果，再與試點前登記的基線、閾值和硬門對照。

| 要看的部分 | 用普通辦公動作怎麼判斷 | 能得出的結論 |
|---|---|---|
| 時間 | 把輸入準備、執行、等待、複核、返工、溝通和異常處理都計入，比較基線與試點的單任務總時長中位數。 | 說明時間是否變化，以及能釋放多少時間容量；不能直接說已經省下現金。 |
| 質量 | 記錄一次通過、人工修改、退回、復算結果、專業複核和關鍵錯誤，不能只統計最終被採用的報告。 | 說明交付是否仍達到同一標準；階段通過或平均效率都不能掩蓋關鍵錯誤。 |
| 風險 | 全量記錄未授權訪問、外發、寫入、錯誤物件、隱私問題、接管和恢復驗證。 | 說明是否觸發停止條件；價值統計不能抵消硬門失敗。 |
| 現金 ROI（現金投入產出比） | 只把已經實際減少的支出、有預算依據的支出避免或可歸因增量毛利計入收益，並扣除訂閱、實施、培訓、複核、返工、維護、治理和已實現失敗損失。 | 說明已實現現金結果能否復算；節省工時、新增檔案或新增對話不能直接寫成現金收益。 |
| 可釋放產能 | 用公式計算任務總時長中位數差額乘以同口徑有效任務量，單獨報告人員可以轉去做什麼，不能把它當作收入。 | 說明時間容量是否釋放；只有真正減少支出、按批准預算避免支出或形成可歸因毛利時，才進入現金收益。 |

例如，週報生成得更快，但人工複核和返工變多：時間未必改善，質量要單獨說明，現金 ROI 不能用想像的工資節省補上。又例如，經營彙報被更多人使用，但一次關鍵口徑錯誤導致業務判斷改變：先停止，保護原件，人工接管並完成恢復驗證，再更新價值賬；不能因為使用量高或報告按時生成就繼續投入。若硬門全部通過、登記閾值達到且新增範圍有相應證據，才進入「擴大」；只有硬門未失敗但流程仍需改進，才是「最佳化」；樣本或週期不足就「保持試點」，觸發硬門或無法驗收則「停止」。

可參考 [第 9 章公開案例圖譜（含 32 個待核驗場景線索）](/zh-tw/qwenwork/ch09-public-case-atlas) 選擇一個週報或經營彙報形態做記錄練習。圖譜只幫助理解場景，不提供你的基線、成本或價值結果；普通記錄至少包含輸入版本、人工修改、異常、驗收和結果。

白話解釋：你決定續不續投，看的是同一批任務的五層賬，不是開啟人數。你週報快了但複核返工變多，時間未必改善、現金 ROI 不能用想像工資補；經營彙報用得多卻一次關鍵口徑錯改了業務判斷，先停、保護原件、接管恢復，再更新賬。你硬門全過且達標才擴大，沒敗可改才最佳化，樣本不足就保持，觸發硬門就停。

## 案例與證據

以「月度經營報告」為例。團隊先記錄人工流程中的資料準備、勾稽、解釋、審閱和返工，再用同一任務邊界記錄試點。若生成報告更快，但財務人員增加了復算和修正時間，總時長可能沒有下降；若報告提前交付但沒有產生已實現支出減少或可歸因毛利，提前量應作為業務結果或可釋放產能報告，而不是直接寫入現金收益。記錄時把輸入版本、人工修改、異常、驗收和結果繫結到同一任務，才不會把「使用過」誤寫成「產生價值」。

同樣，若試點期間出現一次錯誤口徑並改變經營判斷，即使平均時長下降，也要在質量與風險層記錄，並按階段門處理。刪除失敗樣本後再計算一次通過率，或只統計被採用的報告，會使分母失真。

本章公式和預設分類屬於社群實踐規範，不是會計準則、估值意見或已經驗證的行業基準。企業應由財務、業務和資料責任人共同確認憑證、歸因與適用口徑。

白話解釋：你拿「月度經營報告」舉例——快了但財務復算修正變多，總時長可能沒降；提前交了但沒產生已實現支出減少或可歸因毛利，提前量只能報成業務結果或產能，不能寫進現金收益。你刪掉失敗樣本再算通過率、只統計被採用的報告，分母就失真，結論站不住。

## 企業行動

為一條準備復盤的工作流建立一張場景價值賬：

1. 由業務負責人鎖定場景、任務資格、分母、基線期和試點期。
2. 由使用者逐任務記錄輸入準備、執行、等待、複核、返工和異常處理。
3. 由內容複核者使用同一驗收標準記錄一次通過、修改和關鍵錯誤。
4. 由資料/安全責任人全量登記未授權、隱私、權限和接管事件。
5. 由財務或相應責任人核驗現金收益、增量成本、憑證和歸因假設。
6. 分別計算現金結果與可釋放產能，並單列質量、風險和敏感性區間。
7. 對照試點前閾值作出擴大、最佳化、保持試點或停止決定，記錄批准人與後續範圍。

停止訊號包括：基線與試點口徑不同；失敗任務從分母消失；人工複核或返工未計時；把節省工時直接乘工資寫成現金收益；把同一結果重複計入多個專案；短期結果無條件年化；關鍵錯誤被收益數字抵消；計算無法回到任務和憑證。

白話解釋：你建場景價值賬，業務負責人鎖口徑、使用者逐任務記時間、複核者記質量、資料/安全全量記風險、財務核驗現金。你出現口徑不同、失敗從分母消失、省工時乘工資當收益、同結果重複計、短期無條件年化、關鍵錯誤被收益抵消——這些都是停止訊號，賬不能這麼算。

## 邊界與下一步

可復算不等於因果關係已經得到嚴格實驗驗證。前後對照可能受熟練度、季節性和任務難度影響；低頻複雜任務更適合披露完整案例、專業複核和限制，不能偽裝成穩定均值。現金結果還應服從組織財務制度和適用會計要求。

價值度量決定工作流是否值得繼續投入，不決定產品官方路線。產品、夥伴和生態建議應單獨標註公開事實、已實測組合、可行推斷與待驗證假設，避免把建議寫成承諾。

白話解釋：你可復算不等於因果嚴證——前後對照會被熟練度、季節性、難度帶偏；低頻複雜任務你披露完整案例和限制，別偽裝成穩定均值。現金結果還要服組織財務制度。價值度量只管「值不值繼續投」，不管產品官方路線。

## 術語翻成人話

| 術語 | 人話 |
|---|---|
| 現金 ROI | 已實現現金收益減全部增量成本再除成本；你只進「真發生或能核驗」的收益；你算前先鎖口徑 |
| 可釋放產能 | 單任務時長差額乘同口徑任務量，是時間容量不是收入，你別當現金寫，你只報時間容量 |
| 同口徑基線 | 試點前記下的原樣做法資料，你和試點用同一把尺、同一分母比 |
| 分母 | 算比例時「總任務數」的口徑，你失敗任務不能悄悄移出，否則比率失真 |
| 硬門 | 關鍵錯誤、未授權等不可放寬項，你觸發了價值統計也抵不掉，必須停，你遇硬門先停賬 |
| 敏感性區間 | 低/中/高三種假設下的結果範圍，你只動已披露的關鍵假設 |
| 非現金結果 | 避免招聘但無預算、時間重分配等，你單列披露，不能塞進現金賬 |

## 常見問題

**你想證明一條工作流「省了錢」，直接把節省工時乘工資行嗎？**
不行。節省工時只是可釋放產能，不是現金收益。你只有實際減少支出、按已批准預算避免支出，或形成可歸因毛利，才能進現金賬；否則在非現金結果裡單列披露。你別把產能當收入，也別把新增檔案當增量。

**你看到使用量漲、報告按時出，能不能繼續加大投入？**
不能只看這個。你若一次關鍵口徑錯誤改了業務判斷，先停止、保護原件、人工接管並恢復驗證，再更新價值賬。使用量高、出得準時，都不抵消硬門失敗。你別被表面熱鬧騙了，硬門失敗才是紅線。

**你把同一筆好處重複算進多個現金專案，會有什麼後果？**
同一結果只能進一個現金專案，且保留計算路徑。你重複計入，現金 ROI 就被誇大，未參與試點的人沿憑證追賬時會發現對不上，結論作廢。你重複算就自己埋雷，結論一追就穿。

**你短期試點跑出好結果，能不能直接年化去申請預算？**
不能無條件年化。你若要形成預算情景，必須單列業務週期、季節性、任務量上限、維護成本和失敗率假設，並標明這是預測而非已實現收益。你年化得標清是預測，不能當已實現吹。

**你作為財務或業務負責人，價值賬必須能回到什麼？**
必須能回到任務樣本、時間記錄、驗收結果、風險事件和成本憑證。你算出來的數字，要讓沒參與試點的人沿這些憑證復算得出來，否則只是故事不是賬。你經不起復算的賬不算賬，憑證就是底線。
