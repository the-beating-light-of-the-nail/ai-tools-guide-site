# 快速開始：完成第一個可驗收任務

這份快速開始只做一件事：使用 [第 2 章唯一任務卡](/zh-tw/qwenwork/ch02-task-delivery-protocol)，完成一個低風險、可驗收的草稿任務。以下以「把已授權的會議材料整理為內部紀要草稿」為例，不在本頁另建任務卡欄位。

## 1. 選任務

選擇輸入已經取得授權、輸出可以人工核對、失敗後容易回到原狀態的任務。先把本輪範圍限定為生成內部可編輯草稿，不包含傳送、系統寫入或釋出。

若輸入來源、使用許可權或最終檢查人無法確認，先換一個邊界更清楚的任務。

## 2. 填寫任務卡

開啟 [第 2 章任務交付協議](/zh-tw/qwenwork/ch02-task-delivery-protocol)，按該章唯一規範逐項填寫本輪任務卡，並由最終檢查人確認。不要把口頭要求或一段提示詞當成任務卡。

需要組織呼叫語句時，可以使用 [提示詞附錄的任務交付與稽核模板](/zh-tw/qwenwork/appendix-templates)；任務卡欄位及含義仍只由第 2 章定義。

## 3. 確認輸入與許可權

列出本輪實際使用的會議材料、轉寫、參會名單及其版本，確認每項資料的來源、日期、訪問許可權和允許用途。缺少資料、版本衝突或許可權不明時，停止生成並請資料責任人處理。

若任務後來需要傳送、寫入、刪除或釋出，先按 [第 11 章安全治理](/zh-tw/qwenwork/ch11-security-governance) 核對控制規則，展示實際物件和影響，取得所需確認並準備可驗證的回退方式；本頁不重新定義控制等級。

## 4. 生成草稿

把已確認的任務卡和輸入交給 AI，先要求它複述任務邊界，列出缺失、衝突和無法確認的內容。邊界一致後，只生成內部可編輯紀要草稿，不自行補造人名、金額、日期、決定或責任歸屬。

保留原始輸入和生成版本。需要人工確認的內容明確標出，不把未確認內容寫成事實，也不執行任務卡以外的動作。

## 5. 驗收與記錄

由任務卡指定的檢查人逐項驗收草稿。驗收未通過就記錄退回原因並修訂；無法滿足任務卡要求時，結束本輪並保留問題，不用「基本可用」替代通過結論。

儲存本輪任務卡、輸入版本、生成版本、人工修改、異常、驗收結果和最終確認記錄，讓下一次執行能夠解釋差異。

同一任務只有達到 [第 10 章「個人模板候選」階段門](/zh-tw/qwenwork/ch10-pilot-roadmap) 後，才考慮複用為個人模板；階段門的樣本、硬門和核准要求均以該章為準，不在本頁複述。
