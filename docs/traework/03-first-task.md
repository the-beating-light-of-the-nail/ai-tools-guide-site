# 第一个任务：从一句话到交付物

装好之后，用一次完整的任务流走一遍：发起 → 观察 → 验收 → 分享。以 Work 模式为主线。

## 发起任务

1. 在主界面对话框中**选择一个项目**（网页版也可以不选直接发指令，系统会自动创建项目并按指令关键词命名）；
2. 输入任务指令——文字或语音都行；
3. 发送。

输入框还能补充上下文：附件（.pptx、.xlsx 等）、图片、斜杠命令（`/`）、技能。

一个适合第一次跑的任务示例：

```text
读取我上传的销售数据.xlsx，按产品线统计本月销售额和毛利率并排名，
输出一份 Excel 汇总表和一段 200 字的结论摘要。
要求：数字必须与源文件一致，不要推测原因，无法确认的标注待核实。
```

## 观察执行：工具面板

界面右上角「展开工具面板」是观察 AI 干活的地方，按模式提供不同页签：

| 页签 | 可用模式 | 用途 |
| --- | --- | --- |
| 任务摘要 | Work / Design：待办、任务产物、参考信息；Code：待办、上下文 | 看拆解出的步骤与产物 |
| 浏览器 | 全模式 | 预览 AI 产物、验证视觉与交互 |
| 终端 | Code | 运行终端命令 |
| 画布 | Design | 预览/整理产物、导出设计文件 |

## 验收与修改产物

Web 应用类产物开发完成后会自动打开预览页签。修改产物有三种方式：

1. **直接修改**：点右上角「选择元素」→ 选中元素 → 在「设计」或「CSS」面板改属性（手动编辑仅支持文字类元素，可调字号、加粗、对齐）；
2. **评论到对话**：填修改意见，连同所选元素发给 AI 处理；
3. **截图修改**：截取元素或区域 → 可用矩形/箭头标记 → 填修改意见 → 发给 AI（也可添加到评论列表批量发）。

HTML 产物（需求文档、产品原型、分析报告）支持**原型与文档联动**：修改原型某部分后，PRD 文档中对应内容会同步更新。

## 管理任务与产物

- **任务管理**：左侧任务栏悬浮「更多操作」（或对话面板顶部任务名旁）→ 置顶、查看任务文件（列表/树状）、新建/重命名/删除；
- **全局搜索**：界面左上角搜索图标，跨模式查找任务或 Query；
- **产物空间**：左侧导航「我的文件」，集中管理本地产物、云端产物和飞书云文档。卡片「···」菜单可置顶、「在任务中打开」（继承原对话上下文继续编辑）、分享（生成公开链接，产物更新后同一链接仍可看最新版）、下载（仅云端产物）、删除（**会连带删除对应原始任务，不可恢复**）。

## 分享对话

做出好结果想给同事看：对话流中悬浮 Query/答复点「分享」图标（或左侧任务列表右击任务选「分享」）→ 勾选要分享的内容 → 两种形式：

- **生成图片**：复制或下载，适合贴群、贴文档；
- **分享链接**：生成链接和二维码。

## 任务说明怎么写

和所有任务型 AI 一样，TraeWork 的产出质量由任务说明决定。六要素：

| 要素 | 要回答的问题 |
| --- | --- |
| 目标 | 最终要解决什么问题 |
| 输入 | 使用哪些文件、目录或链接 |
| 动作 | 分析、整理、转换还是生成 |
| 约束 | 哪些不能改，采用什么规范 |
| 输出 | 交付什么文件，放到哪里 |
| 验收 | 用什么标准判断合格 |

第一次不熟练？左侧导航顶部有**模板库**，按场景提供预设好任务说明、执行步骤和交付要求的模板，点「做同款」补齐背景素材即可直接发起。
