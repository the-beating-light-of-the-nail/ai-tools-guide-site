# 第一个任务怎么跑通？从一句话拿到能交的活

你刚装好 TraeWork，界面干干净净，输入框在中间闪着光标。你手头其实有材料——一份要统计的销售表、几个散落的文档——可你就是不知道第一句该敲什么。要是复制进聊天框自己写，那又绕回老路：AI 替的活最后还是你干。

这单别想复杂。你走一遍完整流程：发起、观察、验收、分享。跑完这一圈，就明白它和聊天 AI 到底差在哪。

## 发起任务：选好项目，再发指令

你先在主界面对话框里选一个项目。网页版图省事你也可以不选，直接发指令，系统会自动建一个项目，还按你指令里的关键词起名字。

然后把任务指令写进去——文字或语音都行——点发送。

输入框还能补上下文，你往里塞这些：附件（.pptx、.xlsx 这些）、图片、斜杠命令（那个「/」）、技能。你材料给得越齐，它跑偏的概率越低。

第一次别搞复杂。你拿下面这段直接发，把文件名换成你自己的就行：

```text
读取我上传的销售数据.xlsx，按产品线统计本月销售额和毛利率并排名，
输出一份 Excel 汇总表和一段 200 字的结论摘要。
要求：数字必须与源文件一致，不要推测原因，无法确认的标注待核实。
```

## 观察它怎么干：工具面板

你点界面右上角的「展开工具面板」，就能看见 AI 干活的全过程。它会按模式给你不同页签：

| 页签 | 可用模式 | 用途 |
| --- | --- | --- |
| 任务摘要 | Work / Design：待办、任务产物、参考信息；Code：待办、上下文 | 看拆解出的步骤与产物 |
| 浏览器 | 全模式 | 预览 AI 产物、验证视觉与交互 |
| 终端 | Code | 运行终端命令 |
| 画布 | Design | 预览/整理产物、导出设计文件 |

你不用盯死每一行，但得确认它「先读材料、再动手」——这是你验收的前置判断。

## 验收与修改：三种改法

Web 应用类的活干完，会自动打开预览页签。你看不对，有三种方式让它改：

1. 直接修改：你点右上角「选择元素」，选中要改的，在「设计」或「CSS」面板里改属性。注意手动编辑只支持文字类元素，字号、加粗、对齐这些能调。
2. 评论到对话：你填一句修改意见，连着选中的元素一起发给 AI 处理。
3. 截图修改：你截下某个元素或区域，用矩形或箭头标一下，填意见发过去。也能加到评论列表里批量发。

HTML 产物（需求文档、产品原型、分析报告这类）还有个省心功能：原型与文档联动。你改了原型某一块，PRD 文档里对应的内容会跟着同步更新。

## 管任务、管产物

你做好的东西得找得到、管得住。你点左侧任务栏里悬浮的「更多操作」，或者对话面板顶部任务名旁边，能置顶、看任务文件（列表或树状）、新建、重命名、删除。界面左上角的搜索图标是全局搜索，跨模式找任务或 Query 都行。

产物集中放在左侧导航「我的文件」——本地产物、云端产物、飞书云文档都在一块管。卡片上的「···」菜单能置顶、「在任务中打开」（继承原对话上下文接着改）、分享、下载（只云端产物有）、删除。你注意：删除会连带删掉对应的原始任务，而且不可恢复。

## 分享给同事

你做出好结果想给人看，点对话流里悬浮的 Query 或答复的「分享」，或者左侧任务列表右击任务选「分享」，勾选要分享的内容，两种形式挑：

- 生成图片：复制或下载，适合贴群、贴文档；
- 分享链接：生成链接和二维码。

## 任务说明怎么写：六要素

和所有任务型 AI 一样，TraeWork 交的活好不好，全看任务说明写没写清。记六个要素就行：

| 要素 | 要回答的问题 |
| --- | --- |
| 目标 | 最终要解决什么问题 |
| 输入 | 使用哪些文件、目录或链接 |
| 动作 | 分析、整理、转换还是生成 |
| 约束 | 哪些不能改，采用什么规范 |
| 输出 | 交付什么文件，放到哪里 |
| 验收 | 用什么标准判断合格 |

第一次不熟没关系。左侧导航顶部有模板库，里面按场景备好了任务说明、执行步骤和交付要求，你点「做同款」补点背景素材就能直接发。

## 新手常见问题

发起任务必须选项目吗？
不强制。网页版你可以不选，直接发指令，系统会自动建项目并按关键词命名。桌面版建议选一下，方便后面归类找。

工具面板的页签为什么有时没有？
页签是按模式给的。「终端」只在 Code 模式有，「画布」只在 Design 模式有。全模式都有的是「任务摘要」和「浏览器」。

删除产物会把任务也删了吗？
会。卡片「···」菜单里的删除，会连带删掉对应的原始任务，而且不可恢复。你删之前先下载或分享留底。

手动改只能改文字吗？
对。直接修改（选择元素 + 设计/CSS 面板）目前只支持文字类元素，字号、加粗、对齐能调。你复杂布局还是交给 AI 改更稳。

模板库适合什么时候用？
第一次不熟、懒得从头写任务说明时，你点「做同款」补素材直接发，最省事。
