# TraeWork 是什么

**TraeWork** 是字节跳动推出的 AI 原生工作台（官方口号「让 TRAE 为你工作」），2026 年 6 月正式发布。你用一句自然语言说清目标，它就自主拆解步骤、调用技能与工具执行，交付文档、数据报告、演示稿、网页等真实成果——而不是只"回答问题"。

> 官方产品页：[trae.cn/work](https://www.trae.cn/work) ｜ 官方文档：[docs.trae.cn](https://docs.trae.cn/work_what-is-trae-work)

## 和 TraeCode（Trae IDE）是什么关系

TRAE 家族有多条产品线，最容易混淆的是这两条：

| | TraeCode | TraeWork |
| --- | --- | --- |
| 定位 | AI 原生 IDE（编程） | AI 原生工作台（办公） |
| 给谁用 | 开发工程师 | 产品经理、运营、数据分析师等非开发用户 |
| 典型任务 | 写代码、调试、管理代码库 | 文档、数据、演示稿、调研、自动化 |

要点：TraeWork 由 TraeCode 的 SOLO 模式能力发展而来，但它是**独立的桌面应用，不依赖 TraeCode 运行**。两者同属 TRAE 账号体系；积分互通规则见[模型与积分避坑](/traework/adv-models-credits)。

本站同名板块说明：本站聚焦办公人群，所以讲 TraeWork；程序员用的 TraeCode 不在本站覆盖范围。

## 三种模式

TraeWork 界面左上角可在三种模式间切换：

| 模式 | 适合谁 | 干什么 |
| --- | --- | --- |
| **Work** | 非开发用户（产品、运营、数据分析师） | 文档、数据处理、演示稿——本教程主线 |
| **Code** | 开发工程师 | 编码、调试、代码库管理、Git 工作流 |
| **Design** | 有设计需求的用户 | AI 一站式完成设计、修改、定稿交付 |

## 三端形态

- **网页版**：[work.trae.cn](https://work.trae.cn/)，免安装、开箱即用的云端环境，不占本地资源。适合临时需求、外出、快速验证。
- **桌面版**：从 [trae.cn](https://www.trae.cn/) 下载中心获取（macOS / Windows），支持本地和云端两种运行环境，适合长期使用和复杂项目。
- **移动端**：手机应用商店搜「TRAE」，定位是"跨设备的任务下发中心"——通勤路上派任务、看进度、收结果。注意：移动端仅支持 Work 和 Code 模式（无 Design）。

三端**共享同一套账号体系和任务数据**，任务信息实时同步。典型分工：移动端下发任务 → 云端沙箱或已配对的电脑执行 → 结果推送回来。

## 核心能力一览

- **任务自动执行**：你只提目标，AI 自动拆解步骤、调用技能与工具，你验收
- **办公助理**：绑定飞书 / 微信，在聊天窗里直接派活（见[办公助理](/traework/05-bot-assistant)）
- **外部应用授权**：授权后直接操作飞书云文档 / 多维表格 / 日历、GitHub 等
- **插件市场**：飞书、腾讯文档、同花顺 iFinD、通达信、Remotion 视频等热门插件
- **自动化任务**：定时执行资讯汇总、周报、竞品监控等
- **技能（Skills）**：给 AI 装"专业能力说明书"，按需加载（见[Skills](/traework/04-skills)）
- **电脑控制 / 浏览器控制**：授权后让 AI 操作界面、填表单、抓数据
- **语音讨论**：语音多轮讨论需求，会后自动转写清洗成结构化纪要

## 和本站其他工具的关系

- **WorkBuddy**（腾讯）：办公 AI 智能体工作台，定位与 TraeWork 最直接竞争
- **TraeWork**（字节）：AI 原生工作台，三端协同 + 插件生态是特色
- **QoderWork**（阿里）：桌面智能工作助手，浏览器自动化与 IM 频道是强项

三家打法相近（任务委派 + 技能 + 定时 + IM），细节各有取舍。办公场景可以都装上按手感选，很多功能章节可以对照着看。
