# TraeWork 是什么？第一次用之前看这篇

如果你听过 Trae，八成是从写代码的朋友那儿听来的——那是 TraeCode，给程序员用的编程工具。

TraeWork 是字节跳动 2026 年 6 月发布的另一条产品线：给不写代码的人用的 AI 原生工作台，官方口号「让 TRAE 为你工作」。你说一句「把这份销售数据做成带图表的周报」，它自己拆步骤、调工具，交回文档、数据报告、演示稿或网页——而不是甩给你一段文字，让你自己去弄。

> 官方产品页：[trae.cn/work](https://www.trae.cn/work) ｜ 官方文档：[docs.trae.cn](https://docs.trae.cn/work_what-is-trae-work)

## 和 TraeCode（Trae IDE）什么关系

| | TraeCode | TraeWork |
| --- | --- | --- |
| 给谁用 | 开发工程师 | 产品、运营、数据分析这些非开发岗 |
| 干什么 | 写代码、调试、管代码库 | 文档、数据、演示稿、调研、自动化 |
| 一句话 | 程序员的 AI 编程工具 | 办公人的 AI 工作台 |

你先弄清两个容易误会的地方：

- TraeWork 由 TraeCode 的 SOLO 模式能力发展而来，但你不用装 TraeCode 也能直接用；
- 两者同属 TRAE 账号体系，积分怎么互通，见[模型与积分避坑](/traework/adv-models-credits)。

本站只讲 TraeWork；程序员用的 TraeCode 不在覆盖范围，不用操心。

## 三种模式，你只用管一个

你打开界面，左上角就能在 Work / Code / Design 三种模式间切换。第一次用不用纠结——办公场景就在 Work 模式待着，这也是本教程的主线。Code 是写代码的，Design 是做设计的，用不上就当没看见。

## 手机、网页、桌面，先装哪个

- 网页版（[work.trae.cn](https://work.trae.cn/)）：你用浏览器打开就能用，免安装、不占本地资源。临时有需求、外出、想先试试手的，从这儿开始；
- 桌面版：你到 [trae.cn](https://www.trae.cn/) 下载中心拿安装包（macOS / Windows），本地和云端两种运行环境都支持，长期使用装这个；
- 手机 App：你到应用商店搜「TRAE」。它不是缩小版工作台，定位是「跨设备的任务下发中心」——通勤路上派任务、看进度、收结果。注意：手机端只有 Work 和 Code 模式，没有 Design。

三端共用同一套账号和任务数据，实时同步。典型玩法是：你地铁上用手机派个活，云端沙箱或家里电脑执行，结果推回手机。

## 它能干的活

- 任务自动执行：你提目标，它拆步骤、调技能和工具，你验收；
- 办公助理：你绑定飞书 / 微信，在聊天窗里直接派活（见[办公助理](/traework/05-bot-assistant)）；
- 外部应用授权：你授权后它直接操作飞书云文档、多维表格、日历、GitHub；
- 插件市场：飞书、腾讯文档、同花顺 iFinD、通达信、Remotion 视频等热门插件；
- 自动化任务：定时的资讯汇总、周报、竞品监控，到点自动跑；
- 技能（Skills）：你给 AI 装「岗位说明书」，按需加载（见[Skills](/traework/04-skills)）；
- 电脑 / 浏览器控制：授权后让它替你操作界面、填表单、抓数据；
- 语音讨论：聊着把需求定下来，会后它自动转成清洗过的结构化纪要。

## 和本站其他工具什么关系

WorkBuddy（腾讯）、QoderWork（阿里）和 TraeWork 定位接近，都是「任务委派 + 技能 + 定时 + IM」这套打法，细节各有取舍。你办公场景可以都装上，按手感留一两个，很多功能章节能对照着看。

## 新手常见问题

**免费吗？**
注册就送：你新用户一次性拿 2000 通用积分 + 2000 Work 专属积分（31 天有效），另有每日签到、每月登录送积分的活动。积分怎么扣、扣完怎么办，见[模型与积分避坑](/traework/adv-models-credits)。

**不装 TraeCode 能用吗？**
能。TraeWork 是独立应用，你用网页版的话连装都不用装。

**手机上能干活吗？**
能派活、看进度、收结果，重活由云端或电脑执行。把手机端当遥控器，别当主机。
