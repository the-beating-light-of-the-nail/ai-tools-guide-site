# Skills：给 AI 装上"专业能力说明书"

技能（Skills）是 TraeWork 生态里最重要的概念之一：每个技能封装了指令、脚本及相关资源，为智能体提供**可复用、面向特定场景的专业能力**。同样一句话任务，装没装对技能，产出质量可能天差地别。

> 官方文档：[docs.trae.cn/work_skills](https://docs.trae.cn/work_skills)

## Skill 是什么

每个技能就是一个带 `SKILL.md` 文件的文件夹：

```text
skill-name/
├── SKILL.md        # 必须：YAML 头部（name、description）+ 描述/使用场景/指令/示例
├── examples/       # 可选：示例
├── templates/      # 可选：模板
└── resources/      # 可选：资源
```

它的关键设计是**按需加载**：智能体启动时只扫描各技能的简要描述，任务高度相关才加载完整说明——有效减少上下文中的 Token 消耗。

三个相邻概念别混淆：

| | 作用 | 加载方式 |
| --- | --- | --- |
| 技能 Skill | 描述"如何完成任务"的方法 | 按需加载 |
| 规则 Rule | 代码风格、语言框架等规范 | 全量加载、持续占用上下文 |
| MCP Server | 提供"可以调用的工具" | 按连接调用 |

## 装技能：两个来源

**从市场安装**（最常用）：

1. 左侧导航栏顶部点「插件市场」；
2. 进入「技能」页签，搜索目标技能；
3. 点卡片右侧 **+** 安装；点卡片可看详情。

**上传本地技能包**：在网上看到好用的技能包（zip 或 .skill 文件），在「技能」页签右上角点「上传技能」加载。前置条件：压缩包**根级必须包含 SKILL.md**，且 SKILL.md 含 YAML 格式的名称和描述。

## 用技能：三种方式

1. **`/` 快捷调用**：对话框输入 `/` 从列表选；
2. **指令点名**：如"用 codemap 技能总结一下这个分支的改动"；
3. **AI 自动调用**：任务描述命中技能的"适用场景"时自动触发——所以 SKILL.md 里的描述写得越准，自动触发越可靠。

管理：技能卡片滑块启用/禁用；详情弹窗左下角「卸载」。

## 技能的生效范围与运行环境

| 维度 | 说明 |
| --- | --- |
| 项目技能 | 在项目内创建，仅当前项目可用，存于项目 `.trae/skills/` |
| 全局技能 | 在设置中心创建，所有项目可用（macOS/Linux `~/.trae-cn/skills`，Windows `%userprofile%\.trae-cn\skills`） |
| 本地运行 | 仅本地任务（仅桌面版） |
| 云端运行 | 云端任务及 GitHub 拉取的项目（网页版 + 桌面版） |

## 什么时候值得做自己的技能

按官方定位，技能解决三类问题：

- **输出一致性**：设计规范、品牌一致性、格式约定——十次任务走同一条被验证过的路；
- **固定重复工作流**：周报流程、数据清洗 SOP、内容检查清单；
- **沉淀与分享**：把个人经验打包成文件，跨项目、跨团队复用。

判断标准很简单：**同一段任务说明你写过第三遍，就该做成技能了。** 想把一本书或一套方法论蒸馏成技能，思路可以参考 WorkBuddy 板块的[打造 Skill：知识蒸馏](/workbuddy/adv-build-skill/)——SKILL.md 的规范两边是相通的。
