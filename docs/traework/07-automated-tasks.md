# 自动化定时任务怎么设？让 AI 到点自己干

你以前用 TraeWork，是「你问它才动」。自动化定时任务把这个关系反过来：你定好时间，它到你定的点自己跑、自己出结果，全程不用守着，连睡觉它也在跑。官方说明在 [docs.trae.cn/work_automated-tasks](https://docs.trae.cn/work_automated-tasks)。

## 入口和三种建法

你点左栏顶部的「自动化」按钮，进定时任务管理面板。进面板先认三页签：任务模板、已配置、执行历史；创建按钮在右上角。

建法有三种，挑顺手的：

方式一：在对话中创建（推荐，能用大白话定时间）。你点右上角「在对话中创建」，把任务内容和执行时间写进去（比如「工作日早上 9 点」），在输入框左下角选运行环境和输出存储位置，发送后 AI 帮你解读，必要时确认细节，再检查它给出的任务信息调一调。

方式二：手动新建。你点右上角「手动新建」，在弹窗里逐项配置，点「创建」。

方式三：从模板创建。你切到「任务模板」页签选一个（配置已预设好），按需改一改，点「创建」。

## 关键配置项

| 配置 | 可选值 |
| --- | --- |
| 运行模式 | Work / Code（注意：创建后不可改） |
| 运行环境 | 云端 / 本地（创建后不可改） |
| 触发方式 | 固定时间（每天/每周/每月）、间隔触发（分钟/小时/天）、自定义（自然语言，仅对话创建支持） |
| 任务内容 | 完整任务指令 |
| 输出存储位置 | 产物落盘目录（创建后不可改） |

注意最后一列：运行模式、运行环境、输出存储位置这三个，一旦创建就改不了，要改你只能删了重建。

## 官方推荐的四类场景

| 场景 | 任务示例 |
| --- | --- |
| 代码仓库定期维护 | 安全扫描、Bug 排查、补测试用例、变更日报（Code 模式） |
| 信息检索与汇总 | 行业资讯、竞品动态、应用商店评论摘要、政策更新提醒 |
| 品牌舆情 | 舆情周报、社区讨论跟踪、用户反馈归集 |
| 周期性汇报 | 行业速递、运营日报、关键指标监控 |

一个能直接抄的舆情周报任务：

```text
每天早上 9:00，收集过去 24 小时内与【我的公司/产品名】相关的公开报道和社媒讨论，
按"媒体报道 / 用户反馈 / 竞品动态"分类，标注来源和链接；
有效信息少于 3 条时输出说明而不是硬凑内容；
输出一份 Markdown 周报草稿存到 output/ 目录。
```

## 必须记住的限制

1. 对话中创建时，运行模式默认为当前模式且不支持修改，你发现不对也改不了；
2. 任务一旦创建，无法修改运行模式、运行环境和输出存储位置——要改只能删了重建；
3. 你查看执行历史时，TraeWork 当前运行模式需与任务的运行模式一致；
4. 云端任务依赖账号积分，长任务留意[积分消耗](/traework/adv-models-credits)。

## 定时任务的提示词要写得更细

定时任务本质上是无人值守的对话：执行时没你在旁边补话。社区实测你也会踩坑——第一次只写「抓取文章存知识库」，因缺具体参数（存到哪、怎么认证、失败怎么办）而失败；你把完整执行步骤、参数和错误处理写进任务说明后，一次跑通。

写作清单：

- [ ] 数据来源写明确（哪个网站/哪个文档/哪个表格）
- [ ] 输出格式和存储路径写明确
- [ ] 异常处理写明确（数据为空时怎么办、来源失败时怎么办）
- [ ] 你先跑通一次手动对话，再固化为定时任务

一个完整的组合：你把它和[办公助理](/traework/05-bot-assistant)绑定飞书群串起来，就是一条「早 9 点自动日报进群」的流水线。实战案例见[公众号→飞书知识库流水线](/traework/case-feishu-pipeline)。

## 新手常见问题

定时任务能随时改时间吗？
时间、触发方式这些能改。但运行模式、运行环境、输出存储位置这三项创建后就锁死，只能删了重建。

对话里创建和手动创建差在哪？
对话创建能用大白话定时间（比如「工作日早 9 点」），AI 帮你解读成配置；手动创建得自己逐项填。图省事就用对话创建。

为什么我第一次只写一句就失败了？
定时任务是无人值守的对话，没人在旁边补话。漏了存哪、怎么认证、失败怎么办，它就卡住。把步骤和异常处理写全，一次就能跑通。

查执行历史要注意什么？
当前运行模式得和任务运行模式一致，否则历史看不了。你切错模式，历史就空了。

长任务会不会烧积分？
会。云端任务按账号积分计费，长任务留意[积分消耗](/traework/adv-models-credits)。先手动跑通再挂定时，别让它在没人时反复失败烧钱。
