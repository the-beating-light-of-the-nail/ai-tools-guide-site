# 自动化定时任务

到点自动执行预设任务、生成结果，全程无需人工干预——这是 TraeWork 从"你问它才动"变成"到点自己干"的关键功能。

> 官方文档：[docs.trae.cn/work_automated-tasks](https://docs.trae.cn/work_automated-tasks)

## 入口与创建方式

入口：左栏顶部「自动化」按钮 → 定时任务管理面板（三个页签：任务模板、已配置、执行历史；创建按钮在右上角）。

三种创建方式，按顺手程度选：

**方式一：在对话中创建**（推荐，支持自然语言触发时间）

1. 点右上角「在对话中创建」；
2. 输入任务内容和执行时间（如"工作日早上 9 点"）；
3. 输入框左下角选运行环境及输出存储位置；
4. 发送 → AI 解读，必要时确认细节；
5. 检查 AI 输出的任务信息并调整。

**方式二：手动新建**——右上角「手动新建」→ 在弹窗里逐项配置 → 「创建」。

**方式三：从模板创建**——「任务模板」页签选模板（配置已预设好）→ 按需修改 → 「创建」。

## 关键配置项

| 配置 | 可选值 |
| --- | --- |
| 运行模式 | Work / Code（注意：创建后不可改） |
| 运行环境 | 云端 / 本地（创建后不可改） |
| 触发方式 | 固定时间（每天/每周/每月）、间隔触发（分钟/小时/天）、自定义（自然语言，仅对话创建支持） |
| 任务内容 | 完整任务指令 |
| 输出存储位置 | 产物落盘目录（创建后不可改） |

## 官方推荐的四类场景

| 场景 | 任务示例 |
| --- | --- |
| 代码仓库定期维护 | 安全扫描、Bug 排查、补测试用例、变更日报（Code 模式） |
| 信息检索与汇总 | 行业资讯、竞品动态、应用商店评论摘要、政策更新提醒 |
| 品牌舆情 | 舆情周报、社区讨论跟踪、用户反馈归集 |
| 周期性汇报 | 行业速递、运营日报、关键指标监控 |

一个可直接抄的舆情周报任务：

```text
每天早上 9:00，收集过去 24 小时内与【我的公司/产品名】相关的公开报道和社媒讨论，
按"媒体报道 / 用户反馈 / 竞品动态"分类，标注来源和链接；
有效信息少于 3 条时输出说明而不是硬凑内容；
输出一份 Markdown 周报草稿存到 output/ 目录。
```

## 必须记住的限制

1. 对话中创建时，运行模式默认为当前模式且**不支持修改**；
2. **任务一旦创建，无法修改运行模式、运行环境和输出存储位置**——要改只能删了重建；
3. 查看执行历史时，TraeWork 当前运行模式需与任务的运行模式一致；
4. 云端任务依赖账号积分，长任务留意[积分消耗](/traework/adv-models-credits)。

## 定时任务的提示词要写得更细

定时任务本质上是**无人值守的对话**：执行时没有你在旁边补话。社区实测的典型教训——第一次只写"抓取文章存知识库"，因缺少具体参数（存到哪、怎么认证、失败怎么办）而失败；把完整执行步骤、参数和错误处理写进任务说明后，一次跑通。

写作清单：

- [ ] 数据来源写明确（哪个网站/哪个文档/哪个表格）
- [ ] 输出格式和存储路径写明确
- [ ] 异常处理写明确（数据为空时怎么办、来源失败时怎么办）
- [ ] 跑通一次手动对话再固化为定时任务

一个完整的定时 + 推送组合：定时任务生成日报 + [办公助理](/traework/05-bot-assistant)绑定飞书群，就是一条"早 9 点自动日报进群"的流水线。实战案例见[公众号→飞书知识库流水线](/traework/case-feishu-pipeline)。
