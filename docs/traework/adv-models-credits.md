# 进阶：模型管理与积分避坑

TraeWork 按"积分"计费，模型选择直接影响消耗速度。这一章把官方计费文档里最容易踩的坑整理成一张避坑地图。

> 官方文档：[work_models](https://docs.trae.cn/work_models) ｜ [ide_plans-and-billing](https://docs.trae.cn/ide_plans-and-billing)。**价格与套餐截至 2026-08-31，以 [trae.cn/pricing](https://www.trae.cn/pricing) 实时信息为准。**

## 两种积分，先分清

| | 通用积分 | Work 专属积分 |
| --- | --- | --- |
| 适用范围 | TraeCode + TraeWork 均可用 | **仅 TraeWork** |
| 来源 | Pro / Pro+ / Ultra 会员、增购、注册礼包、签到等活动 | Lite 会员、注册礼包、每日签到、邀请 |

消耗规则要点：

- 仅调用 **TRAE 内置模型**消耗积分，调用自定义模型不消耗；
- TraeWork 的消耗顺序：**优先有效期最短的 → 同期 Work 专属优先于通用 → 奖励积分优先于会员积分**；
- Seed-2.1-Turbo 和 Seed-Code 计费享 2.5 折（各档会员均含）。

## 套餐速览（国内版）

| | Lite | Pro | Pro+ | Ultra |
| --- | --- | --- | --- | --- |
| 单月 | ¥49 | ¥99 | ¥239 | ¥699 |
| 连续包月 | ¥45（首月 ¥9.9） | ¥89（首月 ¥59） | ¥219 | ¥629 |
| 积分/月 | 2000 Work 专属 | 4000 通用 | 12000 通用 | 40000 通用 |
| 云端并行 | 2 | 10 | 10 | 20 |

免费用户：每月登录赠 500 通用积分 + 每日签到 200 Work 专属 + 新用户注册 2000+2000 礼包。

**避坑点**：

1. **Lite 只有 Work 专属积分**——如果你同时用 TraeCode 编程，买 Lite 会发现编程那边用不了，直接上 Pro；
2. 增购积分（¥50/1000）全是通用积分，且**仅付费会员可购**；会员到期后仍在有效期内的增购积分可继续用；
3. **不支持降档**，周期结束后才能改订更低档；升级差价按未使用比例折算；
4. 因敏感词拦截、底层模型报错或死循环导致的失败可退积分，本地报错（如磁盘满）不退。

## 模型怎么选

Work 模式内置模型（节选）：Seed-2.1-Pro / Seed-2.1-Turbo、GLM-5.3 / GLM-5.2、DeepSeek-V4-Pro / V4-Flash、Kimi-K3 / K2.7-Code、MiniMax-M3、Qwen3.8-Max 等。标注 `*` 的旗舰模型仅 Pro+ / Ultra / Express 会员可用。

实用策略：

- **日常任务**：默认 Auto Mode（综合速度、性能与资源占用自动选模型）或标准档模型；
- **省钱跑量**：Seed-2.1-Turbo（2.5 折）+ 明确、简短的任务说明（Token 少，消耗低）；
- **重要交付**：关键报告、复杂分析切旗舰档，一次做对比反复返工省。

## 接入自己的模型（不耗积分）

设置 > 模型 > 「添加模型」（**仅桌面版**，且自定义模型仅本地环境可用）：

1. 选预设服务商（按量计费 / Coding Plan / Agent Plan）或「自定义模型」；
2. API 格式二选一：**OpenAI Chat Completions 格式**（兼容 OpenAI、DeepSeek、Kimi、GLM、OpenRouter 等）或 **Anthropic Messages 格式**（Claude 系）；
3. 填 API 地址、模型 ID、密钥，系统会验证；
4. 高级配置可选：上下文窗口、工具调用轮数、是否支持图片、思考模式、Temperature 等。

常用组合速查：Claude-4 = Anthropic 格式 + Claude-4 系列；GPT-5 = OpenAI 格式 + GPT-5 系列；GLM/DeepSeek/Kimi = OpenAI 格式 + 对应系列。

> 密钥只填在客户端设置里，不要写进任务说明或分享的文件。

## 省积分习惯清单

- [ ] 一个任务一个主题，无关内容新开任务（避免重放旧上下文）
- [ ] 先用便宜模型跑通流程，最后一步再切旗舰润色
- [ ] 任务说明写清输出格式，减少返工轮次
- [ ] 长文档先让 AI 出大纲，确认后再全文展开
- [ ] 定时任务跑前先手动跑通一次，避免无人值守时反复失败烧积分
