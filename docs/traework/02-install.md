# 安装、登录与三端协同

TraeWork 的三个端（网页版 / 桌面版 / 移动端）共享账号和任务数据。这一章把它们一次装齐、连起来。

## 网页版：免安装，先体验

直接打开 [work.trae.cn](https://work.trae.cn/)，登录 TRAE 账号即可用。网页版的任务全部在云端执行，不占本地资源——适合先体验核心流程，再决定装不装桌面版。

> 网页版只支持云端任务；要操作本地文件，需要桌面版。

## 桌面版：主力工作台

1. 打开 [trae.cn](https://www.trae.cn/) 下载中心（或产品页「下载 TraeWork」按钮）；
2. 选择 macOS 或 Windows 安装包下载安装；
3. 启动后用手机号登录（与网页版同一账号）。

桌面版相比网页版的关键差异：

| 能力 | 网页版 | 桌面版 |
| --- | --- | --- |
| 运行环境 | 仅云端 | 本地 + 云端 |
| 操作本地文件 | ✗ | ✓ |
| 办公助理（IM 绑定） | ✗ | ✓（首次绑定必须在桌面版发起） |
| 添加自定义模型 | ✗ | ✓ |
| 电脑控制 / 外部浏览器 | ✗ | ✓ |

## 移动端：口袋里的任务中心

1. 手机应用商店搜「TRAE」下载（iOS 需非美区 Apple ID，尚未在美区上架）；
2. 用与桌面版相同的手机号登录；
3. 首页左下角点「任务运行环境」→「连接我的电脑」，按提示完成配对。

连接手机与电脑的完整步骤：

1. 手机 TRAE 移动端登录后，首页左下角点「任务运行环境」；
2. 点「连接我的电脑」；
3. 电脑打开 TraeWork 桌面版，同一手机号登录；
4. 桌面版进入 **设置 > TRAE 移动端**，开启「允许 TRAE 移动端控制当前设备」；
5. 在「仅必要内容会存储在云端」弹窗点「确认」；
6. 授权移动端访问电脑 `/documents` 目录。

注意事项：

- 连接有效期 **180 天**，到期需重新配对；
- 可选「保持电脑处于唤醒状态」，避免任务执行中电脑睡眠；
- 设备离线时，系统会自动切换至云端执行任务，任务不中断；
- 电脑休眠可能中断消息收发（办公助理同理）。

## 三端协同的典型一天

```text
08:30  通勤路上，移动端给云端派一个「整理本周行业资讯」任务
09:00  到工位打开桌面版，任务已跑完，直接验收产物
10:00  在桌面版发起需要本地文件的复杂任务
12:30  午饭时移动端查看进度，追加一句需求
18:00  下班前在桌面版启动长任务，回家用移动端收结果
```

## 新用户积分礼包

新用户注册可一次性获得 **2000 通用积分 + 2000 Work 专属积分**（31 天有效）；另有每日签到领 Work 专属积分、每月登录赠 500 通用积分等活动。积分规则与消耗顺序详见[模型与积分避坑](/traework/adv-models-credits)。
