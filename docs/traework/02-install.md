# TraeWork 怎么装？三端连好，手机和电脑任务不脱节

你刚听同事说 TraeWork 能替你跑活，兴冲冲想装上试试。可它一口气甩出三个端——网页版、桌面版、移动端——你一下懵了：三个都得装吗？账号会不会乱套？手机派了活，电脑怎么接着干？

别慌。这三个端共用同一套账号和任务数据。你在手机上派的任务，到工位开电脑能接着看、接着收。这一篇就把三个端一次装齐、连起来，照着做就行。

## 网页版：免安装，先体验

网页版最省事，不用装。你直接打开 [work.trae.cn](https://work.trae.cn/)，用 TRAE 账号登录就能干活。它的任务全在云端跑，不吃你电脑的本地资源——先走一遍核心流程，顺手了再决定要不要装桌面版。

> 网页版只支持云端任务；要操作本地文件，需要桌面版。

## 桌面版：主力工作台

你要干正活，桌面版才是主战场。装起来就三步：

1. 你打开 [trae.cn](https://www.trae.cn/) 下载中心（或产品页上的「下载 TraeWork」按钮）；
2. 你挑 macOS 或 Windows 安装包，下载并装上；
3. 你用手机号登录（和网页版是同一个账号）。

桌面版比网页版多出几样关键能力，差别一张表看明白：

| 能力 | 网页版 | 桌面版 |
| --- | --- | --- |
| 运行环境 | 仅云端 | 本地 + 云端 |
| 操作本地文件 | ✗ | ✓ |
| 办公助理（IM 绑定） | ✗ | ✓（首次绑定必须在桌面版发起） |
| 添加自定义模型 | ✗ | ✓ |
| 电脑控制 / 外部浏览器 | ✗ | ✓ |

## 移动端：口袋里的任务中心

通勤、排队、躺床上，用手机就能派活。装上它：

1. 你在手机应用商店搜「TRAE」下载（iOS 要用非美区 Apple ID，它还没在美区上架）；
2. 你用和桌面版相同的手机号登录；
3. 进首页左下角点「任务运行环境」→「连接我的电脑」，照提示完成配对。

连接手机和电脑，从头到尾是这么走的：

1. 你手机上登录 TRAE 移动端，首页左下角点「任务运行环境」；
2. 你点「连接我的电脑」；
3. 你电脑打开 TraeWork 桌面版，用同一手机号登录；
4. 桌面版进 设置 > TRAE 移动端，开启「允许 TRAE 移动端控制当前设备」；
5. 在「仅必要内容会存储在云端」弹窗点「确认」；
6. 你授权移动端访问电脑 `/documents` 目录。

配对好，记几件事：

- 连接有效期 180 天，到期要重新配对；
- 可选「保持电脑处于唤醒状态」，免得任务跑到一半电脑睡过去；
- 设备离线时，系统自动切到云端跑任务，活不中断；
- 电脑休眠可能中断消息收发（办公助理也一样）。

## 三端协同的典型一天

连好了，三个端怎么配合？给你看一天的真实节奏：

```text
08:30  通勤路上，移动端给云端派一个「整理本周行业资讯」任务
09:00  到工位打开桌面版，任务已跑完，直接验收产物
10:00  在桌面版发起需要本地文件的复杂任务
12:30  午饭时移动端查看进度，追加一句需求
18:00  下班前在桌面版启动长任务，回家用移动端收结果
```

## 新用户积分礼包

新用户注册能一次性拿到 2000 通用积分 + 2000 Work 专属积分（31 天有效）；另外每天签到能领 Work 专属积分，每月登录还送 500 通用积分。积分怎么用、消耗按什么顺序，看 [模型与积分避坑](/traework/adv-models-credits) 这篇。

## 新手常见问题

**三个端我都要装吗？**
不用全装。你先用网页版登录体验，觉得顺手再装桌面版干正活。移动端看要不要随时随地派活，装不装随你。三个端账号互通，同一个手机号就行。

**桌面版和网页版差在哪？**
网页版只在云端跑，碰不了本机文件，也绑不了办公助理、加不了自定义模型、控不了电脑。这些活都得桌面版来。上面对照表一眼能看清。

**手机和电脑怎么连上？**
你手机登录后，进「任务运行环境」点「连接我的电脑」，电脑端开桌面版、同一手机号登录，再到 设置 > TRAE 移动端 打开允许控制，弹窗确认、授权目录就成了。配对好能用 180 天，到期重连一次。

**iOS 搜不到 TRAE 怎么办？**
它在美区还没上架。你换一个非美区 Apple ID 去应用商店搜「TRAE」就能下。安卓和其它区一般直接搜得到。

**积分会过期吗？**
会。新手套餐的 2000 通用 + 2000 Work 专属积分 31 天有效，领了趁早用。每天签到、每月登录还能续上 Work 专属和通用积分，规则看积分避坑那篇。
