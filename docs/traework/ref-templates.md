# TraeWork 常用指令模板怎么抄？拿来即用

你盯着空白的任务框，最怕的不是不会写，而是不知道从哪句开头。这篇把高频场景的提示词打包好，你拿去改改文件名、填填空就能发。写法要点回顾：六要素（目标/输入/动作/约束/输出/验收）见[第一个任务](/traework/03-first-task)。【】里的替成实际内容。

## 文档类

### 文档速读

```text
帮我看看【文档名/附件】主要写了什么内容，按主题归纳，标注我需要重点关注的 3 个问题。
```

### 周报生成

```text
帮我优化【工作总结文档】，按照本周结论、关键进展、下周计划写周报：
结论用一句话说清本周最值得汇报的成果；关键进展列 3-5 条（做了什么、带来什么结果）；
下周计划 2-3 条（要推进的事、需要的支持）。
```

### 写入飞书并推送

```text
把刚才的【周报/纪要/报告】写入飞书文档，并发送到【群名】。
```

### 两版文档对比

```text
比较【文件A】与【文件B】，输出新增、删除、修改三类差异，
重点标记金额、日期、责任主体和审批条件，生成待确认问题清单，不修改原文件。
```

## 数据类

你拿到表格要分析，别让它瞎编数字，先框死口径。

### Excel 分析

```text
读取【数据文件.xlsx】，先不要修改原文件。
业务问题：【要回答的问题，如各产品线本月表现】。
输出：字段说明与脏数据检查、按【维度】统计的核心指标、图表、
3 条可直接用于复盘的结论。
要求：数字与源文件一致，无法确认的标注待核实。
```

### 数据看板

```text
做一个【周期】数据看板：最上面是【核心指标】总览，
下面是【维度】趋势图、漏斗图和对比图，图表可交互。
```

## 汇报类

### 述职报告

```text
根据我的工作记录整理一份述职报告。要求：
1. 工作内容归类、合并、去重，不写流水账
2. 提炼 3-5 项核心业绩，按"背景—行动—结果—价值—个人贡献"展开
3. 优先用数据和前后对比，区分团队成果与个人贡献
4. 不得虚构信息
5. 输出：述职总结、核心业绩、能力沉淀、问题复盘、下一阶段计划
岗位：【岗位】 述职周期：【周期】 工作记录：【@文档】
```

### 做 PPT（方法论版，见案例篇）

```text
请先不要生成 PPT。先分析【材料】，提取核心主张和论证骨架，
整理一份 memo 和 10 页左右的 slide plan，每页只保留一个 claim。
输出后停住，等我确认。
```

## 自动化类

你想让 AI 定时跑，提示词要比平时写得细——没人半夜替你补话。

### 定时资讯汇总

```text
【工作日早上 9 点】，收集过去 24 小时内与【主题】相关的公开报道，
按【分类维度】分类，标注来源链接；有效信息少于 3 条时输出说明；
输出 Markdown 存到【目录】。
```

### 舆情周报

```text
每周一上午 9 点，汇总上周与【公司/产品】相关的报道和社媒讨论，
输出"媒体报道 / 用户反馈 / 竞品动态"三栏周报，标注情感倾向和来源。
```

## 电脑控制类

你让 AI 动界面，安全弦要绷紧：填完停在提交页等人确认。

### 填表单（安全版）

```text
帮我填写【表单名/网址】表单，信息来自【附件】。
填完后停留在提交页等待我确认，不要点击提交。
```

### 按模板批量处理

```text
复制【模板】文件，将【字段】替换为每条记录的对应数据，
逐条处理后保存到 output/ 目录，最后输出处理清单。
不要发送或发布任何产物。
```

## 流程类

你跑长任务，先用工作流把步子框住再放手。

### Plan 模式（先看计划）

```text
/plan 整理【目录】下的【N】份文件：先给出你的计划（分几步、动哪些文件、
怎么命名），我确认后再执行。
```

### Goal 模式（目标续跑）

```text
/goal 把【目录】下所有【文件类型】转换为【目标格式】，
每完成 10 个抽查 1 个，全部完成且抽查通过后停止。
```

## 新手常见问题

模板里的【】怎么处理？
你把它们替成实际内容就行，比如【文档名】换成你那份文件。别连【】一起发，AI 会当占位符理解。

六要素一定要写全吗？
你第一次写建议写全，跑顺了可以精简。目标、输入、约束、验收这四样最不能省，漏了它容易瞎编。

自动化模板为什么格外长？
你定时任务是无人值守的对话，没人半夜补话。数据来源、路径、异常处理都得写死，否则一跑就卡。

电脑控制的模板为什么要「等待我确认」？
你让 AI 填表单，停在提交页等人确认最稳，别让它自己点提交，出错了难撤回。

数据类模板怎么防 AI 编数？
写明「数字与源文件一致，无法确认的标注待核实」，它就不敢补写。脏数据和口径先框清。
