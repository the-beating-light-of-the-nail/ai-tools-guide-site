# 插件和外部授权怎么接？让 AI 碰得动你的飞书、GitHub

你装好 TraeWork，它默认是个能干活的空壳。真正让它在你工作流上「长」出来的，是插件和外部应用授权：插件把外部工具、服务、数据源接进来；授权让 AI 直接碰你在飞书、GitHub 里的数据。你接上这两样，它才真的长在你的日常里。官方说明在 [work_plugins](https://docs.trae.cn/work_plugins) 和[七大热门插件](https://docs.trae.cn/work_seven-popular-plugins-in-traework)。

## 装插件：三步

你点左侧导航栏顶部的「插件市场」（默认就在「插件」页签）。你找到目标插件，点卡片右侧「安装插件」图标，或者进详情页点右上角「添加插件」。

需要连外部服务的插件，你按提示走完授权这一步。

注意一个时间点：用之前，你在对话输入框左下方选好可用插件（能多选）。插件必须在对话开始前选，禁用状态下你对话里用不了。

## 七大热门插件速览

你先扫一眼这张表，挑跟你日常最贴的。你挑错插件白装，所以先对清楚：

| 插件 | 能干什么 | 亮点 |
| --- | --- | --- |
| 飞书 | 消息、云文档、云盘、多维表格、日历、任务、审批、会议、妙记、OKR | 办公场景首选，示例指令如“日程安排在下周一上午 10 点” |
| 腾讯文档 | 创建/读取/编辑 Word、Excel、幻灯片、智能文档、智能表格、思维导图、流程图 | 在线协作文档一把抓 |
| 企业微信 | 通讯录与消息查询，管理会议、日程、待办、文档及在线表格 | 示例：“添加一个明天 18:00 截止的待办” |
| Remotion | 以编写 React 代码的方式制作视频（布局、动画、字幕、音频） | 代码化视频，适合程序化短片 |
| HyperFrames | 用 HTML + CSS + GSAP 制作视频 | 水墨质感、品牌色示例：#11C566 |
| 同花顺 iFinD | 金融数据查询与投研分析（需 API Key，数据分免费版/订阅套餐） | 注意：债券实时行情不含银行间 |
| 通达信 | A 股/基金/指数/港股行情查询、条件选股（涨停、低 PE、MACD 金叉等） | 不支持期货、期权、债券 |

官方声明：金融类插件内容仅用于展示能力，不构成投资建议。

## 外部应用授权：飞书

授权之后，你不用手动配 MCP Server，就能读写飞书云文档、多维表格、日历、消息、邮箱、会议这些。

你第一次授权飞书，点左栏顶部「插件市场」→ 右上角「管理」→「应用授权」页签。飞书应用右侧点「链接」，跳到飞书授权页。你勾选权限 →「确认授权」→ 二次确认页核对账号与权限 → 点「授权」。

你可授权的模块共 13 个（按能力颗粒度）：多维表格（约 38 项操作，最多）、云文档（25 项）、即时通讯（18 项）、知识库（14 项）、日历/任务/会议/邮箱（各 10 项）、云空间（8 项）、幻灯片、审批、通讯录、电子表格、获取用户身份标识。授权完，TraeWork 会自动装好本地 CLI 和相关技能，你后续在对话里就能直接喊它读飞书文档。

官方给了三条场景链路：

```text
① 需求文档驱动：发送云文档 → 读取内容 → 基于文档干活 → 进展回写文档
② 多维表格驱动：检索记录 → 读取任务详情 → 执行 → 新增/更新记录状态
③ 协作同步：创建日历日程 → 读取会议纪要 → 编辑相关云文档
```

## 外部应用授权：GitHub

入口在左下角头像 → 设置 →「外部应用授权」。你点 GitHub 的「连接」，登录并授权 TRAE-AI CN 访问。授权后你可以：

- AI 创建 PR：AI 看两分支差异并生成摘要 → 一键创建 PR → 打开 GitHub 窗口确认合并；
- 手动创建 PR / AI 检查 PR：让 AI 先看相关文件变更再执行 git diff 审查。

⚠️ GitHub 应用仅 Code 模式支持；桌面版需打开从 GitHub 拉取的项目并切到「云端」。你常做代码评审，这条最实用。

## 权限边界

智能体只在你授权的范围内调用对应服务。

集成类功能的入口分散在两处：设置 > 外部应用授权（账号级），插件市场 > 管理 > 应用授权（插件级）。你拿不准时两处都翻一下，省得漏配。

## 新手常见问题

插件必须在对话前选好吗？
对。你在对话输入框左下方选，而且得在对话开始之前选好；你进了对话再想加，禁用状态下加不进去。

飞书授权要勾哪些模块？
一共 13 个模块按颗粒度给，多维表格最多（约 38 项操作），往下是云文档 25 项、即时通讯 18 项、知识库 14 项，日历/任务/会议/邮箱各 10 项，还有云空间、幻灯片等。你用到哪个勾哪个，别一股脑全给。

金融类插件能当投资建议用吗？
不能。官方明确说这类插件只展示能力，不构成投资建议。你真要查数据，同花顺 iFinD 要 API Key，而且债券实时行情还不包含银行间。你别拿它当买卖依据。

GitHub 授权为什么在网页版用不了？
GitHub 应用仅 Code 模式支持，桌面版还得打开从 GitHub 拉取的项目、切到「云端」才行，你网页版这条路走不通。

授权和插件的入口怎么分？
账号级授权你去「设置 > 外部应用授权」；插件级去「插件市场 > 管理 > 应用授权」。你拿不准时两处都看一眼，比只翻一处稳。
