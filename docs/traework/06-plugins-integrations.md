# 插件与外部应用授权

插件把外部工具、服务与数据源接进 TraeWork；外部应用授权让 AI 直接操作你在飞书、GitHub 里的数据。两者叠加，TraeWork 才真正"长"在你的工作流上。

> 官方文档：[work_plugins](https://docs.trae.cn/work_plugins) ｜ [七大热门插件](https://docs.trae.cn/work_seven-popular-plugins-in-traework)

## 装插件：三步

1. 左侧导航栏顶部点「插件市场」（默认「插件」页签）；
2. 找到目标插件，点卡片右侧「安装插件」图标（或进详情页点右上角「添加插件」）；
3. 需要连外部服务的插件，按提示完成授权。

使用时：**开始对话前**，在对话输入框左下方选择可用插件（可选多个）。注意插件必须在对话开始前选好，禁用状态下无法在对话中使用。

## 七大热门插件速览

| 插件 | 能干什么 | 亮点 |
| --- | --- | --- |
| **飞书** | 消息、云文档、云盘、多维表格、日历、任务、审批、会议、妙记、OKR | 办公场景首选，示例指令如"日程安排在下周一上午 10 点" |
| **腾讯文档** | 创建/读取/编辑 Word、Excel、幻灯片、智能文档、智能表格、思维导图、流程图 | 在线协作文档一把抓 |
| **企业微信** | 通讯录与消息查询，管理会议、日程、待办、文档及在线表格 | 示例："添加一个明天 18:00 截止的待办" |
| **Remotion** | 以编写 React 代码的方式制作视频（布局、动画、字幕、音频） | 代码化视频，适合程序化短片 |
| **HyperFrames** | 用 HTML + CSS + GSAP 制作视频 | 水墨质感、品牌色示例：#11C566 |
| **同花顺 iFinD** | 金融数据查询与投研分析（需 API Key，数据分免费版/订阅套餐） | 注意：债券实时行情不含银行间 |
| **通达信** | A 股/基金/指数/港股行情查询、条件选股（涨停、低 PE、MACD 金叉等） | 不支持期货、期权、债券 |

> 官方声明：金融类插件内容仅用于展示能力，不构成投资建议。

## 外部应用授权：飞书

授权后无需手动配置 MCP Server，即可读写飞书云文档、多维表格、日历、消息、邮箱、会议等：

1. 左栏顶部「插件市场」→ 右上角「管理」→「应用授权」页签；
2. 飞书应用右侧点「链接」，跳转飞书授权页；
3. 勾选权限 →「确认授权」→ 二次确认页核对账号与权限 → 点「授权」。

可授权模块共 13 个（按能力颗粒度）：多维表格（约 38 项操作，最多）、云文档（25 项）、即时通讯（18 项）、知识库（14 项）、日历/任务/会议/邮箱（各 10 项）、云空间（8 项）、幻灯片、审批、通讯录、电子表格、获取用户身份标识。授权完成后，TraeWork 会自动安装本地 CLI 及相关技能。

官方给出的三条场景链路：

```text
① 需求文档驱动：发送云文档 → 读取内容 → 基于文档干活 → 进展回写文档
② 多维表格驱动：检索记录 → 读取任务详情 → 执行 → 新增/更新记录状态
③ 协作同步：创建日历日程 → 读取会议纪要 → 编辑相关云文档
```

## 外部应用授权：GitHub

入口：左下角头像 → 设置 → 「外部应用授权」→ GitHub 点「连接」→ 登录并授权 TRAE-AI CN 访问。授权后可以：

- **AI 创建 PR**：AI 查看两分支差异并生成摘要 → 一键创建 PR → 打开 GitHub 窗口确认合并；
- **手动创建 PR** / **AI 检查 PR**：让 AI 先看相关文件变更再执行 git diff 审查。

⚠️ GitHub 应用**仅 Code 模式支持**；桌面版需打开从 GitHub 拉取的项目并切到「云端」。

## 权限边界

- 智能体只在**获得授权的范围内**调用对应服务；
- 集成类功能入口分散在两处：设置 > 外部应用授权（账号级），插件市场 > 管理 > 应用授权（插件级），拿不准时两处都看一眼。
