# Trae 教程

**Trae** 是字节跳动推出的 AI IDE（国内版 trae.cn，国际版 trae.ai），把 AI 编程助手深度集成进编辑器：Chat 对话、代码补全、Builder 模式从需求直接生成项目、SOLO 模式自主完成长程任务。

本板块改编自开源课程《Trae 编程实战》（[ForceInjection/AI-fundamentals](https://github.com/ForceInjection/AI-fundamentals)，Apache-2.0 协议，5 大部分 20 章），先带你看完基础入门，再进入场景实战。

## 适合谁

- 有一定编程基础、想系统掌握 AI 辅助开发流程的工程师
- 想从"复制粘贴 AI 代码"进阶到"标准化人机协作"的开发者
- 关注 AI IDE 生态（对比 Cursor / Copilot / Qoder）的技术选型者
