# 从长文到能拍的口播与分镜

> 场景：公众号文章写完，领导顺手一句"改成一分钟视频，今天拍出来"。照着文章念是下策——文章为了讲透，短视频为了让人看完；就算口播写顺了，镜头表里写满"配相关画面""这里加 B-roll"，摄影和剪辑还是不知道拍什么。

拿一篇已核验的长文，在豆包工作里连续跑两个任务：

```text
已核验长文
→ 改成 60—75 秒自然口播
→ 人工确认口播事实和节奏
→ 拆成 9 个连续镜头
→ 补齐动作、景别、屏幕文字、素材状态
→ 最后检查版权、隐私和事实边界
```

跑完得到一份约 290 字、正常语速 65—70 秒的口播稿，和一份 68 秒、9 个镜头的分镜执行表。

工具选择：**新媒体写作 Skill**（明确覆盖短视频脚本，擅长口语节奏、开头和听觉理解）做口播；**创意视频 Skill**（离真实拍摄更近，能把机位、动作、B-roll、声音和剪辑要求拆开）做分镜。两个任务**不要混在一个提示词里**——先人工确认口播，再开新任务拆分镜，分镜只围绕定稿安排画面，不会边拆镜头边改事实。（想补充 AI 素材可以选配 Seedance 2.5 视频生成。）

## 任务一：先把长文改成"能说出口"的口播

如果提示词只有"把这篇文章改成一分钟口播"，AI 最容易做的就是删字。要写清五件事：**说给谁听、讲多久、只保留什么、什么绝对不能改、按什么格式交付**：

```text
请使用「新媒体写作」能力，把下面这篇已经核验过的长文改成一段可以直接对镜头说的
短视频口播稿。

目标：
- 平台：视频号 / 抖音都能使用
- 时长：60—75 秒
- 受众：企业里的普通打工人、内容运营新手
- 只讲一个核心问题：【在这里写核心问题】
- 只保留一条清晰结论和一个容易听懂的例子
- 开头 5 秒内进入问题，不用"震惊""一定要"等夸张钩子
- 句子要短，像真实的人在说话，不要论文腔
- 必须保留原文里的关键限制条件，不能把有条件判断改成绝对承诺
- 标注建议停顿【停顿】和需要重读的词【重读】
- 不要生成分镜、镜头或字幕文件
- 不要补写原文没有的数字、案例和结论

请按以下结构输出：
1. 核心信息取舍：用 3 行说明保留了什么、删掉了什么、为什么
2. 最终口播稿：可直接照着念，约 260—320 字
3. 简介补充信息：列出 2—3 条不适合塞进口播、但值得放在视频简介里的边界信息

原始长文：
【把你的已核验长文完整粘贴在这里；或上传文件后写：只读取《文件名》】
```

实测结果：第一句就抛出大家最关心的问题（"很多人做一稿多发，就是把公众号文章复制到小红书……"），中间只保留一个对比例子，并主动保住最危险的一句——原文说"在信息完整、事实已核验的前提下可以提效"，不能改成"用 AI 一定能提效"。全文约 290 字、估算 65—70 秒，标了停顿和重读位置。

> 判断口播能不能用，最笨也最有效的方法：**自己完整念一遍**。凡是需要回头看上一句才明白的地方，都要重新改。

## 任务二：口播确认后，拆成真正能拍的分镜

分镜最怕脱离现实：**只有一部手机，就别让它设计三机位轨道镜头；只有自己拍的素材，就别让它默认用影视片段和图库**。普通人第一次拍口播，用手机 + 三脚架 + 安静的房间就能开录。

> 一个普适经验：做任何形式的自媒体，一开始都要极致轻量化，把大部分精力放在选题与标题（短视频就是开头）上。每次投入够少、又在做正确的事，才坚持得下去，也更容易进入正反馈循环。

实测把条件写死：9:16 竖屏、一位职场人在办公桌前、手机加三脚架，可用素材只有本人正面口播、手部操作、文章录屏和自制关键词卡片：

```text
请使用【创意视频】能力，把下面这份已经确认的口播稿拆成一份可以直接照着拍的分镜执行表。
只做拍摄与剪辑方案，不要生成实际视频，也不要生成字幕文件。

成片条件：
- 比例：9:16 竖屏；总时长：65—70 秒
- 场景：一位职场人在办公桌前对镜口播
- 可用设备：手机、三脚架、笔记本电脑
- 已有素材：本人可拍的正面口播、手部操作电脑、文章页面录屏、自制关键词卡片
- 不使用未经授权的图库、影视片段或他人账号截图
- 节奏：清楚、克制、像实用教程，不要快切炫技

执行要求：
1. 按 0—5 秒、5—12 秒这类连续时间段拆成 8—10 个镜头，
   时间总和必须覆盖 65—70 秒，不能重叠、不能留空。
2. 每个镜头都给出：对应口播原句、人物动作、景别、机位 / 构图、屏幕文字、
   B-roll 或截图、转场、声音要求。
3. 屏幕文字只保留关键词，每屏不超过 12 个汉字，不能把整段口播再贴一遍。
4. 不要写"配相关画面"这种空话，要明确拍什么、屏幕录什么、文字放哪里。
5. 标出每项素材状态：【已有】【需补拍】【需制作】【需确认版权】。
6. 不改写口播里的事实和边界，尤其要保留原稿的限制条件。
7. 最后附一份按拍摄顺序整理的拍摄清单，和按时间顺序整理的剪辑检查清单。

请按以下结构输出：
A. 拍摄设定（机位、光线、收音、背景）
B. 逐秒分镜执行表
C. 拍摄清单
D. 剪辑检查清单
E. 版权与隐私检查

已确认口播稿：
【把上一轮人工确认后的完整口播稿粘贴在这里】
```

它先按口播字数和停顿估算每段时长，再拆镜头——**先算时长再拆**很重要：先写 9 个镜头最后硬凑时间，最容易出现口播念不完或中间空出五秒。实测时间线（9 段相加正好 68 秒，无空挡无重叠）：

| 时间 | 画面任务 |
| --- | --- |
| 0—7 秒 | 中近景说出"复制粘贴式一稿多发"，右手敲桌面三次 |
| 7—13 秒 | 近景强调"省时间不等于有效果" |
| 13—21 秒 | 插入手部滚动文章，解释平台阅读方式不同 |
| 21—30 秒 | 文章录屏对比"公众号顺着看、视频号听你说" |
| 30—37 秒 | 拿起"结构"卡片，强调改的是表达结构 |
| 37—49 秒 | 录屏展示"背景/测试/结论" vs "问题/结论/例子" |
| 49—58 秒 | 用"有条件/绝对化"卡片守住事实边界 |
| 58—63 秒 | 近景强调"有条件判断不能变成绝对承诺" |
| 63—68 秒 | 拉远收尾，桌面全景定格 |

结果最后还有三个兜底清单：按拍摄顺序安排先拍什么、按时间顺序检查怎么剪、版权与隐私怎么查。

> 分镜写得越详细不代表越专业。**真正有用的分镜，是拍摄的人今天拿到，能立刻列出"已有、要补拍、要制作、要确认版权"的清单。**

## 记住这套两段式公式

**长文转口播**写清：谁听、在哪个平台听、要听多久；只讲哪个问题、只保留哪条结论；哪些限制条件不能删；哪些内容移到简介；输出要有停顿、重读和字数检查。

**口播转分镜**写清：设备、场景、比例和已有素材；时间段连续且合计等于总时长；每个镜头有动作、景别、机位、文字、素材和声音；每项素材标状态；最后查版权、隐私和事实边界。

长文、口播和分镜是三种不同的东西：长文负责把事情说完整，口播负责让人一遍听懂，分镜负责让现场真的拍得出来。拆成两次任务，不仅更容易得到好结果，也更容易在每一步发现：到底是内容有问题、表达有问题，还是拍摄执行有问题。
