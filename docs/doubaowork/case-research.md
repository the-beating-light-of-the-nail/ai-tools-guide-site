# 临时被甩一个调研题目，时间紧、材料乱，怎么让豆包工作帮你交一份能上会的报告？

你正忙着别的事，领导突然丢来一句「某某方向你调研一下，周五汇报用」。你一搜网页，几十个标签页全开着，数字来自不同年份，等到真要上会，手里一堆材料却讲不清结论。这篇带你用一份能复用的提示词，把乱糟糟的临时调研，变成一份带着出处、能直接投屏的正式报告。

> 场景：临时接到调研任务，时间紧、题目大。网页越开越多，数字来自不同年份，等到做汇报，手里一堆材料却讲不清结论。

## 动手前，先定三件事

你别一上来就让豆包工作去搜。你先想清楚：这次调研要帮谁做决定、哪些来源能用、最后交一份文档还是一套 PPT。这三件事定下来，再让它去检索、精读和整理，后面的页面才不会反复推倒重来。

一份能用于汇报的调研，要同时处理好四件事：研究问题服务一个具体决策、资料可追溯、结论有证据、页面让读者快速看懂。稳妥的顺序是：先确定范围和验收条件，再收集与核验材料，接着形成结论和证据对应表，最后才制作 PPT。视觉优化放在内容确认之后，能少返很多工。

## 一份通用模板

这份模板适合你临时接到陌生题目时用。你填方括号之前，先确认调研要支持什么决定、谁会阅读、时间和地区范围到哪里为止——问题越具体，检索范围越容易收住。时间紧，你可以减少问题数量和页数，但关键数据的出处必须保留：

```text
请围绕"【调研主题】"开展深度调研，并生成一份面向【目标读者】的 PPT 报告。
本次调研用于支持【具体决策】，研究范围包括【地区范围】，重点关注【核心问题】，
信息时间范围为【开始时间】至【截止时间】。

请先阅读全部附件，再搜索公开资料进行补充。
优先使用政府部门、企业官网、财报、监管文件、学术论文和权威研究机构资料。
对市场规模、增长率、公司经营数据、产品价格、政策规定和时间节点等重要事实，
必须标明来源和发布日期。每个关键结论尽量使用两个独立来源进行交叉验证。

请明确区分：
- 来源中直接说明的事实；
- 根据多个事实形成的分析判断；
- 缺少充分证据的假设。

不要编造市场数据、公司数据、客户案例或来源。
不同来源数据存在冲突时，请展示差异并解释可能原因。

PPT 控制在【15～20】页，建议包含：执行摘要、研究范围、市场概览、关键数据、
竞争格局、用户需求、趋势判断、风险、战略建议、行动计划和来源附录。
每页只表达一个主要观点，标题使用结论式表达。
尽量使用图表、对比矩阵、时间线和流程图表达信息，避免整页大段文字。
所有图表都需要注明数据来源、统计口径和时间。
最后附完整来源清单，包括资料名称、机构、发布日期和网页链接。

请同时输出：
- 完整 PPT；
- 一页管理层摘要；
- 关键结论与证据对应表；
- 调研中仍未确认的问题清单。
```

## 实例：Work Agent 行业研究

你看这个例子。它把市场进入、客户选择、产品定位和路线图放进同一项任务，研究问题因此能围绕管理层决策展开；中国市场是重点，海外材料用于比较，时间范围写得清清楚楚：

```text
请围绕"Work Agent 行业研究"开展深度调研，并生成一份专业的 PPT 报告。

一、研究信息
目标读者：公司管理层、战略负责人和产品负责人
需要支持的决策：
1. 判断 Work Agent 市场是否值得进入
2. 选择优先服务的客户和应用场景
3. 确定产品定位和差异化方向
4. 制定未来 12 至 24 个月的产品路线图
研究区域：以中国市场为重点，同时参考海外市场。
研究时间：研究 2023 年至 2026 年的发展情况，并分析未来 3 年的发展趋势。

二、重点研究问题
1. Work Agent 是什么？与 AI 助手、Copilot 和 RPA 有什么区别？
2. 当前市场处于什么发展阶段？
3. 中国及全球市场的发展空间如何？
4. 国内外有哪些代表性公司和产品？
5. 不同产品的定位、功能和目标客户有什么差异？
6. Work Agent 适合应用在哪些工作场景？
7. 企业客户最关注哪些产品能力？
8. 当前行业面临哪些技术、安全和商业风险？
9. Work Agent 未来 3 年可能出现哪些趋势？
10. 新进入者应该选择什么产品和市场策略？

三、外部调研要求
优先参考：企业官网及官方产品资料、政府/行业协会和研究机构、
上市公司财报及公开材料、学术论文和权威市场报告、可信的科技及行业媒体。
关键数据需要标注来源、发布时间和网页链接。
请区分事实、分析判断和行业预测。无法核实的信息标注"待核验"，不要编造数据或案例。

四、PPT 要求
生成一份 15 至 18 页的中文 PPT：
1. 每页突出一个核心观点；
2. 标题尽量直接表达结论；
3. 避免堆积大段文字；
4. 优先使用图表、对比表、矩阵和时间轴；
5. 图表需要标注数据来源和时间。
```

执行时，系统先读取你的附件和任务范围，再补充公开资料、核对关键数字与时间，把事实、分析判断和待核验信息分别整理，再据此生成报告页面。结果生成之后，你先看关键结论与证据能否逐项对应，再检查市场数据、公司信息和产品能力的发布日期。

## 最后再交给美化技能

内容审核过之后，你再让 PPT 美化类技能（如 guizang-ppt）去处理已经稳定的版本，让工具集中调整版式、配色、图表和页面节奏：

```text
使用 Guizang Ppt Skill 美化 PPT 样式
```

你也可以直接口述风格，比如「修改成新粗野主义风格的 PPT」。你按不同汇报人群和形式，换不同的 PPT Skill 即可。

## 新手常见问题

**临时调研第一步到底该做什么？**
你先定三件事：帮谁做决定、哪些来源能用、交文档还是 PPT。定清楚了再让豆包工作搜，不然页面会反复重做。

**豆包工作会不会自己编数据？**
你要在提示词里写死「不编造」。模板里已经要求它对无法核实的信息标「待核验」，并优先用政府、财报、学术这类权威来源。你收到报告，重点看关键数字有没有挂出处。

**为什么关键数据出处不能省？**
上会时有人追问「这个增长哪来的」，你答不上来就尴尬了。出处保留着，别人质疑你才接得住，也方便你自己回原文核对。

**PPT 能不能一开始就让它做漂亮？**
别急。视觉优化放在内容确认之后。内容没定就先美化，后面每改一处结论，版式都得跟着返工，更累。

**时间特别紧怎么砍？**
你可以减少问题数量和页数，但关键数据的出处必须留着。宁可页数少一点，也不能让结论没了依据。
