# 常用指令模板怎么抄？粘进去改文件名，活就派出去了

你新建任务准备派活，却对着输入框发呆：这句话到底该怎么写，它才听得懂？别自己硬憋。下面这些模板你直接复制，新建「工作任务」粘进去，再补上你的文件、链接、时间范围和输出位置就行。你改的只是文件名和范围，骨架不用动。

三条通用纪律你先记牢：涉及多个文件时建议先创建项目；涉及外部系统时先确认所需连接器已授权；涉及移动、覆盖、发送或发布时，保留人工确认。

## 文件整理

```text
请先读取我提供的文件夹，统计文件类型、数量和重复项。
按照文件类型和主题给出新的文件夹结构与重命名规则。
先输出整理方案和预计改动清单，等我确认后再移动或重命名文件。
不要删除任何文件；遇到同名文件时停止并询问。
```

## Excel 分析

```text
请分析我提供的 Excel 文件。
先检查工作表、字段、缺失值和异常值，再输出核心指标、趋势变化、可能原因和建议行动。
请生成摘要报告和必要图表，并说明每个结论对应的数据范围。
不要修改原文件，把结果保存为新文件。
```

## PPT 生成

```text
请根据这份 Word 文档生成一份 10 页左右的 PPT。
每页包含标题、3-4 个要点和建议图表；所有数据与结论都应来自原文。
风格正式，适合管理层汇报。
先给出页面大纲，确认后再生成完整文件。
```

## 会议纪要

```text
请整理这段会议内容。
输出会议结论、待办事项、负责人、截止时间、风险点和未决问题。
没有明确负责人或截止时间时标记"待确认"，不要自行补写。
重要结论尽量保留对应原话或时间位置，方便复核。
```

## 行业调研

```text
请调研【行业 / 公司 / 产品】，时间范围为【】。
输出市场背景、主要参与者、竞品对比、趋势、机会和风险。
每条关键事实保留来源链接和发布日期；来源之间存在冲突时并列说明。
无法确认的信息标记"待核验"，不要编造。
```

## 定时简报

```text
请创建一份"每日行业简报"的任务说明。
每天【时间】汇总过去 24 小时的【主题】信息，最多 10 条。
每条包含标题、摘要、来源、发布时间和链接；重复事件合并。
来源不足时说明缺失情况，不要为了凑数编造。
先在普通工作任务中运行一次，确认结果后我再到"定时任务"中保存。
```

## 使用工作伙伴或小队

```text
目标：【要完成的交付物】
资料：【项目、文件或链接】
希望由【工作伙伴 / 工作小队】完成。
请先说明分工、交接产物和需要我确认的节点，再开始执行。
未经确认不得对外发送、发布或覆盖正式文件。
```

文件整理这段，适合桌面或下载目录乱了的时候，让它先出方案再动手，不删不改你的原文件。Excel 分析覆盖检查、指标、图表，结果存新文件，原表不动。PPT 生成先给大纲再出全文，避免方向跑偏。会议纪要提取结论、待办、负责人和时间，没负责人的标待确认。行业调研每条事实带来源和日期，冲突并列说明。定时简报先在普通任务跑通，再存成定时任务。

你第一次用，建议从文件整理和 Excel 分析抄起，最贴近日常；做汇报翻 PPT 和纪要；做调研或看简报再看后面。发出去前记得核数字和事实。这些模板都是起点，你按自己情况加减都行，不必照抄每一个字。

你不必每次从头写提示词，骨架都备好了，只改文件名和范围即可。遇到拿不准的活，先来这翻一段，比自己硬憋快。

## 新手常见问题

**这些模板我能直接抄吗？**
能。你新建工作任务、粘进去、换掉文件名和范围就能发，骨架不用自己写。只是交回来后记得核数字和事实。

**涉及发邮件、发消息的活，模板安全吗？**
模板里写了「未经确认不得发送、发布」。你涉及移动、覆盖、发送时一定保留人工确认，别让它擅自外发。

**多文件任务，我该注意什么？**
你涉及多个文件时先建个项目，把材料归到一起；涉及飞书、邮箱这类外部系统，先确认连接器已授权，再派活。

**定时简报为什么先跑一次再保存？**
你先在普通任务里跑一遍，看结果对不对、来源够不够，确认没问题再到「定时任务」里保存，免得每天自动推一堆错的。

**我改了模板，它还是按我的来吗？**
会。你改的文件名、范围、交付要求它都认。模板只是起点，你按自己情况加减都行。
