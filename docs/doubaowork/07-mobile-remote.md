# 手机遥控电脑：出门也不断线

有些任务要跑十几分钟，你总不能端着电脑等它。豆包工作的「手机遥控电脑」适合**人临时离开电脑、但任务还想继续跑**的场景：人在外面看进度、补一句要求，真正干活的还是那台电脑——临时出去一趟，在出租车上也能远程指挥电脑端干活。

## 开启步骤

1. 手机和电脑登录**同一个豆包账号**；
2. 电脑端进入「手机遥控电脑」，开启「可被相同账号的设备控制」；
3. 需要长时间执行时，再打开「**让这台设备保持唤醒状态**」——开着任务去干别的事就不会因锁屏中断；用完记得关；
4. 手机豆包进入工作任务，选择在线电脑。

第一次连接，先发一条**只读测试**，确认手机连的是正确的电脑：

```text
请告诉我下载文件夹中，最新的文件名。
```

## 适合的场景

- 查看一个已经在电脑端运行的长任务进度；
- 让豆包在指定目录中查找候选文件并返回摘要；
- 继续整理本地材料、表格或项目文件；
- 任务等待确认时，通过手机给出下一步指令；
- 接收任务进度提醒，需要时再回到电脑检查最终产物。

## 一个真实片段

临时要改一份总结，人又不在电脑前：手机打开豆包工作连上自己的电脑，让豆包先在本机找到那份总结，再动手改，改完直接通过飞书发回同事——全程没碰电脑，手机上看着它干完。
