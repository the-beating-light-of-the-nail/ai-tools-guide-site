# 人不在电脑前，正在跑的活就没人管了吗？手机遥控电脑，让你出门也能盯着进度、补一句话

你刚给电脑端下了个活，老板喊你去开会，或者地铁上还惦记着那份总结跑到哪一步。电脑搁在桌上，你人已经在外面，总不能端着电脑跑。有些任务一跑就是十几分钟，你干等着也别扭。

这时候用豆包工作的「手机遥控电脑」就顺了。它适合**人临时离开电脑、但任务还想继续跑**的场景：你在外面看进度、补一句要求，真正干活的还是那台电脑。临时出去一趟，在出租车上也能远程指挥电脑端接着干活，不用守在屏幕前。

## 怎么把它打开

你要先确认手机和电脑登录的是**同一个豆包账号**。这步别跳，账号不对，手机根本找不到你的电脑。

接着你在电脑端进「手机遥控电脑」，把「可被相同账号的设备控制」这个开关打开，手机才被允许连上来。

碰到要跑很久的任务，你再额外打开「**让这台设备保持唤醒状态**」。开着它，你中途去干别的事，电脑也不会因为锁屏把任务掐断。不过这是把双刃剑——用完记得关掉，别一直挂着。

随后你在手机豆包里进工作任务，挑那台在线的电脑连上就行。

第一次连，你先发一条**只读测试**，别一上来就让它动真格。目的是确认手机连的确实是你的那台电脑，不是别人共享账号里的机器：

```text
请告诉我下载文件夹中，最新的文件名。
```

它报回来的文件名你认得，就说明连对了。

## 什么情况下用它最值

- 想看一个已经在电脑端跑起来的长任务，走到哪一步了；
- 让豆包去某个目录里翻候选文件，再把摘要甩回来；
- 接着整理本地的材料、表格或者项目文件，不用回电脑前；
- 任务卡在等你确认，在手机上给个下一步指令就能放行；
- 收着进度提醒，等有空了再回到电脑检查最后成品。

## 一个真实片段

临时要改一份总结，人又不在电脑前：手机打开豆包工作连上自己的电脑，让豆包先在本机找到那份总结，再动手改，改完直接通过飞书发回同事——全程没碰电脑，就在手机上看着它干完。

## 新手常见问题

**手机连不上电脑，最可能卡在哪？**
先查账号：手机和电脑是不是登录的同一个豆包账号。再查电脑端「可被相同账号的设备控制」开关有没有打开。这两处有一处没对上，手机就看不见你的电脑。

**「保持唤醒状态」一直开着行不行？**
最好别。它只在任务要跑很久、你又得离开时才打开，防止锁屏把活掐断。活干完了就关掉，别让它一直挂着耗着。

**第一次连接为什么要先发只读测试？**
为了确认手机连的真是你的电脑，不是同名账号里的别的机器。只读测试不会改动任何文件，只问一个文件名，安全又好认。连对了你再派正经活。

**我在手机上能下什么指令？**
和电脑端一样派活就行：查进度、补要求、给确认、让它在指定目录找文件。真正执行还发生在那台电脑上，手机只负责你人不在时远程盯着和指挥。

**飞书发文件这种操作手机上能做吗？**
可以。就像上面那个片段，人在外面，让豆包改完总结直接通过飞书发回同事，全程不用碰电脑。前提是电脑端本来就连着飞书这类通道。
