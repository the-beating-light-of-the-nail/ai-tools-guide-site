# 下班前日报写不出？让群消息和待办自己凑成日报和提醒

你下班前最怕那几行日报：会开了几场、群里回了无数消息、文档改了几版，真到回想时你却说不清今天到底推进了什么。明天要跟进的事也散在各处——有的藏在聊天记录，有的只在会上顺口提过，有的已经过了截止时间。你让豆包工作先把这批记录收拢起来，日报和提醒就有了可靠的起点。

> 场景：下班前那几行日报最难写——会开了几场、群里回了无数消息、文档改了几版，真到回想时却说不清今天推进了什么。

日报和周报你可以共用同一套过程：先让它在群消息、任务和日历里收当天发生的事 → 再区分成果、决定、待办和风险 → 最后把要推进的事项转成提醒。你写报告靠的是当天留下的记录，不用到最后凭记忆硬补。

## 汇总群消息

群消息里混着讨论、通知、表情回复和闲聊。你汇总时更有用的做法是提取已经确认的结论、明确交付、待回答问题和阻塞事项，并保留必要的上下文：

```text
请帮我汇总今天"xxx群"的内容，生成日报。
```

系统会读你指定工作群当天时间范围内的消息，过滤重复通知和闲聊，再提取已确认的结论、行动项、待回答问题和风险。

## 待办任务提醒

提醒要帮你第二天决定先做什么，不能只把待办再念一遍——你结合截止时间、依赖关系、对他人的影响和预计工作量排个序：

```text
将今日待办内容生成提醒，明天早上 9 点提醒我要先做哪些事情。
```

提醒可以留在豆包工作里；你需要在固定时间开始、或要留一整段的工作，也可以写入飞书日历。日报负责说今天发生了什么，提醒负责接住明天的动作——两边用同一份待办状态，任务才不会在不同工具里反复冒出来。

## 一套稳定的日常节奏

你早上看优先级，白天在群里和任务里留记录，晚上汇总成果与风险，再把没完成的事项带到下一天。报告因此成了工作的结果，提醒也接得住后续动作。

## 新手常见问题

**它汇总群消息，会把我闲聊也写进日报吗？**
不会。你提示词让它提取「已确认结论、明确交付、待回答问题、阻塞事项」，它会过滤重复通知和闲聊，只留有用的。

**提醒能直接写进我日历吗？**
能。提醒留在豆包工作里也行；你要固定时间开工或留整段时间的，就写入飞书日历。日报和提醒共用一份待办状态，不重复。

**我白天没留记录，晚上还能出日报吗？**
难。日报靠的是当天留下的群消息、任务、日历记录。你白天随手在群里和任务里留痕，晚上它才好汇总，别全靠记忆补。

**提醒只是把待办念一遍吗？**
不是。你让它结合截止时间、依赖、对他人的影响、工作量排序，帮你决定明天先做什么，而不是复读清单。

**日报和周报能共用一套吗？**
能。你先收当天发生的事，再分成果、决定、待办、风险，最后转提醒。日报和周报走的是同一套过程，只是时间范围不同。
