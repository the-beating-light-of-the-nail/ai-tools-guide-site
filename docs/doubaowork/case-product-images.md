# 手上只有一张随手拍的产品图，怎么让豆包工作生成一整套能上架的主图？

你手里只有一张随手拍的产品原图，背景还是绿植，想上架电商却连一张像样的首图都没有。你以为这是一句生图口令就能解决的事，其实它是一套电商视觉生产工作流。这篇带你用一套技能，把一张原图变成成套主图，还不编造任何产品数字。

你可能会觉得，这不就是一句话让 AI 生张图吗？你真试过就知道，随口一句口令生成的图，往往产品变形、数字乱编。你要想上架卖货，得走一套完整工作流。你跟着下面的技能，把一张随手拍变成成套主图。你不用懂设计，它把最难的部分包了；你也不用担心版权，竞品数字它一概不继承；你只要把真实产品和卖点交给它就行。

## 这个技能帮你做什么

[moyuxl-ecom-image-prompt](https://github.com/AlephAITech/moyuxl-ecom-image-prompt) 技能负责：拆参考、锁事实、定视觉、写生产级提示词、校对成品。两种工作模式：

| 模式 | 适用情况 | 它做的事 |
| --- | --- | --- |
| 参考图反推（重点） | 有产品图 + 几张喜欢的参考图 | 拆开参考图的构图/信息结构/风格，迁移到你的产品上生成新图 |
| 从零策划 | 没有参考图，只有产品 | 从产品身份与买家决策路径推导视觉方向，给 2—4 个可选方向 |

你手上的材料不同，产出也不同：只有产品原图没有方向，它调研卖点、从零策划主图或详情页；产品原图 + 参考图，它拆解参考、迁移手法、生成成套新图；已有完整文案卖点，它直接编译成可复制的生产级生图提示词。

在支持 Agent Skills 的环境里你一条命令安装（也可下载技能文件夹直接导入豆包工作）：

```text
npx skills add https://github.com/AlephAITech/moyuxl-ecom-image-prompt --skill moyuxl-ecom-image-prompt
```

## 实战：1 张手持产品图 → 7 张主图

起点是一张没有任何版式设计的随手拍：手持产品、背景是绿植。

### 参考图分别「借什么」

你不是照抄某一张，而是各取一类机制，再用自己的产品和视觉系统重组：

| 参考图 | 借它的机制 | 明确不搬 |
| --- | --- | --- |
| 棚拍对称式 | 产品居中、左右对称的稳定首图构图 | 它的产品、配色与文案 |
| 原料浸没式 | 产品“泡进”原料中的融合手法 | 它的瓶型与专属画面 |
| 信息图式 | 分栏、卡片、流程线的信息骨架 | 它的原始数据与措辞 |
| 航拍产地式 | 产地氛围与空间叙事 | 它的具体面积/产量数字 |

### 先发散，再收敛

你别急着定稿——围绕同一产品，按构图、场景、信息、色调各试一组方向再挑：

- 第一批·棚拍手法 4 方向：忠实迁移、构图升级、场景叙事、信息设计（忠实迁移版的产品保真与构图稳定度最高）；
- 第二批·原料浸没式 3 变体：产品被红富士苹果环绕——斜插版最贴近参考范式、近景正立版产品占比最大、侧躺版动态感最强；
- 第三批·信息图式 3 变体：真实果园背景加四象限信息与手绘箭头——四象限版信息布局最清晰、画框版产品最突出、行间透视版纵深感最强；
- 第四批·航拍产地式 3 变体：竞品的种植面积、冷库吨位等数据不可继承，统一替换为本品已确认的「源自烟台、当季红富士、100% 鲜苹果汁」等真实信息，不编造规模数字；
- 第五批·原创风格 5 方向：脱离参考图后的探索，覆盖从极简到动态、从清凉到温暖、从日常到高端的完整风格光谱，用于反推最终套系的调性取舍。

## 方法要点

1. 参考图是机制库，不是抄袭对象——每张只借一类构图/信息/氛围机制，产品和数据永远用你自己的；
2. 事实先锁死——产地、成分、卖点等可写上画面的信息，先确认为真实信息，竞品数字不可继承；
3. 批量变体做 A/B——同一机制出 3—4 个变体对比（产品占比、动态感、信息密度），再挑进入最终套系；
4. 调性光谱反推——用原创方向的风格光谱，反过来决定整套主图统一的视觉调性。

## 新手常见问题

**我没有设计基础能用这套技能吗？**
你能。你只要给一张产品原图，它负责拆参考、定视觉、写生产级提示词。你真正要盯的，是产品信息和数字别被它编出来。

**参考图能直接照抄吗？**
不能，也不该。你只借每一张的「机制」——构图、信息骨架、氛围，产品和真实数据永远用你自己的。抄别人的产品和数字，上架就侵权了。

**为什么竞品的面积、产量数字不能继承？**
那不是你的真实信息。技能要求事实先锁死，竞品数字不可继承，统一替换成本品已确认的内容，避免你上架图里出现编造的规模。

**我该一次生成几张？**
你按「先发散、再收敛」来：同一机制出 3—4 个变体对比，挑进最终套系。一次性怼太多反而难选，分批试更清楚。

**生成的图能直接上架吗？**
技能做的是视觉生产，成品质检还要你过一遍：产品占比、信息密度、调性是否统一。确认没问题，再拿去上架。
