# 研究一家公司，怎么让豆包工作把股东减持、回购、管理层变动做成一条能核对的事件线？

你看一家公司，业务和财务最先入眼，可股东减持、回购、股权激励、关联交易和管理层变动，这些容易散落在几十份公告里。你凭「这个股东挺长期主义」「这次回购说明看好公司」下判断，很容易翻车——这些事不能靠人物标签，得回到具体时间、数量、价格、程序和后续兑现。这篇带你用格力电器搭一条治理事件线。

> 场景：研究公司时业务和财务最先被看到，而股东减持、回购、股权激励、关联交易和管理层变动很容易散落在几十份公告里。这些事不能靠人物标签判断——一个股东是不是“长期主义”、一次回购是不是“看好公司”，都要回到具体时间、数量、价格、程序和后续兑现。

这一章用格力电器搭一条治理事件线，把人物印象改写成可以查公告、对日期、看执行结果的事件问题。你最后留下的不是管理层画像，而是一张治理时间线和一组仍需验证的关系。工具用「公告解读」技能，并明确要求工商数据只能补充关系，不能替代交易所和公司公告。

你研究一家公司，很容易先被业务和财务吸引，股东减持、回购这些反而被你忽略。你别急着下人物判断，也别信「长期主义」这种标签。你把减持、回购、管理层变动都拉成一条时间线，回到具体日期、数量和价格去看。你会发现，真正靠谱的不是你的印象，而是事件本身；你缺公告的关系，就老老实实标「待验证」，你千万别用常识替它补证。你按这套方法整理，你后面追加材料也方便，你不用担心它替你猜动机。

## 把治理问题改写成事件问题

```text
请研究格力电器 000651 截至固定数据日的股权、管理层和公司治理情况。

从交易所公告和公司法定披露中梳理控制关系、前十大股东、董事与高管变动、股权激励、
员工持股、回购、增减持、关联交易和重要资本配置事件。
工商数据只用于补充关系，不替代法定披露。

把最近三年的事件按日期排成时间线。每个事件写清公告日期、涉及主体、数量或金额、
实际进度、可能影响和原始链接。影响属于你的分析时单独标注，不从公告事实推测人物动机。

最后输出治理关系图的文字版、利益一致的证据、潜在冲突的证据
和未来十二个月需要跟踪的公告清单。
```

Prompt 给每个事件规定了六个字段：日期（什么时候发生）、主体（谁参与）、数量或金额（影响范围）、实际进度（区分计划与完成）、可能影响（必须标明是分析）、原始链接（回到法定披露）。你这样整理出来的治理材料可以继续追加，而不是读完一次就失去用途。

## 一条时间线，比人物标签更可靠

生成的近三年事件线里，回购是否完成、员工持股怎样安排、股东减持发生在什么时间、关联交易由哪个主体提出，都进入同一套结构。这比只写「管理层重视股东回报」更可靠：回购金额、注销或持有安排、实施进度和公告日期都可以核对；员工持股和激励计划要看解锁条件、资金来源与覆盖对象。事件本身是事实，事件对治理的影响仍然是分析。

一个实操细节：同一事件可能被多份公告重复披露（首次方案、进展公告、完成公告），你应当关联到同一个事件编号，不能在统计时算成三件事——豆包工作可以协助去重，你人工要确认关键字段是否真的指向同一事项。

## 三轮收敛成完整文件

第一轮·法定披露终审：你逐项复核每类事件，补上公告日期、主体、数量、进度、原始链接和截止日状态；工商或媒体材料只能作线索；人物动机、利益一致与潜在冲突必须标成分析栏，不得写成公告事实。

第二轮·生成完整结构：你固定数据截止日（精确到时分），基于实际打开的巨潮公告生成十一部分完整文件——控制关系文字图、前十大股东变化、董监高变动、激励/持股/回购/增减持、关联交易与资本配置、三年时间线、利益一致证据、潜在冲突证据、未来十二个月跟踪表、来源复核表、逐项核对清单。没有发生、没有法定披露或未取得的项目也要逐项写成明确待验证项，不能省略；删除所有未经公告证明的因果判断（如把关联交易金额变化直接归因为某董事离任）。

第三轮·回读验收：你不再扩写，重新打开文件逐项确认——文件名正确、截止日正确、十一部分齐全、待验证项有说明、分析与事实分栏、统计数量自洽、旧文件未被覆盖；任何一项不满足就重新生成再回读。

## 把未确认的关系留在待验证区

公司治理最容易被写成人物故事。你打开时间线后只看事件、时间、决策程序和原始公告，不给人物动机补台词：先核对股东、董事会和管理层的正式身份，不用媒体简称代替法定披露；再按日期排事件——同一个人出现在多份公告里，不等于事件之间已经建立因果；最后看利益冲突、关联关系和表决程序，缺公告的关系只写「待验证」，不用常识替它补证。

治理研究看的是承诺怎样落到事件上：回购方案、实际执行、减持计划、激励条件和关联交易放回同一条时间线。人物可以表达立场，公告负责留下事实。你真正值得跟踪的，是承诺有没有兑现、激励条件有没有变化、利益关系有没有被完整披露。治理研究最怕的不是留白，而是用性格判断替代法定披露。

## 新手常见问题

**工商数据能直接当公告用吗？**
不能。你提示词里写死「工商数据只补充关系，不替代法定披露」。人物关系它能补，但减持数量、回购进度这些必须以交易所和公司公告为准。

**同一件事被多份公告提到，会不会算重复？**
会重复，所以你要让它关联到同一个事件编号。首次方案、进展、完成公告讲的是一件事，统计时不能算成三件。它协助去重，关键字段你再人工确认。

**为什么每个事件要标六个字段？**
日期、主体、数量、进度、影响、原始链接——缺一个你就回不到公告核对。影响那栏必须标成「分析」，不能混进事实。你这么整理，材料能一直追加用下去。

**它会不会替我猜管理层动机？**
你不让。它给的待验证区里，缺公告的关系只写「待验证」，不用常识补证。人物可以表态，事实只认公告。

**三轮收敛听起来麻烦，能省吗？**
最好别省。第一轮核法定披露，第二轮出完整结构，第三轮回读验收。跳过任何一轮，漏掉的待验证项或错算的数量，最后都会变成你报告里的硬伤。
