# 用一个精美的个人网站包装你自己

> 场景：想做个人网站，却一直卡在"等准备好了再做"——照片没挑好、介绍没写完。换个起点：先说清楚你是谁、网站为什么存在。

想做个人网站的人，常常卡在第一步：照片还没挑好、项目介绍没写完、一句自我介绍都要改好几遍。其实可以先从一个更简单的问题开始——**你希望谁看到这个网站，他看完以后记住什么，又愿意继续做什么？**把这几件事说清楚，内容和设计就有了方向。

## design-led-website-builder 在解决什么

AI 很容易生成一个"能打开"的网页；真正麻烦的是，它也很容易生成一个**换掉名字以后还能交给任何人**的网页——白底、通用字体、几张等宽卡片，页面看着完整，却没有多少属于你的东西。

`design-led-website-builder` 这个 Skill 把**设计研究放在写代码之前**，完整流程七步、顺序固定：

1. 接收你已提供的材料，判断是现成品牌、零散个人内容，还是一个参考网站；
2. 锁定网站用途（阅读归档为主的出版型，还是强调作品气质的视觉型）——需求确实有分叉时，只问一轮，选定后再继续；
3. 研究 3—5 个用途相近的**真实网站**，研究对象跟着网站任务走，不会拿炫技作品集去指导需要长期阅读的博客；
4. 寻找 3—8 份可用素材（纸张、木纹、插画、公开授权照片、氛围图）；**真实头像、作品、客户案例和成绩只能使用你提供或确认过的内容**；
5. 用一小段话说明设计方向、参考网站、已找到的素材、不会照抄的部分，以及接下来准备实现什么；
6. 开始搭建：先确定字体、颜色、间距、图片裁切和交互规则，再落实到页面；
7. 完成检查：首屏要让人很快看懂这是谁的网站、这里有什么、下一步能做什么；移动端、键盘操作、动效降级、图片来源和页面性能也在检查范围内。

参考网站只用来理解层级、排版、图片裁切和交互，不能直接复制有辨识度的布局与素材；生成图片可以负责气氛和插画，不能冒充你的照片、产品界面、客户或奖项。

## 安装并跑一遍

直接告诉豆包工作把 Skill 装上：

```text
请安装这个个人网站设计 skill：
https://github.com/liucongg/liucong-skills/tree/main/skills/design-led-website-builder
```

然后一句话开工（提示词里交代了人和目的，Skill 可以直接进入研究阶段）：

```text
$design-led-website-builder 我想制作一个自媒体博主的个人网站，
我全网 ID 都是刘聪NLP，主要想展示我之前分享的一系列文章内容。
```

如果只写"帮我做一个个人网站"，它会先判断可能的几种产品形态，再用一轮问题请你锁定方向。

## 部署到 GitHub Pages

网站做好后，一句话部署：

```text
帮我把这个网站，通过 GitHub 部署到 GitHub Pages 中。
```

没登录 GitHub 的话会先引导登录，随后自动完成部署——从设计研究到上线，全程不需要写一行代码。
