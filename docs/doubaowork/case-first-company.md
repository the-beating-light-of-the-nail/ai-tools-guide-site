# 第一次研究一家公司：从商业模式到八种关键追问

> 场景：第一次看一家公司，最容易从股价、概念或新闻开始——资料收集了一大堆，还是说不清它到底卖什么、客户为什么付钱、利润从哪里来。

更好的起点是先搭一张**公司事实地图**：产品、客户、渠道、成本、竞争壁垒和风险放在同一页，后面的每个问题才有落脚点。这套方法既适合第一次覆盖一家公司，也适合接手别人留下的研究资料。

## 第一步：把这门生意拆清楚

概念可以最后再写。第一轮先回答六个朴素问题：**卖什么、卖给谁、为什么买、怎么交付、成本在哪里、谁有议价权**。工具用「个股研究」Skill，数据截止日固定：

```text
请基于贵州茅台 600519 年报、定期报告、公告和投资者关系材料，拆解这家公司怎样赚钱。

1、说明公司卖什么、卖给谁、通过什么渠道收钱，收入怎样确认，成本主要花在哪里。
按产品和渠道比较收入、毛利率、增长与现金回收。继续分析经销体系、直销渠道、产能、
基酒库存、品牌定价和分红在商业模式中的作用。

2、所有数字写明期间、单位、财报页码或官方链接。把公司披露、管理层说法和你的推断分开。
社会库存、批价和渠道利润若来自第三方调查，单独说明样本与日期。

3、最后交付业务地图、赚钱逻辑、五个关键监控指标和三项容易被忽略的依赖。不直接给投资结论。
```

这段 Prompt 有一个明确的中心：每一项材料都要回答"这家公司怎样把产品变成收入和现金"，与主线无关的品牌故事、历史沿革和泛化行业背景不展开——既控制报告长度，也方便检查材料是否真的改变了对业务的理解。

生成的业务地图最实用的地方，是提醒研究者**不要把一个漂亮的指标单独拿出来**：直销占比变化可能影响渠道关系与回款，产品结构会影响毛利率，基酒产量和库存决定未来可销售规模，终端批价与公司出厂口径不能混用。新财报发布后沿同一张地图更新，不用从公司介绍重新开始。第一次研究公司的读者，可以把业务地图当阅读顺序：先看收入来自哪里 → 毛利率和回款 → 产能与库存 → 最后才讨论品牌与估值。

## 第二步：把八种 Prompt 接到事实底座上

事实底座搭好以后，Prompt 才不会变成八次重复搜索——每种问法打开一个研究入口：

| 研究入口 | 测试标的 | Skill | 主要交付 |
| --- | --- | --- | --- |
| 公司事实底座 | 贵州茅台 | 个股研究 | 业务、产品、渠道和战略变化 |
| 行业周期 | 紫金矿业 | 行业分析报告 | 供需、库存、价格和领先指标 |
| 业务拆解 | 美的集团 | 个股研究 | 业务结构、利润来源和现金回收 |
| 财务质量 | 宁德时代 | 业绩分析 | 利润、现金流、单位与公式复核 |
| 股权与治理 | 格力电器 | 公告解读 | 治理关系、事件线和跟踪清单 |
| 多空分歧 | 寒武纪 | 市场热点分析 | 共同事实、分歧假设和验证节点 |
| 护城河与估值 | 中国神华 | 个股研究 | 护城河证据和估值隐含假设 |
| 尽调级研究 | 比亚迪 | 个股研究 | 业务、行业、财务、治理和反方证据 |

八条提示词（数据截止日均为固定日期）：

**1 · 公司事实底座**：整理核心业务、主要产品、收入与利润来源、主要客户与渠道、产业链位置和最近三年重要战略变化。只用可核验的公告、定期报告和权威来源，每部分三到五条，数字写明期间、单位和原始来源。

**2 · 行业周期**：研究供需、库存、价格、资本开支、新增产能、行业集中度和主要政策变量，区分长期结构因素和短期波动因素；输出当前周期判断、三个领先指标、三个滞后指标，以及未来十二个月要观察的数据。没有可靠数据的地方直接列为缺口，不把价格预测写成确定事实。

**3 · 业务拆解**：量化各业务板块收入、利润、毛利率和近三年趋势，检查是否存在"收入很大但利润贡献有限"的业务，也检查子公司、联营公司和非经常性损益；输出一句话赚钱逻辑、业务结构表和五个持续监控指标。

**4 · 财务质量**：交叉验证利润与经营现金流，检查应收、存货、合同负债、资本开支、折旧摊销、非经常性损益和会计口径变化；所有异常给出**两种解释**和验证路径。

**5 · 股权与治理**：核对控制关系、主要股东、董事会和高管、股权激励、回购、减持、关联交易与资本配置；建立未来十二个月的解禁、回购、激励跟踪表。人物身份、任职时间和事件日期必须回到法定披露。

**6 · 多空分歧**：先列**共同事实**，再分别写多方与空方的核心逻辑、最强反驳、可以被未来数据验证的条件和关键验证节点；未经官方确认的传闻单独列出，不站队。

**7 · 护城河与估值**：用公司披露检查资源禀赋、成本优势、长协定价、一体化运营和分红，再**反推当前估值隐含的煤价、产量、利润率和分红假设**。不要把周期高点外推成长期常态。

**8 · 尽调级研究**：

```text
请对比亚迪 002594 做一份投资者尽职调查报告。研究商业模式与护城河、汽车与电池行业供需、
最近三到五年的财务质量、治理与资本配置、估值隐含假设、空方逻辑和黑天鹅风险。
所有结论区分事实、解释、推断和判断。财务数据必须交叉验证利润与现金流，
公司数据必须与主要同行使用同一报告期比较。每个关键数字注明期间、单位和原始来源。
输出事实摘要、关键财务表、业务与行业分析、估值假设、最强反方证据、未来监控清单和
仍待核验的问题。不要输出买入、卖出、仓位或止损建议。
```

## 长任务要把数据缺口公开

实测中：紫金矿业主动列出 21 处数据缺口；格力形成治理跟踪表；寒武纪把共同事实、多空论据、传闻和资料等级分开。比亚迪报告越过了截止日（用到了 8 月 29 日才披露的半年报），用审计 Prompt 撤回：

```text
请审计刚才的尽调报告。所有数据继续固定在截止日及以前，撤回之后才披露的半年报
及由它推导出的结论。请确认报告是否已覆盖财务质量、治理与资本配置、估值隐含假设、
最强反方证据和黑天鹅风险。缺失的部分只能使用截止日内已正式披露的材料补齐，
无法补齐时保留为待核验问题。最后列出撤回内容、补齐内容和仍未完成的范围。
```

第二轮把最近一期报告退回一季报，撤回全部半年报数字及估值判断；PE TTM 和 PS 得以保留，PB、EV/EBITDA 因缺同口径数据标为待核验——**同行最新报告期和部分第三方数据没有被强行补齐**。另一类常见问题：长任务停在半路（如空目录没生成文件），就用"请从已经提交的原始要求继续执行，直接生成文件并给出文件路径"接续，同时重申截止日、来源和交付格式。

## 好 Prompt 会让问题越来越具体

八种问法不代表每家公司都要跑八遍。第一次覆盖先用商业模式把骨架搭起来；发现收入结构看不懂，转向财报；发现市场争议很大，进入多空审计；发现同行很多，做口径统一后的横向比较。Prompt 真正的价值是**让研究逐步收窄**——问题越问越具体，证据缺口越来越少，这套提问系统才算开始工作。
