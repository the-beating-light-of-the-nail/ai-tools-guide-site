# 整理桌面：先看方案，再动文件

> 场景：桌面 / 下载目录一片狼藉。让豆包工作先"只读扫描 + 出方案"，确认后再动手。

桌面文件一多，先别让豆包工作直接移动文件。让它**只读扫描、列出分类方案；确认无误，再执行整理**。这样既省时间，也避免重要文件被放错位置。

## 第一步：把要整理的文件夹加进项目

豆包工作只能修改**已添加到项目中的本地文件夹**。点击输入框下方的「项目」，选择「添加本地文件夹」，把桌面或目标目录加进来——添加完成后，它才有权限读取并修改里面的文件。

## 第二步：先看分类方案，再确认执行

直接说明想怎么整理。第一次建议让它**先给出分类方案**：准备新建哪些文件夹、每类文件会放到哪里。看过方案后再确认执行，整个过程会稳妥很多。确认后，它会按方案创建目录并移动文件，散落的文件归到对应文件夹里，基础整理的效果已经够用。

## 第三步：系统清理交给专门技能

整理完文件，再试试系统清理：技能库里已有 `Doubao PC Optimizer`，它会按电脑维护流程检查可清理项，再根据确认结果执行。涉及缓存和临时文件这类系统内容时，用专门技能处理更稳妥。

## 三个安全习惯

1. 第一次先选一个**范围较小、可以恢复**的文件夹试运行；
2. 先看**分类方案和移动清单**，确认后再执行；
3. 涉及**删除、缓存和系统清理**时，逐项检查要处理的内容。

流程跑顺以后，再把整理范围扩大到整个桌面或下载目录。
