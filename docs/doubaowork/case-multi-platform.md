# 同一份内容，怎么改成每个平台自己的版本

> 场景：公众号文章刚写完，老板说"小红书也发一下"，过一会儿又补一句"知乎和视频号顺手也做了吧"。听着像复制粘贴，真做起来很费时间：公众号要把事说透，小红书要一张图马上看懂，知乎关心"为什么"，视频号要在几十秒里把冲突讲出来。

这套生产线是四个连续任务：**小红书图文 → 拆成一周内容 → 四平台原生稿 → 发布前审核**：

```text
同一份事实包
→ 先判断平台的特点
→ 再规定每个平台的交付格式
→ 生成草稿
→ 打开成果逐段检查
→ 发布前统一审核
```

工具上只需要两个 Skill：**多平台改写分发**（把同一份内容改成不同平台的结构和语气）和**营销素材审核**（同时查日期、数字、链接、来源、隐私和绝对化表达）。这次没有加链接器或专家团——专用 Skill 已能完整覆盖任务。**工具不是越多越专业，链路越长，事实边界反而越容易在中间丢掉。**

## 任务一：小红书图文，不能只把长文切成九张图

给它的材料只有 5 条已确认的事实，同时明确不能虚构亲身经历、阅读量、收入和客户案例：

```text
请使用"多平台改写分发"能力，把上面的已核验事实包，重新设计成一篇适合小红书
阅读和收藏的图文笔记。不要只把公众号长文切成九段。

【素材】请在这里粘贴你的已核验事实包，或上传事实包文件。

读者是第一次使用 AI 工作工具的职场人和内容运营小白。

交付要求：
1. 先给 3 个小红书标题备选，避免夸张和虚构收益；
2. 输出 8 页卡片：封面 1 页、正文 6 页、结尾互动 1 页；
3. 每页只承担一个信息任务，正文控制在手机屏幕可读范围；
4. 每页给出"页内文案 + 配图 / 版式建议"；
5. 再给一版 300 字以内的小红书正文说明和 8 个以内话题标签；
6. 最后单列"发布前人工复核清单"；
7. 不得虚构亲身经历、阅读量、收入、客户案例或平台规则。
```

运行后，它按"母稿提取 → 平台策略 → 卡片结构"展开——这个中间过程值得看，能帮你判断 AI 是真的在做平台适配，还是只在原文上换几个口语词。最终 8 页各自承担一个信息任务：封面给价值 → 痛点 → 解释事实包 → 区分事实和判断 → AI 的边界 → 完整流程 → 常见坑 → 收藏评论引导，另附约 250 字正文、8 个话题标签和 8 项人工复核清单。

> 好用的判断标准：**卡片里的每一页都应该能回答一个问题**。只是把长文按长度切开，不能算平台改写。

## 任务二：一篇长内容，拆成能独立的短内容

仍用「多平台改写分发」，任务目标从"适配一个平台"改成"把一个母题拆成 7 个独立入口"。提示词里直接规定 7 种形式，最关键的一句是：**每一条脱离原文也能独立成立**：

```text
请使用"多平台改写分发"能力，把这份已确认的长内容，拆成 7 天可分别发布的短内容。

【素材】请在这里粘贴需要拆分的长内容，或上传长内容文件。

形式依次为：小红书图文、朋友圈短帖、问答、60 秒口播、社群讨论、清单卡片、复盘帖。

每一天都要包含独立主题、适合形式、目标读者、核心观点、完整草稿、回到长文的自然入口。
每一条脱离原文也能独立成立，不要写成上中下集，不要重复同一段话，
不新增原文以外的数据、案例或效果承诺。

最后给"一周内容复用检查表"。只生成草稿，不自动排期、不发布。
```

它先给每一天确定独立主题、目标读者和核心观点，再展开完整草稿——没有先写一篇长文再按字数均分。7 天各担不同任务（痛点引入 → 事实包四要素 → AI 边界 → 60 秒三步法 → 社群讨论 → 核对清单 → 一周复盘），还生成了 30 多项复用检查。

## 任务三：一稿真正多发，四个平台原生版本

平台名只是起点，还要把**每个平台最终交什么**写清楚，并要求每个版本后补一行"保留了什么、删掉了什么、为什么这样改"——逼着 AI 把改写逻辑说出来，方便编辑检查：

```text
请使用"多平台改写分发"能力，把共用事实包分别改写成四个平台自己的原生版本，
并先给出平台策略表。

【素材】请在这里粘贴你的共用事实包，或上传事实包文件。

交付：
- 微信公众号：约 800 字，完整讲清三步方法、AI 边界和行动建议；
- 小红书：6 页卡片提纲 + 约 250 字正文，重收藏和复核清单；
- 知乎：约 900 字，以问题开头，有反例、论证和争议收尾；
- 视频号：60 秒口播稿，冲突开场、三步骨架、一句话结论，注意口语节奏。

四个版本只能使用共同事实包。可以改变角度、顺序、结构和语气，
不能改变事实、日期、限制条件。每个版本后标注"保留事实 / 删掉信息 / 为什么改"。
最后给四平台人工复核清单。只生成草稿，不安排发布。
```

执行时它先做一张**平台策略表**（公众号重完整步骤、小红书重收藏动作、知乎重论证、视频号重口语节奏），再分别生成四份草稿。

> 不要把"任务完成"当成验收：结果生成在文档里，必须重新打开逐段检查；生成的是表格、PPT 或文件，就检查那个真正的交付物。

## 任务四：发布前，把日期、链接和敏感表达查一遍

最后切换到「营销素材审核」。为了看它是不是真的能抓问题，实测故意准备了一份"很不干净"的测试稿：正文同时出现两个不同日期；塞入"10 分钟""全网""一定""不用人工""99%""阅读量翻 10 倍"等承诺；一个 `.invalid` 无效链接；来源不明的图片、无来源数据和测试手机号。

```text
请使用"营销素材审核"能力，对下面这份测试稿做发布前只读审核，不要自动修改、不要发布。

【素材】请在这里粘贴或上传待审核稿件。

逐项检查：标题与正文是否一致；两个日期是否冲突；所有数字和效果承诺是否有来源；
链接是否能打开；引用和图片版权是否清楚；是否包含隐私信息；
是否出现"10分钟、全网、一定、不用人工、99%、1000家、爆款、阅读量翻10倍"
等绝对化或无法证明的表达。

请把问题分成"必须修改、建议优化、需要业务确认"，每项给出位置、原文、风险原因
和修改建议；最后给可勾选的发布前清单。无法确认的最新平台规则要明确标成待人工核实。
```

它真的去检查了链接，给绝对化用语、数据来源、版权和隐私分别找依据，而不是只做一遍错别字检查。最终报告抓出 10 项必须修改、4 项建议优化、5 项需业务确认——日期冲突、坏链、绝对化用语、效果承诺、无来源数据、版权不清和电话号码全部被标出，还把"已确认适用规则"和"仍需核实的平台规则"分开。

## 记住这套提示词公式

把一份内容改到任何平台，提示词至少写清五件事：

1. **共同事实包**：哪些事实已确认，来源、时间和限制是什么；
2. **目标读者**：这条内容到底写给谁；
3. **平台交付格式**：不是只给平台名，而是给字数、卡片数、口播时长和结构；
4. **允许改变与禁止改变**：角度、顺序、语气可以改，事实、数字和证据边界不能改；
5. **人工复核和发布边界**：只生成草稿，发布前查日期、数字、链接、引用、版权和敏感表达。

发布前再过一遍清单：四个平台是否用同一份事实包；有没有为适配平台顺手改坏数字、时间或条件；结构是否符合真实阅读动作；链接是否可打开、引用图片是否有来源；有没有绝对化、虚假承诺、隐私或版权风险；**最终交付物是否已重新打开验收**。

一稿多发真正省下来的，是不用每到一个平台都重新想一遍"我到底该怎么改"：事实包守住不变的部分，平台策略决定改变的部分，最后用统一审核把风险兜住。
