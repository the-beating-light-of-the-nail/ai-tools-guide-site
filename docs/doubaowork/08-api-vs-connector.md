# API 服务和连接器，我到底该选哪个？记住一个区别，你当场就能选对

你刚在头像菜单里点开设置，一眼看见两个入口：一个叫「API 服务」，一个叫「连接器」。名字都带个「接」字，你心里犯嘀咕——这俩是不是一回事？点错了，会不会白忙活一天？

先吃颗定心丸：你不用背功能清单，只记一个词就够，叫**方向相反**。把这四个字吃透，后面怎么选都清楚。

## 先把方向看明白

这两个功能，说到底就是「谁主动找谁」不一样。我们用一张表摆清楚：

| | API 服务 | 连接器 |
| --- | --- | --- |
| 方向 | 你在自己的网站或应用里，**调用豆包大模型** | 豆包工作去**读取飞书、网页或其他业务系统** |
| 适合谁 | 开发者 | 普通职场用户 |
| 典型用途 | 给自己的产品接上豆包模型的对话、生成能力 | 让豆包工作直接读飞书文档、腾讯会议记录、Notion 数据库 |

你看左边那列：API 服务，是你自己的网站或应用去「叫」豆包的大模型来干活。右边那列：连接器，是反过来，让豆包工作主动去翻外面的资料。一边拉它进来，一个是它走出去——这就是方向相反的意思。

## API 服务：给开发者

你如果是要给自己做的产品、网站或者小程序里接上豆包的能力，走的就是这条路。

从头像菜单进入「API 服务」，它会跳转到火山引擎的开发者页面。在那边你能拿到调用模型的方式。有一点记一下：模型名称、价格和接入方式可能更新，以当时的官方控制台和文档为准，别拿这篇当死规矩。

## 连接器：给所有人

你如果不是要开发应用，只是想让豆包工作「够得着」外面的数据与工具——加个连接器就够了。

比如你平时资料散在飞书文档、腾讯会议记录、Notion 数据库里，装了连接器，豆包工作就能直接读进去，不用你一份份下载再上传。具体怎么跑通第一个，看这篇：[连接器：先跑一个能验收的小任务](/doubaowork/05-connectors)。

## 怎么选，一句话

你拿不准的时候，问自己一句：我要不要写代码做产品？要，就上 API 服务；不要，只想让豆包工作碰我的外部资料，就加连接器。绝大多数办公场景，连接器就够你用了。

## 新手常见问题

我是普通员工，用得着 API 服务吗？
大概率用不着。API 服务是给开发者往自己产品里接模型用的，你平时让豆包工作读飞书、读会议记录，靠的是连接器。不是开发者，别碰那块就对了。

连接器要写代码吗？
不用你写一行。它本来就是给普通职场用户准备的，装好授权就能让豆包工作读你的外部资料。你只要选好要连哪个系统、给它权限就行。

两个功能能一起用吗？
能，但面向的人不一样。你做产品才需要 API 服务；你日常办公，连接器就够了。多数情况下只用到其中一个，别被名字里的「接」字吓到。

API 服务的价格会变吗？
会变。模型名称、价格和接入方式可能更新，一切以当时火山引擎官方控制台和文档为准。你看到的页面信息跟着官方走，这篇只帮你分清概念。

连接器能读哪些外部系统？
看你接了什么。常见的飞书文档、腾讯会议记录、Notion 数据库都支持。你具体想连哪个，去连接器那篇看怎么跑通第一个。
