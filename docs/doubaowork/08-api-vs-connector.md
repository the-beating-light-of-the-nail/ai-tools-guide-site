# API 服务和连接器，怎么选

这两个功能名字都带"接"，容易混淆。一句话分清：**方向相反**。

| | API 服务 | 连接器 |
| --- | --- | --- |
| 方向 | 你在自己的网站或应用里，**调用豆包大模型** | 豆包工作去**读取飞书、网页或其他业务系统** |
| 适合谁 | 开发者 | 普通职场用户 |
| 典型用途 | 给自己的产品接上豆包模型的对话、生成能力 | 让豆包工作直接读飞书文档、腾讯会议记录、Notion 数据库 |

## API 服务：给开发者

从头像菜单进入「API 服务」，会跳转到火山引擎的开发者页面。模型名称、价格和接入方式可能更新，以当时的官方控制台和文档为准。

## 连接器：给所有人

如果你不是要开发应用，只是想让豆包工作"够得着"你的外部数据与工具——加连接器就够了，详见[连接器：先跑一个能验收的小任务](/doubaowork/05-connectors)。
