# 多 Agent 工作小队怎么用？说人话就能让它自己分工

你手上有个任务，要调研、要分析、要写稿、还要复核，好几道工序串在一起，一个人干到头大。这时候多 Agent（在豆包工作里叫「工作小队」）确实能省时间——但前提是你得让每个角色都清楚自己要干什么、交什么、交给谁。这一篇就讲你怎么把小队用顺，以及那个特别容易找不到的入口。

## 小队里都有谁

你打开「爆款内容创作小队」，点「对话」，能看到四位成员——**创意总监（队长）、爆款营销策划师、爆款内容创作专家、AI 画师**。队长的职责主要是创意设计、团队分工，以及最后的总结交付。

## 直接说人话，它会自己分工

你在对话框里把需求说清楚就行，比如你开了家猫舍想拍抖音，就直接说：

> 我在小区开了家猫舍，养了十几只猫咪，想拍抖音但完全不知道拍啥，帮我想想第一个月怎么拍。

豆包工作会据此主动安排合适的多个专家 Agent 跟进任务，最终几个专家协作完成——你不需要替它写分工方案（但复杂任务仍建议像[上一章](/doubaowork/adv-buddy-or-squad)那样，先确认分工再开工）。

## 一个容易找不到的入口

你任务发出去以后，如果手滑点到了别的界面，想找回刚刚那单：要去「伙伴对话 → 任务」里找，而不是在最近的普通工作任务列表里翻。这一点你记住，省得回头找不到活干到哪了。

## 什么时候值得拆成小队

你拿不准该不该叫小队，对着这张表看信号：

| 信号 | 说明 |
| --- | --- |
| 工序 ≥ 3 道且角色不同 | 策划、写作、设计、复核各有专业口径 |
| 存在前后依赖 | 画师要等文案主线，审核要等全部产物 |
| 你一个人同时顶几个角色 | 最该外包给小队的时刻 |

反过来，单一专业范围内的一次性任务（分析一份表、改一份稿），你开新任务或找单个工作伙伴更省 token、更快，没必要拉一支小队来撑场面。

## 新手常见问题

**我什么都不用管，小队就能自己干完吗？**
你只要在对话框把需求说清，它会自己分工协作。但复杂任务你最好还是先让它列分工、你确认后再开工，免得方向跑偏返工。

**我发出去的任务去哪找？**
你去「伙伴对话 → 任务」里找，别在普通工作任务列表里翻。这是小队独有的入口，你第一次用很容易找错地方。

**什么样的活才值得叫小队？**
工序 Three 道以上、角色不同，或者彼此有前后依赖，比如策划、写作、设计、复核串着来。你一个人顶好几个角色时，最该交给小队。

**简单的活也用小队会不会更慢？**
会。单一专业范围内的一次性任务，开新任务或找单个工作伙伴更省 token、更快。小队适合复杂活，不是万能钥匙。

**小队成员能我自己挑吗？**
你召唤的是现成小队（比如爆款内容创作小队），成员由它定。你想自定义分工，就回到上一章用提示词先写清「谁负责什么、交什么」。
