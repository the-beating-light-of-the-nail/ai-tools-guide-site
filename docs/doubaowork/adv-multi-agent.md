# 多 Agent（工作小队）实操

一个任务需要**调研、分析、写稿和复核**多道工序时，多 Agent（在豆包工作里叫「工作小队」）确实能省时间——前提是每个角色都知道自己要干什么、交付什么、交给谁。

## 小队里都有谁

以「爆款内容创作小队」为例：打开它，点「对话」，可以看到四位成员——**创意总监（队长）、爆款营销策划师、爆款内容创作专家、AI 画师**。队长的职责主要是创意设计、团队分工，以及最后的总结交付。

## 直接说人话，它会自己分工

在对话框里把需求说清楚就行，比如：

> 我在小区开了家猫舍，养了十几只猫咪，想拍抖音但完全不知道拍啥，帮我想想第一个月怎么拍。

豆包工作会据此主动安排合适的多个专家 Agent 跟进任务，最终几个专家协作完成——你不需要替它写分工方案（但复杂任务仍建议像[上一章](/doubaowork/adv-buddy-or-squad)那样，先确认分工再开工）。

## 一个容易找不到的入口

任务发出去以后，如果你点到了其他界面，想找回刚刚的任务：要去**「伙伴对话 → 任务」**里找，而不是在最近的普通工作任务列表里。

## 什么时候值得拆成小队

| 信号 | 说明 |
| --- | --- |
| 工序 ≥ 3 道且角色不同 | 策划、写作、设计、复核各有专业口径 |
| 存在前后依赖 | 画师要等文案主线，审核要等全部产物 |
| 你一个人同时顶几个角色 | 最该外包给小队的时刻 |

反过来，单一专业范围内的一次性任务（分析一份表、改一份稿），开新任务或找单个工作伙伴更省 token、更快。
