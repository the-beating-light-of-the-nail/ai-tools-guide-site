# 从随手收藏到以后真正能搜

> 场景：收藏存了很多，真正要用时怎么也找不到；随手记的灵感当时只一句话，过几天再看已经想不起为什么记、本来准备拿它做什么。

这是两个独立任务，遇到哪个用哪个——不需要为了整理一条灵感，先把整个收藏夹清一遍：

| 独立任务 | 什么时候使用 | 主要交付 |
| --- | --- | --- |
| 收藏很多，要用时搜不到 | 连接知识库、收藏夹和文档目录的只读权限，先盘点再整理 | 可检索目录、建议归档或删除清单 |
| 灵感只记了一句话 | 把碎片笔记、语音或截图直接交给豆包工作，信息不足时先追问 | 笔记草稿，确认后再写入知识库 |

## 收藏很多，真正要用时却搜不到

整理时不能只重新分类、调整文件夹，还要**补齐检索和判断所需的信息**：同一知识在多个工具里各有一份时主版本不清楚；按文件类型或个人习惯分类，未必符合日后真正的搜索方式；很多收藏缺少摘要、关键词和适用场景；没有提前明确操作边界，自动整理还可能误删或移动原文件。

```text
整理这些收藏与资料，让我以后能按真实问题找到它们。
先识别每份内容解决什么问题、适用什么情景、可信度、时间敏感性和原始来源。
合并重复收藏，把只有链接但无法访问、已经过时或没有说明用途的内容单独列出。
按"以后会怎么搜索"生成简短摘要、关键词和关联主题，而不只按文件类型分类。
输出可检索目录、建议归档或删除清单；未经确认不移动或删除原内容。
```

把知识库路径设为工作目录后，这段提示词可以**分五步逐句推进**，每步都有对应产出：

1. 「整理这些收藏与资料……」→ 扫描梳理目录，呈现资料关联，生成按实际问题组织的索引结构图；
2. 「先识别每份内容解决什么问题……」→ 逐份分析，汇总核心结论，生成"可信度 × 时间敏感性"热力图和资料元数据表；
3. 「合并重复收藏……」→ 不改动原文件的前提下归并重复项，待确认内容单独列出；
4. 「按'以后会怎么搜索'生成摘要……」→ 生成检索地图、检索表和摘要表；
5. 「输出可检索目录、归档或删除清单……」→ 汇总成可检索目录、资料分布图和处置建议清单——**所有归档删除只作为建议呈现，确认前不改动原文件**。

最终确认：是否移动、归档或删除，最后由人决定；正式操作前再检查一遍版本、来源和分类有没有判断错。

## 灵感只记了一句话，怎样变成以后找得到的笔记

保留原句，再补上必要的上下文、标题、摘要、关键词和关联内容。原始记录太简略时，整理工具最大的风险是**替你补全意思**——最后的笔记看起来很完整，却已经偏离你当时真正想表达的内容：

```text
把这条碎片灵感整理成一张以后能理解和复用的笔记。
保留原始内容和记录时间，再补充它来自什么情景、触发了什么问题、
可能关联哪些项目或主题、下一步能做什么。
如果原句含义不清，最多问我 3 个关键问题，不要替我编造当时想法。
生成一个可搜索标题、简短摘要、关键词和相关笔记建议。
输出笔记草稿，由我确认后再写入知识库。
```

实测把收件箱里 6 条灵感碎片整理成了可复用笔记：先核对原始内容和时间戳、补充情景/触发问题/关联项目/下一步行动；"最多问 3 个关键问题"这一句会去掉笔记中带推测的内容，含义不清的部分标为"待确认"；随后添加检索卡（可搜索标题 + 摘要 + 关键词 + 相关笔记建议），方便以后全库搜到；最后输出草稿供审阅，确认无误才写入知识库。

验收习惯：抽查一到两条结论能否回到原文件或原始记录；检查数字、日期、版本和对象有没有写错；**只要结果会影响他人、资金、权限、合规或生产系统，就先保留为草稿**。
