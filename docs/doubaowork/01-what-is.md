# 豆包工作是什么？新手第一课

你大概已经在豆包里聊过天：问它周报怎么写，它给你一段范文。然后呢？复制、粘贴、自己改成能交的东西。

豆包工作是字节跳动推出的、面向真实工作任务的 AI 助手（入口：[doubao.com/work](https://www.doubao.com/work)）。它把「然后呢」这一步包了：你说「分析这个文件夹里的销售数据，生成一份汇报 PPT」，它自己读文件、算数、做表、排版，交回一份可以继续编辑的 PPT。

一句话记住区别：聊天 AI 给答案，豆包工作交作业。

## 它具体能帮你干什么

你不是没活干，是活太碎：一份 Excel 要清洗、透视、排名；一段会议录音要变成纪要；一篇文章要改成三个平台的版本。这些活的共同点是——有材料、有明确交付物、过程烦人。

豆包工作就是干这个的。HR、教育、金融、财务、营销、法律、科研、研发……岗位不限，判断标准就一条：你的活里有没有「读一堆材料、产出一份东西」的环节。

不知道从哪开始的话，[场景速查表](/doubaowork/ref-scenarios)按「你是谁 / 你遇到了什么」列了三十多条路线，每条都有现成的提示词。

## 第一次用，别问「你能做什么」

新手最容易踩的坑就是这个。一上来问「你能做什么」，它会回你一大篇功能介绍，看完还是不会用。

正确的开局是派一单小活，四步走完：

1. **给材料**：把文件、文件夹或链接交给它；
2. 说结果：要周报、要 PPT、要表格，说清楚；
3. **定边界**：哪些不能改、拿不准的先问你；
4. 看过程：让它自主推进，关键步骤你把关。

会不会出错？会。所以它交的活你要验收：数字对不对、事实有没有编。它负责干活，你负责验收，这个分工从第一单就要建立。

界面不用提前研究，装好后只看三块：左边找入口，中间看过程和结果，底部写任务、加材料、控权限（详见[主界面、任务和项目](/doubaowork/03-interface)）。

## 新手常见问题

**它会乱动我电脑里的文件吗？**
不会为所欲为。每单任务都有权限档位：始终询问 / 按需确认 / 全部允许。第一单建议选「按需确认」——它每次要动重要东西，都会先问你。

要会写提示词吗？
会说人话就行。把任务当成给同事派活：材料在哪、要什么结果、什么不能碰。这三样说清楚，比背提示词模板管用。

**和聊天豆包是什么关系？**
一家出品，两种分工。聊天豆包管「回答问题」；豆包工作管「完成任务」——能读你授权的资料、调用技能和连接器（连接器就是授权它碰飞书文档这类外部服务的通道）、输出能继续编辑的文件。

**适合我这种岗位吗？**
你的工作里只要出现「读一堆材料、产出一份东西」，就值得试。拿不准就翻[场景速查表](/doubaowork/ref-scenarios)，按人群对号入座。
