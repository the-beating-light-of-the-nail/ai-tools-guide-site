# 生活琐事拿不准？先让它整理资料列清单，关键决定你拍板

旅行怎么排、晚饭吃什么、几款商品怎么选，这些生活小事你看上去都能一句话交代，真做起来却牵扯预算、偏好、实时信息和个人隐私。你一个人查很碎，又怕查不全。豆包工作适合先帮你整理资料、列候选、出清单，预订、付款、诊断这些重要决定，最后仍由你确认。

> 场景：旅行规划、晚饭吃什么、几款商品怎么选。AI 先整理资料、列候选、出清单；预订、付款、诊断等重要决定，最后仍由人确认。

## 先判断是哪类任务

拿不准该放权到哪，对着这张表看：

| 类型 | 豆包工作可以辅助 | 人需要负责 |
| --- | --- | --- |
| 信息整理 | 收集偏好、比较候选、生成清单 | 核对事实并做最终选择 |
| 实时信息 | 查询并整理天气、路线、价格和规则 | 回到官方页面核实最新状态 |
| 健康与隐私 | 整理记录、准备要问专业人员的问题 | 诊断、治疗、用药和紧急处置 |
| 娱乐体验 | 生成文化或娱乐性内容 | 不把结果用于高风险决定 |

你需要特定能力时，在「技能·连接器·伙伴」里搜旅行、天气、地图、生活、健康等关键词。市场内容会变，用前看清技能来源、权限和数据去向；没有合适的技能，你先用普通工作任务完成信息整理。

## 健康咨询：解读体检报告

借医学报告解读类技能，可以把体检报告先读一遍（实测解读比较准，还会生成详细的飞书文档，附饮食建议）：

```text
请解读我上传的体检报告，先确认报告日期、检查机构、项目名称、数值、单位和参考区间。

把结果分成正常、超出参考范围、信息缺失和需要结合其他检查判断四类。
所有数值必须保留原文，不得改写、补全或自行推算。

请用普通人容易理解的语言解释每项指标通常反映什么，以及哪些常见因素可能影响结果。
不要把相关性写成病因，也不要根据单项指标给出确定诊断或患病概率。

最后整理一份复诊时可以询问医生的问题，并列出仍需补充的资料。
不要提供处方、剂量、停药或换药建议。
```

## 消费比较：三款吹风机怎么选

```text
我要比较追觅、戴森、徕芬 3 款吹风机。
主要是长头发使用，不伤头发，预算是 1000 以内。

只使用厂商官网、产品说明书、权威检测资料和我提供的报价。
每项信息注明来源和查询日期。广告宣传、媒体体验和可验证参数分开呈现，
无法核实的内容标记为"待确认"。

先统一比较口径，再用表格列出核心参数、实际使用限制、耗材价格、维护成本、
保修政策、隐私风险、总价和长期成本。
最后分别说明每款产品适合谁、在哪些情况下不适合。
不要因为销量、评分或品牌知名度直接推荐。
```

## 旅游规划：先问清楚，再排行程

```text
我要规划一次去云南的 7 天旅行。

先不要直接排行程。请用不超过 8 个问题确认出发地、日期、同行人、总预算、
交通偏好、住宿要求、饮食禁忌、体力限制、必去地点和明确不去的地点。
已经提供的信息不要重复询问。

收到回答后，先给出两套路线方向，分别说明行程节奏、主要区别、优缺点和预计花费。
等我选定方向后，再生成逐日计划。

逐日计划按上午、下午和晚上排列，写清地点顺序、交通方式、预计用时、餐饮建议、
预约要求和雨天备选。天气、票价、营业时间、预约规则和交通班次注明查询日期及来源。
无法确认的信息标记为"待确认"，不要编造。
```

实测它会先给你两套方案（含节奏、优缺点、预计花费），你选定方向后再生成按上午/下午/晚上排列的逐日计划。

## 新手常见问题

**生活的事全交给它，安全吗？**
你只把整理、列清单、出候选交给它；预订、付款、诊断这些关键决定你自己拍板。它给的方案你核一遍再行动，别闭眼照做。

**实时信息（天气、票价）它给的准吗？**
你让它注明查询日期和来源，最终回到官方页面核实最新状态。实时信息变得快，别拿它的初稿当最终答案。

**体检报告它能当医生用吗？**
不能。你用解读类技能只是先读一遍、整理要问医生的问题；它明确不diagnosis、不开方。真有问题你带清单去问医生。

**商品比较它会不会直接推荐贵的？**
你提示词写了「不因销量、评分或品牌直接推荐」，它按参数和限制客观列。最终适合谁、不适合谁，由你结合自己情况定。

**旅游规划它一次给完行程吗？**
不会。你先答它不超过 8 个问题，它给两套方向，你选了再出逐日计划。这样排出来的行程才合你意。
