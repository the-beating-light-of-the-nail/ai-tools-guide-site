# 随意操作 Excel，秒变数据分析大师

> 场景：工作表一多就头大——列宽对不上、日期格式各写各的、几份明细要合并、公式还要一格格检查。美化、清洗、合并、分析全交给豆包工作。

## Excel 一键美化

美化只解决**阅读效率**，不负责修正数据：表头、列宽、冻结、筛选和交替行底色让明细更容易浏览，减少查看长表时的误操作。原始值、公式和工作表名称应当保持不变。

```text
请美化我上传的《2026年1月销售明细.xlsx》文件，

具体要求：
1. 不修改任何原始数据、公式和工作表名称。
2. 表头使用深蓝色背景、白色加粗文字。
3. 设置适合的列宽和行高，避免文字被截断。
4. 冻结首行并启用筛选。
5. 为数据区域添加交替行底色。
6. 完成后另存为《2026年1月销售明细_美化版.xlsx》。

只调整格式，不要改变数据内容。
```

验收：文字有没有被截断，筛选和冻结是否可用，原始数据有无改动。

## 数据清洗与标准化

清洗要先定义**什么算正确**：空格、地区写法、数值格式和重复记录都有明确规则，模型才有依据处理。无法确定的内容放进"问题数据"，比自动猜一个值更便于追溯。

```text
请清洗我上传的《2026年1月销售明细.xlsx》。

请保留原始工作表不变，新建"清洗后数据"和"问题数据"两个工作表。

清洗规则：
1. 删除文本字段前后的空格。
2. 将"华 东"" 华东"等写法统一为"华东"。
3. 将销售数量、销售单价转换为数值。
4. 将折扣率统一转换为小数，例如 10% 应保存为 0.1。
5. 完全重复的记录只保留一条。

不要擅自补全无法确定的数据。
```

系统会保留原始工作表，把符合规则的记录写入"清洗后数据"，无法确定的内容放进"问题数据"；除本地文件外还会生成在线表格，适合继续查看和协作。

## 多个 Excel 合并

**纵向合并**（1—4 月明细合成总表）：

```text
请合并文件中 2026 年 1 月至 4 月销售明细文件。

处理要求：
1. 按字段名称匹配列，不要只根据列的位置合并。
2. 将所有明细追加到一个名为"销售总表"的工作表。
3. 新增"来源文件"和"来源工作表"两列。
4. 检查各文件是否缺少字段或存在多余字段。
5. 根据订单编号检查重复记录。
6. 不要直接删除存在冲突的重复订单，将其放入"合并异常"工作表。
7. 新建"合并摘要"，列出每个文件的原始行数、有效行数和异常行数。
8. 最终输出《2026年1-4月销售合并表.xlsx》。
```

**横向关联**（交易明细 + 产品信息 + 客户信息三张表）：

```text
请关联以下三个文件：
1. 2026年1-4月销售合并表.xlsx
2. 产品信息表.xlsx
3. 客户信息表.xlsx

关联规则：
1. 使用"产品编号"将产品名称、产品分类、标准售价和单位成本添加到销售总表。
2. 使用"客户编号"将客户名称、客户行业、客户等级和所在省份添加到销售总表。
3. 以销售总表为主表，即使没有匹配到产品或客户，也要保留销售记录。
4. 未匹配到的数据标记为"未匹配"。
5. 将未匹配记录整理到"匹配异常"工作表。
6. 输出产品匹配率和客户匹配率。
7. 不要通过产品名称或客户名称进行模糊猜测。
```

## 数据分析三步走

**公式新增计算列**（保留公式而非写死数值）：

```text
请在 2026年1-4月销售合并表_关联产品客户.xlsx 中新增以下计算列：

1. 销售额 = 销售数量 × 销售单价 ×（1 - 折扣率）
2. 成本金额 = 销售数量 × 单位成本
3. 毛利额 = 销售额 - 成本金额
4. 毛利率 = 毛利额 ÷ 销售额
5. 价格偏差率 =（销售单价 - 标准售价）÷ 标准售价

要求：
1. 使用 Excel 公式，不要把计算结果写成固定数值。
2. 销售额、成本金额、毛利额保留两位小数。
3. 毛利率和价格偏差率显示为百分比。
4. 销售额为 0 时，毛利率显示为空白，不要产生除零错误。
5. 使用统一的公式结构填充全部数据行。
6. 对毛利率小于 10% 的订单使用红色条件格式。
```

**透视与经营汇总**（注意去重与口径）：

```text
请根据 2026年1-4月销售合并表_关联产品客户.xlsx 创建"经营分析"工作表。

需要统计：
1. 各月份的销售额、毛利额、订单数和毛利率。
2. 各区域的销售额、毛利额和客户数量。
3. 各产品分类的销量、销售额和毛利额。
4. 各销售渠道的销售额占比。
5. 各销售人员的销售额排名。

要求：
- 订单数按不同订单编号统计。
- 客户数量按不同客户编号统计。
- 毛利率使用"毛利额合计 ÷ 销售额合计"，不要直接平均明细毛利率。
- 添加总计。
- 金额使用千位分隔符。
```

**管理层仪表盘**（回答管理层每天追问的几件事：规模有没有变化、利润是否健康、哪里低于目标、谁需要跟进）：

```text
请基于"经营分析"创建一个管理层销售仪表盘。

仪表盘包含：
1. 销售额、毛利额、毛利率、订单数四个核心指标。
2. 月度销售额趋势图。
3. 各区域销售额对比图。
4. 产品分类销售额排名图。
5. 销售渠道占比图。
6. 销售人员前 10 名排行榜。
7. 实际销售额与销售目标的完成率。

设计要求：
- 整体使用简洁的商务蓝色风格。
- 核心指标放在顶部。
- 图表标题和单位清晰。
- 不使用 3D 图表。
- 控制颜色数量，避免过度装饰。
- 对低于 80% 的目标完成率使用红色提示。
```

图表数量不必太多，能把异常和趋势讲清楚就够了。实测从合并、关联到公式、透视、仪表盘全流程数据未丢失。
