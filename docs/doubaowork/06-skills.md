# Skill 怎么选，怎么用

豆包工作本身负责理解任务和组织执行；**Skill（技能）是一组可复用的说明、脚本、参考资料和资源**，告诉 Agent 某类任务应该怎么做、调用什么工具、交付什么格式。（Anthropic 于 2025 年 10 月推出 Agent Skills，12 月将其发布为开放标准。）

## 一个标准的 Skill 长什么样

```text
my-skill/
├── SKILL.md          # 唯一必需的文件
├── scripts/
│   └── check.py
├── references/
│   └── guide.md
└── assets/
    └── template.pptx
```

其中只有 `SKILL.md` 是必须的，核心就是一段"这类任务怎么做"的说明：

```markdown
---
name: tech-article-writing
description: 用于撰写 AI 产品、模型评测和科技行业相关文章
---

收到写作任务后：

1. 先确认文章核心角度
2. 查找一手资料
3. 对核心事实交叉验证
4. 根据用户写作风格完成初稿
5. 检查禁用句式和 AI 味表达
```

## Skill 是怎么工作的：渐进式披露

Skill 最关键的设计不是 SKILL.md 本身，而是 **Progressive Disclosure（渐进式披露）**。假设 Agent 装了 100 个 Skill，它不会把 100 份完整内容全塞进上下文——那既浪费 Token，又让模型被无关指令干扰。标准做法分三层：

1. **启动时**只加载所有 Skill 的名称和 description（每个只占几十至上百 Token）；
2. **任务命中时**才加载完整的 `SKILL.md`——比如你说"帮我写一篇豆包工作的公众号文章"，Agent 根据 description 判断 `tech-article-writing` 相关，这时才读全文；
3. **执行中**需要更细的资料才继续读取 `references/style.md`、执行 `scripts/check-ai-phrases.py`。

OpenAI Codex 也采用类似机制。所以 Skill 解决了一个长期困扰 Agent 的问题：**怎么给 Agent 很多知识和工作方法，又不把所有东西永远塞在 Prompt 里。**

## Skill 的四个作用

**1 · 补充程序性知识。** 大模型往往知道大量通用知识，但未必知道你公司的事：`canonical user_id` 在哪张表、`subscriptions` 表是 append-only、查退款要排除某个状态、Grafana 对应的 dashboard ID。Anthropic 内部数百个 Skill 主要集中在 API 与内部库使用、产品验证、数据分析、业务流程自动化、代码脚手架、代码审查、CI/CD、故障 Runbook 和运维九类场景。

**2 · 固定复杂工作流。** 普通 Prompt 是"详细调研一下豆包工作"，模型每次都要重新想：去哪找资料、先查什么、怎么验证、跟谁比、输出什么结构。Skill 把流程固定成：官方网站 → 官方公众号和发布会 → 产品文档 → 实际产品测试 → 同类产品对比 → 核心观点提炼 → 事实核验。这类叫 **Encoded Preference Skill**（按你的工作方式组织既有能力）；另一类 **Capability Uplift Skill** 则补充模型原本做不好或不稳定的能力，如复杂文档、PDF 和 PPT 处理。

**3 · 减少重复 Prompt。** 你反复叮嘱的"不要写得太 AI、长短句结合、不要过度点列、技术内容要克制、不要编造例子"，天然适合做成一个 `writing-style` Skill。以后 Prompt 只需要一句"写一篇豆包工作文章"，写作习惯、资料标准、禁用表达都由 Skill 提供。

**4 · 把经验资产化。** 传统 Prompt 散落在聊天记录、文档和个人脑子里；Skill 是文件，可以 Git 管理、版本回滚、团队共享、A/B 测试、自动评测、持续更新。

## 在豆包工作里找 Skill

打开左侧「技能·连接器·伙伴」：可按**金融、法律、新媒体创作、办公协作、编程、学术**等分类浏览，或在顶部搜索框按名称或需求搜索。找到后点右侧「+」添加；部分技能支持「在对话中试用」。已添加的技能统一在「我的技能」中管理。

也可以**新建或上传自己的技能**：点页面右上角「新建」，选「与豆包对话新建技能」或「上传技能」。上传前检查技能包的来源、脚本和权限范围。

## 用 Skill 解决一个任务

例：文章需要降低 AI 痕迹——在技能市场搜索"去 AI 味"技能，添加后回到工作任务，在输入框输入 `/` 或点「更多技能」选中它，附上文章和具体要求。豆包工作会按技能说明决定处理步骤，并展示执行过程和结果。

完成后重点核对技能要求是否真正落实：是否删除了指定句式、事实和语气是否保留、专有名词有没有被误改。
