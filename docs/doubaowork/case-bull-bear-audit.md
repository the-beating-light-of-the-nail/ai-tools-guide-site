# 市场到底在争什么：从多空分歧到研报事实审计

> 场景：同一家公司，多头能讲出一套完整逻辑，空头也能讲出另一套，两边都引用数据——真正的分歧往往藏在假设里。研报也一样：事实、预测和目标价排在同一页，读者很容易把模型假设当成已经发生的事情。

这一章先用寒武纪寻找多空共同事实，再用工业富联拆一份研报：**先确定双方都承认什么，再检查谁把什么假设放进了结论。**

## 第一部分：多空双方，先把共同事实摆出来

观点越激烈，越要先找共同事实——收入、客户、产品进度和资本开支能不能回源，决定后面的争论有没有地基。用「市场热点分析」能力，匿名消息、二手研报和官方披露分开处理：

```text
请整理截至固定数据日市场围绕寒武纪 688256 的主要分歧。

先列出多方和空方都能核对的共同事实，包括收入、利润、现金流、研发投入、
产品进展、客户和竞争格局。每条事实必须有日期、来源和资料级别。

再分别列出多方与空方对增长、国产替代、竞争、毛利率、研发投入和估值的核心假设。
每个观点写明原始出处、最强反驳、可被证伪的条件和下一次验证节点。
无法找到原始研报时，只能写成二手观点线索，不能保留机构目标价作为事实。

匿名传闻和媒体独家单独放在未确认信息中。
最后输出共同事实表、分歧矩阵、决定性变量和后续验证清单，不替我选择立场。
```

这个顺序会改变回答方式：收入、利润、现金流和研发投入**先按日期与来源记录**，随后才讨论它们是否支持增长逻辑；一个观点必须写出最强反驳与证伪条件——多方要说明出现什么数据会削弱判断，空方也要说明什么变化会迫使自己修正。

### 把口号改写成可以验证的假设

"订单能否转成持续收入"比"国产替代空间很大"更容易验证：前者可以回到收入确认、合同、回款和毛利率，后者没有时间范围和可观察指标就很难判断是否兑现。**分歧矩阵的作用，就是把宏大判断改写成下一次可以检查的变量。**

三个实操要点：

1. **"共同事实"不代表双方结论相同**——同一笔高研发投入，多方理解为未来产品投入，空方担心商业化速度。事实表只确认金额、期间和来源，解释放下一层；两层混在一起，观点就披上了事实的外观；
2. **决定性变量不宜太多**——收入确认、毛利率、现金消耗、产品进展和客户集中度已覆盖大部分争论，每个变量配一个可观察指标和一个时间点，下一轮按原表核对；
3. **每次更新保留旧版本**——新财报支持某项假设时记录新增证据，数据不及预期时写清触发了哪条证伪条件，观点被撤回也保留原因。几个季度之后，这张矩阵才能反映判断怎样随证据变化。

来源是这一轮的主要问题：实测报告主动承认 12 条关键事实没有全部回到第一方材料，部分机构观点来自二手平台——只有机构名称和一个数字，无法证明分析师用了什么盈利预测、估值方法与时间基准。所以要做**来源等级终审**：

```text
请继续完善寒武纪多空分歧报告，完成一次来源等级终审。

重新检查相关材料。公司事实优先回到定期报告、公告和投资者关系原文；
机构观点必须写明机构、作者、发布日期、原始可访问范围。找不到原始研报时，
只保留为二手观点线索，删除目标价和具体盈利预测。匿名传闻继续留在未确认区，
不得因为后续股价变化而补证。

请输出新的《寒武纪多空分歧矩阵.md》，包含共同事实表、多空核心假设、最强反驳、
证伪条件、验证节点、来源等级表、未确认信息和逐项核对清单。
另存为新文件，保留前一版本。最后说明哪些观点因来源不足被降级或删除。不替我选择立场。
```

## 第二部分：拿到研报，先拆事实、假设和目标价

研报不是公告——它可以提供框架和预测，但每一层材料的证据等级不同，目标价更要回到模型假设。用「个股研究」能力检索公开研究材料，同时用公司定期报告核对已发生的事实：

```text
请在网上检索截至固定数据日公开可访问的工业富联 601138 研究资料，
并同时查找公司最近一期定期报告和相关公告。

优先选择两份发布日期与机构清晰、正文或核心假设可以合法访问的券商研报。
若只能取得公开摘要，明确标注资料级别，不假装已经读过完整研报。
分别提取发布日期、作者机构、盈利预测、目标价方法、核心假设、催化剂和风险提示。
研报中的事实、分析师假设和投资观点必须分开。

再用公司原始披露逐项核对收入、利润、毛利率、资本开支、AI 服务器相关业务
和客户或订单说法。无法从公司披露确认的内容明确标注。

最后比较两份研报在哪些事实上一致，在哪些假设上分歧，目标价差异由哪些变量造成。
输出研报对照表、事实核验表、假设敏感项和下一步应该向分析师追问的问题。
不复述整份研报，也不给交易建议。
```

### OCR 材料不等于合格来源

第一版的边界很明显：高盛全文来自第三方研报归档（慧博 OCR 存档，作者名还有 OCR 歧义），不能按机构官网原文处理；UOB PDF 可以直接访问（官方 PDF，印刷日期、目标价方法和盈利预测都有原文支持）。来源审计：

```text
请逐项回查刚才使用的两份研报。列出原始链接、发布日期、机构、作者、可访问范围
和你实际读到的内容。无法合法打开全文时，把所有来自二手摘要的结论降级，
并删除没有原文支持的目标价方法和盈利预测。随后重新生成一张只保留可核验证据的对照表。
```

**研报原文不合格时，不要为了凑齐两份材料而降低门槛。**实测的替换策略：保留已确认可访问的 UOB 官方全文，再找一份机构、作者、发布日期和正文都可从合法渠道直接访问的研报；若确实找不到第二份合格全文，就把任务范围改为"一份合格研报与公司原始披露的核验"，**明确关闭为"截至截止日没有找到第二份合格全文"**，而不是继续保留双研报目标价比较。

> 研报分析的第一步不是抽取目标价，而是**确认你手上这份文件到底是什么**：网页摘要、截图和 OCR 文字都不能直接当成原始研报。研报写了一个数，不等于这个数已经被证明；原文拿不到就把结论降级，不用搜索摘要替它填满。

## 先知道双方在哪个假设上分开

多空争论和研报审计放在一起，最大的好处是能看清观点的来源：同一组事实，可以因为增长持续时间、资本开支强度、竞争格局或估值中枢不同，得到完全不同的结论。研究者需要记录的不只是"谁看多、谁看空"，而是**哪一项假设变化以后，原来的判断会失效**。目标价可以晚一点看——先把事实和假设分开，市场争论才会从情绪变成一组能够继续验证的问题。
