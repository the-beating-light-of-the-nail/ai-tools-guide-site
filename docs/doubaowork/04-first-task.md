# 豆包工作第一单怎么跑？五分钟拿到一份能交的周报

你盯着空荡荡的豆包工作界面，光标在输入框里一闪一闪。材料你其实都有——上周的销售记录、几份散落的会议文档——可你就是不知道第一句该敲什么。复制进聊天框自己写？那又绕回老路了，AI 替的活最后还是你干。

这单别想复杂，就做一份周报。你跟着四步走：建任务、加材料、控权限、验收。跑完这一圈，就能明白它和聊天豆包到底差在哪。

## 建任务：先开一单，别想名字

你点左侧「新工作任务」，任务名随便起，叫「第一单练习」也没人笑你。先把这单当成练手，别想着一步到位做出多惊艳的东西。

进了编辑页，你先加材料。点输入框左边的「+」，或者用「@ 添加资料」，把这次要用的文件、文件夹丢进去。你手上的资料要是在飞书云盘里，它读起来特别顺；也能直接 @ 飞书联系人，把某个同事拉进这单活。

材料加完，你往下看底部，确认选的是「工作任务」，再挑一个权限档位。这里就三档：始终询问、按需确认、全部允许。第一单你选「按需确认」——它每次要动重要东西，都会先弹窗问你，最稳。

模型那栏保持 Auto 就行。活特别磨人再换 Turbo 或 Pro，顺手把推理强度调一调。第一单用 Auto 够了，别在模型上纠结。

## 一条能直接用的提示词

材料齐了，把下面这段直接粘进输入框，改改文件名就能发：

```text
请读取我添加的三份工作记录，整理成一页周报。
结构为：本周完成、关键数据、问题与风险、下周计划。
只使用材料里明确出现的信息；无法确认的内容放进"待确认"，不要补写。
输出 Markdown，同时保留每条关键结论对应的材料名。
```

点发送以后，先别急着收结果。盯着它有没有先读材料、再生成。如果它一上来就给你写周报，说明它压根没先翻你的文件——你这时候补一句「先列出材料清单和时间范围」丢回去，它就会老实先看再动笔。这个判断技巧记住，往后每单都这么验。

## 验收只看四件事

它交回一份 Markdown 周报。照着下面四件事核一遍：

1. 事实有没有写错；
2. 数字能不能对上；
3. 「待确认」项有没有留着，没被它偷偷补写；
4. 格式能不能继续编辑，拿到别处还能改。

四件都过了，这单就算跑通。数字对不上就让它重算，事实写错就指出来让它改。先别急着加技能、接连接器，把第一单的验收手感养出来再说。

## 三个入门任务

周报跑通，手不生了。下面三单拿去练，材料都在 input 目录里，代码块里的提示词直接抄去发就行。

### A · 整理文件

```text
目标：整理 input 目录中的练习文件，便于按类型查找。
```

### B · 会议纪要

```text
请把 input/meeting.txt 整理为结构化会议纪要。
```

### C · Word 转 PPT

```text
把 input/项目汇报.docx 转成 10 页以内的内部汇报 PPT。
```

## 分享前，先过这一关

产物能继续改、下载、按需分享。但点「分享」之前，先确认内容里没有敏感或涉密信息，再按公司规范选共享范围。客户名单、内部报价、未公开数据，别顺手就发出去了。

界面还看不太懂没关系，装好后左边找入口、中间看过程和结果，[主界面、任务和项目](/doubaowork/03-interface) 这篇讲得更细。拿不准从哪类活下手，翻[场景速查表](/doubaowork/ref-scenarios)，按你的岗位对号入座。

## 新手常见问题

**它会不会乱改我电脑里的文件？**
不会为所欲为。每单都有权限档位管着，你第一单选了「按需确认」，它动重要东西前都会先问你。真要它放手干，再切到「全部允许」也不迟。

**提示词要写很长吗？**
不用。会说人话就行——材料在哪、要什么结果、什么不能碰，这三样说清，比背模板管用。上面那段周报提示词，改改文件名就能直接用。

**为什么它一上来就写周报，不读我的文件？**
说明提示词没逼它先看材料。补一句「先列出材料清单和时间范围」丢回去，它就会先翻再写。往后每单都先用这招验它有没有走心。

**模型 Auto、Turbo、Pro 怎么选？**
第一单 Auto 足够，它自己挑合适的。活特别复杂、要长链条推理，再换 Turbo 或 Pro，把推理强度加上去。普通周报和整理文件，用 Auto 就够了。

**分享要注意什么？**
点「分享」前，先确认内容没有敏感或涉密信息，再按公司规范选共享范围。别把客户资料、内部报价顺手发出去。
