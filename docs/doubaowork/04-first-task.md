# 五分钟跑完第一个工作任务

装好以后，用一单小任务把流程走通：建任务 → 加材料 → 控权限 → 验收。

## 创建任务

1. 点击左侧「新工作任务」；
2. 点击输入框左侧「+」或使用「@ 添加资料」，加入本次任务需要的文件、文件夹或其他资料——豆包工作特别支持**飞书云盘数据**，还可以 @ 飞书联系人；
3. 确认底部选择的是「工作任务」，可指定所属项目，并选择权限模式：**始终询问 / 按需确认 / 全部允许**（第一单建议选「按需确认」）；
4. 模型保持 Auto 即可，也可按任务复杂度选 Turbo / Pro 和推理强度。

## 一条能直接用的提示词

```text
请读取我添加的三份工作记录，整理成一页周报。
结构为：本周完成、关键数据、问题与风险、下周计划。
只使用材料里明确出现的信息；无法确认的内容放进"待确认"，不要补写。
输出 Markdown，同时保留每条关键结论对应的材料名。
```

发送以后，看它**有没有先读材料、再生成结果**。如果一上来就写周报，说明提示词还可以再加一句「先列出材料清单和时间范围」。

## 验收只看四件事

1. 事实有没有写错；
2. 数字能不能对上；
3. 「待确认」项有没有留着；
4. 格式能不能继续编辑。

第一单跑通以后，再慢慢加技能和连接器。产物可以继续修改、下载或按需分享；分享前先确认内容不含敏感或涉密信息，并按公司规范选择共享范围。

## 三个入门任务

**A · 整理文件**

```text
目标：整理 input 目录中的练习文件，便于按类型查找。
```

**B · 会议纪要**

```text
请把 input/meeting.txt 整理为结构化会议纪要。
```

**C · Word 转 PPT**

```text
把 input/项目汇报.docx 转成 10 页以内的内部汇报 PPT。
```
