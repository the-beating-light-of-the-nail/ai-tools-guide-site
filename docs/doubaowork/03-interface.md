# 主界面、任务和项目

豆包工作主界面分三个区域，先把这三块看懂，后面的操作都有据可依。

| 区域 | 主要用途 | 使用时重点检查 |
| --- | --- | --- |
| 左侧功能导航 | 新建任务；进入定时任务、技能、连接器、伙伴、云盘和"手机遥控电脑" | 是否进入了正确的任务或功能入口 |
| 中间任务区 | 查看任务拆解、执行过程、工具调用和交付结果 | 任务是否按目标推进，结果是否需要补充或返工 |
| 底部输入与控制区 | 输入需求、添加资料、选择工作任务或项目、设置确认方式、调用技能和连接器 | 资料、目标、约束和确认方式是否正确 |

一句话记法：**左边找入口，中间看过程和结果，底部写任务、加材料、控权限。**

## 任务和项目怎么选

- **任务**：一件事说完、交付即结束，开新任务即可；
- **项目**：同一主题会反复补材料、持续返工，或文件多、时间长、要保持上下文一致——放进项目更合适。

## 模型与响应强度

输入区右下角默认显示 **Auto**，旁边能看到当前响应强度。一般先用 Auto 就够；如果账号或版本提供其他选项，再按任务复杂度、速度和额度要求选择 Turbo / Pro 与推理强度（低 / 中 / 高）。
