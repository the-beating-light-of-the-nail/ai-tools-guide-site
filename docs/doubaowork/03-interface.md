# 打开豆包工作先看这三块：界面、任务和项目

装好了，打开一看：左边一排图标，中间一大片，底部一个输入框。然后呢？

界面你不用研究，记住三块就够：**左边找入口，中间看过程和结果，底部写任务、加材料、控权限。** 其余功能用到再看。

## 左边：入口都在这儿

新建任务在这里，定时任务、技能、连接器、伙伴、云盘、「手机遥控电脑」也都从这里进。

你用的时候只留一个心眼：进对入口。想让它定期干活，别在普通任务里翻，直接进定时任务；想让它读飞书文档，先去连接器。

## 中间：它干活的过程和结果

任务拆解、执行过程、工具调用，最后是交付结果，都在这儿。

跑偏了在这儿就能看出来。比如你让它分析三份文件，它只打开了一份——这时候打断它，比等它写完再推翻重来省事得多。

所以这一片别当装饰。等它写完只看结果，等于把验收的机会让出去了。

## 底部：写任务、加材料、控权限

输入框在这儿。添加资料、选择工作任务或项目、设置确认方式、调用技能和连接器，都在这一带。

你发送前扫一眼：材料齐不齐、目标说清没、确认方式对不对。

## 开任务，还是开项目？

判断标准就一条：

- **一件事说完，交付即结束** → 开任务；
- **同一个主题要反复补材料、持续返工**，或者文件多、时间长、要保持上下文一致 → 放进项目。

你拿不准就先开任务。跑完发现还要改第二版、第三版，再挪进项目也不迟。

## 右下角那个 Auto，要不要动？

输入区右下角默认显示 **Auto**，旁边是当前响应强度。

你先用 Auto。整理文件、写周报、做表格这类活，它够用。等你的账号或版本给出 Turbo / Pro 和推理强度（低 / 中 / 高）的选项，再按任务复杂度、想要的速度和额度去挑。

新手最容易误会的一点：「选最强的就一定最好」。不是。简单活儿开高强度，等得久、额度花得快，出来的东西未必更准。

## 五分钟动线

1. 你在左边点「新工作任务」；
2. 底部输入框加材料，文件或链接都行；
3. 确认权限档位，第一单选「按需确认」；
4. 写下你要什么结果，发送；
5. 你看中间的过程，跑偏了就打断。

详细版见[五分钟跑完第一个工作任务 →](/doubaowork/04-first-task)。

## 新手常见问题

**刚才那个任务找不到了？**
先看你是开在任务里还是项目里，再确认是不是换了登录方式——手机号登录和飞书登录是隔离的，互不相通（见[下载、安装与登录](/doubaowork/02-install)）。

**它老弹窗问我，能不能关掉？**
那是你选了「按需确认」——它要动重要东西会先问你。第一单建议保持这档，等你摸清它的脾气再放宽。

**一定要建项目吗？**
不用。一次性交付的活开任务就够，项目是留给要反复返工、持续补材料的主题的。

**技能、连接器现在就得配吗？**
不用。前几单先把「给材料 → 说结果 → 验收」跑顺，之后再按需要接（[连接器：先跑一个能验收的小任务 →](/doubaowork/05-connectors)）。
