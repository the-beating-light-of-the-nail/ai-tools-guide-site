# 收件箱很满，先找出今天必须处理的事

> 场景：未读邮件堆积如山。先让 AI 排优先级、划处理窗口，把注意力留给真正需要行动的事。

每天一打开邮箱，未读邮件往往已经堆了不少：工作通知、项目进展、协作请求和各种抄送混在一起，一封封查看很费时间，还容易漏掉真正紧急的事项。哪些必须今天回复，哪些可以稍后处理，哪些只需知会？

## 第一步：通过连接器授权邮箱

连接邮箱以后，豆包工作才能读取真实邮件并执行搜索或整理。

1. 点击「技能·连接器·伙伴」，找到**网易邮箱**，点「+」；
2. 进行邮箱授权（授权码的获取方式见[网易邮箱客户端授权码说明](https://help.mail.163.com/faqDetail.do?code=d7a5dc8471cd0c0e8b4b8f4f8e49998b374173cfe9171305fa1ce630d7f67ac2a5feb28b66796d3b)）；
3. 授权完成后展开能力列表，确认**读取、搜索和发送**等操作是否可用；
4. 正式整理前，先读取少量邮件，确认账号、文件夹和时间范围都正确——测试没问题，再做分类和日报。

## 第二步：把收件箱变成一份日报

日报的价值在于把一整页邮件变成**几项能行动的判断**：

```text
读取最近 7 天内收到的邮件。
按今天必须处理、本周处理、等待他人、仅供知会、疑似风险五类整理。
```

提交后，系统会读取最近七天的邮件，按行动时间和处理状态分成五类。这个阶段**只做整理，不发送、不修改原邮件**。即使账号近期邮件很少，空结果也能验证连接器是否正常读取、时间范围和分类规则有没有生效。

## 发送要克制

连接器也支持发送邮件，但工作邮件涉及措辞、收件人、附件和承诺时间——**建议先生成草稿，确认无误后再发送**。
