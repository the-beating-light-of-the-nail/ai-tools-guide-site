# 豆包工作怎么装？Mac / Windows 下载、安装、登录一次讲清

想试豆包工作，卡在第一步的人比想象中多：搜「豆包下载」出来一堆结果，分不清哪个是工作版；下完双击没反应；好不容易登进去，发现上次的任务不见了。

这篇把下载、安装、登录三步一次讲完。你照着做，装完就能用。

## 急着用？看这四行

1. 你打开 [doubao.com/work](https://www.doubao.com/work)，点「下载豆包工作」；
2. 装好以后，你从「应用程序」（Mac）或开始菜单（Windows）启动，别在安装包里直接开；
3. 手机号或飞书账号登录，二选一，选定就别换；
4. 你点左下角头像 →「检查更新」，确认是最新版。

## 下载：只认一个入口

你打开官网 [doubao.com/work](https://www.doubao.com/work)，点「下载豆包工作」，按你的系统和芯片选安装包。

不确定自己的电脑是什么芯片，这样查：

- **Mac**：点左上角苹果菜单 →「关于本机」；
- **Windows**：「设置 → 系统 → 系统信息」。

**只从官方入口下。** 网盘链接、论坛附件、所谓高速镜像，都别碰。你不知道那些包里被加了什么。

## Mac 怎么装

下载得到的是 DMG 安装镜像。双击打开，把「豆包工作」图标拖进「Applications（应用程序）」文件夹，然后从「应用程序」里启动。

新手最常犯的两个错：

- **在 DMG 窗口里直接双击运行。** 能开，但那是个只读的临时盘，更新和设置容易出问题。你要做的只有一步：拖进应用程序再启动。
- **装完找不到图标。** 去启动台搜「豆包工作」，或者打开访达里的应用程序文件夹。

装完，DMG 和安装包可以删，不影响已经装好的程序。

## Windows 怎么装

下载适合你设备的版本，双击安装文件。系统弹出安全提示时，你先看一眼发布者是不是官方，确认没问题再点「运行」，然后按安装向导走完，从开始菜单或桌面启动。

> 公司电脑禁止装软件的话，别想办法绕过终端安全策略，找 IT 管理员确认白名单或企业部署方式。

## 登录：手机号还是飞书

首次启动后按页面引导登录，支持手机号登录和飞书账号登录。

选之前先看这条：**两种登录方式是隔离的。** 手机号登进去和飞书登进去，是两个互不相通的账号，历史任务不打通。

所以你现在公司用什么，就固定用什么。今天手机号、明天飞书，最后你会发现两边各剩一半任务——不是任务丢了，是你在两个地方各干了一半。

## 装完先做三件事

1. 你点左下角头像 →「检查更新」，确认是最新版；
2. 想清楚登录方式，别中途换；
3. 直接派一单小活试手，界面先别研究（[五分钟跑完第一个工作任务 →](/doubaowork/04-first-task)）。

## 新手常见问题

**下载下来打不开，或者提示损坏？**
你先删掉安装包，从官网重新下一次，核对系统和芯片有没有选对。还是不行，就把系统版本、安装包名和报错截图留好，走官方反馈渠道。别去关系统安全功能。

**登录以后没反应？**
检查三处：默认浏览器是不是拦截了登录回跳、网络代理有没有影响认证、系统时间准不准。退出应用重开一次，还不行就保留日志和截图反馈。

**手机上的豆包能用它吗？**
不是一个东西。手机上的聊天豆包负责回答问题，豆包工作负责交付成品，得装电脑版。手机上可以查看进度、远程操控电脑，见[手机遥控电脑](/doubaowork/07-mobile-remote)。

**更新要卸载重装吗？**
不用。点左下角个人头像 →「检查更新」，检测到新版本按提示完成即可。
