# 下载、安装与登录

## 从官方入口下载

打开豆包工作官网 [doubao.com/work](https://www.doubao.com/work)，点击「下载豆包工作」，根据系统和芯片选择安装包。

- **Mac 用户**：不确定芯片时，点左上角苹果菜单里的「关于本机」查看；
- **Windows 用户**：在「设置 → 系统 → 系统信息」里查看。

> **切记：只从官方入口下载，不要从网盘或不明镜像获取安装包。**

## 安装

**macOS**：打开下载得到的 DMG 安装镜像，把「豆包工作」拖入「Applications（应用程序）」文件夹，然后从「应用程序」启动。

**Windows**：下载适合设备的版本后双击安装文件；如系统弹出安全提示，点击「运行」，按安装向导完成安装，再从开始菜单或桌面启动。

## 登录

首次启动后按页面引导登录，支持**手机号登录**和**飞书账号登录**。

> 注意：不同登录方式之间是隔离的——手机号登录和飞书登录各自独立、互不影响。建议固定用一种方式，避免找不到自己的历史任务。

## 更新

点击左下角个人头像，在菜单中选择「检查更新」。检测到新版本时按页面提示完成更新即可。
