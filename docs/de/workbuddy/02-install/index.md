# Kapitel 2: WorkBuddy herunterladen, installieren, anmelden und aktualisieren

## WorkBuddy herunterladen

Um WorkBuddy herunterzuladen, öffnen Sie die offizielle Adresse (https://www.codebuddy.cn/work/), wählen Sie WorkBuddy aus und klicken Sie auf „WorkBuddy herunterladen".

![](/workbuddy/02-install/assets/001_image_GGeabJkE2o.png)

Die Website erkennt automatisch Ihr aktuelles Gerät und stellt fest, welche Version Sie benötigen: Mac ARM64, Mac x64 oder Windows x64.

![](/workbuddy/02-install/assets/002_image_HaXcbwaJXo.png)

***Wichtig: Laden Sie das Installationspaket ausschließlich über den offiziellen Zugang herunter – niemals über Filehoster oder unbekannte Mirror-Quellen.***

## Anmelden

Klicken Sie auf die Anmelde-Schaltfläche

![](/workbuddy/02-install/assets/013_image_MMIXbZJafo.png)

Es erfolgt automatisch eine Weiterleitung zur Anmeldung im Browser

![](/workbuddy/02-install/assets/014_image_MdmYbB2Avo.png)

Wählen Sie die Anmeldung per WeChat-QR-Code – alternativ ist auch die Anmeldung mit der Handynummer möglich

![](/workbuddy/02-install/assets/015_image_WZrBbbWono.png)

Danach können Sie sofort mit WorkBuddy arbeiten

![](/workbuddy/02-install/assets/016_image_Pmh8b7xc8o.png)

*Hinweis: Falls die Installation von Software auf dem Firmenrechner gesperrt ist, umgehen Sie nicht die Sicherheitsrichtlinien – wenden Sie sich an Ihre IT-Administratoren, um Freigaben oder eine Enterprise-Bereitstellung zu klären.*



## Aktualisieren

Klicken Sie unten links auf Ihr persönliches Profil und wählen Sie „Nach Updates suchen", um zu prüfen, ob eine neue Version verfügbar ist. Ist eine neue Version vorhanden, können Sie aktualisieren.

![](/workbuddy/02-install/assets/017_image_Qt1gbb7J3o.png)





## Häufige Fragen

### Das Installationspaket lässt sich nicht öffnen oder gilt als beschädigt

Löschen Sie das Installationspaket und laden Sie es von der offiziellen Website neu; prüfen Sie System- und Chip-Version. Schlägt es weiterhin fehl, notieren Sie Systemversion, Name des Installationspakets und einen Screenshot der Fehlermeldung und nutzen Sie die offiziellen Feedback-Kanäle. Deaktivieren Sie Sicherheitsfunktionen des Systems nicht leichtfertig.

### Nach der Anmeldung passiert nichts

Prüfen Sie, ob der Standardbrowser den Login-Redirect blockiert, ob ein Netzwerk-Proxy die Authentifizierung stört und ob die Systemzeit korrekt ist. Beenden Sie die Anwendung, versuchen Sie es erneut und bewahren Sie Logs und Screenshots auf.

### Dateien können nicht gelesen oder geschrieben werden

Stellen Sie sicher, dass das für die Aufgabe gewählte Arbeitsverzeichnis korrekt ist, dass das System die entsprechenden Verzeichnisrechte erteilt hat und dass die Datei nicht von einem anderen Programm gesperrt ist. Testen Sie zuerst mit einer leeren Textdatei, statt wichtige Dateien erneut für Fehlversuche herzunehmen.

### Sollte man vor dem Update ein Backup machen?

Ein Anwendungsupdate sollte Ihre Arbeitsdateien normalerweise nicht verändern – bei langfristigen Projekten sollten Sie Eingaben, Ergebnisse, Konfigurationen und eigene Skills dennoch in eine Versionsverwaltung aufnehmen oder regelmäßig sichern.
