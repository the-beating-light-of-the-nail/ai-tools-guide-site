# Installation, Anmeldung und geräteübergreifende Zusammenarbeit

Die drei TraeWork-Varianten (Web / Desktop / mobil) teilen sich Account und Aufgabendaten. In diesem Kapitel richten Sie alle ein und verbinden sie.

## Web-Version: ohne Installation zuerst ausprobieren

Öffnen Sie einfach [work.trae.cn](https://work.trae.cn/) und melden Sie sich mit Ihrem TRAE-Account an. Aufgaben in der Web-Version laufen vollständig in der Cloud und beanspruchen keine lokalen Ressourcen – ideal, um zuerst den Kern-Ablauf kennenzulernen und dann zu entscheiden, ob Sie die Desktop-Version installieren.

> Die Web-Version unterstützt nur Cloud-Aufgaben; für lokale Dateien brauchen Sie die Desktop-Version.

## Desktop-Version: der Haupt-Arbeitsplatz

1. Öffnen Sie das Download-Center auf [trae.cn](https://www.trae.cn/) (oder die Schaltfläche „TraeWork herunterladen“ auf der Produktseite);
2. Laden Sie das macOS- oder Windows-Installationspaket herunter und installieren Sie es;
3. Melden Sie sich nach dem Start mit Ihrer Telefonnummer an (denselben Account wie in der Web-Version).

Die wichtigsten Unterschiede der Desktop-Version gegenüber der Web-Version:

| Fähigkeit | Web-Version | Desktop-Version |
| --- | --- | --- |
| Ausführungsumgebung | nur Cloud | lokal + Cloud |
| Lokale Dateien bearbeiten | ✗ | ✓ |
| Office-Assistent (IM-Anbindung) | ✗ | ✓ (die erstmalige Anbindung muss in der Desktop-Version gestartet werden) |
| Eigene Modelle hinzufügen | ✗ | ✓ |
| Computersteuerung / externer Browser | ✗ | ✓ |

## Mobile Version: das Aufgabenzentrum in der Tasche

1. Suchen Sie in Ihrem App-Store nach „TRAE“ und laden Sie die App herunter (iOS erfordert eine nicht-US-Apple-ID, da sie im US-Store noch nicht verfügbar ist);
2. Melden Sie sich mit derselben Telefonnummer wie in der Desktop-Version an;
3. Tippen Sie auf der Startseite unten links auf „Aufgaben-Ausführungsumgebung“ → „Mit meinem Computer verbinden“ und folgen Sie den Anweisungen zum Koppeln.

Vollständige Schritte zum Verbinden von Handy und Computer:

1. Nach der Anmeldung in der TRAE-Mobile-App auf der Startseite unten links auf „Aufgaben-Ausführungsumgebung“ tippen;
2. „Mit meinem Computer verbinden“ antippen;
3. Auf dem Computer die TraeWork-Desktop-Version öffnen und mit derselben Telefonnummer anmelden;
4. In der Desktop-Version zu **Einstellungen > TRAE mobil** gehen und „TRAE mobil darf dieses Gerät steuern“ aktivieren;
5. Im Popup „Nur erforderliche Inhalte werden in der Cloud gespeichert“ auf „Bestätigen“ tippen;
6. Der mobilen App Zugriff auf das Verzeichnis `/documents` des Computers gewähren.

Hinweise:

- Die Kopplung ist **180 Tage** gültig; danach muss neu gekoppelt werden;
- Optional „Computer wach halten“ aktivieren, damit der Rechner während der Aufgabenausführung nicht in den Ruhezustand wechselt;
- Ist das Gerät offline, wechselt das System automatisch zur Cloud-Ausführung – die Aufgabe wird nicht unterbrochen;
- Der Ruhezustand des Computers kann Nachrichtenempfang und -versand unterbrechen (gilt ebenso für den Office-Assistenten).

## Ein typischer Tag mit drei Endgeräten

```text
08:30  Unterwegs per Mobil-App eine Cloud-Aufgabe starten: „Branchennachrichten dieser Woche zusammenfassen“
09:00  Am Arbeitsplatz die Desktop-Version öffnen – Aufgabe fertig, Ergebnis direkt abnehmen
10:00  In der Desktop-Version eine komplexe Aufgabe mit lokalen Dateien starten
12:30  In der Mittagspause per Mobil-App den Fortschritt prüfen und eine Anforderung ergänzen
18:00  Vor Feierabend in der Desktop-Version eine lange Aufgabe starten und zu Hause das Ergebnis per Mobil-App empfangen
```

## Credit-Paket für neue Nutzer

Bei Registrierung erhalten neue Nutzer einmalig **2000 allgemeine Credits + 2000 Work-exklusive Credits** (31 Tage gültig); dazu gibt es tägliche Check-in-Belohnungen in Work-exklusiven Credits, monatlich 500 allgemeine Credits für die Anmeldung und weitere Aktionen. Regeln und Verbrauchsreihenfolge der Credits: siehe [Modelle und Credits: Stolperfallen](/de/traework/adv-models-credits).
