# Herunterladen, Installieren und Anmelden

## Download über den offiziellen Zugang

Öffnen Sie die offizielle Doubao-Work-Website [doubao.com/work](https://www.doubao.com/work), klicken Sie auf „Doubao Work herunterladen" und wählen Sie das Installationspaket passend zu System und Chip.

- **Mac-Nutzer**: Wenn Sie den Chip nicht kennen, sehen Sie im Apple-Menü oben links unter „Über diesen Mac" nach;
- **Windows-Nutzer**: unter „Einstellungen → System → Systeminformationen".

> **Wichtig: Laden Sie die Software nur über den offiziellen Zugang herunter – niemals aus Cloud-Speichern oder unbekannten Spiegelquellen.**

## Installation

**macOS**: Öffnen Sie das heruntergeladene DMG-Installationsabbild, ziehen Sie „Doubao Work" in den Ordner „Programme" (Applications) und starten Sie es dort.

**Windows**: Laden Sie die passende Version herunter und doppelklicken Sie auf die Installationsdatei; falls das System eine Sicherheitswarnung zeigt, klicken Sie auf „Ausführen", folgen Sie dem Installationsassistenten und starten Sie anschließend über das Startmenü oder vom Desktop aus.

## Anmeldung

Folgen Sie nach dem ersten Start der Anleitung auf dem Bildschirm. Verfügbar sind die **Anmeldung mit Handynummer** und die **Anmeldung mit Feishu-Konto**.

> Hinweis: Die verschiedenen Anmeldearten sind voneinander getrennt – Handynummer- und Feishu-Anmeldung laufen jeweils unabhängig. Empfehlung: immer dieselbe Methode verwenden, sonst finden Sie Ihre früheren Aufgaben nicht wieder.

## Updates

Klicken Sie unten links auf Ihren Avatar und wählen Sie im Menü „Nach Updates suchen". Liegt eine neue Version vor, folgen Sie einfach den Hinweisen auf dem Bildschirm.
