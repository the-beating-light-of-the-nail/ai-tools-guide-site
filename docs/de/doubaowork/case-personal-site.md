# Sich selbst präsentieren: mit einer eleganten persönlichen Website

> Szenario: Sie möchten eine persönliche Website, hängen aber bei «ich mache das, wenn alles bereit ist» fest – Fotos nicht ausgewählt, Vorstellung nicht fertig. Beginnen Sie an anderer Stelle: Klären Sie zuerst, wer Sie sind und warum es diese Website gibt.

Wer eine persönliche Website möchte, scheitert oft am ersten Schritt: Fotos noch nicht ausgesucht, Projektbeschreibungen unvollständig, jeder Selbstvorstellungs-Satz mehrfach umformuliert. Besser beginnt man mit einer einfacheren Frage – **Wer soll diese Website sehen, was soll diese Person danach in Erinnerung behalten, und was soll sie anschließend gern tun?** Sind diese Punkte klar, haben Inhalt und Gestaltung eine Richtung.

## Welches Problem design-led-website-builder löst

KI erzeugt leicht eine Seite, die «sich öffnen lässt»; genauso leicht erzeugt sie aber eine Seite, **die nach dem Austausch des Namens an beliebige andere Personen ausgeliefert werden könnte** – weißer Hintergrund, Standardschrift, ein paar gleich breite Karten; die Seite wirkt komplett, enthält aber wenig, das wirklich Ihnen gehört.

Der Skill `design-led-website-builder` setzt **die Designrecherche vor das Schreiben von Code**; der Ablauf hat sieben Schritte in fester Reihenfolge:

1. Er nimmt Ihr bereitgestelltes Material auf und beurteilt, ob es eine fertige Marke, verstreute persönliche Inhalte oder eine Referenz-Website ist;
2. Er legt den Zweck der Website fest (publikationsorientiert mit Lese-Archiv oder visuell betont mit Fokus auf die Ausstrahlung der Arbeiten) – gibt es wirklich Verzweigungen, stellt er nur eine Runde Fragen und fährt nach der Festlegung fort;
3. Er untersucht 3–5 **echte Websites** mit ähnlichem Zweck; was untersucht wird, richtet sich nach der Aufgabe der Website – eine Showreel-Mappe taugt nicht als Maßstab für ein Blog mit langfristiger Leseorientierung;
4. Er sucht 3–8 nutzbare Materialien (Papiere, Holzmaserung, Illustrationen, frei lizenzierte Fotos, Stimmungsbilder); **echte Porträtfotos, Arbeiten, Kundenbeispiele und Erfolge dürfen nur verwendet werden, wenn Sie sie geliefert oder bestätigt haben**;
5. Er erklärt in einem kurzen Absatz die Designrichtung, die Referenz-Websites, die gefundenen Materialien, was nicht kopiert wird und was als Nächstes umgesetzt werden soll;
6. Er beginnt mit dem Aufbau: zuerst Typografie, Farben, Abstände, Bildausschnitte und Interaktionsregeln festlegen, dann auf die Seiten umsetzen;
7. Abschlussprüfung: Der erste Bildschirm muss sofort vermitteln, wessen Website das ist, was es hier gibt und was man als Nächstes tun kann; mobile Darstellung, Tastaturbedienung, reduzierte Animationen, Bildquellen und Seitentempo gehören ebenfalls zur Prüfung.

Referenz-Websites dienen nur dem Verständnis von Hierarchie, Typografie, Bildausschnitt und Interaktion; markante Layouts und Materialien dürfen nicht direkt kopiert werden. Generierte Bilder können Stimmung und Illustration liefern, aber nicht Ihre Fotos, Produktoberflächen, Kunden oder Auszeichnungen vortäuschen.

## Installieren und einmal durchlaufen

Sagen Sie Doubao Work einfach, es soll den Skill installieren:

```text
Bitte installiere diesen Skill für persönliche Website-Gestaltung:
https://github.com/liucongg/liucong-skills/tree/main/skills/design-led-website-builder
```

Dann genügt ein Satz zum Start (der Prompt nennt Person und Ziel, der Skill kann direkt in die Recherche gehen):

```text
$design-led-website-builder Ich möchte eine persönliche Website für einen
Selbstmedien-Blogger erstellen. Meine ID in allen Netzwerken ist LiucongNLP;
ich möchte vor allem die Artikelserie zeigen, die ich bisher geteilt habe.
```

Mit nur „mach mir eine persönliche Website" würde es zuerst mögliche Produktformen abwägen und Sie mit einer Runde Fragen die Richtung festlegen lassen.

## Auf GitHub Pages bereitstellen

Ist die Website fertig, genügt ein Satz zum Deployment:

```text
Stelle diese Website über GitHub auf GitHub Pages bereit.
```

Ohne GitHub-Login führt es zuerst durch die Anmeldung und schließt das Deployment automatisch ab – von der Designrecherche bis zum Livegang, ganz ohne eine Zeile Code.
