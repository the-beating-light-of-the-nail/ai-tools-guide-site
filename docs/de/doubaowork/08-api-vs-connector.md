# API-Dienste oder Konnektoren – was wählen?

Beide Funktionsnamen enthalten „anbinden" und werden leicht verwechselt. Ein Satz zur Abgrenzung: **Die Richtungen sind entgegengesetzt.**

| | API-Dienst | Konnektor |
| --- | --- | --- |
| Richtung | Sie rufen in Ihrer eigenen Website oder App **die Doubao-Großmodelle auf** | Doubao Work **liest Feishu, Webseiten oder andere Geschäftssysteme** |
| Für wen | Entwickler | Normale Büroanwender |
| Typischer Zweck | Der eigenen Produkt die Dialog- und Generierungsfähigkeit der Doubao-Modelle geben | Doubao Work direkt Feishu-Dokumente, Tencent-Meeting-Aufzeichnungen oder Notion-Datenbanken lesen lassen |

## API-Dienst: für Entwickler

Über das Avatar-Menü gelangen Sie in den „API-Dienst" und werden zur Entwicklerseite von Volcano Engine weitergeleitet. Modellnamen, Preise und Integrationswege können sich ändern – maßgeblich sind stets die aktuelle offizielle Konsole und Dokumentation.

## Konnektor: für alle

Wenn Sie keine Anwendung entwickeln wollen, sondern Doubao Work nur „heranreichen" an Ihre externen Daten und Tools lassen möchten – dann genügt ein Konnektor; Details siehe [Konnektoren: zuerst eine kleine, abnehmbare Aufgabe](/de/doubaowork/05-connectors).
