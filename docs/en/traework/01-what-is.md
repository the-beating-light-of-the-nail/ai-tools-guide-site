# What Is TraeWork? Read This Before Your First Run

If you've heard of Trae, chances are you heard it from a friend who writes code—that's TraeCode, the coding tool for programmers.

TraeWork is a different product line from ByteDance, released in June 2026: an AI-native workbench for people who don't write code, under the official tagline "Let TRAE work for you." You say "turn this sales data into a weekly report with charts," and it breaks down the steps and calls the tools itself, handing back a document, a data report, a slide deck, or a web page—rather than tossing you a wall of text and leaving the rest to you.

> Official product page: [trae.cn/work](https://www.trae.cn/work) | Official docs: [docs.trae.cn](https://docs.trae.cn/work_what-is-trae-work)

## How It Relates to TraeCode (Trae IDE)

| | TraeCode | TraeWork |
| --- | --- | --- |
| Positioning | AI-native IDE (programming) | AI-native workbench (office work) |
| Built for | Software engineers | Non-developers such as product managers, operations, and data analysts |
| Typical tasks | Writing code, debugging, managing codebases | Documents, data, slide decks, research, automation |

Two things people get wrong, so sort them out first:

- TraeWork grew out of the SOLO mode in TraeCode, but you can use it without installing TraeCode at all;
- Both belong to the same TRAE account system—see [Models and Credits: Pitfalls to Avoid](/en/traework/adv-models-credits) for how credits carry over.

This site covers TraeWork only; the TraeCode IDE for programmers is out of scope, so don't worry about it.

## Three Modes—You Only Need One

In the top-left corner of TraeWork, you can switch among three modes:

| Mode | Best for | What it does |
| --- | --- | --- |
| **Work** | Non-developers (product, operations, data analysts) | Documents, data processing, slide decks—the main thread of this tutorial |
| **Code** | Software engineers | Coding, debugging, codebase management, Git workflows |
| **Design** | Users with design needs | AI handles design, revisions, and final delivery end to end |

Don't agonize over this on your first run. For office work, stay in Work mode—that's the main line of this tutorial. Code is for writing code and Design is for design work; if you don't need them, pretend they aren't there.

## Mobile, Web, or Desktop: Which to Install First

- **Web**: [work.trae.cn](https://work.trae.cn/)—open it in a browser and you're in. No installation, no local resources used. Start here for a one-off need, when you're away from your desk, or when you just want to try it out.
- **Desktop**: Get the installer (macOS / Windows) from the download center at [trae.cn](https://www.trae.cn/). It supports both local and cloud runtimes, and it's the one to install for long-term use.
- **Mobile**: Search "TRAE" in your phone's app store. It isn't a shrunken workbench; its role is a "cross-device task dispatch center"—assign tasks, check progress, and receive results on your commute. Note: the mobile app has only Work and Code modes, no Design.

All three clients share one account and one set of task data, synced in real time. The typical play: you assign a job from your phone on the subway, a cloud sandbox or your home computer runs it, and the result comes back to your phone.

## Core Capabilities at a Glance

- **Autonomous task execution**: You state the goal; the AI breaks down the steps, invokes skills and tools, and you review the result
- **Office Assistant**: Connect Feishu / WeChat and assign work right from a chat window (see [Office Assistant](/en/traework/05-bot-assistant))
- **External app authorization**: Once authorized, directly operate Feishu Docs / Base / Calendar, GitHub, and more
- **Plugin marketplace**: Popular plugins such as Feishu, Tencent Docs, Tonghuashun iFinD, TDX, and Remotion video
- **Automated tasks**: Run news digests, weekly reports, competitor monitoring, and more on a schedule
- **Skills**: Give the AI "professional capability manuals" that load on demand (see [Skills](/en/traework/04-skills))
- **Computer control / browser control**: Once authorized, let the AI operate interfaces, fill in forms, and pull data
- **Voice discussions**: Talk through your requirements in conversation; after the session, everything is transcribed and cleaned into structured minutes automatically

## How It Relates to the Other Tools on This Site

- **WorkBuddy** (Tencent): an office AI agent workbench, TraeWork's most direct competitor
- **TraeWork** (ByteDance): an AI-native workbench, distinguished by three-client sync and its plugin ecosystem
- **QoderWork** (Alibaba): a desktop intelligent work assistant, strong at browser automation and IM channels

All three take a similar approach (task delegation + skills + scheduling + IM) with different trade-offs in the details. For office work, feel free to install all of them and keep whichever one or two feel right—many feature chapters can be read side by side.

## FAQ

**Is it free?**
You get credits on signup: new users receive 2,000 general credits plus 2,000 Work-specific credits (valid for 31 days), and there are also daily check-in and monthly login events that hand out more. For how credits are deducted and what happens when they run out, see [Models and Credits: Pitfalls to Avoid](/en/traework/adv-models-credits).

**Can I use it without installing TraeCode?**
Yes. TraeWork is a standalone app, and if you use the web version you don't have to install anything at all.

**Can I actually get work done on my phone?**
You can assign work, watch progress, and collect results; the heavy lifting runs in the cloud or on your computer. Treat your phone as the remote control, not the host.

**Which client should I start with?**
Start with the web version if you just want to try it or you're away from your desk—no installation needed. Install the desktop app if you plan to use it long term. Add the mobile app when you start wanting to dispatch work on your commute.
