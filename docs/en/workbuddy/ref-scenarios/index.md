## Basic Office Lookup

| What I want to do | Recommended capability | Human checkpoint |
| --- | --- | --- |
| Schedule, change, or cancel a Tencent Meeting | Tencent Meeting Skill | Topic, time, timezone, attendees, and cancellation scope |
| Get meeting recordings, transcripts, and smart minutes | Tencent Meeting Skill | Recording consent, access permissions, proper nouns, and numbers |
| Turn meeting content into minutes | Transcription + minutes template | Separate facts, decisions, suggestions, and open questions |
| Write action items into a task system | Task connector / API | Owner, deadline, acceptance deliverable, and duplicate writes |
| Generate a PRD from a meeting | PRD template, product manager Skill | Use only confirmed requirements; keep out-of-scope and open items |
| Organize email and draft replies | Email connector, content organizing | Sender, subject, attachments, and send confirmation |
| Generate daily/weekly reports from tasks and meetings | Task, calendar, document Skills | Results backed by task or file evidence; don't write plans as done |
| Batch organize and rename files | File organization, DOCX/PDF | Preview and copy first — no overwriting, no deleting |
| Merge Excel files and reconcile | Excel, data analysis | Primary keys, definitions, exception lists, and amount conservation |
| Compare two versions of a policy, contract, or proposal | Document comparison | Amounts, dates, responsibilities, conditions, and negated statements |
| Generate a reporting PPT from minutes | PPT, charts, brand templates | Outline and evidence mapping first; one conclusion per slide |
| Turn company policies into Q&A | Knowledge base, search | Answers cite clause sources; misses route to a human |
