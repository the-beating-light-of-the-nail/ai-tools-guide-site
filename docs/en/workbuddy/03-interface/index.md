# What Does the WorkBuddy Interface Look Like? Three Areas, and You'll Stop Getting Lost in Five Minutes

You open WorkBuddy for the first time: a column on the left, a big blank space in the middle, another column on the right, and a cursor blinking in the input box. You want it to work for you, but you're afraid one wrong click and it'll start moving files around on your machine. You'd rather study the interface before touching anything, except the screen is full of buttons and it's overwhelming. The interface isn't actually that complicated. Learn three areas and pick up the rest as you go.

Here's the overall picture to hold onto: the WorkBuddy main interface is three areas — the left manages tasks, the middle is where you give instructions and watch it work, and the right shows deliverables and files. This screenshot gives you the whole thing at a glance.

![Three-zone layout: tasks left, chat center, results right](/workbuddy/03-interface/assets/001_image_MuLCbdPyDo.png)

## What Each Area Does

Get these three straight and you basically won't get lost in the interface again.

| Area | Main use | What to check while using it |
|-|-|-|
| Sidebar | Create, search, switch between, and manage tasks | Whether you're in the right task |
| Conversation area | Describe needs, add information, confirm plans | Whether goals and constraints are complete |
| Results area | View deliverables, all files, changes, and previews | Whether filenames, paths, and changes look right |

You may notice two entries in the sidebar, "Tasks" and "Workspaces." The only difference is whether you've set up a "Workspace" directory. A Workspace is a directory WorkBuddy uses to manage tasks: every task gets its own directory space and operates within it. If you don't set one up, tasks run in the default installation directory, and conversations are saved under the "Tasks" directory.

## Why Isolate Working Directories

This isn't just a tidiness habit — it's a security boundary. Pile invoices, weekly reports, and client materials into one big directory and it gets easier for the agent to read the wrong thing, change the wrong thing, or carry client A's information into client B's job. Create a directory space per task and jobs stay out of each other's way.

You can also set permissions per directory space. Turning on "Allow full access" lets the agent read and write files outside the authorized directory — use that one carefully. Prefer scoping a directory per task instead of opening everything at once.

![Workspace permission settings: the full-access toggle](/workbuddy/03-interface/assets/002_image_DtASbQcrto.png)

## Three Working Modes — Which One Should You Use?

WorkBuddy gives you three working modes, and the difference is whether it touches your files.

| Mode | Chinese UI label | What it can do | Best for |
|-|-|-|-|
| Ask | 问一问 | Q&A, understanding, and viewing — no file modifications | Getting familiar with materials, confirming requirements |
| Craft | 做一做 | Can directly operate local files, run code and system commands | Tasks with clear paths and lower risk |
| Plan | 想一想 | Generates a plan first, then executes after you confirm | Multi-step, cross-system, or important-file tasks |

![Choosing among the three modes: Ask, Craft, Plan](/workbuddy/03-interface/assets/003_image_W7VqbwVeJo.png)

Start with Ask or Plan. Ask only answers and never touches anything, so it's the safest. Plan shows you the approach first and waits for your nod. Once you're confident about what it can do, bring Craft in for tasks where it fits.

## Pick a Model That Suits the Job

The default is Auto mode, but you can specify the model you want to use. Different models consume credits at different rates, so don't just go by reputation — go by what fits your work.

![Model selection: auto mode or a specific model](/workbuddy/03-interface/assets/004_image_OzThbMYn5o.png)

| Task characteristics | What to prioritize |
|-|-|
| Lots of text and long documents | Context length, e.g. 1 million tokens (1M) |
| Images and screenshots | Needs visual understanding capability |
| Frequent simple tasks | Prefer fast, low-cost models |

## FAQ

**I keep mixing up the three areas. Which one should I focus on first?**
Get the conversation area in the middle working first — that's where you assign the task and watch how it thinks, and the files and previews in the results area refresh along with it. The sidebar is just for switching and creating, so it can wait.

**Do I have to create a workspace?**
Not strictly. If you don't set one up, WorkBuddy runs in "Tasks" mode inside the default directory. But if you're juggling several different projects, especially ones with client materials, separate workspaces keep jobs from bleeding into each other — and they're safer.

**Ask, Craft, or Plan for my first run?**
When in doubt, pick Ask (answers only, no changes) or Plan (see the approach first, then execute). Craft touches your local files directly, so start with the steadier modes and open up once you know what you're doing.

**Auto or manual model selection?**
Auto is enough for your first job; it picks something suitable on its own. Once you notice a particular job keeps drifting, or the cost is climbing, switch manually using the table above.
