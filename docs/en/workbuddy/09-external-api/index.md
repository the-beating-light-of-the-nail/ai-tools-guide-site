# Chapter 9: How to Connect an External API

You may not have credits but do have your own LLM API — WorkBuddy supports connecting third-party LLM APIs, as well as plans like Coding Plan and Token Plan.

Go straight to it from Settings:

![](/workbuddy/09-external-api/assets/001_image_CaRmbk2N1o.png)

Select the model option:

![](/workbuddy/09-external-api/assets/002_image_PQxNb3id8o.png)

Click Add Model:

![](/workbuddy/09-external-api/assets/003_image_De1fbH0Gho.png)

You can pick from various Coding Plans or a custom API:

![](/workbuddy/09-external-api/assets/004_image_Fa7pb60ARo.png)

For DeepSeek, for example, you just enter your API Key:

![](/workbuddy/09-external-api/assets/005_image_W9u5bNsaMo.png)

You can also connect a local Ollama model (start Ollama locally first; default port 11434, OpenAI-compatible API). The advantages of a local model: **data never leaves your machine, works offline, zero token cost**.

![](/workbuddy/09-external-api/assets/006_image_BSnBbYupuo.png)

> API Keys are sensitive credentials. Enter them only in the client settings — never in task descriptions or files you share.
