# Main Interface, Tasks, and Projects

The Doubao Work main interface has three areas. Understand these three and everything that follows will have a foundation.

| Area | Main Use | What to Check While Working |
| --- | --- | --- |
| Left navigation | Create new tasks; open scheduled tasks, Skills, connectors, buddies, cloud drive, and "remote control from phone" | Whether you've entered the right task or feature |
| Center task area | View task breakdown, execution progress, tool calls, and delivered results | Whether the task is on track toward the goal, and whether results need additions or rework |
| Bottom input and controls | Enter requests, add materials, choose a work task or project, set confirmation mode, invoke Skills and connectors | Whether materials, goals, constraints, and confirmation mode are correct |

A one-line mnemonic: **left to find entry points, middle to watch process and results, bottom to write tasks, add materials, and control permissions.**

## Choosing Between Tasks and Projects

- **Task**: one clearly-scoped piece of work that ends with a deliverable—just start a new task;
- **Project**: an ongoing topic where you'll repeatedly add materials and keep reworking, or one with many files over a long period that needs consistent context—a project is the better fit.

## Models and Response Intensity

The bottom-right of the input area shows **Auto** by default, with the current response intensity next to it. Auto is enough for most work; if your account or version offers other options, choose Turbo / Pro and reasoning intensity (low / medium / high) based on task complexity, speed, and quota needs.
