# Opening Doubao Work for the First Time? These Three Areas Are All You Need

It's installed, so you open it: a column of icons on the left, a big empty space in the middle, an input box at the bottom. And then?

Don't study the interface. Three areas are enough: left to find entry points, middle to watch process and results, bottom to write tasks, add materials, and control permissions. Everything else can wait until you need it.

| Area | Main Use | What to Check While Working |
| --- | --- | --- |
| Left navigation | Create new tasks; open scheduled tasks, Skills, connectors, buddies, cloud drive, and "remote control from phone" | Whether you've entered the right task or feature |
| Center task area | View task breakdown, execution progress, tool calls, and delivered results | Whether the task is on track toward the goal, and whether results need additions or rework |
| Bottom input and controls | Enter requests, add materials, choose a work task or project, set confirmation mode, invoke Skills and connectors | Whether materials, goals, constraints, and confirmation mode are correct |

A one-line mnemonic: **left to find entry points, middle to watch process and results, bottom to write tasks, add materials, and control permissions.**

## The Left: Every Entry Point Lives Here

This is where you create new tasks, and where scheduled tasks, Skills, connectors, buddies, cloud drive, and "remote control from phone" all open from.

Keep one thing in mind as you work: get into the right entry point. If you want it working on a schedule, don't go digging through ordinary tasks — open scheduled tasks. If you want it reading a Feishu doc, go to connectors first.

## The Middle: How It Works, and What It Produced

Task breakdown, execution progress, tool calls, and finally the delivered results all show up here.

This is also where you can see it drifting off course. Say you asked it to analyze three files and it only opened one — interrupt it right there. That's far cheaper than waiting for it to finish and throwing the whole thing out.

So don't treat this area as decoration. If you only look at results after it's done, you've given up your chance to review.

## The Bottom: Write Tasks, Add Materials, Control Permissions

The input box is here. Adding materials, choosing a work task or project, setting the confirmation mode, and calling Skills and connectors all happen in this strip.

Before you hit send, scan it once: are the materials complete, is the goal clear, is the confirmation mode right.

## Starting a Task, or a Project?

There's only one test:

- **Task**: one clearly-scoped piece of work that ends with a deliverable—just start a new task;
- **Project**: an ongoing topic where you'll repeatedly add materials and keep reworking, or one with many files over a long period that needs consistent context—a project is the better fit.

If you can't decide, start a task. If it turns out you need a second and third draft, you can move it into a project later.

## That "Auto" in the Bottom-Right Corner — Should You Change It?

The bottom-right of the input area shows **Auto** by default, with the current response intensity next to it.

Start with Auto. It's enough for organizing files, writing weekly reports, and building spreadsheets. Once your account or version offers Turbo / Pro and a reasoning intensity (low / medium / high), pick based on how complex the task is, how fast you need it, and how much quota you want to spend.

One thing beginners get wrong: "the strongest setting must be the best." It isn't. Run a simple job at high intensity and you'll wait longer, burn quota faster, and the output won't necessarily be more accurate.

## A Five-Minute Route

1. Click "New Work Task" on the left;
2. Add materials in the bottom input box — files or links;
3. Confirm the permission level. For your first task, pick "Confirm As Needed";
4. Write down what result you want, and send;
5. Watch the process in the middle. If it drifts, interrupt.

## FAQ

**I can't find the task I just created. Where did it go?**
First check whether you opened it as a task or inside a project, then check whether you switched login methods — phone-number login and Feishu login are isolated and don't see each other (see [Download, Install, and Log In](/en/doubaowork/02-install)).

**It keeps popping up to ask me things. Can I turn that off?**
That's because you chose "Confirm As Needed" — it asks before touching anything important. Keep that setting for your first job and relax it once you know how it behaves.

**Do I have to create a project?**
No. One-off deliverables work fine as a task. Projects are for topics you'll keep reworking and adding materials to.

**Do I need to set up Skills and connectors right now?**
No. Get "hand over materials → state the outcome → review" running smoothly over your first few jobs, then connect what you actually need ([Connectors: Start with a Small, Verifiable Task →](/en/doubaowork/05-connectors)).
