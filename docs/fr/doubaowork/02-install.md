# Télécharger, installer et se connecter

## Télécharger depuis le site officiel

Ouvrez le site officiel de Doubao Work, [doubao.com/work](https://www.doubao.com/work), cliquez sur « Télécharger Doubao Work » et choisissez le paquet d'installation selon votre système et votre puce.

- **Utilisateurs Mac** : en cas de doute sur la puce, ouvrez le menu Pomme en haut à gauche et consultez « À propos de ce Mac » ;
- **Utilisateurs Windows** : vérifiez dans « Paramètres → Système → Informations système ».

> **Règle absolue : téléchargez uniquement depuis le site officiel, jamais depuis un disque réseau ou un miroir inconnu.**

## Installation

**macOS** : ouvrez l'image DMG téléchargée, glissez « Doubao Work » dans le dossier « Applications », puis lancez-le depuis là.

**Windows** : après avoir téléchargé la version adaptée à votre appareil, double-cliquez sur le fichier d'installation ; si Windows affiche un avertissement de sécurité, cliquez sur « Exécuter », suivez l'assistant d'installation, puis lancez l'application depuis le menu Démarrer ou le bureau.

## Connexion

Au premier lancement, suivez le guide de connexion à l'écran ; la connexion par **numéro de téléphone** et la connexion par **compte Feishu** sont prises en charge.

> À noter : les modes de connexion sont étanches — la connexion par téléphone et la connexion Feishu sont indépendantes l'une de l'autre. Choisissez une seule méthode et gardez-la, pour ne pas perdre vos tâches antérieures.

## Mise à jour

Cliquez sur votre avatar en bas à gauche et choisissez « Rechercher des mises à jour » dans le menu. Si une nouvelle version est détectée, suivez simplement les indications à l'écran.
