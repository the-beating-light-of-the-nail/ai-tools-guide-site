# Résumer automatiquement le rapport quotidien et rappeler les tâches du jour

> Contexte : ces quelques lignes de rapport quotidien avant de partir sont les plus dures à écrire — tant de réunions, tant de messages répondus dans les groupes, tant de versions de documents, et pourtant impossible de dire ce qu'on a vraiment fait avancer.

Ce qu'il faut suivre le lendemain est éparpillé : enterré dans l'historique de chat, évoqué en passant en réunion, ou déjà hors délai. Laissez Doubao Work rassembler d'abord ces traces : rapport et rappels partent alors sur une base fiable.

Rapport quotidien et rapport hebdomadaire partagent le même processus : **collecter d'abord dans les messages de groupe, les tâches et le calendrier ce qui s'est passé dans la journée → distinguer résultats, décisions, choses à faire et risques → convertir enfin ce qui doit progresser en rappels**. Le rapport s'appuie sur les traces laissées dans la journée, sans rien rattraper de mémoire au dernier moment.

## Résumer les messages de groupe

Les messages de groupe mêlent discussions, annonces, réactions emoji et bavardages. Plus utile : extraire **les conclusions confirmées, les livrables explicites, les questions en attente et les blocages**, en gardant le contexte nécessaire :

```text
Résume le contenu du groupe « xxx » d'aujourd'hui et génère mon rapport quotidien.
```

Le système lit les messages du groupe de travail indiqué pour la plage horaire du jour, filtre annonces redondantes et bavardages, puis extrait conclusions confirmées, actions, questions en attente et risques.

## Rappels de tâches

Un rappel doit aider à **décider par quoi commencer** le lendemain, pas se contenter de relire la liste des choses à faire — il peut classer par échéance, dépendances, impact sur les autres et charge estimée :

```text
Génère des rappels à partir de mes tâches du jour ; demain à 9 h, rappelle-moi
ce que je dois faire en premier.
```

Les rappels peuvent rester dans Doubao Work ; les travaux qui doivent démarrer à heure fixe, ou qui exigent un bloc de temps réservé, peuvent aussi être écrits dans le **calendrier Feishu**. Le rapport raconte ce qui s'est passé aujourd'hui, le rappel attrape les actions de demain — les deux s'appuient sur le même statut des tâches, qui n'apparaît ainsi pas en double d'un outil à l'autre.

## Un rythme quotidien stable

Le matin, les priorités ; la journée, laisser des traces dans les groupes et les tâches ; le soir, rassembler résultats et risques ; reporter à la nuit ce qui reste inachevé. Le rapport devient alors **le résultat du travail**, et le rappel attrape les actions qui suivent.
