# Services API ou connecteurs : que choisir

Ces deux fonctions portent toutes deux un mot d'« interface » dans leur nom et se confondent facilement. En une phrase : **elles pointent dans des sens opposés**.

| | Services API | Connecteurs |
| --- | --- | --- |
| Sens | Depuis votre site ou votre application, vous **appelez le grand modèle Doubao** | Doubao Work va **lire Feishu, des pages web ou d'autres systèmes métier** |
| Pour qui | Développeurs | Utilisateurs bureautiques ordinaires |
| Usage typique | Brancher les capacités de dialogue et de génération du modèle Doubao sur votre produit | Laisser Doubao Work lire directement les documents Feishu, les comptes rendus Tencent Meeting, les bases Notion |

## Services API : pour les développeurs

Depuis le menu de l'avatar, « Services API » renvoie vers la page développeur de Volcano Engine. Noms des modèles, tarifs et modalités d'accès peuvent évoluer : référez-vous à la console officielle et à la documentation en vigueur.

## Connecteurs : pour tout le monde

Si vous ne développez pas d'application et voulez seulement que Doubao Work « atteigne » vos données et outils externes — un connecteur suffit, voir [Connecteurs : commencez par une petite tâche vérifiable](/fr/doubaowork/05-connectors).
