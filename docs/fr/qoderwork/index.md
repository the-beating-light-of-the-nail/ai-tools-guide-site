# Tutoriel QoderWork

**QoderWork** est un assistant de travail intelligent de bureau issu de l'écosystème Alibaba (« vous énoncez le besoin, il livre le résultat ») : organisation de fichiers, traitement de données, génération de documents, automatisation du navigateur, tâches planifiées, pilotage à distance par IM — les livrables sont de vrais fichiers déposés sur votre ordinateur, pas un historique de chat.

> Téléchargement officiel : [qoderwork.com](https://qoderwork.com) (version Chine [qoder.com.cn/qoderwork](https://qoder.com.cn/qoderwork)) ｜ Documentation officielle : [docs.qoder.com/zh/qoderwork](https://docs.qoder.com/zh/qoderwork/introduction)

Cette section est une création originale de ce site, rédigée et vérifiée d'après la documentation officielle (au 31-08-2026 ; le produit évolue vite, la documentation officielle prime) ; les études de cas sont adaptées de retours d'expérience de la communauté, avec la source indiquée. La structure reprend la grille en cinq volets du « Livre bleu pratique de WorkBuddy ».

## À qui cela s'adresse

- Les employés de bureau au bureau en désordre et aux fichiers éparpillés
- Les fonctions support qui manipulent chaque jour tableaux, tickets, CV, factures
- Les passionnés d'efficacité qui veulent piloter leur ordinateur à distance depuis une fenêtre de chat
- Ceux qui comparent également WorkBuddy / TraeWork avant de choisir
