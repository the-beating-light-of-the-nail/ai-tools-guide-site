# Qu'est-ce que QoderWork

**QoderWork** est un assistant de travail intelligent de bureau lancé par l'écosystème Alibaba (équipe Qoder / Alibaba Cloud pour la Chine), slogan officiel « **vous énoncez le besoin, il livre le résultat** », qui se présente aussi comme un « agent IA dédié ». Il étend les capacités d'agent de Qoder du domaine du code aux tâches quotidiennes : organisation de fichiers, traitement de données, génération de documents, automatisation du navigateur, tâches planifiées, pilotage à distance par IM — là où l'IA traditionnelle « répond quand on l'interroge et vous laisse faire le travail », QoderWork fait le travail jusqu'au bout et dépose les livrables sur votre ordinateur.

> Documentation officielle : [docs.qoder.com/zh/qoderwork](https://docs.qoder.com/zh/qoderwork/introduction) ｜ Version Chine : [qoder.com.cn/qoderwork](https://qoder.com.cn/qoderwork) (QoderWork CN, canal Alibaba Cloud)

## Les huit capacités

| Capacité | En une phrase |
| --- | --- |
| Traitement de fichiers | Lire, rédiger et organiser en conversation documents, tableaux, présentations et PDF |
| Automatisation du navigateur | Naviguer, remplir des formulaires, extraire des données automatiquement, sans script |
| Contrôle du bureau | Piloter directement clics, saisie et défilement des applications de bureau |
| Tâches planifiées | Exécution automatique périodique ou ponctuelle (journaux, rappels, surveillance) |
| Canaux IM | Connecté à DingTalk, Feishu, WeChat, etc. ; pilotage à distance depuis le chat |
| Skills et extensions | Marketplace de Skills, kits d'experts, serveurs MCP, connecteurs tiers |
| Saisie vocale | Maintenez Fn et parlez ; l'IA transcrit et exécute |
| Mémoire | Mémorisation inter-sessions et personnalisation du style de collaboration ; plus vous l'utilisez, mieux elle vous connaît |

## Les trois concepts clés

Trois concepts soulignés par la documentation officielle de démarrage rapide, inévitables dès la première utilisation :

- **Clarification** : brève confirmation avant le début de la tâche, pour aligner un besoin flou (automatiquement passée si le besoin est clair) — ne l'ignorez pas : les problèmes révélés par la clarification, s'ils ne sont pas traités, finissent en reprises ;
- **Surveillance de tâche** : panneau d'exécution à droite de l'espace de travail, qui montre en temps réel le plan, les appels d'outils, les Skills mobilisés et les fichiers manipulés — l'officiel insiste : « tout est transparent » ;
- **Livrable** : les fichiers locaux réels produits par la tâche (tableaux, rapports, présentations…), enregistrés directement sur votre ordinateur, ouvrables, modifiables et déplaçables à tout moment.

## Lien avec Qoder (plateforme de programmation)

La famille Qoder compte plusieurs gammes : Qoder IDE, plugin JetBrains, CLI, Cloud Agents, **QoderWork**, etc. QoderWork en est la branche « bureautique » pour non-développeurs, une **application bureau indépendante** — il n'existe pas de notion « d'onglet QoderWork à activer dans un autre produit ».

Comptes et avantages liés : QoderWork se connecte avec le compte unifié Qoder ; **le solde de Credits et les avantages d'abonnement sont partagés entre tous les produits Qoder**. À noter : l'historique des tâches est stocké localement et **ne se synchronise pas entre appareils**.

En mai 2026, Alibaba Cloud a fait évoluer Tongyi Lingma en famille de produits Qoder CN ; QoderWork CN en est le client bureau pour la Chine.

## Lien avec les autres outils de ce site

- **WorkBuddy** (Tencent) : espace de travail d'agents IA bureautiques, écosystème de Skills bureautiques mature
- **TraeWork** (ByteDance) : espace de travail natif IA, synergie des trois plateformes + forte intégration Feishu
- **QoderWork** (Alibaba) : assistant de travail intelligent de bureau, fort en automatisation du navigateur et canaux IM

Les trois ont des positionnements proches avec chacun leur accent. Les différenciateurs de QoderWork : local d'abord (les opérations sur fichiers se font en local), une automatisation du navigateur qui « opère le web comme vous », et le pilotage à distance depuis 7 plateformes IM.
