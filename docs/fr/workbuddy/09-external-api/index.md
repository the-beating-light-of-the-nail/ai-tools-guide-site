# Chapitre 9 : Comment se connecter à des API externes

Vous n'avez peut-être pas de crédits, mais disposez de votre propre API LLM — WorkBuddy prend en charge les API d'autres LLM, ainsi que les offres Coding Plan, Token Plan, etc.

Accédez-y directement depuis les paramètres :

![](/workbuddy/09-external-api/assets/001_image_CaRmbk2N1o.png)

Sélectionnez l'option Modèles :

![](/workbuddy/09-external-api/assets/002_image_PQxNb3id8o.png)

Cliquez sur Ajouter un modèle :

![](/workbuddy/09-external-api/assets/003_image_De1fbH0Gho.png)

Vous pouvez choisir parmi divers Coding Plans ou une API personnalisée :

![](/workbuddy/09-external-api/assets/004_image_Fa7pb60ARo.png)

Avec DeepSeek, par exemple, il suffit de saisir la clé API :

![](/workbuddy/09-external-api/assets/005_image_W9u5bNsaMo.png)

Vous pouvez aussi connecter un modèle Ollama local (démarrez d'abord Ollama en local, port par défaut 11434, interface compatible OpenAI). Les avantages d'un modèle local : **les données ne quittent jamais votre machine, usage hors ligne possible, coût en tokens nul**.

![](/workbuddy/09-external-api/assets/006_image_BSnBbYupuo.png)

> La clé API est un identifiant sensible : ne la renseignez que dans les paramètres du client, jamais dans une description de tâche ou un fichier partagé.
