## 提示词五大误区（官方文档）

你写提示词常踩的坑，官方列了五个，你逐一对照能少走弯路：

| ❌ 误区 | ✅ 正解 |
| --- | --- |
| 一句话概括所有需求 | 说具体：目标 + 格式 + 约束 |
| 不检查结果就继续 | 错误会在后续步骤放大，每步抽查 |
| 同一任务混多主题 | 一事一任务，无关新开 |
| 从不使用附件 | "@文件 + 一句要求"胜过一大段描述 |
| 不告诉用途 | 说明"给谁看、用来做什么"，输出更对路 |

## 硬限制备忘

你开工前，这七条硬限制先记牢，省得任务跑一半翻车：

- 一个任务只能关联**一个**工作文件夹；
- 开关连接器后需**新建对话**才生效；
- 定时任务由本地客户端调度：电脑睡眠/关机不触发，错过不补（可手动「立即运行」）；
- CAPTCHA、短信验证码、人脸识别必须人工介入；
- 浏览器连接器仅支持 Chromium 内核；
- 历史任务存本地设备，不会跨设备同步，你换电脑就看不到；
- 技能分享链接约 24 小时有效，你发给同事要趁早。

## 常见问题

**我就是纯新手，该先点哪个功能？**
你先别研究功能，直接进第一个任务跑通一次，感觉比看表来得快。

**我想让它整理文件夹，用哪个？**
你用工作文件夹那套；想看别人怎么整理，去文件整理案例照着做。

**提示词老写不好，表里说的误区我全中怎么办？**
最常见的是「一句话概括所有需求」。你改成「目标 + 格式 + 约束」三件套，效果立竿见影。

**QoderWork、TraeWork、WorkBuddy 我都要装吗？**
不是必须。你按主要需求选一家先跑顺，真遇到短板再补，三家账号独立互不冲突。

**我该先装还是先读？**
你先读上手篇里的第一个任务，装好就能照着做，不用先读完所有章节。

**硬限制里哪条最容易踩？**
你最容易忘的是「一个任务只关联一个工作文件夹」，绑错目录会读错文件，开工前先确认。

**提示词误区改一条就够吗？**
你先从「一句话概括所有需求」改起，改成「目标 + 格式 + 约束」，其余四条顺手对照。

**零基础的我先看哪张表？**
你先看「按人群」那张，对号入座比硬记功能快。
