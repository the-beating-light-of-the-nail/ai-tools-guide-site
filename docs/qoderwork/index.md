# QoderWork 怎么学？从安装到进阶，一份路线图带你走完

你想找个能替你干活的 AI，但市面上工具一堆，不知道从哪下手。这份 QoderWork 指南就是给你这样的办公人写的：从装好它、跑通第一个任务，到文件整理、数据分析、浏览器自动化，一步步来。你不用先懂原理，跟着路线走，边用边懂。

**QoderWork** 是阿里系的桌面端智能工作助手，「你说需求，它交付结果」。文件整理、数据处理、文档生成、浏览器自动化、定时任务、IM 远程指挥，每一样活最后都落到你电脑上，产出的是真实文件。验收也简单：不用翻聊天记录，直接打开硬盘看产物。

> 官网下载：[qoderwork.com](https://qoderwork.com)（国内版 [qoder.com.cn/qoderwork](https://qoder.com.cn/qoderwork)） ｜ 官方文档：[docs.qoder.com/zh/qoderwork](https://docs.qoder.com/zh/qoderwork/introduction)

## 适合谁

- 桌面一团糟、文件满天飞的办公人——你最该先读文件整理案例；
- 每天和表格、票据、简历、单据打交道的职能岗——数据类和批量文档案例对得上；
- 想用聊天窗远程指挥电脑干活的效率玩家——IM 频道和电脑操控给你看；
- 同时在对比 WorkBuddy / TraeWork 的选型者——速查表里三家怎么选说得清楚。

## 常见问题

**我完全是新手，先从哪篇看？**
从第一个任务开始，你跟着跑完一个完整循环，后面的概念一下就通了。

**这份指南里的数据案例是真的吗？**
案例篇改编自社区实战并注明出处，数据来自原作者实测，你当参考即可，别当成官方承诺。

**QoderWork 和其他两家怎么选？**
你常泡钉钉、飞书、微信，或要带登录态跑网页，选它；深度飞书 / 腾讯文档选别的。详见场景速查表。

**看不完所有章节怎么办？**
不用看完。你只挑本周要做的那件事，进对应案例照做，跑通比通读重要。
