# 第一个任务：从描述到产物

QoderWork 的使用循环只有三步：**描述任务 → 监控执行 → 收取产物**。这一章把每一步的细节和官方最佳实践讲清。

## 创建任务的五步

1. **描述任务**：提示词要"面向结果"——直接说"要拿到什么"，而不是"按什么步骤做"；
2. **选择工作台**：输入框左下角，默认「通用」（另有设计/幻灯片/写作三个垂类工作台，见[三大工作台](/qoderwork/adv-workbenches)）；
3. **选择模型**：右下角模型选择器（见下节）；
4. **选择工作目录**（可选）：让 AI 直接读写某个本地文件夹，见[工作文件夹](/qoderwork/04-files)；
5. 发送。

一个适合第一次跑的任务：

```text
分析我上传的销售数据.csv：说明字段含义，按品类统计销售额并排名，
生成一份 Excel 汇总表和 3 条结论。
要求：数字与源文件一致，无法确认的标注待核实。
```

## 丰富上下文的三个入口

| 入口 | 用法 | 适合 |
| --- | --- | --- |
| **+ 按钮** | 从菜单添加：专家套件、技能、连接器、文件 | 上传附件、挂能力 |
| **@ 引用** | 输入 @ 引用已有对象：套件、历史任务、定时任务、文件 | 关联已有内容 |
| **/ 调用** | 输入 / 调用技能与指令（xlsx、pptx、pdf、find-skills 等） | 精确点名 |

官方最佳实践原话："**附上正确引用与附件的任务，几乎总是比一大段文字描述表现更好。**"

## 模型怎么选

| 档位 | 适合 | 消耗 |
| --- | --- | --- |
| 旗舰 | 复杂推理、容错低的关键报告、跨多文件分析 | 最高 |
| 高级 | 强劲均衡的重点项目 | 较高 |
| 标准 | 日常任务，速度与质量平衡——**绝大多数场景够用** | 中 |
| Qwen3.7-Max / Plus | 通义千问系列：Max 进阶推理，Plus 日常又快又省 | 各异 |

两个关键机制：

- **随时切换、立即生效**：同一任务执行中可以换模型，不丢上下文。官方示例打法：标准档收数据 → 旗舰档深度分析 → 标准档格式化输出；
- 余额不足时：购买 Credits，或切高级/标准档降耗。

## 观察执行：任务监控面板

任务监控在工作区右侧，包含三个子面板：

- **待办计划**：AI 拆解出的执行步骤，随进度勾选；
- **产物**：任务输出的文件卡片，点击可在系统中打开；
- **Skills & MCP**：本轮用到的技能和连接器——全程透明。

**中途追加指令**：任务运行中发的消息会排入队列，等当前这轮结束后接着执行（保留完整上下文）；任务结束后发送的立即执行。不满意直接说："按价格从低到高排序""第三条的结论依据是什么"。

## 任务的边界

- 一个任务 = 一次独立的 AI 工作会话，有自己的对话、上下文、监控和产物，**两个任务之间互不共享数据**；
- 相关迭代（初稿→修改→定稿）留在同一任务里；无关的事新开任务——干净上下文，也不浪费 Credits 重放旧对话；
- 所有任务（含未发送的草稿）自动保存；任务列表按"最近"排列，可搜索、分组、置顶、导出为 Markdown、归档（归档可恢复，优先归档而不是删除）。

## 提示词三要素

官方总结的提示词骨架，写任务前过一遍：

| 要素 | 回答什么 | 示例 |
| --- | --- | --- |
| 目标 | 交付物是什么 | "一份 Excel 汇总表" |
| 格式 | 输出成什么 | "输出为 .xlsx，含图表" |
| 约束 | 必须包含/避免什么 | "不虚构数据；金额保留两位小数" |

更多模板见[常用指令模板](/qoderwork/ref-templates)，提示词方法论的完整版（六项进阶技巧 + 五大误区）见[场景速查](/qoderwork/ref-scenarios)的引用。
