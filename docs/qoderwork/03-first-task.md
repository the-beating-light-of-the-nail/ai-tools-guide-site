# 第一次怎么派活给 QoderWork？描述完等它交文件，三步跑通

你盯着输入框，光标一闪一闪。材料你其实都有——一份销售数据表、几份散落的文档——可你就是不知道第一句该写什么。复制进聊天框自己写？那又绕回老路了，AI 替的活最后还是你干。

这一章把 QoderWork 的使用循环讲透：你**描述任务 → 盯着它执行 → 收下产物**。跑完第一单，你就明白它和聊天机器人差在哪。

## 建任务的五步

你新建一个任务，照这五步走：

1. **描述任务**：提示词要「面向结果」——直接说「要拿到什么」，而不是「按什么步骤做」；
2. **选工作台**：输入框左下角，默认「通用」（另有设计 / 幻灯片 / 写作三个垂类工作台，见[三大工作台](/qoderwork/adv-workbenches)）；
3. **选模型**：右下角模型选择器（下节细说）；
4. **选工作目录**（可选）：让 AI 直接读写某个本地文件夹，见[工作文件夹](/qoderwork/04-files)；
5. 发送。

一个适合你第一次跑的任务，把下面这段直接粘进去，改改文件名就能发：

```text
分析我上传的销售数据.csv：说明字段含义，按品类统计销售额并排名，
生成一份 Excel 汇总表和 3 条结论。
要求：数字与源文件一致，无法确认的标注待核实。
```

## 给任务加料的三个入口

你描述得再清楚，也不如把材料直接挂上去。三个入口这么用：

| 入口 | 用法 | 适合 |
| --- | --- | --- |
| **+ 按钮** | 从菜单添加：专家套件、技能、连接器、文件 | 上传附件、挂能力 |
| **@ 引用** | 输入 @ 引用已有对象：套件、历史任务、定时任务、文件 | 关联已有内容 |
| **/ 调用** | 输入 / 调用技能与指令（xlsx、pptx、pdf、find-skills 等） | 精确点名 |

官方最佳实践原话：“**附上正确引用与附件的任务，几乎总是比一大段文字描述表现更好。**”所以你手上有文件，优先 @ 或 + 挂上去。

## 模型怎么选

你选模型时看这张表，日常别纠结：

| 档位 | 适合 | 消耗 |
| --- | --- | --- |
| 旗舰 | 复杂推理、容错低的关键报告、跨多文件分析 | 最高 |
| 高级 | 强劲均衡的重点项目 | 较高 |
| 标准 | 日常任务，速度与质量平衡——**绝大多数场景够用** | 中 |
| Qwen3.7-Max / Plus | 通义千问系列：Max 进阶推理，Plus 日常又快又省 | 各异 |

两个关键机制你得知道：

- **随时切换、立即生效**：同一个任务执行中你也能换模型，不丢上下文。官方示例打法是：标准档收数据 → 旗舰档深度分析 → 标准档格式化输出；
- 余额不足时：你买 Credits，或者切到高级 / 标准档降耗。

## 盯着它干：任务监控面板

你派完活，进度在工作区右边，分三个小面板：

- **待办计划**：AI 拆出来的执行步骤，跟着进度一个个勾；
- **产物**：任务输出的文件卡片，点一下就能在系统里打开；
- **Skills & MCP**：这轮用到的技能和连接器——全程透明，你能看见。

**中途追加指令**：任务跑着的时候你发的消息会排队，等当前这轮结束接着执行（上下文完整保留）；任务结束后再发，就立即执行。不满意直接说：“按价格从低到高排序”“第三条的结论依据是什么”。

## 任务的边界，别踩

你建任务时记住几条边界：

- 一个任务 = 一次独立的 AI 工作会话，有自己的对话、上下文、监控和产物，**两个任务之间互不共享数据**；
- 相关迭代（初稿 → 修改 → 定稿）留在同一任务里；不相干的事新开任务——上下文干净，也不浪费 Credits 重放旧对话；
- 所有任务（含没发送的草稿）自动保存；任务列表按「最近」排，能搜索、分组、置顶、导出成 Markdown、归档（归档能恢复，优先归档而不是删除）。

## 提示词三要素

你写任务前，过一遍这张骨架：

| 要素 | 回答什么 | 示例 |
| --- | --- | --- |
| 目标 | 交付物是什么 | “一份 Excel 汇总表” |
| 格式 | 输出成什么 | “输出为 .xlsx，含图表” |
| 约束 | 必须包含 / 避免什么 | “不虚构数据；金额保留两位小数” |

更多模板见[常用指令模板](/qoderwork/ref-templates)，提示词方法论的完整版（六项进阶技巧 + 五大误区）见[场景速查](/qoderwork/ref-scenarios)的引用。

## 新手常见问题

**第一句到底该写什么？**
别写「你能做什么」这种开场。你直接写结果：要什么文件、什么格式、什么不能碰。上面那段销售数据提示词，改改文件名就能直接发。

**模型选哪个不浪费？**
绝大多数场景标准档够用。你等活特别复杂、要跨多文件推理，再上高级或旗舰。同一任务里还能中途换档，不丢上下文。

**它可以同时帮我做两件不相干的事吗？**
不建议。两个任务互不共享数据，你最好一事一任务，上下文干净，也省 Credits。

**中途发现它跑偏了怎么办？**
直接发消息追一句指令，会排进队列等这轮结束接着跑。你说“按价格从低到高排序”，它就照做。

**草稿没发送会丢吗？**
不会。所有任务含未发送草稿都自动保存，按最近排列，还能归档（归档能恢复）。
