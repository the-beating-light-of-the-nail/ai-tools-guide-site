# 连接器与 MCP 怎么接？让 AI 替你操作浏览器和钉钉，不用你守着

你想要的从来不是「让它回答一个问题」，而是「让它去钉钉发个消息」「让它把网页里的表格搬下来」。QoderWork 的连接器干的就是这个——它是你电脑和外部系统之间的桥。开启后，AI 能像你一样操作浏览器、读写系统日历和邮件、对接 Microsoft 365 和钉钉。MCP 则是接更多外部工具的开放协议。

> 官方文档：[connectors](https://docs.qoder.com/zh/qoderwork/connectors) ｜ [钉钉 MCP 实战](https://docs.qoder.com/zh/qoderwork/mcp-walkthrough)

## 连接器总览

你从这里进统一入口：左侧导航 → 扩展 → 连接器，有「市场」和「已安装」两个选项卡。默认全部关闭，只有你明确完成授权与配置，QoderWork 才拿到相应权限。

| 类别 | 连接器 |
| --- | --- |
| 内置 | **浏览器**（网页操作、数据提取、表单填写）、**macOS 应用**（提醒事项、日历、备忘录、邮件、通讯录）、**Microsoft 365**（Outlook / 日历 / 联系人 / To Do / OneNote / OneDrive） |
| 集成市场 | 钉钉、飞书、Notion、Linear、Todoist、Canva、Supabase、Vercel、Neon、Slack、Figma、Google 日历、Google 地图、LINE、企查查等 |

## 接入步骤（三个高频的）

浏览器连接器（QoderWork 的招牌能力）：你在连接器页找「浏览器」点 + →「在 Chrome 应用商店中安装」扩展 → 状态显示「扩展已连接」。它复用你真实的浏览器登录态——后台导数据、填表单都不用你重新登录。

**Microsoft 365**：点「连接微软账户」→ 浏览器弹窗登录 → 确认授权。

钉钉：「市场」选项卡 → 钉钉卡片 →「登录钉钉账号」完成授权。

⚠️ 关键限制：你开关连接器后，需要新建一个对话任务才能生效——别在原来的对话里追问「怎么没反应」。

## MCP：AI 世界的 USB 接口

MCP（Model Context Protocol）是标准化 AI 应用接外部工具的开放协议。你从连接器页右上角「+ 添加」进，两种方式：

1. **粘贴 JSON 配置**导入（推荐）；
2. 手动填写。

两种服务器类型：Streamable HTTP / SSE（远程托管，URL 访问，推荐前者）；**STDIO**（本地命令行启动，需 Node.js / Python）。JSON 结构示例：

```json
{
  "mcpServers": {
    "钉钉文档": {
      "type": "streamable-http",
      "url": "https://mcp-gw.dingtalk.com/mserver/...key=..."
    }
  }
}
```

## 实战：接入钉钉 MCP（四步）

钉钉有自己的 MCP 市场，适合你已用钉钉协作的团队：

1. 打开 [mcp.dingtalk.com](https://mcp.dingtalk.com) 并登录，按关键词搜索（带「平台精选」标签的是官方推荐）；
2. 在 MCP 详情页右侧「使用 MCP」区域，复制 JSON Config；
3. QoderWork 连接器页「+ 添加」→ 粘贴 JSON →「通过 JSON 导入」（钉钉 MCP 一般无需额外 Headers，留空即可）；
4. 验证：服务名称左侧显示绿色圆点即连接成功，然后你在对话里直接试：

```text
帮我找一下名为《2026 Q3 营销计划》的文档
帮我查一下北京的天气（高德地图 MCP）
帮我创建一个明天上午 10 点的日程（钉钉日历 MCP）
```

常用钉钉 MCP：钉钉文档、钉钉日历、钉钉通讯录、钉钉待办、钉钉群聊、高德地图、钉钉 AI 表格。

## 注意事项与故障排查

- 浏览器连接器仅支持 Chromium 内核（Safari / Firefox 暂不支持）；任务执行期间你别手动去碰被托管的标签页；
- macOS 应用首次开启会弹系统权限，你误拒了就去「系统设置 → 隐私与安全性」手动放行；
- 验证码、短信验证、扫码登录需要你人工接管；
- MCP 连不上你按顺序查：JSON / URL 完整性 → 网络 → 额外授权要求 → 删除重加。

**最佳实践**：你直接在 Prompt 里给 URL；连接器与本地文件读写结合着用；复杂流程你先手动跑通，再固化为 Skill 或定时任务。

> MCP 的通用原理与安全边界（它和 API 的关系、「怎么连」与「连了安不安全」），见 WorkBuddy 板块的[看懂 AI 工作系统](/workbuddy/11-ai-work-system/)。

## 新手常见问题

连接器默认是开着的吗？
不是。默认全部关闭，只有你明确授权并配置后，QoderWork 才拿到权限。你没开的，它碰不到。

我开了连接器，为什么对话里没反应？
你开关连接器后，得新建一个对话任务才生效。在原来的对话里追问是没反应的，新开一单就好。

**浏览器连接器支持所有浏览器吗？**
只支持 Chromium 内核，也就是 Chrome、Edge 这类。Safari 和 Firefox 暂时接不上。

MCP 连不上先查什么？
你按顺序查：JSON / URL 完不完整、网络通不通、有没有额外授权要求，最后才删除重加。

**钉钉 MCP 怎么判断连成功了？**
服务名称左侧显示绿色圆点就是连上了。你直接在对话里发一句“找一下某文档”试一下就知道。
