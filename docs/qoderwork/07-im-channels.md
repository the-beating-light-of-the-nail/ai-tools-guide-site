# IM 频道：聊天窗里远程指挥

打开 IM 频道，QoderWork 就接入你常用的聊天工具。核心原则官方一句话说清：**"哪里来的，回哪里去"**——IM 里发的消息，结果回传到同一个聊天窗口；桌面端创建的任务结果留在桌面端，不会推送 IM。

> 官方文档：[docs.qoder.com/zh/qoderwork/im-channels](https://docs.qoder.com/zh/qoderwork/im-channels)

## 七个平台的接入方式

| 平台 | 接入方式 |
| --- | --- |
| **钉钉** | 扫码完成应用注册和绑定（二维码过期可刷新） |
| **飞书 / Lark** | 扫码自动创建应用并配置权限与事件回调 |
| **微信** | 扫码授权，"即开即用" |
| **企业微信** | 快捷绑定（扫码推荐）或手动配置（管理后台建机器人，填 Bot ID 和 Secret） |
| **Slack** | 填 Bot Token（xoxb- 开头）+ App-Level Token（xapp- 开头）→ 测试连接 |
| **WhatsApp** | 手机扫码绑定 |

## 准入策略：开放还是配对

- **开放模式**：所有人和群都能直接对话；
- **配对模式**：经你允许后会话才能用（以会话为单位：私聊允许后该用户可对话；群聊允许后群内所有成员可对话）。

个人使用建议默认配对模式——避免机器人被同事随意调用消耗你的 Credits。

## 桌面端仍是管控中心

所有 IM 会话在桌面端映射为**独立会话窗口，上下文完全隔离**。在桌面端你可以：查看进度、接管操作、调整 MCP/Skill/连接器配置（对所有 IM 会话生效）。

## /bind：把消息路由到指定任务

IM 里可直接下指令管理任务绑定：

```text
/bind          查看可绑定的任务列表
/bind 2        绑定编号为 2 的任务
/unbind        解除绑定
```

绑定后，IM 消息直接转发至该任务，回复实时同步回 IM。前置条件：已开通 IM 频道 + 桌面端存在该任务。消息顺序有保证：连续发送多条时按顺序依次处理，不丢消息、不乱序。

## 支持的消息类型

文本、图片（OCR、背景替换）、文件（PDF/Excel/PPT/Word/CSV/TXT 等）、语音（自动识别）、合并转发消息、图片+文字组合——把合同照片、报销发票直接丢进聊天窗就能处理。

## 五个典型场景

| 场景 | 打法 |
| --- | --- |
| 移动端轻量对话 | 通勤时发"查一下上季度华东区报价单的关键数字" |
| 图片文件处理 | 拍下合同/票据发过去："提取关键条款/金额，汇总成表" |
| 远程派活 | 手机指挥家里电脑执行长任务并回传产物 |
| 定时结果推送 | 定时任务生成日报 → 每早 9 点自动推送到钉钉群（配合[定时任务](/qoderwork/08-automation)） |
| 群聊协作 | @机器人"总结今天群里讨论的要点和待办" |

## 注意事项

- 钉钉群的「归属组织」需与创建机器人的组织一致；
- 从开放模式切回配对模式后，之前未配过的用户需重新配对；
- 「移除配置」会清除全部信息；
- 多个频道可同时开启、完全独立，上下文不互通。
