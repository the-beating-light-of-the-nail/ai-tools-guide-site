# 怎么在微信钉钉里远程指挥 QoderWork？发条消息，结果回原处

你人在外面，手机上想让它干点活，可电脑在公司、桌面端没开——这种时候你就需要 IM 频道。打开它，QoderWork 就接进了你常用的聊天工具。官方一句话说清核心原则：**“哪里来的，回哪里去”**——你在 IM 里发的消息，结果回传到同一个聊天窗口；桌面端创建的任务结果留在桌面端，不会推到 IM。

> 官方文档：[docs.qoder.com/zh/qoderwork/im-channels](https://docs.qoder.com/zh/qoderwork/im-channels)

## 七个平台的接入方式

你按自己用的平台选接入法：

| 平台 | 接入方式 |
| --- | --- |
| **钉钉** | 扫码完成应用注册和绑定（二维码过期可刷新） |
| **飞书 / Lark** | 扫码自动创建应用并配置权限与事件回调 |
| **微信** | 扫码授权，“即开即用” |
| **企业微信** | 快捷绑定（扫码推荐）或手动配置（管理后台建机器人，填 Bot ID 和 Secret） |
| **Slack** | 填 Bot Token（xoxb- 开头）+ App-Level Token（xapp- 开头）→ 测试连接 |
| **WhatsApp** | 手机扫码绑定 |

## 准入策略：开放还是配对

你有两种模式可选：

- **开放模式**：所有人和群都能直接对话；
- **配对模式**：经你允许后会话才能用（以会话为单位：私聊允许后该用户可对话；群聊允许后群内所有成员可对话）。

个人使用建议你默认配对模式——免得机器人被同事随意调用，白白消耗你的 Credits。

## 桌面端仍是管控中心

你在 IM 里聊的每个会话，在桌面端都映射成**独立会话窗口，上下文完全隔离**。在桌面端你能：查看进度、接管操作、调整 MCP / Skill / 连接器配置（对所有 IM 会话生效）。

## /bind：把消息路由到指定任务

你在 IM 里能直接下指令管理任务绑定：

```text
/bind          查看可绑定的任务列表
/bind 2        绑定编号为 2 的任务
/unbind        解除绑定
```

绑定后，IM 消息直接转发到该任务，回复实时同步回 IM。前置条件：你已开通 IM 频道 + 桌面端存在该任务。消息顺序有保证：你连续发多条，它按顺序依次处理，不丢消息、不乱序。

## 支持的消息类型

你往聊天窗里丢什么它都接得住：文本、图片（OCR、背景替换）、文件（PDF / Excel / PPT / Word / CSV / TXT 等）、语音（自动识别）、合并转发消息、图片 + 文字组合——你把合同照片、报销发票直接丢进聊天窗就能处理。

## 五个典型场景

你拿不准能用来干啥，看这五个：

| 场景 | 打法 |
| --- | --- |
| 移动端轻量对话 | 通勤时发“查一下上季度华东区报价单的关键数字” |
| 图片文件处理 | 拍下合同 / 票据发过去：“提取关键条款 / 金额，汇总成表” |
| 远程派活 | 手机指挥家里电脑执行长任务并回传产物 |
| 定时结果推送 | 定时任务生成日报 → 每早 9 点自动推送到钉钉群（配合[定时任务](/qoderwork/08-automation)） |
| 群聊协作 | @机器人“总结今天群里讨论的要点和待办” |

## 注意事项

- 钉钉群的「归属组织」需与创建机器人的组织一致；
- 你从开放模式切回配对模式后，之前没配过的用户需重新配对；
- 「移除配置」会清除全部信息；
- 多个频道可同时开启、完全独立，上下文不互通。

## 新手常见问题

**我在微信里发的消息，结果会跑哪去？**
回到你发消息的那个聊天窗口。官方原则就是“哪里来的，回哪里去”——桌面端的任务结果不会乱推到 IM。

**开放模式和配对模式选哪个？**
你个人用，建议默认配对模式。不然同事随便 @ 机器人，消耗的都是你的 Credits。

**手机拍的票据能直接处理吗？**
能。你拍下报销发票发进聊天窗，它做 OCR 提取金额、商户，汇总成表。

**怎么把 IM 消息绑到某个具体任务？**
你在 IM 里发 `/bind` 看可绑列表，再 `/bind 2` 绑定编号 2 的任务，`/unbind` 解除。绑定后消息直接转发过去。

**多个 IM 频道能同时开吗？**
能，而且完全独立，上下文不互通。你钉钉和微信可以同时接。
