# 进阶：电脑操控、语音输入与应用快照

浏览器自动化之外，QoderWork 还能直接操控你的电脑界面、听你说话、截取当前应用——这是它"AI 智能专员"人设的完整形态。

> 官方文档：[computer-use](https://docs.qoder.com/zh/qoderwork/computer-use) ｜ [voice-input](https://docs.qoder.com/zh/qoderwork/voice-input)

## 电脑操控（Computer Use）

让 QoderWork 完成那些必须在图形界面里操作的任务。四项核心能力：

- **屏幕感知**：操作过程中持续截屏，确认上一步成功再决定下一步；
- **鼠标键盘控制**：点击、双击、拖拽、输入、快捷键，精度到像素级；
- **后台自主执行**：不抢占你的前台焦点，你可以继续干别的；
- **跨应用流程**：根据实时反馈动态调整，而非照搬固定脚本。

**开启**：扩展 → 连接器 →「计算机控制」卡片开启 → 确认弹窗 → 首次授权两项系统权限：**辅助功能**（读取 UI 元素树）和**屏幕录制**。macOS 14+ 起，Windows 自 v0.5.7 支持。

**执行透明**：每个动作走"截屏 → 操作描述 → 实际操作 → 结果确认（再次截屏核对）"四阶段，全程在任务监控里可见。

**执行策略三选**（重要）：

| 策略 | 行为 | 适合 |
| --- | --- | --- |
| 每次询问（默认） | 每次操控先确认 | 不可逆操作（发邮件、提交订单） |
| 自动执行 | 连续执行不询问 | 熟悉的重复流程 |
| 禁用 | 关闭操控 | 只想用其他能力时 |

实测示例（阿里工程师徐靖峰）：

```text
从杭州去三亚旅游，帮我去飞猪携程搜索机票比价，然后帮我制定一个旅行攻略，
生成一个 PDF，并且把日程加到 Mac 自带的日历里。
```

产出：三亚攻略 PDF + 含详细时间安排的日历日程。

**限制与注意**：

- CAPTCHA、短信验证码、人脸识别无法完成，需要你手动介入；
- 速度慢于纯对话（每步都要截屏分析）；界面复杂时精度下降；
- 授予访问权限 = 授予操控权限——AI 可以"以你的身份"驱动其他应用；
- 运行前关闭含密码的窗口；操控期间不要手动抢被控应用；
- 官方建议：**网页任务优先用浏览器自动化，比电脑操控更快更精准**。

## 语音输入：按住 Fn 说话

默认**按住 Fn 键即录音**，无需点图标（备用入口：输入框右侧麦克风图标）。五步：按住 → 说需求（无严格时长限制）→ 自动转录显示在输入框 → 按需编辑 → 发送。

- 依赖操作系统内置语音识别引擎，语种取决于已装语言包；需麦克风权限；
- 使用策略："**语音起草、键盘修正**"；
- v0.6.2 起实时转写；v0.6.6 语音快捷键自动发送；v0.7.1 声纹隔离（嘈杂环境只保留你的声音）；
- 配合玩法：语音 + 附件（附 PDF 后说"总结要点列出待办"）；交付后口头追加（"标题再大一些"）。

## 应用快照（Beta）

从"看到问题"到"开始提问"只要一步：同时按下左右两个 Option 键（可自定义全局快捷键），捕获**最前方应用的截图与可读文本**作为对话上下文——屏幕上有个报错想问 AI？一个快捷键搞定。需 macOS 辅助功能 + 屏幕录制权限（授权一次即可）。

## 快捷键速查（macOS / Windows）

| 功能 | macOS | Windows |
| --- | --- | --- |
| 打开设置 | ⌘, | Ctrl+, |
| 创建新任务 | ⌘N | Ctrl+N |
| 搜索全部任务 | ⌘G | Ctrl+G |
| 当前任务中搜索 | ⌘F | Ctrl+F |
| 发送消息 | ↵ 或 ⌘↵ | Enter |
| 插入换行 | ⇧↵ | Shift+Enter |
| 快速切换任务 | ⌃Tab | Ctrl+Tab |

另有 **QuickPick**：全局快速任务窗口（如 ⌥Space 或双击修饰键触发），不切主窗口随时提交任务。
