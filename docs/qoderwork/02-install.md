# 怎么把 QoderWork 装到电脑上？十分钟装好，登录后不踩隐私坑

你点开官网的下载按钮，结果页面弹出两个东西：一个 .dmg，一个 .exe。你盯着它们犯嘀咕——到底该下哪个？装完会不会乱动我电脑里的文件？这一篇就把你从「下载」一路带到「登录后第一眼该看什么」，一步步走完。

QoderWork 是个跑在你自己电脑上的桌面软件，不是网页。它对系统的要求是这样的：

- macOS 14 及以上（Apple Silicon 和 Intel 两种芯片都支持）；
- **Windows 10 及以上 64 位**；
- 磁盘至少留 500MB；
- 网络要稳，因为模型、技能和连接器都得从云端拉下来。

> 官方安装文档：[macOS](https://docs.qoder.com/zh/qoderwork/installation-macos) ｜ [Windows](https://docs.qoder.com/zh/qoderwork/installation-windows)

## 去哪下载

你有两个入口，看你是国际版还是国内版：

- 国际版：[qoderwork.com](https://qoderwork.com)（官方快速开始文档指定的地址）；
- 国内版：[qoder.com.cn/qoderwork](https://qoder.com.cn/qoderwork)（走阿里云渠道，用 Qoder CN 账号登录）。

## macOS 怎么装

你下载 .dmg 之后，把它拖进「应用程序」文件夹就算装上了。第一次启动如果被系统拦下，别慌：打开「系统设置 → 隐私与安全性」，在最底下点一下「仍然打开」——这个提示只会出现一次。

接着用已有的 Qoder 账号直接登录；没有就邮箱注册，或者用第三方账号登录。进到工作界面，你就装好了。

更新很省心：它默认在后台检查，但要你点确认才会下载并重启，绝不会不问你就替你换掉当前版本。你想手动查，点菜单栏的 QoderWork → 检查更新就行。

卸载也简单，拖进废纸篓即可。你要是想连配置一起清干净，退出登录后在终端执行 `rm -rf ~/.qoderwork`——注意，这会清掉没同步到云端的本地任务历史。

## Windows 怎么装：先选对安装包

你在 Windows 上会看到两个安装包，**功能完全一样**，差别只在安装位置和权限：

| | 系统版 X64(System) | 用户版 X64(User) |
| --- | --- | --- |
| 安装位置 | Program Files | %LOCALAPPDATA% |
| 谁能用 | 所有账户 | 仅当前账户 |
| 管理员权限 | 需要 | **不需要** |

官方原话是这么说的：“拿不准就选用户版：不需要管理员权限，安装最省事。”所以你拿不准，闭眼选用户版。

要是被 SmartScreen 拦了，点「更多信息」→「仍要运行」就能继续。卸载走「设置 → 应用 → 已安装的应用 → 搜 Qoder → 卸载」；想清配置就删 `%USERPROFILE%\.qoderwork`。

## 登录后先做三件事

你刚登录进去，别急着派活，先做三件小事：

1. **切中文**：左下角有语言设置（默认可能是英文，你看不懂就先把它改成中文）；
2. **看积分**：右上角点 Credits 按钮看余额。新用户注册会送积分礼包；国内版还有每天签到来领积分的活动（留意活动有效期，别让它过期）；
3. 理解计费：QoderWork 按 Credits 扣费，和 Qoder 全家桶共用一个余额。模型分标准 / 高级 / 旗舰三档，消耗不一样——日常任务用标准档就够。想细看怎么省钱，翻[意识、成本与安全环境](/qoderwork/adv-memory-cost)。

## 装不上？对照这张表

你遇到报错时，先翻这张表：

| 问题 | 解决 |
| --- | --- |
| macOS 提示“无法验证开发者” | 系统设置 → 隐私与安全性 → 仍要打开 |
| Windows 权限不足 | 换用户版安装包，或以管理员身份运行 |
| 低于 macOS 14 | 无法启动，需先升级系统 |
| 任务执行提示权限不足 | 检查是否授权了对应工作目录 |

## 隐私三条，你得心里有数

你最担心的「它会乱翻我文件吗」，官方给了三条口径：

1. 文件操作在你电脑本地完成，不会上传到云端；但相关文本内容会发给大模型的服务商去处理；
2. 它只能进你明确授权的工作目录，没授权的目录真要访问，会先问你同不同意；
3. 文件内容不会在云端永久存着。

## 新手常见问题

**它会不会偷偷上传我电脑里的文件？**
不会。文件操作在你的电脑本地完成，只有文本内容会发给大模型服务商处理，文件本身不会传到云端永久存储。你没授权的目录它进不去，真要进会先问你。

**我该下哪个 Windows 安装包？**
拿不准就选用户版（User）。它不需要管理员权限，装在你的个人目录里，最省事。系统版需要管理员权限、所有账户都能用，普通人不常用得上。

装完要立刻付费吗？
不用。新用户注册送积分礼包，国内版还有每日签到领积分。你先看积分余额，日常任务用标准档模型，消耗很慢。

**登录后界面是英文的，正常吗？**
正常，默认可能是英文。你点左下角语言设置切到中文就好，这是登录后第一件该做的事。

**我想彻底卸载并清空记录怎么办？**
拖进废纸篓卸载软件；要清配置，退出登录后在终端执行 `rm -rf ~/.qoderwork`（Windows 删 `%USERPROFILE%\.qoderwork`）。注意这会清掉没同步的本地任务历史。
