# 案例：数据分析与调研报告

从"十万行表格"到"带来源的调研 PPT"，这一章讲 QoderWork 的数据类打法。

> 社区素材：CSDN[《阿里 QoderWork 最新实操指南》](https://blog.csdn.net/weixin_43107715/article/details/157585560)（2026-01/02，2.9 万阅读）与官方用户案例库。

## 场景一：十万行 CSV 的四点指令

CSDN 实测：上传 10634 行（另一场景为十万行级）营业数据 CSV，一条指令完成多维分析：

```text
分析这份景区客流数据 CSV：
1. 按"景点类型"（博物馆/古镇水乡）分组；
2. 计算总人数、男女人数、男女比例（保留 1 位小数）；
3. 产出 Excel 汇总 + 按性别分色的柱状图；
4. 保存到"数据报告/202601"目录。
```

任务监控面板自动拆成四步：读取 → 分组计算 → 图表生成 → 保存。实测十万行级数据**手动 2 小时 → 约 30 秒**。

官方同类场景（10634 行营业日报）的四维分析模板：

```text
@营业日报.xlsx 按"销售人员"（客户数/案件种类/总销售额/人均）、
"月份"（趋势/环比）、"客户"（Top 20 贡献度/集中度）三个维度分析，
输出报告（表格+图表），再分别翻译成日文和英文版。
```

价值不在"快"，在**随时切换分析维度**——传统报表换个口径要重做，这里一句话。

## 场景二：带来源的调研 PPT

```text
调研【户外服饰】市场，做一份 12 页 PPT：
- 调研维度：2025 营收与 2026 预测、Top 5 品牌份额（Patagonia、The North Face 等）、
  可持续产品占比、线上渠道增速
- 结构：封面 → 目录 → 市场规模 → 品牌分析 → 趋势洞察 → 总结
- 图表：趋势用折线图、份额用饼图、对比用条形图
- 所有数据标注来源（Statista / IBISWorld），找不到的数据标注"待核实"
```

关键在最后一条：**所有数据标注来源**。AI 生成的市场数字必须可溯源，否则汇报现场一个提问就翻车。生成后可继续对话调整配色和版式。

## 场景三：万行销售数据的报告流水线

官方典型案例的标准四步：

```text
@sales_data.csv：
1. 说明行列数与字段类型
2. 按类别统计销售额与平均单价，列出 Top 10 产品
3. 按月分析趋势
4. 生成交互式 HTML 报告（自动调用 Python 绘图）
```

## 方法论：数据任务的五个习惯

1. **先让 AI 描述数据**（字段含义、脏数据、缺失值），确认理解一致再分析；
2. **指标口径写进指令**（"毛利率 = 毛利/销售额"），别让 AI 猜；
3. **异常值单独列出**，不要混在汇总里被平均掉；
4. **图表类型你来定**（趋势折线、占比饼图、对比柱状），AI 默认选择未必符合汇报语境；
5. **抽查三个数字**与源文件手工核对——AI 算错概率低但存在，汇报翻车成本高。

## 成本提示

数据类任务读大文件消耗 Token 较多。控制成本的打法：先用[标准档模型](/qoderwork/03-first-task)跑通流程，确认中间结果正确后，最后一步再切旗舰档出报告。更多见[意识、成本与安全环境](/qoderwork/adv-memory-cost)。
