# 案例：浏览器自动化——20 分钟整理 230 篇公众号文章

浏览器自动化是 QoderWork 公认的强项。这一章的主案例来自一位网络工程师的完整实测，零代码完成过去要写 Python 爬虫的活。

> 改编自朱嘉盛（公众号"网工手艺"）的实测[《阿里 QoderWork 浏览器自动化初体验：20 分钟搞定 230 余篇公众号文章链接》](https://zhuanlan.zhihu.com/p/2057217208250528785)（2026-07）。

## 任务背景

博主想把公众号 200 多篇历史文章整理成【发布日期】【标题】【链接】三要素表格，再导入腾讯 ima 知识库，变成可对话的"个人知识助理"。

- 手动方案：800 多次复制粘贴；
- 爬虫方案：被公众号后台登录态 + 接口加密劝退；
- QoderWork 方案：接管已登录的浏览器页面，零代码。

## 完整流程（11 步）

1. 下载安装（Windows 选 X64 User 版），登录阿里云账号；
2. 单独建工作目录：`D:\QoderWork\公众号文章整理`；
3. 底部工具栏「管理连接器」→ 找到「浏览器」→ 启用；
4. 安装浏览器扩展（Chrome 走应用商店；Edge 手动装：`edge://extensions` 开发人员模式 → 把安装目录下的 chrome-extension 文件夹拖入）；
5. **关键一步**：人工用浏览器登录 mp.weixin.qq.com，进入"内容管理 → 发表记录"——公众号后台要本人扫码，AI 无法独立完成身份验证，所以让它**接管已登录的页面**；
6. 点浏览器工具栏的 QoderWork 扩展图标，面板显示"当前标签页 已连接"即接管成功；
7. 准备模板 Excel（序号、发布日期、标题、链接四列）放入工作目录；
8. 派活（提示词全文）：

```text
请查看【模板】网工手艺-微信公众号发表记录链接.xlsx 内容。
这些是从 EDGE 浏览器中已连接的页面里，点击"内容管理"→"发表记录"获取的，有分页。
请参考模板文件，把 24 个分页中逐个发布记录，
按【发布日期】【标题】【链接】整理成 excel 文件。
```

9. 任务监控区自动拆解四步：提取 24 页发表记录 → 读取模板结构 → 按模板生成 Excel → 验证文件；
10. 迭代两三轮：第一轮漏了部分文章、第二轮补全、第三轮调格式——"急事得缓做，AI 做事，人校准"；
11. 导入 ima 知识库（每次 10 个链接，200 多篇约 20 轮），个人文章库变成可 AI 问答的知识库。

**结果**：238 条记录（2021-11 至 2026-06 全部文章），标题/日期/链接一个不落，链接自动设为可点击超链接，按时间倒序排列。全程**不到 20 分钟**（手动需要半天）。

## 技术亮点：AI 自己找到了 API

QoderWork 没有笨拙地逐页点"下一页"，而是**发现发表记录页内嵌了结构化数据变量 `publish_page`，直接通过页面接口一次性拉取全部记录**——作者类比"老练的脚本小子先 inspect 元素找 API 再批量拉数据"。这是 Agent 与"录屏回放式 RPA"的本质区别：它看得到页面结构，会挑效率最高的路径。

## 同款打法：电商五店铺日报（官方用户案例）

跨境电商运营每天逐个登录 5 个后台导数据，"早课"1 小时还常漏店：

```text
依次登录美/欧/日三个站点后台，进入业务报告页导出昨日数据，
合并为一个 Excel：各站销售额/订单量/退货率、Top 10 热销 SKU、
环比变化下降项标红，最后附 200 字内运营摘要。
```

跑通后**封装为 Skill**，以后每天一句"跑一下今天的店铺日报"。效果：**1 小时 → 10 分钟**；数据积累后追加 30 天趋势分析。

## 可迁移场景

批量下载网页资料、自动填表申报、定时抓取行情、批量截图存档、跨网站比价汇总——凡是你会在浏览器里重复做的，都可以试着派给它，全程零代码。

## 三条安全提醒

1. 采集过程会读取浏览器登录凭证——**勿在公共设备操作**；
2. 导出数据做好账号信息脱敏；
3. AI 爬取的数据**务必人工抽检**（标题、日期、链接各抽几条）。
