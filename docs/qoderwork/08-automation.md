# QoderWork 定时任务怎么设？到点自己干，六种周期一次讲清

你定了每天早上看运营数据的习惯，结果一忙就忘。或者你希望每周自动出份竞品追踪，省得周末补。QoderWork 的定时任务就是干这个的：你写好一次，它到点自己跑，不用你守着。官方一句话说透——它让 QoderWork 从「你问它才动」变成「到点自己干」。

> 官方文档：[docs.qoder.com/zh/qoderwork/scheduled-tasks](https://docs.qoder.com/zh/qoderwork/scheduled-tasks)

## 它是怎么跑的

到了预定时间，它自动新建一个对话任务，按你写好的 Prompt 执行，结果存在那个对话里。定时任务能调 MCP 工具、用连接器（浏览器自动化、macOS 原生应用）、跑技能、读写本地文件——凡是手动任务能用的能力，定时任务都能用。

## 两种创建方式

方式一：对话里直接说（推荐）

你不用懂 cron，直接在对话里说时间 + 任务，它替你推断频率、时间、内容。这些说法它都认：

```text
每隔 3 小时……
每个月最后一个工作日……
每周二和周四下午 2 点……
```

**方式二：面板手动建**

你点左侧导航「定时任务」→ 右上角「+ 新建定时任务」→ 填好 → 保存即生效。

## 计划时间六种

| 频率 | 适合 |
| --- | --- |
| 不重复（指定日期时间执行一次） | 会议准备、截止检查、定时发送 |
| 间隔（每 N 小时 / 天） | 价格监控、进度轮询 |
| 每小时 | 监控告警、服务巡检 |
| 每天 | 每日早报、数据报表 |
| 每周 | 周报草稿、竞品追踪 |
| 每月 | 月度分析、账单汇总 |

其他配置：任务名称、任务 Prompt、工作目录（可选，建议指定以获得固定上下文）、附件（可选）。

## 管理与调试

- 卡片左上角开关启停；
- 「...」菜单：立即运行（调试或补执行）/ 删除 / 编辑；
- 执行记录状态：成功 / 执行中 / 失败。

## 必须知道的限制

1. 由本地桌面客户端调度：执行时间以你电脑系统时区为准；电脑睡眠或关机无法触发——重要任务你开「保持系统唤醒」（定时任务页右上角有这开关）；
2. 错过的任务不会自动补执行，你在执行记录里点「立即运行」手动补；
3. 每次执行创建独立对话，与手动对话一样消耗 Credits；
4. 浏览器自动化任务前置：连接器已开浏览器且 Chrome 保持运行；目标网站登录过期会导致失败。

## 写 Prompt 的清单

你写无人值守的提示词，越细越稳：

- [ ] 数据来源写明确（哪个文件 / 哪个网页 / 哪个系统）
- [ ] 输出格式与存储位置写明确（「输出 Markdown 存到 reports/ 目录」）
- [ ] 判断标准写明确（「环比跌幅超过 20% 标红」）
- [ ] 异常处理写明确（「数据为空时输出说明，不要硬凑」）
- [ ] 先手动跑通一次，调好 Prompt 再固化

一个完整模板：

```text
任务名称：每日运营早报
时间：每个工作日早上 9:00
Prompt：读取 data/ 目录下昨日的运营数据文件，生成早报：
1. 核心指标汇总（销售额、订单量、退款率），附环比
2. 环比波动超过 ±20% 的指标标黄并给出可能原因（数据里找不到原因就标注待核实）
3. 输出 Markdown 存到 reports/{日期}-早报.md，同时推送到钉钉「运营群」
```

推送 IM 需要[IM 频道](/qoderwork/07-im-channels)已配置——定时任务 + IM 是 QoderWork 自动化的黄金组合。

进阶玩法（把「跑一下」变成一句话触发）见[电商日报案例](/qoderwork/case-browser)与[对话式创建技能](/qoderwork/adv-skill-create)。

## 常见问题

**电脑关机了，定时任务还会跑吗？**
不会。它由本地客户端调度，电脑睡眠或关机就触发不了。重要任务记得开「保持系统唤醒」。

**错过的时间点会补跑吗？**
不会自动补。你在执行记录里点「立即运行」手动补一次就行。

**定时任务也扣 Credits 吗？**
扣，和手动对话一样消耗。所以先用标准档跑通流程，再固化成定时任务更划算。

**完全不懂 cron 能设吗？**
能。你直接在对话里说「每周二周四下午 2 点……」，它替你推断，不用写表达式。
