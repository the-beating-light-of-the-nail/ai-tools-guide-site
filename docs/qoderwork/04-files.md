# 工作文件夹：让 AI 直接读写你的文件

工作文件夹是 QoderWork 与"聊天式 AI"最大的分水岭：授权一个本地目录后，AI **直接读写你电脑上的文件**，无需手动上传下载。官方原话："合理组织文件夹并选定为工作目录，是让 QoderWork 发挥最大价值的关键操作。"

## 设置方法

1. 点 + 新建任务；
2. 输入框下方点「在文件夹中工作」（部分版本文案为「选择工作目录」）；
3. 在系统文件选择器里选中目标文件夹；
4. 直接输入需求，AI 自动读取文件夹内容。

**硬限制：一个任务只能关联一个工作文件夹**；要处理不同文件夹，分别建任务。

## 什么时候用文件夹

| 场景 | 建议 |
| --- | --- |
| 处理单个文件 | 直接拖拽上传到对话 |
| 多个相关文件 | 工作文件夹 |
| 文件会持续增加 | 工作文件夹（AI 能立刻感知新文件） |
| 产物需要存到指定位置 | 工作文件夹 |

## 文件安全三条规则

1. **只访问你明确授权的目录**——其他位置确需访问时，会先征求你的同意；
2. **不会永久删除文件**——删除操作只移入系统回收站；
3. **文件内容不会永久存储**——处理时发送给 AI 模型，但不在云端永久保存。

建议：只授权常用工作文件夹，避免把整个用户目录设为工作目录。

## 支持的格式

| | 格式 |
| --- | --- |
| 读取 | PDF、Word(.docx)、Markdown、纯文本、RTF、Excel(.xlsx/.xls)、CSV、TSV、PNG/JPG/SVG/GIF（支持 OCR）、全部代码源文件、PowerPoint(.pptx)、JSON/YAML/XML/SQL |
| 输出 | Word、PDF、Markdown、HTML、Excel、CSV、PPTX、PNG、SVG、交互式 HTML 报告、任意语言代码、JSON/XML |

几乎覆盖办公全场景；唯一常见缺口是老式 .doc / .ppt 二进制格式，遇到先转成 docx/pptx。

## 持续使用：一次设置，长期复用

工作文件夹的真正威力在"持续积累"。官方比喻：**"文件夹是「原料仓」，提示词是「施工图」。"**

典型循环：

```text
第一周：把 12 份部门年度汇报放进「2024年度总结」文件夹，选定工作目录，
        让 AI 生成年度总结 → 6 分钟拿到成品
第二周：新增 3 份数据，打开 QoderWork（工作目录没变，无需重选），
        一句"加入了新的数据，请更新报告" → 5 分钟内更新完成
```

组织文件夹的四个技巧：

1. **命名带日期或序号**：`2024-03-月考成绩.xlsx`，AI 排序不乱；
2. **一事一文件夹**：不要把生活和三个项目混在一个目录；
3. **格式统一**：相同模板、相同列名的文件能自动对齐合并；
4. **善用子文件夹**：支持递归读取，按 `原始材料/输出/参考` 分层。
