# QoderWork 是什么

**QoderWork** 是阿里系（Qoder 团队 / 国内为阿里云计算）推出的桌面端智能工作助手，官方口号「**你说需求，它交付结果**」，也自称"AI 智能专员"。它把 Qoder 的 Agent 能力从代码领域扩展到日常工作场景：文件整理、数据处理、文档生成、浏览器自动化、定时任务、IM 远程指挥——传统 AI 是"你问它答，动手还得靠自己"，QoderWork 是直接把活干完，产物落到你电脑上。

> 官方文档：[docs.qoder.com/zh/qoderwork](https://docs.qoder.com/zh/qoderwork/introduction) ｜ 国内版：[qoder.com.cn/qoderwork](https://qoder.com.cn/qoderwork)（QoderWork CN，阿里云渠道）

## 八大能力

| 能力 | 一句话说明 |
| --- | --- |
| 文件处理 | 对话式读取、编写、整理文档、表格、演示稿和 PDF |
| 浏览器自动化 | 自动导航网页、填表单、提取数据，无需写脚本 |
| 桌面控制 | 直接操控桌面应用的点击、输入、滚动 |
| 定时任务 | 周期性或一次性自动执行（日报、提醒、监控） |
| IM 频道 | 连接钉钉、飞书、微信等，聊天窗里远程指挥 |
| 技能与扩展 | 技能市场、专家套件、MCP 服务器、第三方连接器 |
| 语音输入 | 按住 Fn 说话，AI 转录并执行 |
| 意识（记忆） | 跨会话记忆与协作风格个性化，越用越懂你 |

## 三个核心概念

官方快速开始文档强调的三个概念，第一次用就会遇到：

- **澄清**：任务开始前的简短确认，用来对齐模糊的需求（需求清晰则自动跳过）——别嫌烦，澄清暴露的问题不处理，最后都会变成返工；
- **任务监控**：工作区右侧的执行面板，实时展示计划、工具调用、用到的技能和被操作的文件——官方强调"一切都是透明的"；
- **产物**：任务输出的真实本地文件（表格、报告、幻灯片……），直接保存在你电脑上，可随时打开、编辑、转移。

## 和 Qoder（编程平台）的关系

Qoder 家族包括 Qoder IDE、JetBrains 插件、CLI、Cloud Agents、**QoderWork** 等多条产品线。QoderWork 是家族中面向非程序员的"办公版"分支，是**独立的桌面应用**——不存在"在其他产品里切换到 QoderWork 标签"的概念。

账号与权益互通：QoderWork 使用 Qoder 统一账号登录，**Credits 余额和会员权益在所有 Qoder 产品间共享**。注意：历史任务保存在本地设备，**不跨设备同步**。

## 和本站其他工具的关系

- **WorkBuddy**（腾讯）：办公 AI 智能体工作台，办公三件套技能生态成熟
- **TraeWork**（字节）：AI 原生工作台，三端协同 + 飞书生态深
- **QoderWork**（阿里）：桌面智能工作助手，浏览器自动化与 IM 频道是强项

三家定位相近、各有侧重。QoderWork 的差异化：本地优先（文件操作在本地完成）、浏览器自动化"像你一样操作网页"、7 个 IM 平台远程指挥。
