# QoderWork 指令模板怎么套用？16 个拿来即用的例子，改两处就能发

你对着输入框发过呆吗？知道要它干活，却不知道这句话该怎么写——写短了它理解偏，写长了还不如自己动手。这一页给你 16 个能直接复制的指令模板，你只要把 `【】` 和 `{}` 里的占位符换成自己的内容，就能发出去。

## 模板怎么用

别整段照抄。你拿到模板先做三件事：

1. 换占位符：`【】` 和 `{}` 里的内容换成你的真实目录、文件名、字段。留着不换，它只能猜。
2. 补约束：模板给的是骨架，你要是关心输出格式、要不要先确认、数据不能瞎编，就在末尾加一句。
3. 先跑小样：涉及移动、重命名、删除、提交的指令，你先让它出方案，确认后再执行。

提示词的三要素（目标 / 格式 / 约束）写在[第一个任务](/qoderwork/03-first-task)，你觉得模板不够用时去那儿看原理。

## 怎么挑

你不确定用哪个模板时，先判断这一步是「读文件」「算数据」「改文档」「定时跑」还是「操作浏览器」——对着下面的分类找就行。你是新手，建议从文件整理类开始：这一类不会动到外部系统，你就算指令写得糙，损失也只是多花几分钟重跑一遍。

## 文件整理类

### Downloads 大扫除

```text
扫描【目录】，找出所有重复的文件，保留最新版本，生成清单等我确认后再执行。
```

### 分类归档

```text
整理【目录】：图片移入 assets/images/、文档(.md/.txt/.pdf)移入 docs/、
配置(.json/.yaml/.toml)移入 config/、代码按语言归入 src/。
执行前先给出方案；最后生成整理报告（数量统计 + 目录树）。
```

### 照片归档

```text
整理【照片目录】：读取 EXIF 拍摄时间，按年月建文件夹（2026-01/），
移动并重命名为"日期_序号.jpg"，生成 CSV 清单。先给方案，确认后再动文件。
```

### 收据/票据归档

```text
识别【文件夹】中每张收据照片的日期、金额、商户、类型（餐饮/交通/住宿/其他）：
按"日期-类型-金额-商户.jpg"重命名，按类型归档，
生成 Excel 报销汇总表。先输出识别预览，我确认后再重命名。
```

## 数据分析类

### Excel 多维分析

```text
@【数据.xlsx】分析：
1. 说明字段含义，检查缺失值和异常值
2. 按【维度】统计【指标】并排名
3. 按月/周出趋势
4. 生成 Excel 汇总 + 图表
要求：数字与源文件一致，无法确认的标注待核实。
```

### 十万行级 CSV

```text
分析【客流/销售数据.csv】：
按【分组字段】分组；计算总量、占比（保留 1 位小数）；
产出 Excel + 分色柱状图；保存到【输出目录】。
```

### 调研 PPT（带来源）

```text
调研【主题】，做一份【N】页 PPT：覆盖【维度清单】；
结构：【封面→…→总结】；趋势用折线图、份额用饼图；
所有数据标注来源，找不到的标注"待核实"。
```

## 文档处理类

### 简历批量筛选

```text
遍历【文件夹】全部简历，按 JD 筛选：【要求 1/2/3】；
合格者归档至"合格简历-【岗位】"文件夹；
输出 Excel：姓名、联系方式、【关键项】、匹配度（1-10 分）、推荐理由。
```

### 批量格式统一

```text
将【文件夹】中的 10 份 Word 文档统一调整为：标题宋体加粗 18 号、
正文宋体 12 号、1.5 倍行距、首行缩进 2 字符。先预览一份给我确认。
```

### 文档对比

```text
比较【文件A】与【文件B】：输出新增、删除、修改三类差异，
重点标记金额、日期、责任主体、审批条件，生成待确认问题清单。
```

## 自动化类


### 自然语言定时

```text
每隔 3 小时检查【网页/文件】，有更新就摘要通知我。
```


## 流程类

### 让 AI 先出方案

```text
【任务描述】。请先给出你的计划（分几步、动哪些文件、怎么命名），
我确认后再执行。
```

### 封装技能

```text
/create-skill 把刚才的【流程名】封装为技能：
触发语：【一句话】；步骤：【编号步骤】；
输出：【格式与位置】；边界：【不做什么】。
```

## 常见问题

**为什么我照抄模板，出来的结果还是不对？**

多半是占位符没换干净，或者你没说清输出格式。你把 `【】` 里的内容换成具体路径和文件名，再补一句「输出成 Excel」「先给方案别动文件」，准确率会高很多。

**模板里的中文括号要一起删掉吗？**

要。`【】` 和 `{}` 只是这一页的占位标记，你换成真实内容时得连括号一起去掉，别留着。

**涉及删除和提交的指令，怎么避免误操作？**

你在末尾加一句「先输出方案，我确认后再执行」。上面「让 AI 先出方案」和「操作类任务（安全版）」两个模板就是干这个的，你直接拿去用。

**常用模板能存下来下次直接调吗？**

能，而且更省事。你用「封装技能」那个模板，把跑通的流程固化成技能，以后一句话就能触发，不用每次都翻这一页。
