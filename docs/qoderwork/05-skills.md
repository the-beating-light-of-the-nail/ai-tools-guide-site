# 技能与专家套件

技能（Skill）是"一份提前写好的工作指南"；专家套件（Expert Kit）是把一个岗位的专业知识、工作流和判断标准整体打包。两者是 QoderWork 生态里"从会用到专业"的两级台阶。

> 官方文档：[skills](https://docs.qoder.com/zh/qoderwork/skills) ｜ [expert-kits](https://docs.qoder.com/zh/qoderwork/expert-kits)

## 技能：AI 的"专业能力说明书"

每个 Skill 本质是一个包含 SKILL.md 文件的文件夹，存于 `~/.qoderwork/skills/`。SKILL.md 用自然语言写，无需代码，写清"面对某类任务时遵循的步骤、输出格式和注意细节"。

四大价值：告别重复解释、保证输出一致性、个人经验变成可复用资产、让 AI 从"通才"变"专才"。

**获取的四个渠道**：

1. **对话中搜索安装**：直接说"帮我找一个做 XX 的技能"，内置 find-skills 检索推荐，一键安装；
2. **Skill 广场浏览**：扩展 → 技能，市场里挑；
3. **从开源社区获取**：发一个 GitHub 仓库链接，自动克隆、放置、加载；
4. **手动上传**：技能页点「安装技能」上传 SKILL.md 文件。

**使用的四种方式**：自动触发（描述需求自动匹配）、`/` 快捷调用、`@` 添加上下文（注意：@ 是补充上下文，不是调用）、对话中点名（"使用 xxx 技能生成组图"）。

**内置技能 9 个**：docx / pdf / pptx / xlsx（提到对应文件类型自动触发）、find-skills、create-skill、plugin-creator、install-skill-dependency、vm-error-recovery。

**分享**：技能页点个人技能旁的分享图标 → 复制链接 → 对方一键安装。注意：**分享链接有效期约 24 小时**，且只能分享自己创建的技能。

## 专家套件：把"懂行"打包给团队

官方定位："让 AI 变成一个真正懂行的专业人士。"套件 = Skill + 数据连接 + 工作流 + 输出标准的整合包——解决的不是"AI 怎么做某件事"，而是"**如何让团队统一使用同一套 AI 工作方案**"，实现一人配置、全员复用。

**内置 12 个套件**：产品管理、产品设计、企业法务、企业财税、合同管理、咨询交付、市场营销、投研分析、投行业务、股权投资、财富管理、科技服务助手。

**用法**：

1. 扩展 → 专家套件，点卡片右侧 + 安装（技能自动加载）；
2. 新建任务，输入 `/` 选套件名（如 `/审查合同`），描述需求。

**安装第三方套件**：右上角「+ 添加」→「上传套件」，上传 .zip 包（须含 `.qoder-plugin/plugin.json`，plugin.json 必含 name 字段）。

## 一个真实案例：律师的 20 年经验资产化

官方实战页记录了一位律所合伙人的用法（著作权侵权案应诉）：

- 边办案边创建 Skill：证据整理（分类规则+编号体系）、类案检索（首轮结果不理想后**收窄案由范围**）、抗辩体系构建（第三稿调整论证层次）、答辩状起草；
- 结果：**四天独立完成全套应诉文书**——答辩状、质证意见、证据清单、代理词、356 页证据册；
- 结案后把十个 Skill 整合为法务专家套件分发给团队，新人一键生成、合伙人审核。

打造套件的四步：①用 Skill 跑通一个工作流（起点：选你最近一周重复做过两次以上的工作）→ ②补 Skill 覆盖完整流程 → ③整合为专家套件 → ④分享给团队。

三个常见误区：套件输出是高质量**初稿**不是终稿；不能一次封装永久使用（要迭代）；套件不是越大越好（聚焦"合同审查"而非"所有法务工作"）。

## 自己做技能：/create-skill

对话中输入 `/create-skill`，描述"触发语 + 步骤 + 输出格式"，QoderWork 帮你生成 SKILL.md。详细打法见进阶篇[对话式创建技能](/qoderwork/adv-skill-create)。

> 想把整本书蒸馏成技能集？思路参考 WorkBuddy 板块的[打造 Skill：知识蒸馏](/workbuddy/adv-build-skill/)——SKILL.md 规范两边相通。
