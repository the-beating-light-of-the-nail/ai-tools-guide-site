# 进阶：意识、成本与安全工作环境

三个"越用越顺"的机制：让 AI 记住你（意识）、让 Credits 花得值（成本）、让任务跑在隔离区（安全工作环境）。

> 官方文档：[memory](https://docs.qoder.com/zh/qoderwork/memory) ｜ [settings](https://docs.qoder.com/zh/qoderwork/settings)

## 意识：跨会话记忆与个性化

意识（Awareness，v0.6.0 上线）是 QoderWork 的记忆与个性化系统：持续记录你的偏好和工作习惯，让新对话自带完整上下文。三层机制：记忆、反思、技能自进化。

入口：左侧导航「意识」图标。两个主开关：

- **意识模式**：总开关；
- **自动记忆**：自动维护用户画像与长短期记忆，定期触发记忆反思。

进化动态面板：记忆趋势图（按天/周/月）、今日统计（审查次数、新增记忆、技能更新数、反思次数）、近期动态。

**意识信息文件对照表**（想深度定制就看这里）：

| 条目 | 文件/位置 |
| --- | --- |
| 存储位置 | `~/qoderwork/awareness/main` |
| 协作风格 | SOUL.md（可选预设或自定义） |
| 工作手册 | AGENTS.md（可直接编辑） |
| 用户画像 | USER.md（自动维护，不建议手改） |
| 长期记忆 | MEMORY.md（自动维护） |
| 短期记忆 | memory/ 目录（按天对话摘要） |
| 备份与恢复 | 意识目录可导出/导入（多设备同步靠手动） |

三个**不可恢复**的危险操作：重置协作风格、重置工作手册、清空记忆——动手前三思。

实用建议：发现 AI 犯同一个错 → 立刻写进规则/工作手册，不要每次靠嘴纠正；记忆不是越多越好，定期清理过时内容——权威性来自"每条都算数"。

## Credits 成本控制

QoderWork 按 Credits 计费，与 Qoder 全家桶共享余额（国际版：Pro $20/月=2000 Credits、Pro+ $60、Ultra $200；资源包 $20/1500；国内版有签到、师生认证等加赠活动）。模型档位消耗差异大（标准/高级/旗舰逐级升高），省钱打法：

1. **分步用模型**：标准档跑通 → 旗舰档出关键结论 → 标准档格式化（切换即时生效不丢上下文）；
2. **先跑通再固化**：完整执行一次工作流了解成本，再配定时任务；
3. **任务单一主题**：无关内容新开任务，避免重放旧上下文；
4. **输出写明字数/格式**：减少返工轮次（社区实测：明确"300 字"比开放式输出省一半）；
5. **技能复用**：成熟的 Skill 一次配置反复使用，比每次重新描述省 Token。

## 安全工作环境（本地 VM 沙盒）

设置 → 高级 → 安全工作环境：在你的电脑上单独开辟一块**独立空间**跑任务，文件数据不离开设备。清理工作环境文件只释放磁盘，不删对话和产物。适合：处理敏感材料、测试来源不明的技能、跑大批量文件操作。

配合三条底线使用：

1. 只授权必要的[工作目录](/qoderwork/04-files)；
2. 第三方技能先在隔离目录测试（它会要什么权限，先看清楚）；
3. 数据共享开关默认保持关闭（设置里可选"数据不用于产品改进"的隐私模式；企业账号该设置仅管理员可改）。

## 系统设置速查

- **通用**：语言、主题、界面风格、字体字号、开机自启动、**保持系统唤醒**（防任务中断，建议常开）、桌面/声音通知、网络代理；
- **系统权限七项**：完全磁盘访问、录屏录音、辅助功能、麦克风、自动化、通知、位置服务——用到哪项开哪项；
- **快捷键与 QuickPick**：见[电脑操控与语音输入](/qoderwork/adv-computer-use)；
- **实验特性**：生成式 UI、弹出独立窗口、对话列表筛选，尝鲜可开。
