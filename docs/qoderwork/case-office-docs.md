# QoderWork 怎么批量处理文档和多媒体？简历、单证、票据、字幕一次跑完

你每天被这些活淹没：115 份简历要筛、几十页英文单证要翻、一相机 Roll 的收据要归档、会议录音要出字幕。它们有个共同点——规则明确、量大、容易错。这类活恰恰是 QoderWork 的主场：你把规则写清，它一把跑完。

> 素材来源：CSDN 实操指南、官方用户案例库、社区实测（文内注明），你照着抄就能落地。

## 场景一：115 份简历批量筛选

你扔给它一个装了 115 份 Word 简历的文件夹，附上 JD 要求，它自己筛：

```text
遍历【简历文件夹】中全部 115 份 Word 简历，按以下 JD 要求筛选：
- 英语六级或雅思 6.0 以上
- 有小红书或 Instagram 运营经验
- 熟悉海外社媒算法
合格者归档至"合格简历-海外运营"文件夹；
输出 Excel：姓名、联系方式、英语水平、运营经验、匹配度（1-10 分）、推荐理由。
```

实测约 1.5 分钟完成，示例输出：「匹配度 8 分，雅思 6.5，有 3 个月 Instagram 账号运营经验」。你注意一点：匹配度评分只是参考，终面前的复核省不掉。

## 场景二：外贸 Tech Pack 结构化

外贸跟单员每份订单 20 多页英文 PDF、30+ 测量点（POM）、允差表、7 个尺码的分数数值（1/2"、3/4"）。手工 2-3 小时 / 份，曾因误读半英寸致整批返工、损失二十多万。你按订单建文件夹「订单-2024SS-客户 ABC」，设为工作目录，再下指令：

```text
逐份提取 Tech Pack 中的测量点并翻译中文：
列出结构：测量部位 | 英文名 | 中文名 | 允差(+/-)；
每行为各尺码数值；分数数值保持原始精度（1/2"、3/4"）。
请特别注意分数单位的准确性，这直接关系到生产品质。
```

效果：2-3 小时 / 份 → 10 分钟处理 3 份，准确率 100%。你之后复用只要一句：「新到了两个 Style 的 Tech Pack，请按之前的格式处理。」——这正是[工作文件夹](/qoderwork/04-files)持续复用的威力。

## 场景三：报销收据照片归档

你拍了一堆收据，文件名全是随机字符串。四步指令就理清：

```text
识别【收据文件夹】中每张照片的消费日期、金额、商户、类型（餐饮/交通/住宿/其他）：
1. 按"日期-类型-金额-商户名.jpg"重命名（如 20260301-餐饮-128元-某餐厅.jpg）
2. 按类型建子文件夹归档
3. 生成 Excel 报销汇总表（日期/类型/金额/商户/备注）
先输出识别结果预览，我确认后再重命名。
```

OCR 识别 + 分类 + 重命名一步到位，重命名前还会拿给你确认。

## 场景四：多媒体处理三连

你遇到音频、视频这类多媒体活，也能一把过。

音频转双语字幕（CSDN）：你传一段 MP3——

```text
生成时间轴精度 1 秒的 SRT 字幕，同时输出"时间 + 中文 + 英文"三栏 Word，
存到"会议记录"文件夹。
```

SRT 能直接拖进剪映。

视频批量转 GIF（沉默王二实测）：

你要把长视频压成 GIF，这句就够。

```text
把文件夹里所有视频转成 GIF，控制在 10M 以内，速度调成 2 倍速，
生成后备注清楚视频时长、生成时间和适配场景。
```

全部压在 10M 内且带备注，替掉你「录屏 → 剪辑 → 导出 → 反复调帧率」的半小时手工。

PPT 转视频（徐靖峰实测）：

```text
@【演示文稿.pptx】打开并浏览每一页，制作成一个短视频，时长尽量短一点。
```

它自动完成翻页录制、字幕与配音合成。

## 打法总结

你把这些场景归纳一下，打法就清楚了。

| 场景共性 | 设计要点 |
| --- | --- |
| 规则明确（字段 / 格式固定） | 把字段清单和格式写进指令 |
| 量大 | 文件夹批量 + 模板文件 |
| 易错（单位 / 精度 / 命名） | 关键约束单独强调（「分数单位直接关系品质」） |
| 需复用 | 跑通后固化为 Skill，一句话触发 |

你交付之前，自己完整过一遍——抽三份核对字段、打开 GIF 看能否播放、检查 Excel 公式。这一条通用验收谁都替不了。

## 常见问题

**匹配度评分能直接当录用依据吗？**
不能。它只是初筛参考，帮你从 115 份里圈出值得看的人，终面判断得你自己做。

**外贸单证里的分数单位会不会被算错？**
你把「分数精度直接关系生产品质」写进指令，它会原样保留 1/2"、3/4"，不会擅自换算。

**收据重命名前我能先看一眼吗？**
能。指令里加一句「先输出预览，我确认后再重命名」，它就不会贸然动文件。

**这类流程跑熟了怎么省事？**
固化成一个 Skill，下次一句话触发，不用每次重写那段长指令。
