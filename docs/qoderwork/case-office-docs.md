# 案例：批量文档处理与多媒体

简历筛选、外贸单证、票据归档、音视频处理——这些"规则明确、量大、易错"的文档活，是 AI 办公的主场。

> 素材来源：CSDN 实操指南、官方用户案例库、社区实测（文内注明）。

## 场景一：115 份简历批量筛选（CSDN 实测）

```text
遍历【简历文件夹】中全部 115 份 Word 简历，按以下 JD 要求筛选：
- 英语六级或雅思 6.0 以上
- 有小红书或 Instagram 运营经验
- 熟悉海外社媒算法
合格者归档至"合格简历-海外运营"文件夹；
输出 Excel：姓名、联系方式、英语水平、运营经验、匹配度（1-10 分）、推荐理由。
```

实测约 **1.5 分钟**完成，示例输出："匹配度 8 分，雅思 6.5，有 3 个月 Instagram 账号运营经验"。注意：匹配度评分是参考，终面前的复核不能省。

## 场景二：外贸 Tech Pack 结构化（官方用户案例）

外贸服装跟单员，每份订单 20 多页英文 PDF、30+ 测量点（POM）、允差表、7 个尺码的分数数值（1/2"、3/4"）。手工 2-3 小时/份，曾因误读半英寸致整批返工损失二十多万元。做法：按订单建文件夹「订单-2024SS-客户ABC」，设为工作目录：

```text
逐份提取 Tech Pack 中的测量点并翻译中文：
列出结构：测量部位 | 英文名 | 中文名 | 允差(+/-)；
每行为各尺码数值；分数数值保持原始精度（1/2"、3/4"）。
请特别注意分数单位的准确性，这直接关系到生产品质。
```

效果：**2-3 小时/份 → 10 分钟处理 3 份，准确率 100%**。复用只要一句："新到了两个 Style 的 Tech Pack，请按之前的格式处理。"——这正是[工作文件夹](/qoderwork/04-files)持续复用的威力。

## 场景三：报销收据照片归档（官方用户案例）

痛点：收据照片文件名全是随机字符串。四步指令：

```text
识别【收据文件夹】中每张照片的消费日期、金额、商户、类型（餐饮/交通/住宿/其他）：
1. 按"日期-类型-金额-商户名.jpg"重命名（如 20260301-餐饮-128元-某餐厅.jpg）
2. 按类型建子文件夹归档
3. 生成 Excel 报销汇总表（日期/类型/金额/商户/备注）
先输出识别结果预览，我确认后再重命名。
```

OCR 识别 + 分类 + 重命名一步到位。

## 场景四：多媒体处理三连

**音频转双语字幕**（CSDN）：上传 MP3 →

```text
生成时间轴精度 1 秒的 SRT 字幕，同时输出"时间 + 中文 + 英文"三栏 Word，
存到"会议记录"文件夹。
```

SRT 可直接导入剪映。

**视频批量转 GIF**（沉默王二实测）：

```text
把文件夹里所有视频转成 GIF，控制在 10M 以内，速度调成 2 倍速，
生成后备注清楚视频时长、生成时间和适配场景。
```

全部符合 10M 限制且带备注——替代"录屏→剪辑→导出→反复调帧率"的半小时手工流程。

**PPT 转视频**（徐靖峰实测）：

```text
@【演示文稿.pptx】打开并浏览每一页，制作成一个短视频，时长尽量短一点。
```

自动完成翻页录制、字幕与配音合成。

## 打法总结

| 场景共性 | 设计要点 |
| --- | --- |
| 规则明确（字段/格式固定） | 把字段清单和格式写进指令 |
| 量大 | 文件夹批量 + 模板文件 |
| 易错（单位/精度/命名） | 关键约束单独强调（"分数单位直接关系品质"） |
| 需复用 | 跑通后固化为 Skill，一句话触发 |

最后一条通用验收：**交付物拿给别人之前，自己完整过一遍**——抽三份核对字段、打开 GIF 看能否播放、检查 Excel 公式。
